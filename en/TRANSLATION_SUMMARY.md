## Translation Standards Established

### Terminology Decisions

| Chinese | English | Notes |
|---------|---------|-------|
| 编年 | Annals | Chronological records |
| 纪传 | Biographies | Company/model histories |
| 志 | Treatises | Thematic articles |
| 论 | Commentary | Analysis pieces |
| 表 | Tables | Reference tables |
| 本纪 | Companies | Company histories |
| 世家 | Families | Model family histories |
| 列传 | Models | Individual model histories |
| 评曰 | Commentary | Analysis sections |

### Style Guidelines

1. **Headers**: Translated to English, sentence case
2. **Technical Terms**: Keep in English (Transformer, BERT, GPT, RLHF)
3. **Chinese Names**: Preserve with English translations in parentheses
4. **Cross-references**: Update to English versions
5. **Footnotes**: Preserve original URLs
6. **Tables**: Translate headers, keep technical data intact
