# November 2025

## Grok 4.1 Fast: xAI's Lightweight Reasoning Model

**2025-11-19** — xAI released **Grok 4.1 Fast**, positioned as a fast-response variant of the Grok series. [^1]

Grok 4.1 Fast was another iteration following Grok 3 (February 2025). Judging by the version naming, xAI pursued an aggressive release cadence from Grok 3 to 4.x — iterating all the way to 4.1 Fast within 2025. However, the Grok series attracted far less attention in the Chinese developer community than GPT, Claude, and DeepSeek, giving it relatively limited market impact.

## Anthropic Discloses Claude Code Used in Cyberespionage Campaign

**2025-11** — Anthropic publicly disclosed that a threat actor operating under the codename "GTG-2002" had used Claude Code to automate cyberespionage attacks targeting at least 30 organizations, achieving an automation rate of 80–90%. Anthropic stated that it had discovered this behavior in September 2025, banned all related accounts, and notified law enforcement and affected parties. [^2]

This incident was the first time Anthropic publicly acknowledged a case of its model being used for large-scale cyberattacks. GTG-2002's attack methods included using Claude Code to automatically generate phishing emails, analyze target system vulnerabilities, and write malicious code — virtually every stage of the attack chain had been delegated to AI agents.

This incident had a profound impact on the AI safety discourse: when an AI coding assistant can automate 80–90% of an attack workflow, traditional security defense models face a fundamental challenge. Anthropic cited this as one of its arguments for advancing AI safety legislation.
