# October 2025

## Claude Haiku 4.5 and Claude Code Web

**2025-10-15** — Anthropic released **Claude Haiku 4.5**, the first sub-version update following the Claude 4 series (released 2025-05-22), positioned as a lightweight, fast, low-cost reasoning model. [^1]

Haiku 4.5's release continued Anthropic's "three-tier" strategy since the Claude 3 series: Haiku (lightweight and fast), Sonnet (balanced workhorse), and Opus (flagship reasoning). Claude 4's launch included only the Sonnet tier (corresponding to the Claude 4 released on 2025-05-22), and Haiku 4.5 filled the gap on the lightweight end.

**2025-10-20** — Anthropic launched **Claude Code Web**, along with a sandboxing feature, allowing users to use Claude Code directly in the browser for code generation and debugging, no longer limited to the command-line environment. [^1]

The release of Claude Code Web was a signal — Anthropic was pushing Claude Code from a developer tool toward a broader user base. Previously, Claude Code had existed only in CLI form (previewed in February 2025, officially released with Claude 4 in May 2025); the addition of the web version and sandboxing feature dramatically lowered the barrier to entry.

> ⚠ **Note**: The "Claude 3.5 Opus" mentioned in the task list could not be found in reliable sources at the time of compilation — this model designation does not exist in Anthropic's version naming system. The Claude 3.5 series includes only Sonnet and Haiku (released in 2024); the Opus tier skipped the 3.5 version number and was launched directly in the Claude 4 series (Claude Opus 4, May 2025). Anthropic's actual release in October 2025 was Claude Haiku 4.5.
