# August 2023

## Code Llama: Meta officially enters the AI coding assistant race

> Just one month after Llama 2's release, Meta "retrained" it — this time using only code data. Code Llama was not a standalone model but a code-specialized version of Llama 2. With this move, Meta declared: the open-source world's AI coding assistant need not depend on OpenAI.

**2023-08-24** — Meta AI released **Code Llama**, a family of code-specialized large language models based on Llama 2.[^1] It offered four parameter sizes: 7B, 13B, 34B, and 70B, along with two variants: **Code Llama - Python** (Python-optimized) and **Code Llama - Instruct** (instruction-following optimized). All models released weights under a research license, consistent with Llama 2.

### Model family

| Version | Parameters | Training basis | Core positioning |
|------|------|---------|---------|
| Code Llama 7B | 7B | Llama 2 7B + code data | Lightweight local deployment, low-latency completion |
| Code Llama 13B | 13B | Llama 2 13B + code data | Balance of performance and speed |
| Code Llama 34B | 34B | Llama 2 34B + code data | High-quality code generation |
| Code Llama 70B | 70B | Llama 2 70B + code data | Flagship, competitive with GPT-3.5-level coding |
| Code Llama - Python 7B/13B/34B | Same as above | Code Llama + continued pretraining on Python data | Python-specific optimization |
| Code Llama - Instruct 7B/13B/34B | Same as above | Code Llama + instruction fine-tuning | Conversational coding and instruction following |

In terms of training methodology, Code Llama was built on top of Llama 2 by performing continued pretraining with approximately 500B tokens of code data.[^1] Data sources included public GitHub code repositories and code-related natural language text (such as StackOverflow Q&A). This was not training from scratch — it was "refreshing" a general model that had already learned language and reasoning with code data, focusing its capabilities on the coding domain.

### Performance

Code Llama 70B achieved **53.7%** (pass@1) on HumanEval, the highest score among open-source code models at the time.[^1] For comparison:

| Model | HumanEval pass@1 | Release date |
|------|:--:|:--:|
| Codex 12B (OpenAI) | 28.8% | 2021-08 |
| Code Llama 7B | 29.9% | 2023-08 |
| Code Llama 34B | 48.8% | 2023-08 |
| Code Llama 70B | 53.7% | 2023-08 |
| GPT-4 (OpenAI) | 67.0% | 2023-03 |
| Claude 3.5 Sonnet (Anthropic) | 92.0% | 2024-06 |

Code Llama 70B's 53.7%, while far below GPT-4's 67%, provided the community with GPT-3.5-level coding capability as an open-weight model — requiring no API call fees, deployable locally, freely fine-tunable, and adaptable to private codebases.

Notably, Code Llama 7B (29.9%) already surpassed Codex 12B (28.8%).[^1] A 7B open-source model matched OpenAI's pioneering work within two years. This was a continuation of the Llama family's "small yet efficient" approach in the coding domain.

### Long-context capability

Code Llama introduced a key technical feature: **Long Context Fine-Tuning**.[^1] Standard Llama 2 had a context window of 4K tokens; through an additional long-context fine-tuning phase, Code Llama expanded the context window to **100K tokens**.

This capability was crucial in coding scenarios: understanding a moderately sized codebase, processing a long function, analyzing cross-file dependencies — all these tasks required more context than 4K tokens could provide. 100K tokens meant Code Llama could "see" approximately thousands of lines of code at once, representing a qualitative leap for code completion and code Q&A.

### Meta's strategic position

Code Llama's release marked Meta's official entry into the AI coding assistant arena. Prior to this, competition in AI coding assistants had primarily played out between OpenAI (Codex/Copilot) and GitHub; Anthropic's Claude had coding capabilities but had not yet positioned itself as a coding assistant. Code Llama changed the landscape — it proved that open-source models could build code-specialized models, and make them quite powerful.

From the Llama ecosystem perspective, Code Llama was the first implementation of Meta's "general foundation + specialized variants" strategy:

- **Llama 2** (2023-07): General-purpose language model foundation
- **Code Llama** (2023-08): Code-specialized version
- Subsequently: **Llama Guard** (safety), **Purple Llama** (red-team testing), and other specialized models

This "one foundation, many specializations" strategy transformed the Llama ecosystem from a single model into a model family — each specialized model inheriting the foundation's language understanding while gaining significant enhancement in specific domains.

### The starting point of the open-source coding assistant ecosystem

After Code Llama's release, the community rapidly integrated it into various AI coding tools. HuggingFace saw a proliferation of fine-tuned versions based on Code Llama — custom models targeting specific programming languages (Rust, Go, Java), specific frameworks (React, Django), and even specific code styles. Local runtime tools like Ollama and llama.cpp enabled Code Llama to run on consumer-grade hardware — a quantized 7B Code Llama required only 4GB of VRAM.

This laid the model foundation for the subsequent open-source coding assistant ecosystem (such as Continue, Tabby, Aider, and other open-source Copilot alternatives). Before Code Llama, what the "open-source Copilot" lacked was not frontend tools, but a sufficiently capable underlying model. Code Llama filled that gap.

### Commentary

Code Llama itself was not a groundbreaking release — it was a code-continued-training version of Llama 2, with a straightforward technical approach and no architectural innovation. But its position was important: **it was the starting point for the open-source community to obtain a "commercially usable, fine-tunable, locally deployable" code model.**

Before Code Llama, developers trying to build an "open-source Copilot" faced the problem that the underlying models were not strong enough (StarCoder scored approximately 33% on HumanEval), or were too strong but prohibited commercial use (Codex). Code Llama 70B's 53.7% plus open commercial license made "AI coding assistant based on open-source models" a realistic option for the first time.

Meta's strategy was as clear as ever: don't make money selling models; build an ecosystem through open source. The more people used Code Llama, the more irreplaceable the Llama ecosystem became. This logic applied to Code Llama exactly as it did to Llama 2 — open source is not charity, it is competition.
