# August 2021

## Codex: When the Language Model Started Writing Code

> "Write a Python script to change the date format in a CSV from MM/DD/YYYY to YYYY-MM-DD." — Codex, with 12B parameters, solved 28.8% of programming problems on a benchmark called HumanEval (GPT-3 scored 0%). Then it became GitHub Copilot. The way programmers work has never been the same.

### Release

**2021-08-10** — OpenAI released **Codex**, a code generation model based on the GPT-3 architecture and fine-tuned on publicly available GitHub code. With 12B parameters, it was accessible via API. Alongside it, OpenAI released the **HumanEval** benchmark — a test set of 164 hand-crafted programming problems designed to evaluate a model's actual coding ability.[^1]

Codex achieved a pass@1 score of 28.8% on HumanEval (passing tests on the first generation), compared to GPT-3's 0%. This was an enormous leap — while GPT-3 had demonstrated nascent code generation capabilities, Codex transformed it into a reliable tool.

### GitHub Copilot

Codex's most far-reaching impact was not in the paper but in the product it powered — **GitHub Copilot**. On 2021-06-29 (two months before the paper's release), GitHub and OpenAI jointly launched Copilot's technical preview, powered by the Codex model. On 2022-06-21, Copilot became generally available at $10/month per user.[^2]

Copilot was the first widely deployed "AI programming assistant." It appeared in the editor as completion suggestions — you write a function name and a comment, and it completes the entire function body. By 2023, Copilot had over 1 million paying users, and the code it generated accounted for more than 40% of new code on GitHub.

### Impact

- **Paradigm shift in programming**: from "writing code" to "reviewing code + prompting code," Copilot initiated a transformation that continues to accelerate
- **Birth of the AI-assisted programming category**: after Codex/Copilot, tools like Gemini Code Assist, Cursor, Windsurf, and Claude Code (Claude 3.5 Sonnet) sprang up like bamboo shoots after rain
- **HumanEval became the standard**: this 164-problem benchmark remains one of the core metrics for evaluating code model capabilities

### Commentary

Codex was the critical leap in the GPT trajectory from "language" to "productivity." GPT-2 proved zero-shot, GPT-3 proved few-shot, but what the public saw was text — entertaining demos, far from monetization. Codex directly embedded an LLM into a product with genuine revenue potential — writing code. This was the first time a large language model was deployed as a "productivity tool" rather than an "impressive technology." From then on, "can our model help people write code?" became the unwritten standard for measuring LLM utility. After Copilot's success, the AI programming tools market ballooned to billions of dollars within three years. And the starting point of it all was a 12B-parameter model and 164 hand-crafted programming problems.
