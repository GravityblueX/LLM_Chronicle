# 开源模型许可证对照表

> 本表收录大模型领域主要开放权重模型的许可证，按模型族分组，对照其许可类型、商用权限、主要限制与 OSI 认证状态。只列可以下载权重的模型——纯 API 闭源服务（GPT-4、Claude、Gemini 等）不在表中。

---

## 说明

- 「开放权重」指可下载模型参数；「开放代码」指训练/推理代码可查；「开放数据信息」指知道训练数据来源与处理方式。三者是不同概念。
- OSI 认证仅适用于代码/软件层面。Open Source AI Definition（OSAID）发布后，权重模型可申请 OSAID 合规认证，但截至 2026 年中尚无模型正式通过。[^1]
- 许可证名称取官方原文。中文翻译仅作说明。
- 「是否可商用」指许可证本身是否允许——不涵盖第三方知识产权风险（如训练数据版权争议）。
- 同一模型族的不同版本可能有不同许可，表中按行区分。如有重要版本变更，在附注中说明。

## 许可证分类速查

### 经典开源许可证（OSI 批准、无行为限制）

| 许可证 | 模型族 |
|--------|--------|
| **MIT** | DeepSeek-V2、V3、R1；Phi；EleutherAI（GPT-Neo/J/NeoX 等） |
| **Apache 2.0** | Mistral（7B、Mixtral）；Qwen2.5（多数）、Qwen3（全部）；Falcon（180B）；Yi |

### 自定义开放许可证（允许商用、但有限制条款）

| 许可证 / 类型 | 模型族 | 典型限制 |
|---------------|--------|----------|
| **Llama Community License** | Llama 2 / 3 / 3.1 | 月活超 7 亿须额外许可 |
| **Gemma Terms of Use** | Gemma 1 / 2 | 禁止生成有害内容、武器开发等特定用途 |
| **CreativeML Open RAIL-M** | Stable Diffusion | 禁止违法、歧视、虚假信息、医疗决策等使用方式 |
| **RAIL 1.0** | BLOOM | 附使用行为限制 |

### 仅限非商用的开放权重

| 许可证 | 模型族 | 限制 |
|--------|--------|------|
| **CC BY-NC 4.0** | Command R / R+ | 不可商用 |
| **研究许可** | Llama 1（原始） | 仅限经审批的研究人员 |

## 附注

- Llama 1 的「事实开源」是特殊案例：原始许可为非开源研究许可，但权重在 BitTorrent 上全面泄漏后成为事实上的开放资源。Meta 未追究泄漏责任，并在四个月后主动以商用许可发布 Llama 2。
- Qwen2.5 的 3B 和 72B 使用自定义 Qwen License 而非 Apache 2.0。Qwen3 已全系统一为 Apache 2.0。
- Stable Diffusion 3 及后续版本（SD3 Medium、SD3.5）许可条款另有调整，部分版本增加了对大规模商业用户的限制，不属于 CreativeML Open RAIL-M。本表仅列社区使用最多的 1.x–SDXL 世代。
- EleutherAI 是全栈开放最彻底的 LLM 项目：从数据（The Pile）到训练代码（GPT-NeoX）到权重到训练日志全部公开。在「开源 AI」的标准讨论中常被作为对照极值。
- 关于 OSI Open Source AI Definition（OSAID）与上述许可证的关系，详见《志·开源运动》§六。
