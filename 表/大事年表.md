## 读表提示

这张表到 2026 年出现了一个明显变化：**“模型发布”不再足以概括一个时代。**

同样重要的节点越来越多来自：

- Agent runtime；
- 工具 / Agent 协议；
- sandbox / durable state；
- 价格与缓存；
- 权重许可证；
- trusted access / safeguards；
- 云托管与本地运行。

换句话说，历史对象正在从“一个 checkpoint”扩展为“智能怎样被训练、运行、授权、组合和交付”。
