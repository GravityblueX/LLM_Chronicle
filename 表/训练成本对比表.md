>

## 附注

### 与主要融资事件的对照

训练成本的量级与同期融资事件形成了清晰的映射：

- **GPT-4 的 $63M—$100M+** 训练成本发生时，OpenAI 刚获得 Microsoft 约 $100 亿战略投资（2023-01）。单次训练开支约占该轮融资的 0.6%—1%（见[《主要融资与估值表》](主要融资与估值表.md)[^3]）。
- **Llama 3.1 405B 的 ~$60M+** 训练成本由 Meta 自有资金承担——Meta 的 AI 研发预算估计在 $30—40 亿/年量级，此训练仅占其年度算力预算的一小部分。
- **DeepSeek-V3 的 ~$5.6M** 训练成本由母公司幻方量化自有资金支持，无传统融资（见[《主要融资与估值表》](主要融资与估值表.md) DeepSeek 附注）。557 万美元的数字仅为 GPT-4 估算成本的约 **6%**。

### 与算力变迁的对照

GPU 集群规模从 GPT-3 的 ~10K V100 到 Llama 3.1 405B 的 ~16K H100，再到 xAI Colossus 的 100K H100——训练前沿模型的算力门槛持续上升（见[《志·算力变迁》](../志/算力变迁.md) §四—五）。DeepSeek-V3 用 2,048 H800（出口管制降规版）在 $5.6M 预算内完成前沿水准训练，是这条上升曲线中的显著异常值。

### 统计口径说明

1. **成本口径**：本表"训练成本"仅指 GPU 计算费用（GPU 小时 × 单价），不含数据标注、清洗、人力、基建、电力冷却、中间试验训练等开支。实际总拥有成本（TCO）通常为表中数字的 2—5 倍。
2. **GPU 小时单价**：闭源模型按公有云 A100/H100 按需实例价格估算；DeepSeek 按 H800 市场价 ~$2/hr 估算（自报数据）。自建集群的实际折旧成本可能低于云价格。
3. **MoE 模型**：GPT-4 和 DeepSeek-V3 均为 MoE（Mixture of Experts）架构，总参数量远大于每 token 激活参数量。训练成本主要由 GPU 小时数和集群规模决定，而非参数规模本身。
4. **DeepSeek-R1**：R1 在 V3 基座上进行 RL 训练。表中"~$6M 总计"包含 V3 基座的 ~$5.6M 训练成本加上 R1 特有的 RL 阶段开销。RL 阶段的具体成本未公开，此数字为综合估算，存疑。
5. **DeepSeek-V4**：截至编纂时（2026-06），V4 技术报告尚未公开，训练成本、GPU 配置等信息不可得。V4 的 API 价格约为 GPT-5.5 的 1/370（见《编年·2026年4月》），但推理价格优势不直接等同于训练成本优势。
