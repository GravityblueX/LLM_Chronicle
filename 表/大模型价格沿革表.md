## 说明

本表记录有代表性的 API 公开定价节点，统一为美元 / 每百万 token（$/1M）。**价格必须连同日期、输入/输出、cache、effort、时段等条件理解；同一模型今天的价格可能与发布日不同。**

人民币历史价格仅在来源足够明确时保留近似美元换算。更完整分析见《论·价格战》。

## GPT-5.6 的 cache 价格示例

2026-08-21 后，公开价格中 cached input 显著低于普通输入：

| 模型 | Input | Cached input | Output |
|---|---:|---:|---:|
| GPT-5.6 Sol | $4.00 | $0.40 | $20.00 |
| GPT-5.6 Terra | $2.00 | $0.20 | $12.00 |
| GPT-5.6 Luna | $0.20 | $0.02 | $1.20 |

这张表比单纯“输入 / 输出”更能代表 Agent 时代的价格结构：大量 system prompt、工具定义、代码库和长 context 会被反复复用。[^16][^17]

## 价格维度已经不止 token

截至 2026 年，横向比较至少还要记录：

| 维度 | 例子 |
|---|---|
| Cached input | GPT-5.6、Claude prompt caching |
| Batch | Claude 等提供批处理折扣 |
| Reasoning / effort | Claude Sonnet 5、GPT-5.6 |
| Fast / priority | GPT-5.6 Fast mode |
| Peak / off-peak | DeepSeek V4 |
| Region | 部分厂商提供区域专属 inference，可能有倍率 |
| 免费层 | GPT-5.6 Luna、Gemini 开发者入口等 |
| Self-host | Qwen / DeepSeek / Kimi 等开放权重：API 费可为零，但 GPU / 运维不为零 |

因此，任何只列一个 `$ / 1M token` 的“最便宜模型排行榜”都只能回答很小一部分问题。

## 应该新增的真正指标

Agent 工作负载更适合计算：

- **$/successful task**
- **$/PR merged**
- **$/research report delivered**
- **$/customer case resolved**
- **平均 retries / task**
- **人类审查分钟 / task**

同一价格的模型，如果一个需要反复重试，最终系统成本可能差很多倍。
