# 前沿模型对比矩阵（2026 年前沿版）

## 说明

本表对比截至 2026 年中的主流前沿大语言模型，覆盖六大维度：推理能力、编程能力、多模态支持、上下文长度、API 价格、开源程度。数据来源为官方技术报告、官方定价页面和公开评测排行榜。`*` 标注的数字为行业广泛引用的估计值，开发方未公开确认。因评测设置差异（prompt 格式、few-shot 数、采样温度等），同一 Benchmark 的跨模型分数比较应确保设置一致。

> **体例依据**：[00_体例.md §四](../00_体例.md) — 志、表。表不设"评曰"——纯数据，不议论。

## 附注

### 关于闭源模型的数据来源

GPT-5.5、Claude 4、Gemini 3.x Pro 等闭源模型的具体参数规模、训练细节和评测分数通常不完整公开。本表中标注 `*` 的数字来源于：
- 开发方在发布博客或技术报告中选择性公布的 Benchmark 分数
- 行业媒体报道和第三方评测复现
- LMArena（原 Chatbot Arena）等人类盲测排行榜的 Elo 排名推断

这些数字应被视为参考值而非精确数据。

### 关于开源程度的分类

- **MIT 开源**：模型权重、训练代码、方法完全公开，无商业使用限制（DeepSeek V4、DeepSeek R1）
- **Apache 2.0**：类似 MIT 的宽松许可，但可能附带专利授权条款（Qwen 3）
- **闭源**：仅提供 API 访问，模型权重和架构细节不公开（GPT-5.5、Claude 4、Gemini 3.x Pro）

开源程度不等于可用性——闭源模型的 API 服务通常更稳定、功能更完整；开源模型需要用户自行部署和维护。详见《开源模型许可证对照表》。

### 与其他表的交叉引用
