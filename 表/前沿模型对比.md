# 前沿模型对比矩阵（2026-08-28）

## 说明

旧版表使用了大量 `*` 标注的行业估计参数、Benchmark 和价格。这种数字在模型快速迭代期很容易把传闻固化成“事实”，因此本版改用以下原则：

1. **只写官方 / 论文 / 可核验公开资料明确给出的数据；**
2. 闭源模型参数未披露就写“未披露”，不猜；
3. 不把不同 prompt、tool、effort 设置下的 Benchmark 强行放进统一排行榜；
4. 重点比较 2026 年真正影响部署的维度：**能力层级、Agent / 工具、多模态、上下文、价格、权重开放与运行门槛。**

> 本表是“系统定位速查”，不是“谁是世界第一”的排行榜。

## 三、“开放”维度不能只看权重

| 模型 | 权重可得 | 许可证 / 访问 | 普通个人本地运行 | 典型控制权 |
|---|:--:|---|---|---|
| GPT-5.6 | ❌ | 托管 API / 产品 | ❌ | 厂商托管，低运维 |
| Claude 5 / Fable / Mythos | ❌ | 托管；高风险层分级访问 | ❌ | safeguards / trusted access 强 |
| Gemini 3.x | ❌ | Google 托管 | ❌ | Google Cloud / Workspace / Android 分发 |
| DeepSeek V4 | 依具体发布 | DeepSeek 生态 | 视具体权重 / 规模 | 低价 API + 国产硬件 / 自托管路线 |
| Kimi K3 | ✅ | Kimi K3 License | **极难** | 可检查 / 修改，但 2.8T 部署高度依赖集群 |
| Qwen3.8 2.4T | ✅ | 以具体权重 License 为准 | **极难** | Max 权重开放，推理系统成为门槛 |
| Muse Glimmer 30B | ✅ | Apache 2.0 | **可行** | 本地 / 离线 / 私有运行时控制 |

开放权重与实际运行自主权不是同一指标。

## 四、Agent 时代应该比较什么

### 不再建议的比较方式

- 未披露参数用“行业传闻”补齐；
- 把开发方各自选的 Benchmark 放一行直接排名；
- 一个模型只写一个 token 单价；
- “开放 = 免费 = 本地可跑”；
- “旗舰 = 实际生产调用最多”。

### 更有用的比较维度

| 维度 | 问题 |
|---|---|
| Task completion | 它能不能把完整工作做完？ |
| Long-horizon stability | 工作几十 / 几百步后是否漂移？ |
| Tool reliability | 工具选择和参数错误率怎样？ |
| Computer use | 能否稳定操作 GUI / browser？ |
| Context utilization | 不只是“能装多少”，而是能否用好长 context？ |
| Retry rate | 失败后要重跑多少次？ |
| Cost / successful task | 完成同一任务总共多少钱？ |
| Latency | 交互式还是后台任务？ |
| Auditability | 是否有 trace、diff、checkpoint？ |
| Deployability | API、本地单卡、还是多机集群？ |
| Governance | 权限、safeguards、风险访问层如何设计？ |

## 五、2026 年最清楚的产品分层

当前前沿市场已经不是“六家公司各一个旗舰”，而是每家公司内部形成层级：

- **OpenAI**：Luna → Terra → Sol → ultra / Fast；
- **Anthropic**：高频 Sonnet → 高端 Opus → 更受控 Fable / Mythos；
- **Google**：高吞吐 Flash 与更高端 Pro / Deep Think 分工；
- **DeepSeek**：Flash → Pro，并加入峰谷调度；
- **开放权重生态**：消费级本地 Agent（Glimmer）与 2T—3T 云集群级开放旗舰（Qwen/Kimi）并存。

因此“最强模型”这个单数概念越来越缺乏部署意义。

真正的问题是：

> **对这个任务，我该在哪个能力 / 价格 / 延迟 / 开放 / 风险层上买智能？**

## 六、数据纪律

本表以后应遵守：

1. 未公开参数不猜；
2. 未统一评测不做精确 Benchmark 横排；
3. 价格必须带日期；
4. 供应商声称与独立评测分开；
5. “开源”优先写具体许可证 / 开放权重；
6. 当前数据易变，更新时覆盖本表日期。
