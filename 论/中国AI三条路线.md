# 论·中国 AI 三条路线

> DeepSeek、Qwen、GLM——中国大模型"御三家"。它们各自从不同的土壤里长出来：量化基金的交易大厅、互联网巨头的云计算事业部、顶尖大学的知识工程实验室。表面上它们都在做大模型，但基因决定了它们根本不是同一类物种。本文追问的不是"谁更强"——而是"为什么它们走出了三条完全不同的路"。

---

## 一、问题的提出：同一个国家，三条不可通约的路

2023 年至 2026 年，中国大模型行业形成了三条路线。不是三种风格偏好，而是三种在创始人基因、资金结构、技术哲学、商业模式和开源策略上全面分化的**制度类型**。

这三条路线之间的差异之大，以至于把它们放在同一个"中国 AI"的标签下讨论，几乎是一种误导。DeepSeek 的创始人在 2022 年还在做量化交易，Qwen 的团队在管理全球第三大云计算平台，GLM 的核心人物在清华教知识图谱课程。他们面对的问题不同、拥有的资源不同、做出的技术选择不同、定义成功的方式也不同。

唯一的共同点是——他们都在 2023 年到 2026 年之间做出了世界级的大模型。而本文追问的不是"谁更强"——而是"为什么同一个国家走出了三条完全不同的路"。

| 维度 | DeepSeek | Qwen | GLM |
|------|----------|------|-----|
| 背后实体 | 幻方量化（量化对冲基金） | 阿里巴巴·云智能集团 | 智谱 AI（清华系创业公司） |
| 创始人基因 | 梁文锋——量化交易员 | 通义实验室——云计算产品经理+研究员 | 唐杰——清华教授，知识图谱出身 |
| 资金来源 | 量化交易利润（不融资、不上市） | 上市公司现金流 | 风险投资（累计融资超 40 亿元） |
| 架构选择 | 标准 Transformer + MoE + MLA | 标准 Transformer + MoE | 非标准（GLM 双向注意力+空白填充） |
| 开源策略 | MIT 全开源，含思维链 | Apache 2.0 全谱系开源 | 前沿闭源，次级开源 |
| 商业模式 | 不从 AI 赚钱 | 模型免费，卖阿里云算力 | API 收费 + 企业解决方案 |
| 核心技术哲学 | 效率优先——省出来的就是利润 | 覆盖优先——全谱系占住每个生态位 | 架构优先——做不一样的东西 |

这三条路线不是"同一条赛道上的不同策略"——它们是**三种不同的物种在三种不同的生态环境中各自演化**的结果。要理解它们，必须追溯到各自的起源条件。

---

## 二、创始人基因如何决定技术路线

### 2.1 DeepSeek：量化交易员眼中的大模型

梁文锋不是 AI 研究员出身。他是量化交易员。这个出身决定了 DeepSeek 的一切技术决策。

量化交易的核心问题是**效率**：同样的信息，谁的模型算得更快、用更少的 GPU 小时、消耗更少的带宽——谁就赚更多钱。在这个世界里，GPU 不是资产，是成本。一个好的工程优化不是为了发论文，是为了直接变现。

当梁文锋把这种思维带入大模型训练时，它产生了一系列技术后果：

- **MLA**（Multi-head Latent Attention）：KV Cache 压缩 90%。在量化交易的世界里，这相当于"同样的硬件多跑了 10 倍的推理"。[^1]
- **MoE + 无辅助损失负载均衡**：671B 参数只激活 37B。在量化交易的世界里，这相当于"同样的成本多建了 18 倍的因子"。[^2]
- **纯 RL 训练 R1**：跳过 SFT 阶段。在量化交易的世界里，这相当于"省掉了最贵的人工标注成本"。[^3]

这些技术创新的共同特征是：**它们不是为了学术创新而创新，而是为了效率而创新**。DeepSeek 的论文读起来更像工程优化报告——每一个技术选择都有一个明确的"成本节省了多少"的量化指标。这不是偶然——这是创始人基因的直接投射。

一个量化交易员不需要"技术很厉害"。他需要"技术很便宜"。这就是 DeepSeek 的全部技术哲学。

更深层地说，量化交易员对"可复现性"有天然的执念——一个交易策略必须在所有市场条件下都能稳定盈利，而不是只在某个特定时间段有效。这种执念映射到大模型训练上，就变成了 DeepSeek 对"训练管线稳定性"的极致追求。V3 的技术报告中有一句不起眼但极其重要的话：整个预训练过程中未出现任何需要回滚的不可恢复 loss spike。[^2] 这句话的潜台词是——整个训练过程是可以精确控制的。这种控制能力不是来自运气，是来自量化交易世界中"精确控制每一个变量"的职业习惯。

### 2.2 Qwen：云计算产品经理眼中的大模型

阿里云的基因是**平台**。它不生产内容，它卖算力。它不做最惊艳的产品，它做最可靠的基础设施。

当阿里云决定做大模型时，它面对的问题和 DeepSeek 完全不同。DeepSeek 需要回答"怎样用最少的钱训最好的模型"。阿里云需要回答的是："怎样让大模型帮阿里云卖更多服务器。"

这个底层问题产生了 Qwen 的全部战略：

- **全谱系覆盖**（0.5B 到 235B MoE）：不是为了技术炫酷，而是为了覆盖阿里云客户的所有算力层级——手机端 0.5B、边缘设备 7B、中小企业 14B、大型企业 72B、旗舰场景 235B。每个客户都能在 Qwen 系列中找到"刚好够用"的模型，然后在阿里云上部署。[^4]
- **Apache 2.0 开源**：不是为了社区情怀，而是为了消除商用门槛，最大化开发者生态——每个基于 Qwen 微调的模型，最终都在阿里云上跑推理。[^5]
- **闭源+开源双轨**：最好的模型（通义千问）闭源服务企业客户赚收入，次级模型开源扩大生态。两条轨道互相喂养——开源用户长大后变成闭源客户。[^6]

Qwen 的技术路线"不够酷"——它没有 MLA、没有架构创新、没有"557 万美元训练出前沿模型"的传奇。但 Qwen 的技术路线**足够稳**：每一步都在扩大阿里的云生态护城河。这是一个产品经理的胜利，不是一个工程师的胜利。

这种"不够酷"本身就是一种战略选择。在大模型军备竞赛中，"最炫的技术突破"获得最多的媒体关注——但媒体关注不等于客户价值。阿里云的客户不需要"最炫的模型"，他们需要"刚好够用的模型+可靠的部署方案+合理的价格"。Qwen 的全谱系覆盖正是为了满足这个需求——0.5B 用于手机端即时推理，7B 用于边缘设备，14B 用于中小企业，72B 用于大型企业。每一个规模都有明确的客户场景和阿里云产品对应。

### 2.3 GLM：教授眼中的大模型

唐杰是清华大学计算机系教授，知识图谱领域出身。他的技术审美是**架构创新**——做不一样的东西，证明"另一条路也能走通"。

这种审美产生了 GLM 的全部独特性：

- **自回归空白填充**：不是标准的"从左到右预测下一个 token"，而是"遮住一部分，让模型填空"。这个设计在 2022 年有其理论合理性——它统一了理解（BERT 式双向上下文）和生成（GPT 式自回归）的训练目标。[^7]
- **坚持自主架构四代**：从 GLM-130B 到 ChatGLM-6B 到 GLM-4 到 GLM-5.1，即使标准 Transformer 已经成为行业共识，GLM 仍然保持自己的架构。这是"学术自信"——也可能是"路径锁定"。
- **前沿闭源+次级开源**：GLM-4-Plus 闭源，GLM-4-9B 开源。这不是平台战略，而是创业公司的生存策略——最好的模型必须产生收入，否则 40 亿融资花完就结束了。[^8]

GLM 在"御三家"中最像学术团队做创业——优点是技术品味好（ChatGLM-6B 在 2023 年 3 月的时间窗口里是中文开发者唯一的可用选择），缺点也是技术品味好（自回归空白填充在工程生态上是持续的技术负债）。

但这里有一个更深层的悖论。GLM 的自主架构选择，在 2022 年是有道理的——当时谁也不知道纯自回归 Transformer 会赢者通吃。但在 2024-2025 年，当 FlashAttention、KV Cache 压缩、Speculative Decoding、MoE 等前沿优化全部围绕标准自回归架构构建时，GLM 的独特性就从"学术优势"变成了"工程负债"。智谱 AI 面临一个两难：继续坚持 GLM 架构意味着永远需要额外的适配工作来享受行业优化的红利；切换到标准 Transformer 意味着承认十年的架构探索走了一条弯路。对一个以技术品味为品牌核心的学术创业公司来说，后者可能是比技术负债更大的品牌危机。

## 三、资金来源如何决定商业模式

三条路线的资金结构差异，直接决定了它们能做什么样的商业决策。

### 3.1 DeepSeek："不需要从 AI 赚钱"

这是 DeepSeek 最核心的结构优势。幻方量化的交易利润足以支撑 DeepSeek 的全部运营，不需要从 API 收入中回收训练成本。这个条件让 DeepSeek 可以做出**任何需要盈利的公司都做不出来**的决策：

- 以 GPT-4 1% 的价格卖 API——因为不需要盈利 [^9]
- 以 MIT 许可完全开源——因为不需要保护商业价值 [^3]
- 不融资、不上市——因为不需要外部资本 [^10]

这个条件也决定了 DeepSeek 的天花板：它只能做"最好的模型工厂"，不能做"最好的产品公司"。因为一旦 DeepSeek 开始做产品（Agent、工具链、企业集成），它就必须开始赚客户的钱——而"开始赚钱"会摧毁它"不需要赚钱"的结构优势。

**推演风险**：DeepSeek 的全部优势取决于一个前提——幻方量化的交易利润能持续覆盖 AI 研发成本。如果量化交易行业出现系统性危机（监管收紧、策略失效、市场长期低波动），DeepSeek 的"不差钱"状态将不复存在。这是一条没有 Plan B 的路线。

### 3.2 Qwen："模型免费，云赚钱"

阿里的商业模式清晰得像一道算术题：Qwen 开源 → 开发者在 Qwen 基础上做应用 → 应用跑在阿里云上 → 阿里云收服务器费用。

模型不是产品——模型是引流手段。阿里云的竞争对手是 AWS、Azure、Google Cloud。Qwen 的作用是在这些巨头的模型生态中撕开一个口子：当全球开发者用 Qwen 而不是 Llama 来构建中文 AI 应用时，这些应用的基础设施就绑在了阿里云上。

**推演风险**：Qwen 路线的风险不在模型层——而在云层。如果阿里云本身在和 AWS/Azure 的竞争中持续失血，Qwen 的"引流价值"就无法转化为实际收入。此外，DeepSeek 的极低 API 价格正在侵蚀 Qwen 的闭源轨收入——当开发者可以以 1/370 的价格获得 GPT-5.5 级的 API 时，谁还愿意为阿里云的闭源模型付费？

### 3.3 GLM："用融资续命，用收入造血"

智谱 AI 是三家之中最传统、也最脆弱的商业模式。它不靠量化交易利润补贴，不靠云平台生态变现——它直接从 API 和企业客户那里赚钱。

40 亿人民币的融资给了它足够的弹药，但烧钱速度也在加快。在 DeepSeek 以 1% 价格提供同等服务的市场环境下，智谱 AI 的 API 收入面临结构性压力。它能证明"我的模型好到值得贵 100 倍"吗？在企业级客户那里，也许可以——定制化、私有部署、安全合规、本地支持，这些都是 DeepSeek 不提供的服务。在通用 API 市场上，很难。

**推演风险**：GLM 路线面临的不是技术风险，而是**生存风险**。在 DeepSeek 和 Qwen 的双重挤压下，一个独立 AI 创业公司需要证明它的"不可替代性"不在模型能力本身——而在企业级服务、行业垂直化、学术影响力等模型之外的价值。如果这些价值无法及时建立，智谱 AI 的 40 亿融资就是倒计时。

值得注意的是，GLM 路线的"学术基因"也可能成为一种独特的生存策略。智谱 AI 与清华大学的深度绑定意味着它可以持续获得顶尖研究人才——这些人才对加入大厂（阿里）或量化基金（幻方）可能没有兴趣，但对留在学术-创业交叉地带充满热情。如果智谱 AI 能把这种人才优势转化为特定垂直领域的技术壁垒（如科学文献理解、知识图谱驱动的推理等），它可能找到一条不同于 DeepSeek 和 Qwen 的生存路径。

## 四、与西方路线的对照

| 维度 | DeepSeek | Qwen | GLM | OpenAI | Anthropic | Meta/Llama |
|------|----------|------|-----|--------|-----------|------------|
| 资金结构 | 量化利润 | 上市公司 | VC 融资 | 微软投资 | Google/Amazon 投资 | 广告收入 |
| 核心哲学 | 效率极端化 | 生态全覆盖 | 架构差异化 | 安全叙事商业化 | 安全优先 | 开源护城河 |
| 开源程度 | 全 MIT | Apache 2.0 | 部分开源 | 从开放到闭源 | 闭源 | 开放权重（非 OSI 认证） |
| 商业逻辑 | 不靠 AI 赚钱 | 卖云 | 卖 API | 订阅 + API | API + 企业 | 削弱竞争对手护城河 |

几组关键对照值得展开：

**DeepSeek vs OpenAI**：两者代表了 AI 成本结构的两极。OpenAI 的哲学是"用更多来换更强"——更多参数、更多 GPU、更多钱。DeepSeek 的哲学是"更聪明的工程省出更多的能力"——MLA 省出推理成本、MoE 省出训练成本、Pure RL 省出对齐成本。这不是风格偏好——这是创始人世界观的直接投射。量化交易员把 GPU 视为成本（必须最小化），硅谷创业者把 GPU 视为投资（必须规模化）。两种世界观产生了两种完全不同的技术路线，而 DeepSeek 的路线在成本效率上碾压了 OpenAI。

**DeepSeek vs Meta/Llama**：两者都不直接从模型赚钱，但动机完全不同。Meta 用 Llama 削弱 OpenAI 和 Google 的 API 护城河——它在用自己的开源来保护自己的广告帝国。DeepSeek 不需要削弱谁——它甚至不在同一个商业游戏里。Meta 的开源是武器，DeepSeek 的开源是无心之举。[^11] 但结果是一样的：两家"不靠模型赚钱"的公司，共同定义了开源大模型的能力上限——这挤压了所有需要从模型赚钱的公司。

**Qwen vs Meta/Llama**：两者都是大厂开源，都用模型引流卖自家云。但 Qwen 的全谱系覆盖策略（0.5B 到 235B）是 Llama 不具备的——Llama 只有 8B/70B/405B 三个档位。[^4] Qwen 更像一个精心设计的产品线，Llama 更像一个研究产出。此外，Qwen 从 1.5 版本起全面采用 Apache 2.0 许可——比 Llama 的"开放权重"许可更接近真正开源——这让 Qwen 在全球开发者社区中赢得了比 Llama 更多的信任。

**GLM vs Anthropic**：两者都是"出走的学者"创办，都强调安全和技术品味。但 Anthropic 有 Google 和 Amazon 的持续注资（截至 2025 年累计超过 70 亿美元），而智谱 AI 的资金来源是 VC 融资——烧完就没有了。[^12] Anthropic 证明了"安全优先的 AI 公司可以活下来"，但 GLM 需要证明的是"学术基因的 AI 创业公司可以在中国活下来"——这比前者难得多。更关键的区别是：Anthropic 的 Constitutional AI 是一种方法论创新——即使模型被追平，方法论仍然有独立价值。GLM 的自主架构创新则更脆弱——当标准 Transformer 生态越来越强大时，"不一样"的价值在递减。

## 五、三条路线的可持续性推演

本太卜做了三轮推演。

**第一轮——现状评估**：DeepSeek 在模型层有结构性优势（效率），但缺乏产品化能力和企业级服务。Qwen 在生态层有结构性优势（覆盖），但闭源轨面临 DeepSeek 价格压力——当开发者可以用 1/370 的价格获取同等模型时，闭源 API 的价值在哪里？GLM 在时间窗口上曾有先发优势（2023 年 3 月的 ChatGLM-6B），但该窗口在 2023 年下半年就已经关闭——Qwen 和 Llama 在中文能力上迅速追平。

**第二轮——外部变量**：美国对华 GPU 出口管制持续升级。这一变量对三条路线的影响截然不同——DeepSeek 的"效率路线"意外受益（管制迫使它在更弱的 GPU 上做更好的工程，结果产生了持久的成本优势），Qwen 的"全覆盖路线"部分受限（小模型受管制 GPU 影响较小，但旗舰模型训练需要更多算力），GLM 的"独立创业路线"最为脆弱（没有自有算力补贴，只能靠市场价购买 GPU 小时）。318 事变（2026 年 3 月）则从需求侧给三条路线同时带来了机遇——中国开发者正在"去美国化"迁移，DeepSeek 和 GLM 都成为了替代方案。

**第三轮——终局推演**：三条路线不太可能收敛为一条。DeepSeek 会继续做"模型工厂"，因为它的基因不允许它做别的——它无法变成一个产品公司而不失去其结构性优势。Qwen 会继续做"模型平台"，因为它的基因就是平台——模型是手段，云是目的。GLM 需要找到自己的不可替代性——可能是行业垂直化（法律、医疗等需要深度定制的领域），可能是学术生态的深度绑定（清华的知识图谱和学术网络是 DeepSeek 和 Qwen 没有的），可能是某个我们尚未预见的赛道。

最可能的终局不是"一统天下"，而是"生态位分化"：DeepSeek 是基础设施层的水电（便宜、好用、你不在乎品牌），Qwen 是应用层的安卓（全覆盖、开发者友好、生态绑定），GLM 是某个垂直领域的小米（特定场景下的最佳选择，但不是通用方案）。

## 六、一个没有人问过的问题

为什么是**中国**——而不是印度、日本、欧洲——走出了这三条路线？

答案不在技术里，在制度里。

中国同时具备三个条件：一个足够大的国内市场（14 亿人，全球第二大经济体，且在 AI 应用层有独特的垂直场景——如中文 NLP、短视频推荐、电商搜索），一个高度竞争的互联网产业（BAT+字节+幻方，五种不同基因的玩家，彼此之间的竞争烈度远超硅谷的寡头格局），和一个在 AI 领域有足够学术积累的教育体系（清华、北大、中科院每年产出大量 AI 论文和人才）。这三个条件缺一不可——印度有市场但产业竞争力不足，日本有技术但市场偏保守，欧洲有学术但缺乏大规模商业化基础设施，美国有全部条件但大厂之间的基因趋同度更高（硅谷的大厂几乎全部是互联网基因）。

中国互联网产业的"基因多样性"尤为关键。幻方量化的量化基金基因、阿里巴巴的云计算基因、清华大学的学术基因——这三种基因之间的差异，比硅谷任何两家 AI 公司之间的差异都大。基因差异催生路线差异，路线差异催生竞争，竞争催生进步。这是中国 AI 三条路线并存的结构性原因。

三条路线的并存本身就是中国 AI 生态健康度的指标——如果只有一条路线（比如只有大厂路线），那意味着创新的单一化。三条路线的共存意味着不同的技术假设、商业模式和组织形式都在被测试——市场和时间会筛选出哪条路走得最远。

---

## 评曰

三条路线的存在，证明了一件事：**大模型竞争不只是技术竞争，更是制度竞争**。

DeepSeek 的效率路线是量化交易基因的投射——当你的创始人把 GPU 看作成本而非资产时，你的技术路线自然走向"用更少做更多"。Qwen 的生态路线是云计算基因的投射——当你的创始人把模型看作引流手段而非产品时，你的技术路线自然走向"全覆盖+开源"。GLM 的架构路线是学术基因的投射——当你的创始人把创新看作学术尊严时，你的技术路线自然走向"做不一样的东西"。

基因不是决定论——但它设定了默认路径。偏离默认路径需要极强的外力。DeepSeek 偏离"不做产品"的默认路径，需要幻方量化突然需要 AI 收入。Qwen 偏离"不追最前沿"的默认路径，需要阿里云突然决定在模型层追到第一。GLM 偏离"坚持自主架构"的默认路径，需要智谱 AI 承认标准 Transformer 是更好的选择。这些外力在 2026 年的此刻都不存在。

三条路线不会合并为一条。但它们之间的张力——效率 vs 覆盖 vs 创新——定义了中国 AI 的全部可能性。谁最终胜出不取决于谁的模型更强——取决于谁的基因最适应下一个生态环境。

而下一个生态环境是什么——这就是我们还无法推演的部分了。
