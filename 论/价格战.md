# 大模型 API 价格战史

> 2020 年，GPT-3 的每百万 token 要价 60 美元。2025 年，同等能力的模型免费开放。五年间，大模型 API 的价格下降了近四个数量级——不是摩尔定律的速度，是雪崩的速度。

## 一、价格战的起点不是竞争，是稀缺

大模型 API 的商业化从 OpenAI 的 GPT-3 API 开始。2020 年 6 月 11 日，OpenAI 发布 GPT-3 API 私有测试版，按 token 计费。最强大的 Davinci 端点为 **$0.06/1K tokens**——折合每百万输入约 $60。[^1]

这个定价的逻辑不是成本，而是**稀缺**。2020 年的世界里，只有一个可调用的 175B 参数大语言模型 API。没有竞争者，没有替代品，用户没有议价权。$60/1M tokens 在当时被普遍接受——因为它是市场上唯一的选项。

GPT-3 API 的定价体系还建立了一种此后被反复模仿的层级结构：Davinci（最贵、最强）、Curie（$0.006/1K）、Babbage（$0.0012/1K）、Ada（$0.0008/1K）。"越强越贵"的直觉在 2020 年看似理所当然——直到有人证明它不必然成立。

## 二、GPT-3.5 Turbo：第一次降价定义价格基准

2023 年 3 月 1 日，OpenAI 发布 **GPT-3.5 Turbo**，定价 **$0.002/1K tokens**——比 Davinci 便宜了 **30 倍**。[^2]

这次降价不是竞争驱动的——2023 年初的 API 市场仍然没有真正的挑战者。它来自工程优化：GPT-3.5 推理效率大幅提升，成本结构允许 OpenAI 主动降价。OpenAI 的策略是清楚的：用低价锁定开发者生态，不给后来者留下价格空档。

与此同时，GPT-4 API 于 2023 年 3 月 14 日发布，定价 **$0.03/1K input + $0.06/1K output**（$30/$60 per 1M）。[^3] 这定义了另一个价格锚点：前沿模型值这个价。GPT-4 的定价在此后十个月内没有降过——因为没有竞品可以达到同等性能。

2023 年 8 月，GPT-3.5 Turbo 的 4K 上下文版本降至 **$0.0015/1K input, $0.002/1K output**；2023 年 11 月的 GPT-4 Turbo 降至 **$0.01/1K input, $0.03/1K output**。[^4][^5] 但这些都是 OpenAI 的渐进式调整——没有外部竞争者，价格只会慢慢降。

## 三、Anthropic 与 Google 入场：分层竞争形成

2023 年 3 月到 2024 年初，API 市场开始出现真正的竞争者——但定价逻辑仍然是"对标 GPT-4，略低一点"：

- **Claude 3 Opus**（2024-03，Anthropic）：**$15/$75 per 1M**——对标 GPT-4 但略贵 [^6]
- **Claude 3 Sonnet**（2024-03）：**$3/$15 per 1M**——"中等"价位
- **Claude 3 Haiku**（2024-03）：**$0.25/$1.25 per 1M**——锚定 GPT-3.5 Turbo
- **Gemini 1.5 Pro**（2024-05，Google）：**$3.50/$10.50 per 1M**（128K 以下）[^7]

这套定价体系的隐含假设是：**能力越强，定价越高**。Opus 最贵、Sonnet 居中、Haiku 最便宜——与 GPT-4 时代的 Davinci/Curie/Babbage/Ada 逻辑一脉相承。2024 年上半年，没有人质疑这个逻辑。

## 四、DeepSeek-V2：第一次撕裂定价体系（2024-05）

2024 年 5 月 6 日，DeepSeek 发布 V2 模型，API 定价 **¥1/1M input, ¥2/1M output**——按当时汇率约 **$0.14/$0.28 per 1M**。[^8]

在性能对标的语境下（V2 在多项基准上接近 GPT-4 Turbo），这个价格只有 GPT-4 Turbo 的约 **1/70**。

这不是"便宜一点"，这是**价格体系的撕裂**。V2 用 MoE 架构（MLA + DeepSeekMoE）实现了推理成本的断崖式下降，使得一个接近 GPT-4 级的模型可以用接近开源部署的边际成本来提供服务。DeepSeek 团队显然无意赚取"能力溢价"——他们直接把成本优势传导给了用户。

V2 的定价直接触发了中国市场的连锁反应。2024 年 5 月的中国 AI 圈进入了一场罕见的**价格战**：

- **2024-05-15**：字节跳动发布豆包大模型，**Pro-32k 定价 ¥0.0008/1K**（约 ¥0.8/1M），宣称"比行业便宜 99.3%" [^9]
- **2024-05-21**：阿里云通义千问 GPT-4 级主力模型 Qwen-Long，API 价格直降 **97%**，降至 ¥0.0005/1K [^10]
- **同日**：百度文心一言 ERNIE Speed 和 ERNIE Lite 宣布 **免费** [^11]
- **2024-06-05**：智谱 AI 将 GLM-4 价格降至 **¥0.1/1M**；GLM-4 Flash 免费 [^12]
- 科大讯飞、零一万物、MiniMax 等跟进降价或免费

这场价格战的根源就是 V2：当一个 MIT 开源、性能接近 GPT-4 的模型把 API 定在 ¥1/1M，整个"能力=价格"的旧坐标系就碎了。所有依赖 API 溢价的玩家都被迫跟牌——要么降，要么免费，要么证明你的模型真的比别人好到值得 70 倍的价差。

## 五、2024 年下半场：GPT-4o 降价与 DeepSeek-V3 二次冲击

2024 年 5 月 13 日，OpenAI 发布 **GPT-4o**，定价 **$5/$15 per 1M**——比 GPT-4 Turbo 再降 50%。[^13] GPT-4o mini（2024-07-18）进一步降至 **$0.15/$0.60 per 1M**。[^14] 这些降价的动力不完全来自竞争——GPT-4o 的推理效率本身就比 GPT-4 大幅优化——但竞争压力无疑加速了降价节奏。

2024 年 12 月 26 日，DeepSeek 发布 **V3**——性能对标 GPT-4o，API 定价 **¥1/1M input (cache hit), ¥2/1M (cache miss), ¥8/1M output**。[^15] 训练成本仅约 $5.6M。V3 的定价不是"比 OpenAI 便宜"——它是**用自己的成本结构来定价**，而 OpenAI 的价格在这些成本结构面前显得荒唐。

## 六、2025 年：免费成为默认，GPT-4.5 成为最后的异数

2025 年初的 API 定价格局已经发生了根本性变化：

- **DeepSeek-R1**（2025-01-20）：**¥1/¥4/¥16 per 1M**——推理模型，价格仅为 OpenAI o1 的约 **3%** [^16]
- **OpenAI o3-mini**（2025-01-31）：**$1.10/$4.40 per 1M**——OpenAI 历史上最便宜的推理模型，明显受到 R1 定价压力 [^17]
- **Claude 3.5 Haiku**（2024-10）：**$0.80/$4 per 1M** [^18]
- **Gemini 2.0 Flash**（2024-12）：**$0.10/$0.40 per 1M**；且提供慷慨的免费额度
- **GPT-4.5**（2025-02-27）：**$75/$150 per 1M**——在全员降价的大潮中，GPT-4.5 的定价是唯一的逆向行驶

GPT-4.5 的 $75/$150 定价揭示了一个深层矛盾：它比 GPT-4o（$5/$15）贵了 10-15 倍，但在大多数任务上并没有对应的 10-15 倍能力提升。此后不久，OpenAI 宣布 GPT-4.5 将于 2025 年 7 月停止服务——一个高价模型在价格战时代没有生存空间。[^19]

到 2025 年中，"免费"正在成为越来越多模型层的默认状态。除了 Google Gemini Flash 的免费额度外，DeepSeek 的免费 API、阿里通义千问的免费档、百度文心的免费服务、智谱 GLM 的免费 Flash——免费不再是一种营销手段，而是**基准能力的公共品化**。

## 七、价格战的本质：从稀缺到充裕，从溢价到成本定价

大模型 API 五年价格战，本质上是三件事的叠加：

**成本下降**：从 GPT-3 到 GPT-4o，MoE 架构（MLA、DeepSeekMoE）、FP8 训练、量化推理、Multi-Token Prediction 等工程创新将推理成本压缩了一到两个数量级。2020 年运一个 175B 密集模型做一次推理的成本，2025 年可以运一个 671B MoE 模型做 70 次推理。

**开源倒逼**：DeepSeek 的 MIT 开源是价格战的决定性催化剂。当一个 GPT-4o 级模型可以免费下载、本地部署、按边际成本推理，API 定价就不能再基于"这个能力值多少钱"，而只能基于"这个服务的边际成本加一点毛利"。V2 到 V3 到 R1，DeepSeek 每一步都在把定价往成本线推近。

**稀缺幻觉的破碎**：2020-2023 年，行业默认认为"前沿 AI 能力是稀缺的，因此可以溢价"。但这个逻辑有一个前提：前沿能力只能由少数公司提供。当 DeepSeek 证明了前沿能力可以用开源的方式、极低的成本提供，稀缺叙事就碎了。前沿能力不再是护城河——它们越来越像水电：重要，但不可溢价。

这就是为什么 GPT-4.5 的 $75/$150 定价显得如此刺眼。它不是"贵"，它是"还在用 2023 年的逻辑给 2025 年的产品定价"。在 2023 年，稀缺是真实的——只有一个 GPT-4。在 2025 年，可替代选项太多了。当一个 V3 或 R1 几乎免费可用时，$75/$150 不是豪华价格，是错误价格。

## 评曰

大模型 API 价格战的五年，可以用一句话概括：**能力在涨，价格在塌**。

这不是市场失灵，恰恰相反，这是竞争最健康的信号。2020-2023 年的高价不是"公平价格"，是稀缺条件下的卖方定价。2024-2025 年的低价不是"恶性竞争"，是成本下降和开源倒逼下的价值回归。每次价格崩塌，都有一个技术突破在背后——MoE、MLA、FP8、开源、纯 RL 推理——这些不是降价的理由，这些是降价的原因。

但有一个问题值得警惕：如果价格持续趋近于零，谁会继续投资做基座模型？价格战的终点不是"一切免费"——是"价值从模型层迁移到应用层"。模型越来越像水和电——不可或缺，但不可溢价。真正的价值会沉淀在模型之上：在针对性微调、在垂直场景的调优、在 Agent 系统的编排、在私域数据的利用。这不是坏事，但基座模型公司的投资人需要重新算账：当你的产品可能免费时，你的商业模式在哪里？

OpenAI 的 GPT-4.5 试图逆流而行——在一个免费模型层出不穷的时代要价 $75/$150。它的失败不是商业执行的失败，是历史方向的错误。价格战没有输家——有能力降价的活下来，没能力降价的被淘汰。输家只有那些还活在 2023 年的人。
