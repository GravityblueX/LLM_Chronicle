# 大模型价格战：从 Token 单价到“完成一项工作多少钱”

> 大模型 API 的价格确实经历过雪崩式下降，但“模型最终都会免费”并不是这段历史的终点。2026 年以后，价格体系反而变复杂了：便宜的 Flash / Luna 层继续塌价，旗舰和高完成率 Agent 重新获得溢价；缓存命中、推理 effort、Fast mode、batch、地域、峰谷时段都开始改变账单。价格战没有结束——**只是从“每百万 token 谁便宜”升级成“谁能用最低总成本把任务做完”。**

---

## 一、2020—2023：价格来自稀缺

GPT-3 API 的早期定价建立了一个非常直观的市场：模型越强，token 越贵。

最强 Davinci 的早期价格约为 $0.06 / 1K tokens，也就是约 $60 / 1M。[^1]

在 2020 年，这不是“暴利价格”还是“成本价格”的学术争论，而是稀缺价格：市场几乎没有同等可调用替代品。

**2023-03-01**，GPT-3.5 Turbo 把价格大幅降到 $0.002 / 1K tokens。[^2]

同月 GPT-4 又重新建立前沿溢价：输入 $30 / 1M、输出 $60 / 1M。[^3]

所以早期市场的默认规律是：

> **智能等级越高，价格等级越高。**

后来所有价格战，本质上都在破坏这条线性关系。

---

## 二、2024：DeepSeek V2 第一次把“能力溢价”撕开

DeepSeek-V2 的历史位置不只是便宜，而是它证明**相近能力可以来自完全不同的成本结构**。

MoE 与 MLA 让推理所需激活参数和 KV cache 大幅下降；DeepSeek 把这些工程收益直接反映到 API 定价。[^4]

随后中国市场出现密集降价：豆包、Qwen、文心、GLM 等快速跟进。

这改变了价格竞争的方向。

过去是“我比 GPT-4 弱一点，所以便宜一点”；V2 以后变成：

> **我可以和你处在相近任务能力区间，但便宜一个数量级以上。**

能力不再天然对应一个固定美元价格。

---

## 三、2024—2025：推理效率把价格继续向下推

GPT-4o、GPT-4o mini、Gemini Flash、DeepSeek V3 / R1 等型号不断降低“足够好”的调用成本。[^5][^6][^7]

尤其 DeepSeek-R1 把此前昂贵的 reasoning 模型拉入低价 / 开放权重竞争，迫使市场重新思考：推理 token 为什么必须是奢侈品？[^8]

这一阶段很容易得出一个看似合理的结论：

> 大模型最终会像水电一样，价格无限接近边际成本。

这个判断只对了一半。

**基础智能层确实在商品化；但任务本身也在变长、变复杂。**

聊天模型一次只回答几百 token；Agent 一项任务可能搜索几十次、运行代码几十轮、调用多个模型、持续数小时。

单位 token 更便宜，不等于一项工作更便宜。

---

## 四、为什么“每百万 token”开始失真

假设有两个模型：

- A：$0.20 / 1M 输入，成功率 40%，平均重试 3 次；
- B：$2 / 1M 输入，成功率 90%，一次完成，工具调用也更少。

即使 B 的标价贵十倍，最终任务总成本也可能更低。

Agent 负载里至少存在这些成本：

- input / output tokens；
- reasoning tokens / effort；
- cache write / cache read；
- web search；
- browser / computer use；
- code execution / sandbox；
- storage；
- 多 Agent 并行；
- retry；
- 延迟导致的人工等待；
- 人类审核。

所以真正应该比较的是：

> **Cost per successful completed task（每个成功完成任务的总成本）**

而不是孤立的 $/MTok。

## 五、2026：模型价格从一条线变成价格矩阵

### 5.1 GPT-5.6：同一家族内部同时做免费、降价和高端 premium

GPT-5.6 发布时形成 Sol / Terra / Luna 三层。

**2026-07-30**，OpenAI 将 Terra API 调整到约 $2 输入 / $12 输出每百万 token，Luna 降到约 $0.20 / $1.20；Luna 相较初始价格下降约 80%。[^9]

**2026-08-06**，Luna 成为 ChatGPT Free / Go 的默认文本模型，并扩展免费访问。[^10]

**2026-08-21**，Sol API / credits 又临时降价超过 20%；公开价从原 $5/$30 调整到约 $4/$20。[^11]

同一个 GPT-5.6 家族同时存在：

- 免费消费入口；
- 极低价 Luna；
- 中档 Terra；
- 高能力 Sol；
- 更高 compute 的 `ultra`；
- 更高速度的 Fast mode。

“模型价格”已经不再是一个数字，而是**能力、延迟和计算预算的曲面**。

### 5.2 Gemini 3.7 Flash：工作马主动打价格 / 性能比

**2026-08-13**，Gemini 3.7 Flash 以 $0.75 输入 / $3.75 输出每百万 token 的年内 introductory price 上线，Google 明确称其为原 3.6 Flash 初始价格的一半。[^12]

但 Google 强调的不只是价格，而是减少 manual oversight 和 retries。

这正是 Agent 经济学的新竞争语言：

> **贵不贵，要和需要重试多少次一起算。**

### 5.3 Claude Sonnet 5：中档模型吃掉上一代旗舰能力

Claude Sonnet 5 的最终价格固定为 **$2 输入 / $10 输出每百万 token**；Anthropic 同时提供 prompt caching、batch 等进一步折扣机制。[^13]

更重要的是，Anthropic 用 effort 设置展示同一个模型内部不同的 cost-performance 区间。

于是“Sonnet 是多少钱”也不再充分描述实际成本——同一个型号可以因为 effort、cache、batch 和任务复杂度产生完全不同的账单。

---

## 六、DeepSeek V4：最便宜的公司也开始卖旗舰溢价

如果价格战真的是一条永远向零的直线，那么最难解释的就是 DeepSeek 2026 年 8 月。

V4-Flash 曾以约 **$0.14 输入 / $0.28 输出每百万 token**成为著名低价模型之一。[^14]

但 **2026-08-13**，DeepSeek 正式发布 V4-Pro：约 **$1.32 输入 / $3.96 输出**，分别约为 Flash 的 9 倍和 14 倍。[^15]

这不是 DeepSeek 放弃低价路线，而是它承认：

> **更高 Agent 完成率可以重新产生能力溢价。**

同日 Reuters 还报道 DeepSeek 将 V4-Pro / Flash 引入**峰谷定价**，不同模型、token 类型和使用时段的涨幅差异很大。[^16]

这是大模型服务第一次越来越像传统计算基础设施：

- 高峰贵；
- 低峰便宜；
- 资源调度影响价格；
- 用户可以把非紧急 Agent 任务搬到便宜时段。

价格从模型属性变成**资源调度机制**。

---

## 七、缓存正在改变“输入 token”的含义

很多 Agent 会反复带着：

- 系统提示；
- 代码仓库索引；
- 工具定义；
- 长文档；
- 历史 context。

如果每一轮都按完整输入价重新收费，长程 Agent 成本会迅速爆炸。

因此 prompt / context caching 变成核心价格杠杆。

OpenAI GPT-5.6 的 cached input 价格显著低于普通输入；Anthropic 也公开宣传 prompt caching 可带来大幅成本节省。[^11][^13]

这意味着“1M 输入 token”已经分成两种经济对象：

- 新读取 / 新计算的 token；
- 可复用状态的 token。

缓存不是一个小优化，而是 Agent 商业化的条件之一。

---

## 八、Reasoning effort：计算预算开始显式商品化

o1 时代的推理模型已经让用户为更多 test-time compute 付费。

到 2026 年，这个机制从“选 reasoning model”进一步细化为**选 effort**。

Claude Sonnet 5、GPT-5.6 等产品都把推理投入做成可调节参数。[^9][^13]

于是定价逻辑变成：

> 同一个模型，不同问题值得投入不同计算预算。

这很像数据库 query planner 或云服务器 autoscaling：不是所有请求都要用最大规格。

模型厂商开始出售的不只是“一个模型”，而是**可动态分配的智能计算预算**。

---

## 九、Fast mode / Priority：延迟本身成为商品

对于后台研究任务，十分钟和一分钟可能区别不大；对于 coding loop、实时客服、交互式 UI，延迟可能比 token 价格重要。

GPT-5.6 的 Fast mode 就代表这种分层：同样的核心模型，用户可以为更快响应选择不同服务等级。[^17]

因此 API 定价开始越来越接近云计算：

- 普通实例；
- 高优先级实例；
- batch；
- cached；
- region-specific；
- peak/off-peak。

“模型 API”正在成为真正的计算服务，而不是简单的软件订阅。

---

## 十、免费没有消失，但它变成漏斗的底层

免费模型仍然越来越强。

GPT-5.6 Luna 进入免费用户，Gemini 保持开发者低成本 / 免费入口，开放权重模型也允许用户自行承担算力成本。[^10]

但这不意味着所有能力都趋向零价。

更准确的结构是：

| 层 | 价格趋势 | 商业作用 |
|---|---|---|
| 基础聊天 / 轻任务 | 接近免费 | 获客、规模与生态 |
| 高吞吐 workhorse | 持续降价 | 生产 Agent 主力负载 |
| 前沿专业能力 | 保留溢价 | 高价值任务 |
| ultra / fast / special access | 更高价格 | 时间敏感、极高难度任务 |
| open-weight self-host | 模型许可可免费 | 成本转移到 GPU、运维与工程 |

价格战不是把整张表压成零，而是把每一层重新定价。

---

## 十一、开放权重并没有消灭 API 生意

早期有一种判断：只要前沿模型开放权重，API 就只能按边际成本收费。

Kimi K3 / Qwen3.8 说明现实更复杂。

2T—3T 开放模型的权重可以免费获得，但高性能部署需要大型集群、推理工程和云容量。

因此开放权重可以同时催生：

- 自托管；
- 第三方托管；
- 原厂 API；
- 云市场；
- 专用推理服务商。

免费的是**复制权重的许可**，不是电、GPU、网络和工程。

大模型经济学因此出现类似开源数据库的结构：软件本身开放，托管服务仍然可以是大生意。

---

## 十二、从“模型多少钱”到“工作多少钱”

2023 年可以拿一张价格表比较模型：GPT-4 $30/$60，Claude 某型号多少。

2026 年更合理的预算表应该是：

| 指标 | 为什么重要 |
|---|---|
| input / output $/MTok | 基础推理成本 |
| cached input | 长上下文复用成本 |
| average output length | 强模型可能更短也可能更长 |
| effort / reasoning budget | test-time compute |
| task success rate | 失败会带来 retry |
| average tool calls | 搜索 / browser / code 额外成本 |
| latency | 人类等待与交互体验 |
| retry rate | 直接放大总成本 |
| parallel agents | 缩短时间但增加 compute |
| human review time | 常被忽略的最贵成本 |

最终单位应从：

> **$/1M tokens**

迁移为：

> **$/successful task**、**$/PR merged**、**$/research report delivered**、**$/case resolved**。

这才是 Agent 时代的价格战。

---

## 十三、评曰：价格没有归零，价格单位换了

大模型价格史最显眼的曲线当然是向下的。

2020 年一百万 token 是奢侈计算；2026 年轻量模型可以低到几毛美元，甚至被消费级订阅和免费层吞掉。

但如果因此断言“模型会像水电一样没有溢价”，就忽略了另一条同时发生的曲线：**模型正在承担越来越完整、越来越长的工作。**

一次 API 调用越来越便宜，一项 Agent 任务却可能包含一百次调用、十个工具、三个子 Agent 和半小时 sandbox。

DeepSeek V4-Pro 的高价回摆尤其说明问题：连最以低价著称的公司，也认为更高 Agent 能力可以对应明显溢价。

所以价格战真正摧毁的不是“所有模型价格”，而是**把能力等级直接映射到 token 单价的旧定价法**。

2026 年的新价格体系更像云计算：基础层极便宜，高阶层按性能收费，缓存、时段、优先级、地域和计算预算全部参与计价。

这也把竞争推进到更难的位置：

> 用户不再只问“哪个模型便宜”，而问“哪个系统能以最低总成本，把我的工作可靠做完”。

价格战没有结束。

它只是终于从卖 token，进入了卖**完成的工作**。
