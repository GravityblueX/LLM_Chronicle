# 推理经济学

> 训练一个前沿模型要花几千万到上亿美元——但这个成本是一次性的。推理一个前沿模型每天要处理数十亿次请求——这个成本是永续的。当模型训练成本趋于收敛、能力差异逐渐缩小时，AI 行业的竞争焦点正在从"谁能训出最好的模型"转向"谁能以最低的成本跑出最好的模型"。推理不再是训练的附属品——它是决定商业模式能否成立、AI 能力能否普及的生死线。

---

## 一、成本结构的翻转

大模型行业的经济学正在经历一场结构性翻转。

2023 年以前，行业关注的核心问题是训练成本——GPT-4 的训练成本估计在 1 亿美元量级，Meta 训练 Llama 3 405B 消耗了约 30.8M H100 GPU 小时。[^1] 能否训出前沿模型、是否有足够的算力去训，是决定公司生死的第一道门槛。

但到 2025-2026 年，训练成本的绝对值虽然仍在增长，其**相对意义**已经发生了根本变化。DeepSeek V3 用 2.788M H800 GPU 小时（约 557 万美元）训出了对标 GPT-4o 的模型——这个数字在 2023 年看来近乎不可能。[^2] 开源模型的蒸馏和微调进一步压低了"获得前沿能力"的准入门槛。训练一个前沿模型仍然昂贵，但不再是不可想象的昂贵。

与此同时，推理成本的规模在指数级增长。ChatGPT 在 2023 年初每天处理数亿次请求；到 2025 年，全球 LLM API 日调用量已达数百亿次量级。每一次请求都消耗 GPU 时间、显存和电力——这些是可变成本，随用户量线性增长。一个订阅用户如果重度使用，其月度推理成本可能远超订阅费本身。

这就是推理经济学的核心矛盾：**训练是固定成本，推理是可变成本。当模型数量和用户规模同时增长时，可变成本的总量将远超固定成本。**

推理成本因此成为决定哪些模型能活下来、哪些商业模式能成立、哪些 AI 能力能到达普通用户手中的关键变量。它不是技术细节——它是整个 AI 产业的地基之一。

## 二、1/370：推理成本的断崖

推理成本的下降不是线性的，而是断崖式的。

2020 年，GPT-3 Davinci 的 API 定价为 $60/百万 token（详见《大模型价格沿革表》）。[^3] 这个定价的逻辑不是成本，而是稀缺——当时只有一个可调用的 175B 参数 API，没有竞争者，用户没有议价权。

到 2026 年 4 月，DeepSeek V4 的 API 定价据报道仅为 GPT-5.5 的约 **1/370**。[^4] 六年间，最前沿模型的推理单价下降了约两个数量级——不是摩尔定律的速度，是雪崩的速度。

这个断崖背后有三根支柱。

**第一根支柱是架构效率。** DeepSeek 的 MLA（Multi-head Latent Attention）将 KV Cache 压缩到原来的 5%-10%——推理成本中"显存占用"这一项直接降低 90%（详见《推理优化志》《DeepSeek 世家》）。[^5] MoE 架构使 671B 总参数的模型在推理时只激活 37B 参数——前向传播的计算量降至密集模型的一小部分。[^2] MLA + MoE + FP8 三项叠加，使 DeepSeek 的推理成本结构比同性能的密集 Transformer 模型低一到两个数量级。

**第二根支柱是推理框架优化。** FlashAttention 把注意力的内存占用从 O(n²) 降到 O(n)。[^6] vLLM 的 PagedAttention 将显存利用率从 50%-60% 提升到 95% 以上。[^7] Continuous Batching 消除了传统批处理中短请求被长请求拖后腿的效率损失。推测解码（Speculative Decoding）用小模型草稿加大模型验证，把推理吞吐提升 2-4 倍且无损质量。[^8] 这些优化单独看都是"工程改善"，叠加在一起就是一到两个数量级的成本差异。

**第三根支柱是开源倒逼。** DeepSeek V3 开始全面采用 MIT 许可证开源——任何人可以下载权重，在自己的服务器上按边际成本运行。[^2] 当一个 GPT-4o 级模型可以免费部署，API 定价就不能再基于"这个能力值多少钱"，而只能基于"服务的边际成本加一点毛利"。开源模型的存在，把整个行业的定价逻辑从"能力溢价"压向了"成本定价"。

三项支柱叠加的结果是：推理成本以远超硬件摩尔定律的速度在下降。每一年，同等能力的模型推理成本都比上一年低一个数量级。而这个趋势——至少在 2026 年——还没有减速的迹象。

## 三、推理芯片：专用硬件的崛起

推理成本的下降不仅来自软件优化——硬件层面也在发生根本性变化。

传统上，大模型推理运行在通用 GPU 上——主要是 NVIDIA 的 A100 和 H100/H200。这些 GPU 设计时兼顾训练和推理，但在纯推理场景下存在结构性冗余：训练需要的高精度计算单元、大规模互联、大容量 HBM 在推理时利用率偏低。

2024-2025 年，一批专注于推理的芯片公司开始崭露头角：

**Groq** 由前 Google TPU 架构师 Jonathan Ross 创办，开发了 LPU（Language Processing Unit，语言处理单元）。[^9] LPU 的核心特点是**确定性执行**——没有缓存未命中、没有分支预测失败、没有内存访问随机延迟，每一步计算的时间都是确定的。这使得 LPU 在推理场景下可以实现极低的延迟和极高的吞吐量。Groq 在 2024-2025 年多次展示了在 Llama 模型上的推理速度记录——token 生成速度比同规模 GPU 部署快一个数量级。[^9]

**Cerebras Systems** 采取了更激进的路线——**晶圆级引擎**（Wafer-Scale Engine, WSE）。[^10] 它不是把芯片做得更小，而是把一整块晶圆做成一个芯片——WSE-2 拥有 850,000 个计算核心和 2.6TB 的片上 SRAM。Cerebras 在 2025 年展示了基于 WSE 的推理性能，在特定场景下的吞吐量远超 GPU 集群。[^10]

**NVIDIA** 并没有坐视。H200 增加了 HBM 容量（141GB），B100/B200 进一步提升推理效率。NVIDIA 的护城河不仅在硬件——更在软件生态：CUDA、TensorRT-LLM、Triton 推理服务器，这些构成了开发者无法轻易迁移的锁定效应。[^11]

推理芯片的竞争格局在 2026 年初渐趋清晰：NVIDIA 仍然是默认选择，但在大规模推理部署中，Groq 和 Cerebras 的专用方案开始进入视野——尤其在延迟敏感和吞吐密集的场景中。推理硬件的多样化意味着推理成本的下降不会只靠软件优化——硬件本身的进化也在加速这个过程。

## 四、商业模式之争：按 token 与订阅制

推理成本的变化正在重塑 AI 产品的商业模式。当前存在两种主流模式——按 token 计费和订阅制——它们代表了两种截然不同的经济逻辑。

**按 token 计费**（API 模式）是面向开发者的定价方式。用户按实际消耗的 token 数量付费，价格透明、弹性可控。OpenAI API、DeepSeek API、Google Gemini API、Anthropic Claude API 都采用这种模式。[^12]

按 token 计费的优势在于**与成本直接挂钩**：提供商的收入与推理消耗成正比，定价可以精确反映推理成本。劣势在于**需求不确定性**：用户可能因成本不可预测而犹豫使用，尤其在长对话、大批量处理等场景下。DeepSeek 的策略是将按 token 价格压到极低——当 API 价格仅为竞品的 1/370 时，用户的成本焦虑几乎消失。

**订阅制**（ChatGPT Plus $20/月、Claude Pro $20/月等）面向终端用户。[^13] 用户支付固定月费，获得一定额度的模型使用权。

订阅制的优势在于**收入可预测**：每月用户数 × 月费 = 稳定的收入流。劣势在于**成本与收入脱钩**：重度用户每月消耗的推理资源可能远超 $20——据报道，GPT-4 初期 OpenAI 的 $20 订阅费是亏本的。[^13] 轻度用户则为重度用户补贴了成本。

推理成本的下降正在改变这个平衡。当推理成本足够低时，订阅制的"重度用户亏本"问题自然消解——每个月 $20 的推理成本可以支撑大量的使用量。这就是为什么推理优化不仅仅是一个技术问题——它决定了"20 美元无限使用"这个用户体验是否可持续。

2025-2026 年出现了一种混合趋势：多家公司同时提供订阅制和 API 按量计费，让用户按需选择。OpenAI 的 ChatGPT Plus/Pro/Enterprise 对应不同层级的订阅，同时 API 服务面向开发者。DeepSeek 提供极低价的 API，同时面向终端用户免费。[^4] 这种双轨并行不是妥协——是推理成本下降后自然出现的最优解。

## 五、推理经济学的深层逻辑

推理经济学不仅仅是"谁更便宜"——它揭示了 AI 产业的一个深层结构性变化。

**能力趋同是推理成本竞争的前提。** 2023 年，GPT-4 和其他模型之间存在明显的质量差距——用户愿意为更好的模型支付溢价。到 2025-2026 年，GPT-5.5、Claude 4、Gemini 3.x、DeepSeek V4、Qwen 3 在多数任务上的差距已经缩小到 5%-10% 以内。当能力差距缩小时，价格差距就成了决定性因素——"便宜 370 倍且能力差距在 10% 以内"比"贵 370 倍但好 10%"在大多数商业场景中更有说服力。

**推理成本决定 AI 的普及速度。** 从 2020 年 $60/百万 token 到 2026 年不到 $0.10/百万 token——推理成本每降低一个数量级，可触达的用户群就扩大一个数量级。在 $60 的时代，AI 是精英研究机构的工具。在 $0.10 的时代，AI 可以嵌入每一个应用、每一个设备、每一次交互。推理优化的终极意义不在于"更便宜"——而在于"更多人可以用"。

**价值从模型层迁移到应用层。** 当推理成本趋近于零，基座模型本身的商业价值将被压缩——它越来越像水电：不可或缺，但不可溢价。真正的价值将沉淀在模型之上：在针对性微调、在垂直场景的调优、在 Agent 系统的编排、在私域数据的利用。DeepSeek 可以把 API 定到 1/370 是因为它不靠 API 赚钱——但依赖 API 收入的公司必须回答：当模型本身可能免费时，你的商业模式在哪里？[^14]

这不是坏事。推理成本的下降是 AI 民主化的真正推动力——FlashAttention、MLA、FP8、PagedAttention 这些"工程技术细节"，是让更多人能用到 AI 能力的底层基础设施。历史上的每一次技术普及——电力、互联网、移动通信——都伴随着核心成本的数量级下降。AI 的推理成本曲线，正在重复这个模式。

## 评曰

推理经济学的故事，可以用一句话概括：**从"模型值多少钱"到"推理花多少钱"。**

2020 年，行业默认前沿 AI 能力是稀缺的，因此可以溢价。这个假设在 2023 年之前是成立的——只有一个 GPT-4，没有替代品。但 2024 年 DeepSeek V2 的 MLA 架构证明了推理成本可以降低 90%；2024 年 V3 的 $5.6M 训练成本证明了前沿能力不是天价；2025 年 R1 的 MIT 开源证明了最好的推理模型可以免费获得。每一步都在把"稀缺"叙事推向瓦解。

到 2026 年，GPT-5.5 定价 $130/百万 token 而 DeepSeek V4 定价约 $0.35/百万 token——370 倍的价差已经不是"好一点所以贵一点"，而是两种完全不同的成本结构在碰撞。OpenAI 仍在用 2023 年的稀缺逻辑给 2026 年的产品定价。DeepSeek 用 2026 年的成本结构给 2026 年的产品定价。历史告诉我们，这两种逻辑碰撞时，后者的赢面更大。

但推理经济学的终局不是"一切免费"。免费的水也需要管道、水厂、维护。推理芯片（Groq、Cerebras）的崛起说明——即使推理成本趋近于零，"零成本地把推理送到用户手中"本身仍然有价值。推理经济学的终局是：**模型层成为基础设施，价值上移到应用层和分发层。** 就像互联网时代，TCP/IP 协议免费但 Google 值万亿——不是因为协议不重要，而是因为协议之上的应用更有价值。

对基座模型公司而言，这既是威胁也是机会。威胁在于——如果模型本身不能溢价，那么纯靠模型 API 收入的商业模式将不可持续。机会在于——如果推理成本足够低，AI 可以渗透到每一个之前因成本而无法触及的场景。更大的市场，更低的单价——这不一定是更坏的生意，但一定是一个不同的生意。
