# 开源模型的经济学

> 2023 年初，一个 65B 参数的 Llama 模型被上传到 4chan。三年后，Meta、DeepSeek、阿里正在用开源模型重塑 AI 产业的商业逻辑。开源模型从"威胁"变成"战略"，不是因为它变得更慷慨了——而是因为经济学逻辑变了。

## 一、开源曾经是威胁

在 2022 年之前，"开源"在 AI 领域有两个截然相反的叙事。一个是学术界的——TensorFlow、PyTorch、BERT 都是开源的，开源是科学进步的自然方式。另一个是商业界的——开源意味着把价值拱手让人，闭源才是商业可持续的。

这个叙事在 Llama 1 泄漏事件（2023 年 2 月）中被撞了一下。Meta 向经审批的研究人员提供 Llama 1 的权重，四天后全部权重被上传到 4chan 和 BitTorrent。[^1] 一个商业公司试图用学术分发模式控制一个巨大商业价值的模型——而互联网按照自己的逻辑把它变成了公共产品。

但真正有价值的不是泄漏本身，而是泄漏后的连锁反应。全球开发者基于 Llama 1 构建了 Alpaca（Stanford, $600 微调）、Vicuna（Berkeley）、GPT4All 等数百个微调版本。一个 13B 的"小模型"在多数基准上超越了 175B 的 GPT-3——这个事实本身揭示了 Chinchilla 缩放定律的核心主张。[^2] 但它同时揭示了一个更深的事实：**开源模型一旦进入互联网，就不再属于原公司。** 社区会把它拆开、重组、微调、量化、部署到各种奇奇怪怪的设备上。而这些派生工作累积起来的价值，可能比原始权重的发布者想象的更大。

这才是"开源作为威胁"的真实含义。不是开源模型本身的技术威胁——一个开源 65B 模型不可能在能力上直接威胁 175B 的 GPT-3。而是**开源模型创造了一个不可控制的生态**。社区做的微调、量化、工具链、硬件适配，都在降低模型的准入门槛。当准入门槛降到一定程度，闭源 API 的"独家能力"就开始贬值。

## 二、Llama 2 的分水岭：从威胁到战略

Meta 在 2023 年 7 月发布的 Llama 2 是一个真正的转折点。[^3] 它做了三件事：

1. **允许商用**。这是第一个明确允许商用的开源大规模语言模型。此前 Llama 1 的许可仅限于研究用途。
2. **与 Microsoft Azure 合作分发**。微软同时押注 OpenAI（闭源）和 Meta（开源）。
3. **Zuckerberg 发表事实上的"开源宣言"**（2024 年 7 月正式发布）：Meta 不靠模型赚钱，开源可以削弱竞争对手的护城河。[^4]

这第三条是最关键的。它把开源从"被迫的技术扩散"变成了**主动的商业策略**。

Zuckerberg 的逻辑是这样的：如果 OpenAI、Google 和 Anthropic 是唯一拥有最先进模型的玩家，它们会建立难以逾越的护城河——通过堆积更多的算力、更强的模型、更高的定价。但如果出现了一个强有力的开源竞争者（哪怕是第二强的），它的存在本身就是对闭源护城河的永久威胁。开发者有了替代选择，企业有了谈判筹码，用户有了退出权利。LLaMA 的存在不会让 Meta 直接赚钱——但它可以防止任何闭源公司垄断 AI 市场。

这个逻辑的本质是：**开源模型是 AI 市场的反垄断工具。** 它的商业价值不在模型本身，而在它创造的市场结构。Linux 在服务器市场、Android 在移动市场、Chromium 在浏览器市场——都是这个逻辑的经典应用。

## 三、DeepSeek 的激进开源：成本优势 + MIT 许可证

如果 Llama 系列是把开源从威胁变成战略，那么 DeepSeek 就是把这种战略推到了极致。

DeepSeek-R1 在 2025 年 1 月 20 日发布，采用 MIT 许可证完全开源——包括模型权重、训练技术和思维链输出。[^5] 这不是 Llama 式的"开放权重但有限制"，而是"真正自由的开源"。

但开源本身不是 DeepSeek 的核心武器。开源是放大器。真正的武器是**成本优势**。

DeepSeek-V2（2024 年 5 月）的 API 价格定为 GPT-4 Turbo 的约 1%。DeepSeek-V3（2024 年 12 月）的训练成本仅为约 557 万美元——GPT-4 训练成本的 6%。DeepSeek-R1 的 API 输出价格仅为 o1 的约 3%。DeepSeek-V4（2026 年 4 月）的价格被第三方报道为 GPT-5.5 的约 1/370。[^6]

把"MIT 开源"和"1/370 的价格"放在一起，产生的就不是技术竞争——而是**经济结构的重构**。

MIT 开源意味着任何人都可以下载权重，在自己的服务器上运行，不需要付费。1/370 的价格意味着即使你选择付费 API，成本也低到几乎等于带宽费。两者叠加的效果是：**使用闭源模型的经济理由在大幅缩水。** 如果你的应用不需要当前绝对最强的那一点性能差距，你没有任何理由继续使用闭源 API。而大多数商业应用确实不需要那一点性能差距——它们需要的是可靠、便宜、可定制的模型。

这就是 DeepSeek 对闭源商业模型的结构性威胁。它不是靠"更好的模型"竞争——它是靠"好到足够强，同时便宜到让闭源的经济模型失效"来竞争。

## 四、阿里的双轨策略：开源抢社区，闭源抢收入

阿里在 2023 年 4 月发布通义千问后，同年 8 月发布了 Qwen 开源系列（7B/14B/72B），此后 Qwen 2（2024-06）、Qwen 2.5（2024-09）、Qwen 3（2025-04）持续迭代，覆盖从 0.5B 到 235B 的全谱系。[^7] Apache 2.0 许可。

阿里的策略和 DeepSeek 不同，和 Meta 也不同，但三者的结合构成了开源模型经济学的三种模式：

| 公司 | 开源动机 | 收入来源 | 开源程度 |
|------|----------|----------|:--:|
| Meta | 削弱闭源护城河 | 社交网络广告 | 开放权重，有限制许可 |
| DeepSeek | 扩大生态覆盖（+ 不需要靠 AI 赚钱） | 量化交易基金 | MIT，完全开源 |
| 阿里 | 社区生态 + 云基础设施绑定 | 阿里云 | Apache 2.0 |

Meta 的策略是"低程度开源 + 广泛分发"——不靠开源赚钱，开源是护城河的破墙锤。DeepSeek 的策略是"高程度开源 + 极低成本"——不靠 AI 赚钱，开源是生态的放大器。阿里的策略是"中等程度开源 + 商业双轨"——开源抢社区，闭源抢收入。

这三种模式在 2023-2026 年间共同定义了一个经济学事实：**在大模型领域，开源不再是理想主义，而是经过精密计算的商业策略。**

## 五、开源的经济学原理：从边际成本到退出权

如果把开源模型的经济学浓缩到几个核心命题，大概是这样的：

**第一，开源改变边际成本结构。** 训练一个大模型需要巨额固定成本（算力、数据、人才），但一旦训练完成，分发模型权重的边际成本趋近于零。闭源 API 的商业模式是在固定成本之上叠加每次调用的边际收入——靠每次 token 生成收费来摊销训练成本。开源模型打破了这种摊销结构：它把固定成本当作沉没成本，把分发成本降到零附近，让整个行业的经济账目变得无法解释——为什么 o1 每月要收 $200 订阅费，而 MIT 开源的 R1 可以免费使用？

**第二，开源创造网络效应。** 一个开源模型的用户越多，微调、工具链、文档、部署方案就越多——生态越繁荣，下一个用户越有理由选择它。这种网络效应和闭源的产品生态（如 ChatGPT 的插件市场）是镜像的：一个靠开放标准运转，一个靠平台锁定运转。前者更难被任何一个行为体垄断。

**第三，开源提供退出权。** 这是最重要的一点。当一个企业使用闭源 API 时，它的技术栈绑定在供应商的定价、可用性、政策和服务条款上。如果供应商涨价、断供、变更条款、或受到出口管制——企业没有替代方案。使用开源模型，企业拥有权重本身。它可以迁移到任何云、任何硬件、任何部署环境。这种"退出权"在 2025-2026 年的"318 事变"中从理论问题变成了实践问题——当御三家集体收紧中国地区的 API 访问时，拥有开源模型的企业可以平滑过渡，没有的企业被一夜锁死。[^8]

"退出权"这个概念来自政治经济学——Albert Hirschman 的退出、发声与忠诚框架。在大模型经济中，它是最被低估的资产。退出权不是"现在就用开源替代闭源"——而是"如果（when）闭源不行了，你有路可退"。它降低了闭源供应商对市场的定价权——因为你的客户随时可能离开。

## 六、开源不会消灭闭源——但会让闭源必须解释自己的价值

开源模型不会让闭源模型消失。前沿能力的争夺仍然需要巨大的训练预算，而训练预算需要回收——闭源 API 是最直接的回收管道。企业级 SLA、安全合规、产品集成、品牌信誉——这些都是开源难以替代的。

但开源模型改变了权力结构。在 Llama 1 之前，闭源模型的唯一替代是使用更弱的模型，或者自己训练——两者都不现实。Llama 之后，开源模型成了一个切实可行的备选方案。DeepSeek-R1 之后，开源模型在某些任务上甚至和闭源模型打平或超越。2026 年的现实是：**如果一个场景不需要绝对最强的 SOTA，开源模型几乎总是更优的经济选择。**

这迫使闭源公司回答一个问题：你的溢价值吗？以前闭源不需要回答这个问题——因为没有可比的替代品。现在有了。而一旦溢价需要被证明，闭源公司的利润率就会从垄断性向竞争性收缩。

这不是"开源 vs 闭源"的道德之争。这是经济学。开源模型不是免费午餐——它的训练成本来自不靠 AI 赚钱的商业模型（Meta 靠广告，DeepSeek 靠量化基金）或来自生态锁定（阿里靠云）。但无论在哪种模式下，开源都在重新分配 AI 能力的定价权——把它从少数闭源公司的手中推向更大的开发者群体。

## 评曰

开源模型的经济学史，可以浓缩成一句话：**它从意外泄漏开始，以重新定义市场竞争规则结束。**

Llama 1 的 4chan 泄漏是意外。Llama 2 的商用许可是战略。Llama 3.1 的 405B 和开源宣言是宣言。DeepSeek-R1 的 MIT 开源是极限压力测试——"如果我最强，但我仍然开源，那么闭源的正当性还剩多少？" Qwen 3 的全谱系开源是生态建设——"我不只要最强的模型，我要覆盖每一个部署场景。"

这个进程中有一个非常清晰的趋势：**开源模型每一次迭代，都在降低"不开源"的道德合法性。** 当 Llama 3.1 证明"开源可以接近前沿"，闭源被质疑的是能力壁垒。当 DeepSeek-R1 证明"开源可以在推理上比肩 o1"，闭源被质疑的是独占的必要性。当 Qwen 3 证明"开源可以覆盖全谱系"，闭源被质疑的是生态覆盖的不可替代性。

但该说的另一句话也要说：开源模型没有解决训练的版权问题，没有解决训练数据的透明问题，没有解决模型滥用的安全问题。Meta 的"开源宣言"被 Llama 4 的评测争议戳穿。[^9] DeepSeek 的"MIT 开源"背后是一个不需要靠 AI 赚钱的量化基金——这个前提是任何其他公司都不具备的。阿里的"双轨"是最稳健的策略，但它在技术前沿上一直比最顶尖的闭源模型差半步。

开源模型的真正意义不在道德高地——而在于它给了用户**选择权**。在一个被少数闭源公司主导的市场里，选择权本身就是最稀缺的资源。
