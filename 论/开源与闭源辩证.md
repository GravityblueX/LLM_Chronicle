# 开源与闭源辩证：开放权重作为商业策略的三种面孔

> 大模型行业里喊"开源"最多的几家公司，没有一家是纯粹为了开源理想在做事。Meta 喊开源是为了削弱竞争对手的护城河，Mistral 喊开源是为了敲开企业市场的门，DeepSeek 喊开源是为了打破闭源公司的叙事垄断。"开源"在传统软件世界是许可证问题，在大模型世界是商业策略问题。这篇论分辨三种把"开放"当武器的打法——不是批评，而是拆解，因为策略比口号更有史学价值。

## 一、"开源"三层皮：为什么这个词在大模型时代不够用

传统软件的开源很简单：代码公开、自由使用、自由修改、自由分发。OSI 守了几十年这套定义，边界清楚。

大模型把这件事搅浑了。一个模型放出来，可能同时存在三种不同层面的"开放"：

- **权重开放**：你可以下载 `.safetensors` 或 `.gguf`，部署、量化、微调——但不知道训练数据是什么、训练代码怎么写；
- **代码开放**：训练脚本、推理代码、评测流水线公开——但权重不一定给你；
- **数据开放**：训练数据的来源、构成、筛选方式披露——但不等于每条原文都给你。

Meta、Mistral、DeepSeek 三家都只走到了第一层或第一层半：开放权重为主，辅以部分代码和论文，但训练数据的完整配方从来不是他们的承诺。OSI 2024 年发布的 Open Source AI Definition 1.0 试图纠正这一点——它要求"首选修改形式"包括数据、代码、参数三要素。但这个定义目前对行业几乎没有约束力：每一家都继续用"开源"做市场语言，却没有人真正递交 OSI 认证。[^1]

这恰好说明问题不在"谁更诚实"，而在"开源"这个词在大模型时代已经不够用了。我们需要换一个问法：**每一家为什么开放、开放到什么程度、留了什么后手**。正是这三个问题，区分出三种不同的商业策略。

## 二、Meta：把事故包装成战略，用开放建平台

LLaMA 最开始不是故意开放的产物。2023 年 2 月 24 日，Meta 将 LLaMA 论文和权重发放给经审批的研究者，没有打算面向公众分发。但发布后不到两周，权重经 4chan 和 BitTorrent 泄漏，进入了不可回收的公共网络。[^2][^3]

接下来的四个月很关键。泄漏不是 Meta 主动制造的，但 Meta 观察到的现象是：社区立刻围绕 LLaMA 建起了完整的下游生态——Alpaca、Vicuna、LoRA 微调、本地量化、llama.cpp。这个生态不是 Meta 建的，却靠着 LLaMA 活着。而 OpenAI 和 Google 的闭源模型没有任何类似的社区扩散效应。

四个月后，Meta 做出了一个战略选择。**2023 年 7 月 18 日**，Llama 2 发布。与前身不同，Llama 2 明确允许商用，只对月活超 7 亿的服务保留许可审批权。[^4] 这个限制对绝大多数企业没有影响——只有 Google、Apple、Amazon 级别的平台才需要额外申请。

再过一年，**2024 年 7 月 23 日**，Llama 3.1 发布，旗舰模型 405B 参数，能力接近闭源前沿。同日，Mark Zuckerberg 发表《Open Source AI Is the Path Forward》，把开放路线解释为类似 Linux 的基础设施策略：开放创造生态，生态降低供应商锁定，反锁定削弱对手。[^5][^6]

Meta 的逻辑链条是清楚的：

1. Meta 不靠卖模型赚钱——它的收入来自广告；
2. 因此 Meta 不怕模型免费扩散，反而怕模型被一两家闭源公司垄断；
3. 如果 Anthropic 或 OpenAI 的闭源模型成为行业唯一标准，Meta 的社交和广告业务会受制于人；
4. 所以 Meta 的最优策略不是做最强模型，而是把"足够好"的模型免费分发给所有人——让闭源公司的定价权被削弱；
5. 限制大平台使用（7 亿 MAU 门槛）则是最后一道防线：防止竞争对手直接用 Llama 建起比 Meta 自己的产品更强的平台。

这就是为什么说 Meta 的"开源"是战略武器，不是道德选择。它的开放程度——权重开放但数据不公开、训练代码不完整——完美匹配它的战略目标：给开发者足够的工具来削弱闭源公司，但保留足够的黑箱来防止别人全面超越 Meta 自己。

## 三、Mistral：用 Apache 2.0 敲开企业门，关起门来卖更好的

Mistral AI 的策略比 Meta 更精密。它不喊"开源是基础设施"这种宏大叙事，而是用三样东西精确地组合攻击：

1. **宽松许可**：Apache 2.0——商业使用零限制，不需要额外申请；
2. **小模型大能力**：Mistral 7B（2023-09-27）在多项基准上超过 Llama 2 13B，Mixtral 8x7B（2023-12-11）用 MoE 设计在性能上接近 Llama 2 70B 但推理快六倍；[^7][^8]
3. **闭源产品线并行**：Mistral Large、Le Chat 等服务在开放权重模型之外独立运营，以 API 形式收费。

这个组合的妙处在于：开放权重模型负责建立口碑和生态——开发者用 Mistral 7B 做项目、写教程、建工具，企业做 PoC 验证可行性；而真正赚钱的、能力更强的、有服务保障的模型，走的是闭源 API。Apache 2.0 是入场券，入场之后的深度合作、高并发调用、企业级 SLA，都不是免费的。

Mistral 把这种策略玩得坦率：2024 年，当记者问 CEO Arthur Mensch 是否所有模型都会开源时，他的回答大致是——我们会在可以开源的地方开源，但这不意味着所有模型都必须开源。这和 Meta 的"开放战略主义"不同，Mistral 不是想把开源当武器去打别人，而是把开源当渠道来卖自己。

对行业来说，Mistral 的启示是：**开放权重不必是"全开"或"全闭"的二选一**。一家公司完全可以同时拥有开放权重模型和闭源 API 模型，二者不矛盾——前者获取生态和声誉，后者获取收入和深度关系。

## 四、DeepSeek：MIT 许可证是一颗逻辑炸弹

DeepSeek 的策略是最激进的，也是最需要从地缘角度理解的。

**2025 年 1 月 20 日**，DeepSeek 发布 R1。R1 不只是又一个开放权重模型：它附带 MIT 许可证——在大模型主流许可中最宽松的一类，允许任何用途，包括商业使用、修改和再分发，只需要保留版权声明。[^9][^10] 同时发布的还有完整论文、R1-Zero 的训练方法、6 个蒸馏小模型，以及最重要的——**可观察的思维链**。

把这几件事放在一起看，DeepSeek 打的是一套组合逻辑：

1. MIT 许可证意味着任何公司——包括 OpenAI、Google、Anthropic 的竞争对手——都可以拿 R1 去微调、蒸馏、商用，不受限制。相比之下，Llama 的 7 亿 MAU 门槛限制了超大平台；
2. 公开论文和训练方法意味着学术界和竞争团队可以复现、改进、验证。R1-Zero 用纯粹的强化学习加规则奖励就发展出推理行为——这是以前只有闭源实验室才敢声称的能力；
3. 可观察思维链意味着外部可以检查模型"在想什么"——直接挑战了 o1 把推理过程藏起来的做法。这不仅是能力竞争，更是信任机制的竞争。

DeepSeek 不是在做慈善。它的战略语境和 Meta、Mistral 完全不同：作为一个中国 AI 实验室，DeepSeek 面临美国芯片出口管制的限制，H800 的能力远不如 H100。在这样的约束下，"做最大的模型"不是最优路线。"做最开放的顶级模型"却是——因为开放可以绕过管制的叙事逻辑：你禁我的芯片，但我做出来的模型全世界都能用，而且用的是 MIT 许可，你没法禁止你的开发者去下载。

这不是阴谋论。把 R1 的发布形式和时机（o1 发布四个月后、美国 AI 政策辩论激烈期）放在一起看，R1 的历史位置就很清楚了：它不是追赶，是打断。打断了"前沿推理能力必须是闭源美国公司产品"的默认假设。MIT 许可证的意义不在于授权了什么，而在于让这个打断不可撤销——任何人一旦下载，能力就永远在公共领域。

## 五、三条路线的共同 DNA

Meta 用"开放"打平台战，Mistral 用"开放"做渠道，DeepSeek 用"开放"拆围墙。三家策略不同，但有三条共通的底层逻辑：

**第一条：没有一家开放了全部。** 三家都没有公开训练数据的完整清单和筛选细节；Meta 和 Mistral 没有公开训练代码；DeepSeek 虽然公开了论文和方法，但训练流程是否完全可以由外部复现仍存疑问。它们开放的都是"足够多"——足以建立生态和信誉，不足以让别人完整复制自己的核心优势。

**第二条：开放的程度和公司的商业模式直接挂钩。** Meta 不卖模型，所以敢放权重；DeepSeek 不走闭源 API 路线为主，所以 MIT 许可不影响其核心收入（如果有的话，更多是关注度和生态地位）；Mistral 有闭源产品线，所以它的开放是限量版的——够用，但最好的还是要付费。

**第三条：用户获得了退出权。** 这是三条路线客观上共同推动的最真实的进步。不管每一家出于什么动机，结果是：开发者不再只有一个 API 供应商可选。他们可以在 Llama、Mistral、Qwen、DeepSeek 之间切换和组合，可以对模型做本地微调，可以在断网环境下部署。退出权不等于免费——迁移有成本、调优要人力、推理要硬件——但退出权存在这件事本身，就改变了供应商和用户之间的权力关系。

## 评曰

大模型的开源不是道德剧，不是某一天一群理想主义者决定对抗商业巨头的故事。它是商业计算穿了一件开源的外套——外套是真的，里面的算盘也是真的。

Meta 把 LLaMA 泄密事件扭转为生态战略，Mistral 用 Apache 2.0 开门、关门卖更好的，DeepSeek 用 MIT 许可拆掉"前沿推理能力必须闭源"的围墙——三家没有一家是"为了开源本身"，但三家共同做了一件事：让大模型的可获得性从一两家公司的 API 端点，扩散到了全世界的硬盘上。

史官记这一笔，不为赞美，不为批判，只为区分——区分"开源"这个词在不同公司嘴里到底是策略、是渠道、还是炸弹。一个词被用得越滥，就越需要拆开看。拆开之后真相并不坏：商业策略如果恰好推动了公共能力扩散，它仍然值得被记录。只是别把策略写成理想，也别把理想当成已经发生的现实。
