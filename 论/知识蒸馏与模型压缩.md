# 知识蒸馏与模型压缩

> 知识蒸馏是大模型史中最安静的技术主线。它不制造新闻头条，不炸掉股市市值，不卷入地缘政治——直到 Anthropic 在 2026 年 2 月用"蒸馏攻击"把这项 2015 年的老技术推到国家安全的风口上。从 Hinton 实验室的朴素想法到 DeepSeek-R1 的工业化蒸馏流水线，知识蒸馏走过的路，是一部"同样的数学，不同的罪名"的实录。

## 一、Hinton 的蒸馏：一个没有专利的朴素想法

2015 年，Geoffrey Hinton、Oriol Vinyals 和 Jeff Dean 在 arXiv 投稿了一篇题为《Distilling the Knowledge in a Neural Network》的论文。[^1] 想法极其朴素：一个大模型（称为 teacher）的 softmax 输出不是只有"正确答案"这一个信息——它在所有错误选项上的概率分布，也包含了 teacher 对各个选项之间相似性和区分度的"暗知识"。如果让一个小模型（称为 student）去拟合 teacher 的完整概率分布，而不是仅仅拟合训练数据的 one-hot 标签，小模型就能学到比原始训练数据更丰富的结构。

这个想法的重要之处不在于它的数学深度——softmax 加温度参数、KL 散度作为损失函数，机器学习领域的基础操作——而在于它改变了一个默认假设：**训练信号不一定只能来自标注数据，也可以来自另一个模型。**

在 Hinton 的文章中，这是纯粹的学术探索。它解决的问题是"怎么把一个大模型塞进手机里"，而不是"怎么从别人的模型里窃取能力"。论文的标题用词是"distilling"——从大模型中蒸馏出知识，就像从溶液中蒸馏出精华。这个隐喻本身就暗含了"大模型中的知识是精炼过的、浓缩的"这一前提。

此后十年，知识蒸馏在图像识别、语音识别、NLP 中被广泛应用。从 ResNet 到 BERT 再到 GPT，只要你想把一个巨无霸模型推向边缘设备，蒸馏几乎是必由之路。它和量化、剪枝、低秩分解一起，构成了模型压缩的三件套。在这个阶段，蒸馏是"工程优化"——没有人觉得它有什么道德问题。

## 二、蒸馏进入大模型时代：从压缩到迁移

进入 Transformer 时代后，蒸馏的角色悄然扩大。在 BERT 时代（2018-2019），DistilBERT 用蒸馏将一个 340M 的 BERT-base 压到了 66M，保留了 97% 的下游任务性能。[^2] 这仍然属于"部署优化"的范畴。

但到了 2023-2024 年，蒸馏开始承担另一个角色：**能力迁移**。用高质量的大模型输出，去训练高质量的小模型。

DeepSeek-R1 在 2025 年 1 月的发布中，除开源 660B 的主模型之外，同时发布了 6 个蒸馏小模型（1.5B 到 70B 参数）。[^3] 这不是"压缩"——这是**知识迁移**。DeepSeek 用 R1 的推理链输出作为教师信号，去微调 Qwen 和 Llama 系列的小基座模型，让这些小模型在数学和编程任务上直接超越 OpenAI o1-mini。一个 32B 的蒸馏模型，达到甚至超越了 660B 主模型 70% 以上的推理能力——这在 Hinton 的原始论文框架下，属于正常的蒸馏效应。

但蒸馏在这里发生了一个微妙的变化：teacher 模型的"暗知识"在常规任务上是概率分布的细微结构——而推理模型（如 R1、o1）的"暗知识"是**思维链本身**。蒸馏一个推理模型，等于蒸馏它的思考方式，而不只是它的答案。

这引出了蒸馏在大模型时代的核心二元性：**蒸馏可以是一种教学，也可以是一种复制。**

- 如果你蒸馏自己的模型——让大 R1 教小 Qwen，这是教学。
- 如果你蒸馏别人的模型——用 API 输出去微调自己的基座模型，这就是复制。

两者的数学操作完全相同。唯一的区别是 teacher 模型的来源。而这个区别在法律和道德上都没有清晰的边界——Hinton 从未为蒸馏申请专利，这项技术不属于任何人。

## 三、蒸馏攻击：2026 年 2 月的一场风暴

2026 年 2 月 23 日，Anthropic 公开指控三家中国 AI 公司——DeepSeek、月之暗面（Moonshot AI）、MiniMax——通过约 2.4 万个虚假账号，与 Claude 进行超过 1,600 万次对话，实施"工业级别的模型蒸馏攻击"。[^4]

这里有三个层次的问题，要分开说。

**第一，技术上的蒸馏是客观存在的。** 通过 API 收集模型输出，再用这些输出微调自己的模型，这在技术上是可行的，也确实被整个行业广泛实践。Anthropic 自身也通过第三方 API 使用者的交互数据来改进自己的模型，除非条款明确禁止。蒸馏不是黑客攻击——它只是 API 的另一种用法。

**第二，规模化是关键变量。** Hinton 的原始蒸馏，是用一个 teacher 去教一个 student——一对一的师生关系。Anthropic 描述的 "2.4 万个账号、1,600 万次对话" 是工业化规模——一个巨大的"学生军团"同时向同一个 teacher 提问。这不再是师生关系，而是一种系统性能力抽取。它触及了 API 商业模式的一个隐含假设：API 的商业模式默认用户用模型来处理自己的任务，而不是收集训练数据来替代这个模型。

**第三，叙事战场上没有干净的人。** Anthropic 指控别人"偷窃模型输出"，但 Anthropic 自身在训练 Claude 时使用了从盗版书网站下载的 700 万本书。Elon Musk 嘲讽 Anthropic 为"MisAnthropic"，写道："怎么敢偷 Anthropic 从人类程序员那里偷来的东西？" The Register 的标题更直接：《Anthropic 指控中国 AI 实验室盗用内容——就像它自己做的一样》。[^5]

这不是说蒸馏攻击没有问题。而是说在 AI 训练数据的合法性链条上，没有一只手是干净的。从互联网抓取训练数据，从 API 收集模型输出，用受版权保护的材料训练模型——这些行为在技术手段上没有本质区别，只有法律叙事的差异。谁拥有训练数据的权利，谁就可以定义什么是"蒸馏"什么是"盗窃"。

## 四、模型压缩：从技术到战略

蒸馏之所以能成为一个史论主题，不只是因为它被卷入了地缘政治，更因为它在 2023-2026 年间经历了一次战略转型。

在这个转型中，蒸馏从"模型优化"变成了"模型传播"。

在 Hinton 时代，蒸馏的目标是**压缩**：把模型缩小，保持能力，降低部署成本。在 DeepSeek 时代，蒸馏的目标是**传播**：把核心推理能力从大模型批量转移到小模型，让推理能力进入全谱系部署。

DeepSeek-R1 的蒸馏策略是这条新路线的范本：[^3]

| 蒸馏模型 | 基座 | 参数 | AIME 2024 |
|----------|------|------|:---:|
| R1-Distill-Qwen-1.5B | Qwen2.5-Math | 1.5B | 28.9% |
| R1-Distill-Qwen-7B | Qwen2.5-Math | 7B | 55.5% |
| R1-Distill-Qwen-14B | Qwen2.5 | 14B | 69.7% |
| R1-Distill-Qwen-32B | Qwen2.5 | 32B | 72.6% |
| R1-Distill-Llama-70B | Llama 3.3 | 70B | 70.0% |

1.5B 的蒸馏模型就能达到 28.9% 的 AIME 正确率——这比大部分未经蒸馏的 7B 乃至 13B 模型更强。蒸馏把推理能力从"大模型的专利"变成了"可以分发的商品"。而这恰恰是 Anthropic 最恐惧的事情：如果蒸馏可以如此高效，那么任何封闭 API 的最先进能力都可以被提取、压缩、分发——API 商业模式的护城河在蒸馏面前是透水的。

## 五、蒸馏为什么是一个史学问题

知识蒸馏之所以值得被写成一篇史论，不是因为它有多少参数、多少基准、多少性能跃升。而是因为它在 2026 年暴露了一个大模型时代尚未解决的根本问题：

**模型的能力到底属于谁？**

从互联网抓取的训练数据，属于写作者、摄影师、程序员——但抓取者认为这是"公开可访问信息"。从这些数据中训练出的模型参数，属于训练者——尽管参数中凝结了前者的劳动。从模型 API 中蒸馏出的输出，属于蒸馏者——尽管输出是前两者的合成产物。从蒸馏输出中训练出的新模型，属于新模型的训练者——尽管它的能力链条追溯到最后，是一系列无法被清晰归属的贡献。

这是一条**产权链上的所有环节都在模糊地带**的流水线。

Hinton 在 2015 年发明蒸馏时，不会想到十年后它会被"国家安全"包裹成制裁理由。蒸馏只是数学——一个模型通过拟合另一个模型的输出来学习。但数学一旦进入 API 商业生态，就会被"所有权""授权""滥用""窃取"这些法律词汇武装。在 API 服务条款里，"你不可以使用本模型输出来训练竞争模型"是一条可以写进的规则。但这条规则的可行性和道义正当性，都建立在"训练数据来源可追溯"这个前提上——而整个 AI 行业都建立在一个相反的前提下。

这就是蒸馏的史论位置。它不是大模型史上最显眼的技术，但它处于**知识财产、模型能力和地缘政治三者的交叉点**上。蒸馏的合法性没有被解决，只是被地缘政治暂时冻结了。

## 评曰

知识蒸馏在大模型史中是一种"无主的工具"。它不属于任何一家公司，不收费，不需要授权，不需要 GPU 集群——只需要两个模型的输入输出对齐。

Hinton 发明它的时候，想的是"怎么把一个大模型放进手机"。DeepSeek 用它的时候，想的是"怎么把推理能力分发给全世界的开发者"。Anthropic 禁止它的时候，想的是"怎么保护我们的 API 商业模型"。

同一项技术，同一个数学原理，三个完全不同的叙事。蒸馏的历史，就是 AI 行业从"学术共同体"变成"产权战场"的微缩史。

但这其中最需要被记住的一点是：**蒸馏的哲学前提——知识可以从一个模型中提取并转移——本身就是在说，模型不是人。** 人不能把智商蒸馏给另一个人。模型可以。因为模型的"知识"不是生物意义上的学习，而是统计模式的压缩和传输。在这个意义上，蒸馏不是盗窃——它是模型作为信息压缩器这一本质属性的自然推论。你无法"偷"一个压缩算法——你只能复制它。而 AI 产业之所以对蒸馏如此紧张，恰恰是因为它知道：在蒸汽机的逻辑面前，栅栏是挡不住的。
