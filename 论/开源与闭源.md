# 开源与闭源：大模型时代的两种社会契约

> 大模型竞争表面上是参数、算力和榜单的竞争，深层是合法性的竞争：闭源公司用产品稳定性、品牌和安全承诺换取信任；开源社区用可复现、可迁移和可审计换取信任。这不是道德剧——"开源"在大模型时代是商业策略的外套，"闭源"是能力溢价的护城河。这篇论试图拆开来看：谁在什么时刻用了什么策略，改变了什么。

> 这场争论的史学意义在于：大模型是人类历史上第一种**训练成本以亿计、分发成本趋近于零**的数字产品。它的经济学结构天然趋向垄断——训练需要巨额资本，而资本需要回报，回报需要控制分发。开源运动打破了这个逻辑链：它证明了一种可能性——巨额训练成本可以由不需要直接回收它的主体承担（广告公司、量化基金、主权基金），而分发可以完全免费。这是前所未有的经济结构实验。其结果将决定：AI 能力是成为少数公司的私有财产，还是成为人类的公共基础设施。

## 一、闭源的起点：能力优先，接口开放

GPT-3（2020-06）是大模型闭源路线的真正起点。175B 参数，API-only——不公开权重，不公开训练数据，不公开训练细节。这个决定在当时被视为对"Open"之名的背叛，但从商业逻辑看，它完美回应了一个现实问题：**Chinchilla scaling law 说训练好东西需要大量算力，大量算力需要大量资金，大量资金需要商业回报，商业回报需要控制分发。** 闭源 API 是这个逻辑链的自然终点。[^1]

ChatGPT 的成功把这个逻辑从理论变成了现实。五天百万用户，两月破亿——普通用户并不需要理解模型，只需要一个可用、可靠、低门槛的产品界面。

闭源路线的优势很明确：

- **产品体验统一**：模型、工具、账号、计费和安全策略在一个体系中闭环；
- **安全策略集中**：供应商可以统一更新拒答规则、滥用检测和系统提示；
- **商业回款直接**：能力以订阅或 API 形式变现，支撑继续训练更大模型；
- **版本控制权**：供应商可以随时更新模型、修复漏洞、调整行为——用户始终使用最新版本。

但它也留下一个无法消除的问题：外部世界只能相信供应商的说法。参数规模、训练数据、系统提示、推理过程、安全评估，大多不可独立验证。能力越强，黑箱越厚。GPT-4 的技术报告完全不公开参数规模、训练数据量、模型架构——开启了大模型"黑箱发布"的时代。Anthropic 的 Claude 系列同样不公开架构细节，只给出安全评估报告。Google 的 Gemini 在发布时甚至被曝 demo 视频剪辑造假——当一切都不可验证时，连产品演示都可以是精心编排的表演。

闭源路线的根本张力在于：**它的商业模式建立在信息不对称之上——用户为不理解的东西付费。** 当这种不理解是技术复杂性造成的（用户确实不知道怎么训练模型），信息不对称是自然的。但当它是刻意制造的（公司故意不公开关键参数以维持能力壁垒），信息不对称就变成了权力关系。开源运动的真正意义，不是让每个人都自己训练模型——而是让"你无法验证"这句话不再成立。

## 二、"开源"三层皮：为什么这个词在大模型时代不够用了

传统软件的开源很简单：代码公开、自由使用、自由修改、自由分发。OSI（Open Source Initiative）守了几十年这套定义，边界清楚。

大模型把这件事搅浑了。一个模型放出来，可能同时存在三种不同层面的"开放"：

- **权重开放**：你可以下载 `.safetensors` 或 `.gguf`，部署、量化、微调——但不知道训练数据是什么、训练代码怎么写；
- **代码开放**：训练脚本、推理代码、评测流水线公开——但权重不一定给你；
- **数据开放**：训练数据的来源、构成、筛选方式披露——但不等于每条原文都给你。

Meta、Mistral、DeepSeek 三家都只走到了第一层或第一层半：开放权重为主，辅以部分代码和论文，但训练数据的完整配方从来不是它们的承诺。[^2]

**OSI 的困境：定义赶不上现实。** 2024 年 10 月，OSI 发布了 Open Source AI Definition（OSAID）1.0——它要求"首选修改形式"包括数据、代码、参数三要素。[^3] 但这个定义目前对行业几乎没有约束力：每一家都继续用"开源"做市场语言，却没有人真正递交 OSI 认证。原因很现实——公开训练数据意味着公开数据采购合同、数据清洗流水线、可能的版权风险和商业秘密。对 Llama 和 Qwen 这样用了海量网络爬取数据的模型来说，"公开训练数据"在法律上近乎不可能。

这恰好说明问题不在"谁更诚实"，而在"开源"这个词在大模型时代已经不够用了。我们需要换一个问法：**每一家为什么开放、开放到什么程度、留了什么后手**。正是这三个问题，区分出不同的商业策略。

这种模糊性不是大模型独有的——它是"基础设施类软件"开源的宿命。Linux 内核是完全开源的，但 Red Hat 的企业版不是；Android 是开源的，但 Google Play Services 不是；Chromium 是开源的，但 Chrome 不是。大模型的"开源"正在复制这个模式：权重开源，但数据不开、训练流程不开、最佳实践不开。**"开放到足够吸引生态，封闭到足够保护核心"——这是基础设施开源的永恒张力。**

## 三、开源许可证的演化：从法律文本到商业武器

大模型的许可证演化本身就是一部微缩的策略史。在传统软件世界，许可证是法律文本——选择 Apache 2.0 还是 GPL 还是 MIT，影响的是下游用户的义务和权利，但不影响软件本身的能力。在大模型世界，许可证是商业策略的精确表达——选择什么许可、保留什么权利、设置什么门槛，直接决定了模型的扩散范围和竞争效果。

**Apache 2.0（传统开源）**：最早的开源大模型沿用了软件世界的许可证——Mistral 7B、Qwen 系列均采用 Apache 2.0。它允许任何用途（包括商用），不需要额外申请，只需保留版权声明。[^4] 这是最"传统"的开源路径：宽松到几乎没有限制。

**Llama License（开放权重）**：Meta 从 Llama 2 开始使用自定义许可证。它允许商用，但保留了一道"暗门"——月活超过 7 亿的应用需要向 Meta 申请额外许可。[^5] 这个 7 亿 MAU 门槛精确地瞄准了 Google、Apple、Amazon 等超大平台，对绝大多数企业没有影响。这不是 OSI 意义上的"开源"——它是"足够开放以建立生态，足够限制以保护自己"。

**MIT License（完全开放）**：DeepSeek 从 V3 开始采用 MIT 许可——大模型主流许可中最宽松的一类，允许任何用途，包括商业使用、修改和再分发，只需要保留版权声明。[^6] MIT 许可没有 MAU 门槛，没有使用限制，没有申请流程——权重一旦下载，就永远在公共领域。

**混合策略**：Mistral 后来展示了另一种玩法——同一公司的不同模型用不同许可。开源的用 Apache 2.0，闭源的用 API 服务。两者不矛盾：前者获取生态和声誉，后者获取收入和深度关系。阿里的 Qwen 系列也走了类似的路：开源模型用 Apache 2.0，同时通过阿里云提供商业 API 和企业服务。

许可证的演化揭示了一个真相：**许可不是法律细节，而是商业策略的精确表达**。Apache 2.0 说"我什么都不限制，用我吧"；Llama License 说"用吧，但你不能用我来打败我"；MIT 说"随便用，我根本不在乎你用它做什么"。三种许可对应三种策略——渠道敲门、平台防御、叙事爆破。

值得注意的是，这个演化方向是**单向的**：从限制走向宽松。Llama 1 的学术许可 → Llama 2 的商用许可（但有 MAU 限制） → DeepSeek 的 MIT（完全无限制）。每一次许可的放宽都伴随着模型能力的提升——当模型足够强、生态足够大时，更宽松的许可反而能带来更大的战略收益。这不是巧合——这是"开放程度与能力自信成正比"的规律。

但反向的力也同样存在。当模型能力成为国家安全议题时，许可证的政治化不可避免——美国已经开始讨论是否需要限制某些模型的出口（类似于芯片出口管制的"模型出口管制"）。如果这个趋势成真，MIT 许可证的"完全开放"可能会遇到政治天花板——许可证演化的故事远未结束。

## 四、三种开源策略的深层比较

### 4.1 Meta：把事故包装成战略，用开放建平台

LLaMA 最开始不是故意开放的产物。2023 年 2 月 24 日，Meta 将 LLaMA 论文和权重发放给经审批的研究者，没有打算面向公众分发。但发布后不到两周，权重经 4chan 和 BitTorrent 泄漏，进入了不可回收的公共网络。[^7][^8]

接下来的四个月很关键。泄漏不是 Meta 主动制造的，但 Meta 观察到的现象是：社区立刻围绕 LLaMA 建起了完整的下游生态——Alpaca、Vicuna、LoRA 微调、本地量化、llama.cpp。这个生态不是 Meta 建的，却靠着 LLaMA 活着。而 OpenAI 和 Google 的闭源模型没有任何类似的社区扩散效应。

四个月后，Meta 做出了一个战略选择。**2023 年 7 月 18 日**，Llama 2 发布——明确允许商用，只对月活超 7 亿的服务保留许可审批权。[^9] 再过一年，**2024 年 7 月 23 日**，Llama 3.1 发布，旗舰模型 405B 参数，能力接近闭源前沿。同日，Mark Zuckerberg 发表《Open Source AI Is the Path Forward》，把开放路线解释为类似 Linux 的基础设施策略。[^10][^11]

Meta 的逻辑链条是清楚的：

1. Meta 不靠卖模型赚钱——它的收入来自广告；
2. 因此 Meta 不怕模型免费扩散，反而怕模型被一两家闭源公司垄断；
3. 如果 Anthropic 或 OpenAI 的闭源模型成为行业唯一标准，Meta 的社交和广告业务会受制于人；
4. 所以 Meta 的最优策略不是做最强模型，而是把"足够好"的模型免费分发给所有人——让闭源公司的定价权被削弱；
5. 限制大平台使用（7 亿 MAU 门槛）则是最后一道防线：防止竞争对手直接用 Llama 建起比 Meta 自己的产品更强的平台。

Meta 的"开源"是战略武器，不是道德选择。它的开放程度——权重开放但数据不公开、训练代码不完整——完美匹配它的战略目标：给开发者足够的工具来削弱闭源公司，但保留足够的黑箱来防止别人全面超越 Meta 自己。

### 4.2 Mistral：用 Apache 2.0 敲开企业门，关起门来卖更好的

Mistral AI 的策略比 Meta 更精密。它不喊"开源是基础设施"这种宏大叙事，而是用三样东西精确地组合攻击：

1. **宽松许可**：Apache 2.0——商业使用零限制，不需要额外申请；
2. **小模型大能力**：Mistral 7B（2023-09-27）在多项基准上超过 Llama 2 13B，Mixtral 8x7B（2023-12-11）用 MoE 设计在性能上接近 Llama 2 70B 但推理快六倍；[^12][^13]
3. **闭源产品线并行**：Mistral Large、Le Chat 等服务在开放权重模型之外独立运营，以 API 形式收费。

这个组合的妙处在于：开放权重模型负责建立口碑和生态——开发者用 Mistral 7B 做项目、写教程、建工具，企业做 PoC 验证可行性；而真正赚钱的、能力更强的、有服务保障的模型，走的是闭源 API。Apache 2.0 是入场券，入场之后的深度合作、高并发调用、企业级 SLA，都不是免费的。

Mistral 的启示是：**开放权重不必是"全开"或"全闭"的二选一**。一家公司完全可以同时拥有开放权重模型和闭源 API 模型，二者不矛盾——前者获取生态和声誉，后者获取收入和深度关系。

### 4.3 DeepSeek：MIT 许可证是一颗逻辑炸弹

DeepSeek 的策略是最激进的，也是最需要从地缘角度理解的。

**2025 年 1 月 20 日**，DeepSeek 发布 R1。R1 不只是又一个开放权重模型：它附带 MIT 许可证——在大模型主流许可中最宽松的一类。[^14][^15] 同时发布的还有完整论文、R1-Zero 的训练方法、6 个蒸馏小模型，以及最重要的——**可观察的思维链**。

把这几件事放在一起看，DeepSeek 打的是一套组合逻辑：

1. MIT 许可证意味着任何公司——包括 OpenAI、Google、Anthropic 的竞争对手——都可以拿 R1 去微调、蒸馏、商用，不受限制。相比之下，Llama 的 7 亿 MAU 门槛限制了超大平台；
2. 公开论文和训练方法意味着学术界和竞争团队可以复现、改进、验证。R1-Zero 用纯粹的强化学习加规则奖励就发展出推理行为——这是以前只有闭源实验室才敢声称的能力；
3. 可观察思维链意味着外部可以检查模型"在想什么"——直接挑战了 o1 把推理过程藏起来的做法。这不仅是能力竞争，更是信任机制的竞争。

DeepSeek 不是在做慈善。它的战略语境和 Meta、Mistral 完全不同：作为一个中国 AI 实验室，DeepSeek 面临美国芯片出口管制的限制，H800 的能力远不如 H100。在这样的约束下，"做最大的模型"不是最优路线。"做最开放的顶级模型"却是——因为开放可以绕过管制的叙事逻辑：你禁我的芯片，但我做出来的模型全世界都能用，而且用的是 MIT 许可，你没法禁止你的开发者去下载。

这不是阴谋论。把 R1 的发布形式和时机（o1 发布四个月后、美国 AI 政策辩论激烈期）放在一起看，R1 的历史位置就很清楚了：它不是追赶，是打断。打断了"前沿推理能力必须是闭源美国公司产品"的默认假设。MIT 许可证的意义不在于授权了什么，而在于让这个打断不可撤销——任何人一旦下载，能力就永远在公共领域。

但 DeepSeek 的开源不只是一颗逻辑炸弹——它还是一次经济学结构的重构。DeepSeek-V2（2024-05）的 API 价格定为 GPT-4 Turbo 的约 1%。DeepSeek-V3（2024-12）的训练成本仅为约 557 万美元——GPT-4 训练成本的 6%。[^22] DeepSeek-R1 的 API 输出价格仅为 o1 的约 3%。把"MIT 开源"和"1/370 的价格"放在一起，产生的就不是技术竞争——而是**经济结构的重构**。MIT 开源意味着任何人都可以下载权重，在自己的服务器上运行，不需要付费。极低的价格意味着即使你选择付费 API，成本也低到几乎等于带宽费。两者叠加的效果是：**使用闭源模型的经济理由在大幅缩水。** 如果你的应用不需要当前绝对最强的那一点性能差距，你没有任何理由继续使用闭源 API。而大多数商业应用确实不需要那一点性能差距——它们需要的是可靠、便宜、可定制的模型。

DeepSeek 对闭源商业模型的结构性威胁在于：它不是靠"更好的模型"竞争——它是靠"好到足够强，同时便宜到让闭源的经济模型失效"来竞争。当一家公司的 API 价格是竞争对手的 1/370，同时权重完全免费——竞争对手的定价就不是"贵"，而是"无法解释"。

### 4.4 阿里（Qwen）：开源抢社区，闭源抢收入

阿里在 2023 年 4 月发布通义千问后，同年 8 月发布了 Qwen 开源系列（7B/14B/72B），此后 Qwen 2（2024-06）、Qwen 2.5（2024-09）、Qwen 3（2025-04）持续迭代，覆盖从 0.5B 到 235B 的全谱系。[^20] Apache 2.0 许可。

阿里的策略和 DeepSeek 不同，和 Meta 也不同。阿里云是全球第三大云平台，它需要的是开发者生态——Qwen 开源模型是吸引开发者使用阿里云的"钩子"。当一个开发者在 Qwen 上做了微调、部署在阿里云上、积累了数据和工作流——他就被锁进了阿里云的生态。这是 Google 用 Android 做过的事：开源操作系统锁定手机厂商，Google Play 锁定用户。

阿里的"双轨"策略代表了最稳健的商业模型：开源模型抢社区、抢开发者心智、抢市场份额；闭源 API（通过阿里云 DashScope）抢企业收入、提供 SLA 和技术支持。这种策略在技术前沿上一直比最顶尖的闭源模型差半步，但它在生态覆盖的广度上无出其右——从 0.5B 的端侧模型到 235B 的旗舰模型，每一个部署场景都有对应的 Qwen 版本。

### 4.5 四种策略的比较

| 维度 | Meta | Mistral | DeepSeek | 阿里（Qwen） |
|------|------|---------|----------|--------------|
| 许可证 | Llama License（有限制） | Apache 2.0 | MIT（最宽松） | Apache 2.0 |
| 核心动机 | 削弱竞争对手护城河 | 敲开企业市场门 | 打破叙事垄断 | 社区生态 + 云绑定 |
| 收入来源 | 社交广告（不靠模型赚钱） | 闭源 API + 企业服务 | 量化交易基金（不靠 AI 赚钱） | 阿里云 |
| 开放程度 | 权重开放，数据不公开 | 部分模型开放，部分闭源 | 权重+论文+方法，数据不公开 | 权重开放，数据不公开 |

三种策略的共同 DNA：

**第一，没有一家开放了全部。** 四家都没有公开训练数据的完整清单和筛选细节；Meta 和 Mistral 没有公开训练代码；DeepSeek 虽然公开了论文和方法，但训练流程是否完全可以由外部复现仍存疑。它们开放的都是"足够多"——足以建立生态和信誉，不足以让别人完整复制自己的核心优势。

**第二，开放的程度和公司的商业模式直接挂钩。** Meta 不卖模型，所以敢放权重；DeepSeek 不走闭源 API 路线为主，所以 MIT 许可不影响其核心收入；Mistral 有闭源产品线，所以它的开放是限量版的——够用，但最好的还是要付费；阿里靠云赚钱，所以开源模型是引流工具而非利润中心。商业模式决定了开放的上限——**一家公司的许可证选择，比它的公关声明更诚实地暴露了它的真实意图。**

**第三，用户获得了退出权。** 这是四条路线客观上共同推动的最真实的进步。不管每一家出于什么动机，结果是：开发者不再只有一个 API 供应商可选。他们可以在 Llama、Mistral、Qwen、DeepSeek 之间切换和组合，可以对模型做本地微调，可以在断网环境下部署。退出权不等于免费——迁移有成本、调优要人力、推理要硬件——但退出权存在这件事本身，就改变了供应商和用户之间的权力关系。在传统软件世界，这叫"避免供应商锁定"（vendor lock-in avoidance）；在大模型世界，它的重量远超传统软件——因为模型不是一个工具，它是整个技术栈的大脑。

## 五、开源模型的经济学：从边际成本到退出权

开源不只是"免费"。它改变了整个市场的经济结构。在 2022 年之前，"开源"在 AI 领域有两个截然相反的叙事。一个是学术界的——TensorFlow、PyTorch、BERT 都是开源的，开源是科学进步的自然方式。另一个是商业界的——开源意味着把价值拱手让人，闭源才是商业可持续的。Llama 1 的泄漏撞开了第二个叙事：**开源模型一旦进入互联网，就不再属于原公司。** 社区会把它拆开、重组、微调、量化、部署到各种奇奇怪怪的设备上。而这些派生工作累积起来的价值，可能比原始权重的发布者想象的更大。

真正有价值的不是泄漏本身，而是泄漏后的连锁反应。全球开发者基于 Llama 1 构建了 Alpaca（Stanford，$600 微调）、Vicuna（Berkeley）、GPT4All 等数百个微调版本。一个 13B 的"小模型"在多数基准上超越了 175B 的 GPT-3——这个事实本身揭示了 Chinchilla scaling law 的核心主张。[^21] 但它同时揭示了一个更深的事实：**开源模型创造了一个不可控制的生态**。社区做的微调、量化、工具链、硬件适配，都在降低模型的准入门槛。当准入门槛降到一定程度，闭源 API 的"独家能力"就开始贬值。

经济学上，开源模型的竞争力建立在三个原理之上：

**第一，开源改变边际成本结构。** 训练一个大模型需要巨额固定成本（算力、数据、人才），但一旦训练完成，分发模型权重的边际成本趋近于零。闭源 API 的商业模式是在固定成本之上叠加每次调用的边际收入——靠每次 token 收费来摊销训练成本。开源模型打破了这种摊销结构：它把固定成本当作沉没成本，把分发成本降到零附近。DeepSeek-R1 的 API 输出价格仅为 o1 的约 3%，DeepSeek-V4 的价格被第三方报道为 GPT-5.5 的约 1/370。[^16] 当 MIT 开源和 1/370 的价格叠加——使用闭源模型的经济理由在大幅缩水。

**第二，开源创造网络效应。** 一个开源模型的用户越多，微调、工具链、文档、部署方案就越多——生态越繁荣，下一个用户越有理由选择它。这种网络效应和闭源的产品生态（如 ChatGPT 的插件市场）是镜像的：一个靠开放标准运转，一个靠平台锁定运转。Linux 在服务器市场、Android 在移动市场、Chromium 在浏览器市场——都是"开放标准创造网络效应"的经典应用。大模型开源运动正在复制这个模式。

**第三，也是最重要的——开源提供退出权。** 当一个企业使用闭源 API 时，它的技术栈绑定在供应商的定价、可用性、政策和服务条款上。如果供应商涨价、断供、变更条款、或受到出口管制——企业没有替代方案。使用开源模型，企业拥有权重本身。它可以迁移到任何云、任何硬件、任何部署环境。[^17]

"退出权"这个概念来自政治经济学——Albert Hirschman 的退出、发声与忠诚框架。在大模型经济中，它是最被低估的资产。退出权不是"现在就用开源替代闭源"——而是"如果（when）闭源不行了，你有路可退"。它降低了闭源供应商对市场的定价权——因为你的客户随时可能离开。

## 六、闭源公司的反制：四张牌

开源在侵蚀闭源的护城河，但闭源公司不是坐以待毙。它们手里有四张反制牌。

**第一张牌：能力迭代速度。** 闭源公司（OpenAI、Google、Anthropic）在前沿能力上仍然保持 6-12 个月的领先窗口。o1 开创推理模型品类时，开源阵营花了四个月才由 DeepSeek-R1 追上。当 GPT-5 发布时，这个窗口可能再次拉大。闭源公司赌的是：只要前沿能力的代差足够大，企业就会为最新能力付费——即使开源模型"足够好"，"足够好"和"最好"之间的差距仍然是一个可定价的商品。这种"前沿独占期"的商业模式，类似于电影行业的院线窗口期——先在最贵的渠道卖，等热度过了再放到更便宜的渠道。

**第二张牌：生态锁定。** OpenAI 的 ChatGPT 插件市场、自定义 GPT、项目配置；Google 的 Workspace 集成、Android 内置；Anthropic 的 Claude Code、MCP 协议——这些都不是独立的模型服务，而是围绕模型建立的完整工作流。用户一旦习惯了某个生态（对话历史、自定义配置、团队协作），迁移成本就不再是模型本身，而是整个工作习惯和组织流程。这是开源模型难以复制的壁垒——开源提供了模型权重，但不提供产品体验、用户界面和生态惯性。

**第三张牌：安全叙事。** 闭源公司最大的叙事武器是"安全"——模型越强，滥用风险越大；控制越集中，安全越有保障。OpenAI 在 GPT-2 的"太危险"叙事中开创了这个策略，此后每一个闭源发布都在强化这个逻辑。当 DeepSeek-R1 把推理思维链完全公开时，闭源公司的回应是："公开推理过程可能被恶意利用——攻击者可以学习模型如何推理，从而设计更精巧的越狱策略。"安全叙事的吊诡之处在于：它既是真实的关切，也是方便的借口。但只要发生一起严重的开源模型滥用事件——比如用开源模型大规模制造虚假信息或合成危险物质的指令——安全叙事就会获得事实性的弹药，而闭源公司的定价权就会获得道德背书。

**第四张牌：合规与认证。** 企业级客户（金融、医疗、政府）对供应商有严格的合规要求——SOC 2、ISO 27001、GDPR 数据处理协议、HIPAA（医疗数据）。闭源 API 供应商可以提供完整的合规包——数据不出境、审计日志、安全承诺、责任赔偿。开源模型的部署者需要自己承担合规责任——模型行为的不可预测性、数据处理的合规性、安全事件的责任归属——这些全部落在部署者头上。对很多企业来说，"可以审计"不如"已经认证"——这是闭源公司尚未被开源威胁到的核心领地。

---

## 七、开源不会消灭闭源——但会让闭源必须解释自己的价值

开源模型不会让闭源模型消失。前沿能力的争夺仍然需要巨大的训练预算，而训练预算需要回收——闭源 API 是最直接的回收管道。企业级 SLA、安全合规、产品集成、品牌信誉——这些都是开源难以替代的。

但开源模型改变了权力结构。在 Llama 1 之前，闭源模型的唯一替代是使用更弱的模型，或者自己训练——两者都不现实。Llama 之后，开源模型成了一个切实可行的备选方案。DeepSeek-R1 之后，开源模型在某些任务上甚至和闭源模型打平或超越。2026 年的现实是：**如果一个场景不需要绝对最强的 SOTA，开源模型几乎总是更优的经济选择。**

这迫使闭源公司回答一个问题：你的溢价值吗？以前闭源不需要回答这个问题——因为没有可比的替代品。现在有了。而一旦溢价需要被证明，闭源公司的利润率就会从垄断性向竞争性收缩。

这不是"开源 vs 闭源"的道德之争。这是经济学。开源模型不是免费午餐——它的训练成本来自不靠 AI 赚钱的商业模型（Meta 靠广告，DeepSeek 靠量化基金）或来自生态锁定（阿里靠云）。但无论在哪种模式下，开源都在重新分配 AI 能力的定价权——把它从少数闭源公司的手中推向更大的开发者群体。

这个权力再分配的速度超出所有人的预期。2023 年初，闭源模型的能力领先开源一个量级——GPT-4 对 Llama 1 是碾压级差距。2024 年中，差距缩小到半代——Llama 3.1 405B 在多数基准上接近 GPT-4。2025 年初，开源在特定维度上反超——DeepSeek-R1 的推理能力与 o1 持平，而价格只有 3%。到 2026 年，闭源模型的"前沿独占期"已经从一年缩短到几个月。这个趋势如果持续，闭源公司的利润空间会被持续压缩——不是因为开源更好，而是因为开源**足够好**。

---

## 八、真正的分界线：退出权

开源不会消灭闭源，闭源也无法消灭开源。

闭源模型适合追逐最前沿能力、复杂产品体验和统一服务承诺。开源模型适合本地化、定制化、低成本部署和主权可控。企业会同时使用二者：用闭源模型处理高价值、快速变化的能力需求，用开源模型处理可控、可审计、可私有化的场景。Microsoft 在 Azure 上同时提供 OpenAI 模型和 Llama 模型；企业在核心业务用 GPT-4，在内部知识库用 Qwen 微调版——这种"混合部署"已经是 2026 年的常态。

但真正的分界线不是"开放"与"封闭"，而是**用户是否拥有退出权**。如果一个组织可以在 API 断供、价格上涨或政策变化时迁移到开源模型，它就拥有谈判能力；如果不能，它只是闭源平台的租户。

"退出权"这个概念来自政治经济学——Albert Hirschman 的"退出、发声与忠诚"（Exit, Voice, and Loyalty）框架。在大模型经济中，它是最被低估的资产。退出权不是"现在就用开源替代闭源"——而是"如果（when）闭源不行了，你有路可退"。它降低了闭源供应商对市场的定价权——因为你的客户随时可能离开。退出权不等于免费——迁移有成本、调优要人力、推理要硬件——但退出权存在这件事本身，就改变了供应商和用户之间的权力关系。

在 2026 年的现实中，退出权已经从理论变成了实践——当御三家集体收紧中国地区的 API 访问时，拥有开源模型的企业可以平滑过渡，没有的企业被一夜锁死。[^18] 这个事件让整个行业理解了退出权的真正重量：它不是保险——它是主权。

退出权的存在也重新定义了"竞争"的含义。在闭源独占时代，竞争是模型能力的竞争——谁的 benchmark 分高。在开源共存时代，竞争变成了"模型能力 × 分发便利性 × 退出成本"的综合竞争。闭源公司必须同时在能力上领先、在生态上锁定、在价格上合理——因为用户随时可以带着权重走人。这个压力结构是健康的——它迫使每一家公司不只是做最好的模型，而是做最好的服务。

## 评曰

大模型的开源与闭源之争，不是道德剧。闭源带来了产品化速度和安全集中治理，开源带来了独立验证和技术扩散。前者回答"怎样让十亿人立刻用上 AI"，后者回答"怎样让 AI 不被少数接口垄断"。

开源模型的经济学史，可以浓缩成一句话：**它从意外泄漏开始，以重新定义市场竞争规则结束。** Llama 1 的 4chan 泄漏是意外。Llama 2 的商用许可是战略。DeepSeek-R1 的 MIT 开源是极限压力测试——"如果我最强，但我仍然开源，那么闭源的正当性还剩多少？" Meta 把 LLaMA 泄密事件扭转为生态战略，Mistral 用 Apache 2.0 开门、关门卖更好的，DeepSeek 用 MIT 许可拆掉"前沿推理能力必须闭源"的围墙，阿里用全谱系开源编织云生态——四家没有一家是"为了开源本身"，但四家共同做了一件事：让大模型的可获得性从一两家公司的 API 端点，扩散到了全世界的硬盘上。

这个进程中有一个清晰的趋势：**开源模型每一次迭代，都在降低"不开源"的正当性。** 当 Llama 3.1 证明"开源可以接近前沿"，闭源被质疑的是能力壁垒。当 DeepSeek-R1 证明"开源可以在推理上比肩 o1"，闭源被质疑的是独占的必要性。当 Qwen 3 证明"开源可以覆盖全谱系"，闭源被质疑的是生态覆盖的不可替代性。

但该说的另一句话也要说：开源模型没有解决训练的版权问题，没有解决训练数据的透明问题，没有解决模型滥用的安全问题。DeepSeek 的"MIT 开源"背后是一个不需要靠 AI 赚钱的量化基金——这个前提是任何其他公司都不具备的。Meta 的"开源宣言"被 Llama 4 的评测争议戳穿。[^19] "开源"本身不是美德——它是一种策略选择，有收益也有代价。当开源模型被用于深度伪造、自动化攻击或大规模虚假信息生成时，"开放"的代价由整个社会承担，而收益由发布者独占。 开源不是免费的午餐——它的训练成本来自不靠 AI 赚钱的商业模型（Meta 靠广告，DeepSeek 靠量化基金）或来自生态锁定（阿里靠云）。

未来的大模型秩序，大概率不是一方胜出，而是形成分层：最前沿能力短期闭源，成熟能力逐步开源；通用助手闭源产品化，行业模型开源私有化；国家和大型企业保留开源替代路线，个人用户继续购买最省心的闭源服务。这个分层结构意味着：**闭源不会消失，但它的定价权会被开源持续压缩；开源不会统治，但它的存在会让整个市场的权力结构向用户倾斜。**

史官要记录的，不是哪一方更高尚，而是谁在什么时刻改变了能力的分配方式。大模型的开源不是道德剧，不是某一天一群理想主义者决定对抗商业巨头的故事。它是商业计算穿了一件开源的外套——外套是真的，里面的算盘也是真的。一个词被用得越滥，就越需要拆开看。拆开之后真相并不坏：商业策略如果恰好推动了公共能力扩散，它仍然值得被记录。只是别把策略写成理想，也别把理想当成已经发生的现实。
