# 开源与闭源：大模型时代的两条合法性路线

> 大模型竞争表面上是参数、算力和榜单的竞争，深层是合法性的竞争：闭源公司用产品稳定性、品牌和安全承诺换取信任；开源社区用可复现、可迁移和可审计换取信任。二者不是简单的先进与落后，而是两种不同的社会契约。

## 一、闭源的起点：能力优先，接口开放

GPT-3 之后，OpenAI 把最前沿模型封装为 API。用户不能得到权重，也不能完整知道训练数据和训练细节，但可以通过稳定接口调用能力。ChatGPT 的成功证明了这条路线的商业威力：普通用户并不需要理解模型，只需要一个可用、可靠、低门槛的产品界面。[^1]

闭源路线的优势很明确：

- **产品体验统一**：模型、工具、账号、计费和安全策略在一个体系中闭环；
- **安全策略集中**：供应商可以统一更新拒答规则、滥用检测和系统提示；
- **商业回款直接**：能力以订阅或 API 形式变现，支撑继续训练更大模型。

但它也留下一个无法消除的问题：外部世界只能相信供应商的说法。参数规模、训练数据、系统提示、推理过程、安全评估，大多不可独立验证。能力越强，黑箱越厚。

## 二、开源的反击：从泄漏到战略

Llama 的意义不只在模型能力。2023 年初，LLaMA 权重外泄后，社区迅速围绕它发展出 Alpaca、Vicuna、LoRA 微调和本地部署生态。Meta 后来发布 Llama 2，并允许在一定条件下商用，等于把一次意外扩散转化为长期战略。[^2]

开源路线的优势也很明确：

- **可迁移**：模型可以进入企业内网、个人电脑、边缘设备和受监管场景；
- **可改造**：社区能做微调、量化、蒸馏、工具链适配；
- **可审计**：至少权重行为可以被独立测试，安全与偏见不完全依赖厂商自述。

这条路线不是免费的午餐。开源模型同样可能被滥用；许可证常常并非 OSI 意义上的完全开源；训练数据也未必公开。但它改变了权力结构：用户不再只能租用能力，也可以保存、复制和改造能力。

## 三、DeepSeek 时刻：开源成为国家级替代方案

DeepSeek-R1 把开源路线推到新的高度。它不只是发布模型，而是把推理模型、蒸馏模型、论文与 MIT 许可证一起抛向世界。[^3] 这件事的史学意义在于：开源不再只是“追赶闭源”的低成本替代，而成为一种主动的合法性宣言——我强，并且我允许你验证、部署和改造。

这改变了闭源公司的叙事压力。o1 证明了推理模型的新品类，但隐藏思维链；R1 则用公开模型和可观察推理过程抢走了“推理模型应该如何被信任”的定义权。闭源仍然可以更强、更稳定、更易用，但它必须解释为什么关键能力不能被验证。

## 四、两条路线会长期共存

开源不会消灭闭源，闭源也无法消灭开源。

闭源模型适合追逐最前沿能力、复杂产品体验和统一服务承诺。开源模型适合本地化、定制化、低成本部署和主权可控。企业会同时使用二者：用闭源模型处理高价值、快速变化的能力需求，用开源模型处理可控、可审计、可私有化的场景。

真正的分界线不是“开放”与“封闭”，而是**用户是否拥有退出权**。如果一个组织可以在 API 断供、价格上涨或政策变化时迁移到开源模型，它就拥有谈判能力；如果不能，它只是闭源平台的租户。

## 评曰

大模型的开源与闭源之争，不是道德剧。闭源带来了产品化速度和安全集中治理，开源带来了独立验证和技术扩散。前者回答“怎样让十亿人立刻用上 AI”，后者回答“怎样让 AI 不被少数接口垄断”。

未来的大模型秩序，大概率不是一方胜出，而是形成分层：最前沿能力短期闭源，成熟能力逐步开源；通用助手闭源产品化，行业模型开源私有化；国家和大型企业保留开源替代路线，个人用户继续购买最省心的闭源服务。史官要记录的，不是哪一方更高尚，而是谁在什么时刻改变了能力的分配方式。
