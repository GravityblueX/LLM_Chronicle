# 2023年5月

## SoVITS-SVC、「AI 孙燕姿」与开源语音合成浪潮

> 一个歌声音色转换工具，让「AI 孙燕姿」唱遍华语乐坛，也让无数普通人第一次亲手触摸到了扩散模型和语音 AI。

**2023-03-10** — **SvcDevelopTeam** 在 GitHub 开源 **So-VITS-SVC**（SoftVC VITS Singing Voice Conversion）初版仓库，基于 VITS[^2]（变分推理端到端 TTS）与 SoftVC（软内容编码器），实现歌声的音色转换——保留原曲的音高、节奏与语调，替换为目标歌手的音色。项目提供 GUI 和整合包（含 Colab notebook），大幅降低使用门槛。采用 AGPL-3.0 许可证。[^1]

**2023-05** — **「AI 孙燕姿」现象爆发**。B 站用户使用 SoVITS-SVC 将孙燕姿的音色模型应用于大量流行歌曲，从《好汉歌》到周杰伦曲目，视频迅速出圈，引发全民热议。大量用户首次通过下载整合包、训练音色模型来体验 AI。HuggingFace 上随之形成了活跃的音色模型分享社区。[^3]

**随后** — 因法律风险（版权与肖像权争议），SoVITS-SVC 项目宣布**停止维护**（归档）。仓库 README 声明："本轮限时更新即将结束，仓库将进入 Archieve 状态"。GitHub 星标在归档时已逾 28k（截至 2026-05 回看），Fork 5k+。社区 Fork 和模型分享在 B 站、HuggingFace 上继续繁荣。[^1]

### 后继：GPT-SoVITS（2024 年 1 月）

**2024-01-14** — **RVC-Boss** 在 GitHub 创建 **GPT-SoVITS** 仓库，将 GPT（生成式预训练 Transformer）与 SoVITS 结合，实现**少样本语音克隆**——"1 min voice data can also be used to train a good TTS model"。项目采用 MIT 许可证。[^4]

GPT-SoVITS 迅速成为中文开源语音合成的事实标准。截至 2026 年 5 月，仓库已获 57.7k star、6.3k fork，仍在持续迭代。它保留了 SoVITS-SVC 的 WebUI 易用性传统，同时大幅提升了合成质量和跨语言能力。

### 影响

SoVITS-SVC → GPT-SoVITS 这条线，是大模型时代**消费级 AI 应用最先出圈的典范之一**。其影响远超语音合成本身：

- **全民体验 AI**：「AI 孙燕姿」让数以百万计的普通用户第一次亲手操作 AI 模型——下载整合包、训练音色模型、生成翻唱歌曲——比 ChatGPT 更早让「AI」成为一个动词。
- **技术启蒙的跳板**：大量用户在折腾 SoVITS 和 GPT-SoVITS 的过程中，首次接触到 VITS 架构、扩散模型（DDPM）、流匹配（Flow Matching）、声码器等概念，不少人由此进入 AI 研究和开发领域。
- **模型分享生态**：B 站、HuggingFace 上形成了庞大的音色模型分享社区，上千个角色模型被训练和公开，形成了独特的「AI 翻唱」亚文化。
- **降低门槛的范式**：从需要数小时高质量录音（传统 TTS）到「1 分钟语音即可」，GPT-SoVITS 改写了语音克隆的可及性。
