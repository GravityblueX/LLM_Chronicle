# 2023年5月

## SoVITS-SVC、「AI 孙燕姿」与开源语音合成浪潮

> 一个歌声音色转换工具，让「AI 孙燕姿」唱遍华语乐坛，也让无数普通人第一次亲手触摸到了扩散模型和语音 AI。

**2023-03~04** — 国内音乐合成爱好者 **Rcell** 在 GitHub 开源 **So-VITS-SVC**（SoftVC VITS Singing Voice Conversion），基于 VITS（变分推理端到端 TTS）与 SoftVC（软内容编码器），实现歌声的音色转换——保留原曲的音高、节奏与语调，替换为目标歌手的音色。项目提供 GUI 和整合包，大幅降低使用门槛。潮新闻, 2023-05-19[^1]; 腾讯云, 2023-05-12[^2]

**2023-05** — **「AI 孙燕姿」现象爆发**。B 站用户使用 SoVITS-SVC 将孙燕姿的音色模型应用于大量流行歌曲，从《好汉歌》到周杰伦曲目，生成效果"和原唱一模一样"。视频迅速出圈，引发全民热议。澎湃新闻报道称，"这个项目名叫 SoftVC VITS Singing Voice Conversion"。[^3] 品玩以《「AI孙燕姿」全网沸腾！AI翻唱大爆发，整个华语乐坛都「复兴」了》为题报道。[^4]

**随后** — 因法律风险（版权与肖像权争议），SoVITS-SVC 项目宣布**停止维护**。但 GitHub 星标已涨至 8.4k，社区 Fork 和模型分享在 B 站、HuggingFace 上继续繁荣。腾讯云报道称"项目虽停更，但星标涨至 8.4k"。[^2]

### 后继：GPT-SoVITS（2024 年 1 月）

**2024-01** — **RVC-Boss** 发布 **GPT-SoVITS**，将 GPT（生成式预训练 Transformer）与 SoVITS 结合，实现**少样本语音克隆**——仅需 1 分钟音频即可训练出高质量的 TTS 模型。项目上线两天即获 1.4k GitHub star。稀土掘金, 2024-01-25[^5]; Medium/David Cochard[^6]

GPT-SoVITS 迅速成为中文开源语音合成的事实标准，持续迭代至 v4（2025 年 4 月）和 v2pro（2025 年 6 月）。它保留了 SoVITS-SVC 的 WebUI 易用性传统，同时大幅提升了合成质量和跨语言能力。

### 影响

SoVITS-SVC → GPT-SoVITS 这条线，是大模型时代**消费级 AI 应用最先出圈的典范之一**。其影响远超语音合成本身：

- **全民体验 AI**：「AI 孙燕姿」让数以百万计的普通用户第一次亲手操作 AI 模型——下载整合包、训练音色模型、生成翻唱歌曲——比 ChatGPT 更早让「AI」成为一个动词。
- **技术启蒙的跳板**：大量用户在折腾 SoVITS 和 GPT-SoVITS 的过程中，首次接触到 VITS 架构、扩散模型（DDPM）、流匹配（Flow Matching）、声码器等概念，不少人由此进入 AI 研究和开发领域。
- **模型分享生态**：B 站、HuggingFace 上形成了庞大的音色模型分享社区，上千个角色模型被训练和公开，形成了独特的「AI 翻唱」亚文化。
- **降低门槛的范式**：从需要数小时高质量录音（传统 TTS）到「1 分钟语音即可」，GPT-SoVITS 改写了语音克隆的可及性。
