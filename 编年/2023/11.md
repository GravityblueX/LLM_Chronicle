# 2023年11月

## DeepSeek-LLM 67B：DeepSeek 的开源入场

> 一家来自中国的量化基金孵化出的 AI 团队，用一个 67B 参数的模型首次叩开了开源 LLM 的大门——超越 Llama 2，追平 GPT-3.5，但真正重要的是它之后要走的路。

### 发布

**2023-11-29** — 深度求索（DeepSeek，由幻方量化创始人梁文锋创办）正式发布 **DeepSeek-LLM**，包含 7B 与 67B 两个规模，同时开源 Base 与 Chat 版本。这是 DeepSeek 团队首个公开的大语言模型。代码采用 MIT 许可证，模型权重采用 DeepSeek Model Agreement 发布。GitHub: deepseek-ai/DeepSeek-LLM[^1]; arXiv:2401.02954, 提交于 2024-01-05[^2]

模型从零开始训练，使用 2 万亿 token 的中英双语数据集，Base 模型在推理、编程、数学与中文理解上全面超越 Llama 2 70B。Chat 模型通过 SFT + DPO（Direct Preference Optimization，而非当时主流的 RLHF）进行对齐，在开放式评测中超越 GPT-3.5。[^2]

### 关键技术数据

### 技术意义

DeepSeek-LLM 的技术贡献主要在两条线：

**Scaling law 研究**：论文系统研究了开源配置（7B 与 67B）下的 scaling law，在 Chinchilla 之后为中等规模模型的算力-数据配比提供了独立验证。DeepSeek 团队提出了"长期主义"（Longtermism）理念——训练数据和架构设计不是为了一次发布的最优，而是为未来迭代的可扩展性。

**DPO 替代 RLHF**：Chat 模型使用 DPO 进行对齐，不依赖 RLHF 的奖励模型训练与 PPO 优化。Rafailov 等人的 DPO 论文（arXiv:2305.18290）刚发表半年，DeepSeek 是较早将其应用于 67B 规模模型的团队之一。这种"轻对齐"范式在后续的 DeepSeek-V2 和 R1 中被进一步推进到极端——R1-Zero 甚至完全跳过了 SFT。

### 评价

DeepSeek-LLM 本身不是最亮眼的那一颗星。67B 参数、超越 Llama 2、追平 GPT-3.5——这些在 2023 年底的开源 LLM 竞赛中是"体面"而非"震撼"。如果 DeepSeek 止步于此，它不过是又一家"也做了一个 70B 开源模型"的中国公司。

但它没有止步。

从 LLM 到 V2（2024-05），再到 V3（2024-12）和 R1（2025-01），DeepSeek 走了一条清晰的路线：**每一代模型都把效率当作核心指标，而不是参数规模**。LLM 论文中的 scaling law 研究是这条路的起点——"先搞清楚怎么有效训练，再谈怎么做大"。这条方法论在后来的 V2（MoE+MLA 降推理成本）、V3（$5.6M 训练成本）和 R1（纯 RL 炼推理）中一以贯之。

用十年建城的眼光看，DeepSeek-LLM 是地基。不华丽，但扎实。没有它，就没有后来的 V2、V3、R1。每个团队的每一步，都是从第一铲土开始的。

### 评曰

DeepSeek-LLM 的发布在 2023 年底的中国 AI 圈并没有引起太大波澜。彼时所有目光都在 ChatGPT 一周年（2023-11-30）和 Llama 2 的开源生态上——谁能想到，一年后"DeepSeek"这三个字会成为整个硅谷讨论最多的话题。

这篇论文没有后来 V3 和 R1 那种"炸裂"的数据——$5.6M 训练成本、MIT 开源、纯 RL 涌现推理。但仔细读，它已经展现了 DeepSeek 团队最鲜明的三个特点。第一，**不迷信参数规模**——67B 对标 70B，不是因为做不大，而是因为"够了"。第二，**轻对齐路线**——用 DPO 而不是 RLHF，暗示了对训练管线复杂度的警惕。第三，**开源**——从第一天起就公开了模型权重，这在当时国产 LLM 圈并不多见。

这些特点在当时是"选择"。两年后回头看，它们是"必然"。
