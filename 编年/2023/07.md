# 2023年7月

## Llama 2：开源从事故变成战略

> 四个月前，Llama 是被泄漏的。四个月后，Meta 主动发布了 Llama 2——完全开源，允许商用，通过微软 Azure 分发。从"被迫开放"到"主动开放"，Zuckerberg 只用了 145 天。

### 发布

**2023-07-18** — Meta 与微软联合发布 **Llama 2**，三个规模：7B、13B、70B。所有版本均提供预训练基座模型和指令微调版（Llama 2-Chat）。[^1]

关键变化：**开源许可证允许商用和研究**。与 Llama 1 的"研究用途仅限经审批的机构"完全不同。虽然许可证仍包含一些限制（月活用户超过 7 亿需要额外许可），但这是第一个真正意义上的"商用开源大规模语言模型"。

另一个重要的战略动作：**与微软合作分发**。Llama 2 不仅可以在 Meta 的渠道下载，还可以通过 Azure AI 目录直接部署——这在 AI 行业是一个意味深长的信号：微软同时押注了 OpenAI（闭源）和 Meta（开源）。"我们不再赌一个方向了"——这是微软没有说出口但用行动表明的策略。

### 训练与性能

- 训练数据：2T tokens，比 Llama 1 增加 40%
- 上下文窗口：4,096 tokens（Llama 1 是 2,048）
- 70B 版本在 MMLU 上达到 68.9%——虽然仍低于 GPT-4 的 86.4%，但已经与 GPT-3.5 持平，且完全开源可商用
- Llama 2-Chat 70B 在人类评估中与 ChatGPT (GPT-3.5) 大致持平

Llama 2-Chat 使用了大量 RLHF 对齐工作——Meta 的论文花了很大篇幅描述他们对安全性和有用性的优化，这在开源的"原始基座模型"发布中并不常见。Meta 显然从 Sydney 事件和其他 AI 安全争议中吸取了教训。

### 影响

Llama 2 的商用许可是一个临界点。在此之前，"开源大模型"的讨论中总有一个问号：能商用吗？Llama 2 回答了这个问号。此后，基于 Llama 2 的商业产品开始出现——从企业级 AI 助手到垂直行业的定制模型。它让开源 LLM 从"学术玩具"变成了"商业可用的基础设施"。

### 评曰

从"泄漏事故"到"主动开源"，Llama 2 是大模型史上最成功的战略转身之一。Meta 用了 145 天，完成了一次品牌重塑：原本是一个被盗的模型，变成了一个被奉为"开源 AI 旗帜"的模型。

这背后的商业逻辑清晰到近乎冷酷。Zuckerberg 不需要靠卖 API token 赚钱——Meta 的收入来自广告。开源 Llama 对 Meta 的威胁为零（它不卖 AI 服务），但对 Google 和 OpenAI 的威胁巨大。每一个部署 Llama 的企业，就少了一个购买闭源 API 的客户。开源不是慈善——开源是竞争。

另一个不常被注意的角度：微软同时投资了 OpenAI（闭源）并通过 Azure 分发 Llama 2（开源）。这是一手妙棋——无论闭源赢还是开源赢，微软都站在赢家一边。在 2023 年 7 月，这是整个大模型行业最优雅的风险对冲。

## Claude 2：100K 上下文的首个商用模型

> 在 2023 年 7 月，一次对话能塞进几百页文档还是一个科幻想法。Anthropic 把它变成了 API 参数。Claude 2 没有在 benchmark 上全面超越 GPT-4——但它打开了一扇门：让模型处理整本书、整份财报、整个代码库，而不再只是几千字的片段。

### 发布

**2023-07-11** — Anthropic 发布 **Claude 2**，同时上线面向公众的 beta 聊天网站 claude.ai（限美国/英国）。API 价格与 Claude 1.3 持平。[^2]

Claude 2 是 Anthropic 从"闭门研究"走向"公开商用"的关键一步。此前的 Claude 1.x 主要通过 API 向合作伙伴提供，没有面向公众的界面。Claude 2 首次让普通用户注册账号即可与 Claude 对话——这比 ChatGPT 晚了近八个月，但 Anthropic 并不急于抢时间。它在安全对齐和上下文长度上押注。

### 100K 上下文：把整本书塞进提示词

Claude 2 最突出的突破是 **100K token 上下文窗口**（约 75,000 词）。作为对比：GPT-4 当时的公开上下文为 8K（32K 版仅限特定合作伙伴），GPT-3.5 为 4K。Claude 2 的上下文是 GPT-4 公开版的 12.5 倍。[^3]

这意味着用户可以一次性提交数百页文档给 Claude 分析——整份财报、整部法律、整本小说。Anthropic 在演示中把《了不起的盖茨比》全文（72K tokens）载入，改动了一行字，Claude 在 22 秒内找出了修改之处。

100K 上下文不只是"更长"——它改变了可使用场景的类别。传统 RAG（检索增强生成）需要把文档切成碎片然后做向量搜索，结果可能丢失跨段落的推理和全局结构。而把整个文档直接放进上下文，模型可以自己建立全文理解。Anthropic 明确将这个对比写进了博客："对于复杂问题，这很可能比基于向量搜索的方法好得多。"[^3]

### 性能提升

Claude 2 在多个基准上相比 Claude 1.3 有显著提升：[^2]

| 基准 | Claude 2 | Claude 1.3 | 提升 |
|------|:--:|:--:|:--:|
| Bar Exam（选择题） | 76.5% | 73.0% | +3.5 |
| Codex HumanEval（编程） | 71.2% | 56.0% | +15.2 |
| GSM8k（小学数学推理） | 88.0% | 85.2% | +2.8 |
| GRE 阅读/写作 | 超过 90% 考生 | — | — |
| GRE 定量推理 | 约中位数水平 | — | — |

同时，Anthropic 报告 Claude 2 在内部安全红队评估中**无害响应率是 Claude 1.3 的 2 倍**——这在从 Claude 1.x 的 Constitutional AI 基础上延续了对齐优先路线。[^2]

### 商业落地

Claude 2 是 Anthropic 首次大规模商业落地的产品。发布时已经与两家合作伙伴公开合作：

- **Jasper**（AI 内容平台）：工程 VP 称 Claude 2 在长文本低延迟场景中"能与其他最先进模型正面交锋"，上下文窗口比竞品大 3 倍
- **Sourcegraph**（代码 AI 平台）：其 AI 编码助手 Cody 使用 Claude 2 的 100K 上下文来传递更多代码库背景，同时利用其更新的训练数据（包含更新的框架和库知识）

这两个合作案例分别代表了 Claude 2 两个核心卖点：长文档理解（Jasper）和大型代码库上下文（Sourcegraph）。

### 在 GPT-4 阴影下的生存策略

2023 年 7 月的大模型格局：GPT-4 已经发布四个月，在几乎所有主流 benchmark 上保持明显领先。Claude 2 没有选择在 GPT-4 最强的维度上正面对抗——它选择了两个 GPT-4 当时没有覆盖的突破口：

1. **上下文长度**：GPT-4 公开版只有 8K。如果你需要分析一份 50 页合同或一本技术手册，Claude 2 是唯一选择
2. **安全透明度**：Anthropic 公开了模型卡、Constitutional AI 方法论和红队评估结果，而 GPT-4 的技术报告几乎没有参数和训练细节

这种"不对称竞争"奠定了 Anthropic 后续的产品哲学——不是做最强的模型，而是做最有用的模型；不是和你比智商，是和你比能用多久不出事。

### 评曰

Claude 2 不是 2023 年最强的模型，但它是 2023 年最重要的"长上下文"信号。在它之前，100K 上下文是一个研究概念。在它之后，它成了所有模型必须回答的需求。2024 年初，Gemini 1.5 Pro 带着 1M 上下文拍马赶到；GPT-4 Turbo 扩展至 128K；中国的 Kimi 更是以 200 万字上下文作为核心卖点。这条赛道的起点，就是 Claude 2 在 2023 年 7 月踩下的第一脚。

更深一层：Claude 2 证明了"不对称竞争"在大模型市场是可行的。不是只有正面超越 GPT-4 一条路——你可以选择 GPT-4 不擅长或不在乎的维度，在那里建立滩头阵地，然后逐步向其他维度扩散。Anthropic 后来在 Claude 3、Claude 3.5 Sonnet 上一步步缩小了与 OpenAI 的通用能力差距，但它的起点不是追赶，是迂回。
