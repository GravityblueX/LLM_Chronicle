# 2023年4月

## 中系模型的集体登场：文心一言、通义千问、ChatGLM

> ChatGPT 发布四个月后，中国互联网三巨头和一个清华实验室在同一个月亮出了各自的答案。这不是一次协调行动，但放在一起看，它们画出了中国 AI 未来三年的路线图：三条路——闭源、开源、学术开源——从同一个起点出发，走向了完全不同的方向。

### 背景：ChatGPT 的冲击

ChatGPT 在 2022 年 11 月发布后，全球互联网公司陷入集体恐慌。Google 发布了"红色警报"，微软快速将 GPT-4 集成入 Bing。但在中国，情况更复杂——ChatGPT 不支持中国地区注册，也不提供中文优化。这意味着中国用户既无法直接使用，也无法期待 OpenAI 为中国市场做适配。

这给中国 AI 公司留下了一个窗口：**造一个中国人能用的 ChatGPT**。时间窗口很窄——所有人都知道 OpenAI 不会等，Google 不会等。2023 年 3 月至 4 月，中国的主流大模型产品在一个月内密集发布。

### 文心一言：百度的全栈闭源路线

**2023-03-16** — 百度在北京总部召开发布会，正式推出 **文心一言**（ERNIE Bot）。CEO 李彦宏亲自站台演示。发布会当天，百度港股跌 6%——市场对 demo 的录播而非实时演示表示失望。[^1]

文心一言基于百度的 ERNIE 系列模型（从 2019 年的 ERNIE 1.0 迭代至 ERNIE 3.0/4.0），是当时中国唯一拥有从芯片（昆仑芯）到框架（飞桨 PaddlePaddle）到模型（ERNIE）到应用（文心一言 + 百度搜索）的**全栈自研**体系。这是百度的最大筹码——不受 GPU 禁运的完全制约，不受开源框架的依赖。

百度选择了**闭源 + API + 产品矩阵**的路线，与 OpenAI 高度相似。发布后，文心一言逐步接入百度的全线产品——搜索、地图、网盘、文库。策略是：用 AI 改造百度已有的海量用户产品，而非单独打造一个新的超级 App。

到 2024 年，文心一言升级至 4.0，据称用户数超过 2 亿。但在开发者社区中，百度的闭源策略和飞桨生态的封闭性一直是被批评的焦点。

### 通义千问：阿里的开源 + 云生态路线

**2023-04-11** — 阿里云在北京阿里云峰会上发布 **通义千问**（Tongyi Qianwen）。CEO 张勇宣布"阿里巴巴所有产品未来都将接入大模型"。[^2]

通义千问的定位从一开始就与文心一言不同：它不是一个人的助手，而是**所有阿里产品的 AI 底座**——钉钉、天猫精灵、淘宝搜索、高德地图、阿里云，全部接入。

更关键的战略选择在 2023 年 8 月揭晓：阿里发布了 **Qwen** 开源系列（7B/14B/72B）——这是中国互联网巨头中第一个大规模开源 LLM 的举动。此后 Qwen 2（2024-06）、Qwen 2.5（2024-09）、Qwen 3（2025-04）持续迭代，覆盖从 0.5B 到 235B 的全规模谱系，Apache 2.0 许可——成为全球最完整的开源 LLM 家族之一。

阿里的路线与百度形成了鲜明对比：

| | 百度（文心一言） | 阿里（通义千问/Qwen） |
|---|---|---|
| 模型策略 | 闭源 | 闭源 + 开源双轨 |
| 分发渠道 | 自家产品矩阵 | 阿里云 + 开源社区 |
| 目标用户 | C 端消费者 + B 端企业 | 开发者 + 企业 + 阿里生态 |
| 底层框架 | 飞桨 PaddlePaddle | 开源兼容（PyTorch） |
| 定位 | ChatGPT 的中国替代 | 中国 AI 基础设施 |

阿里的双轨策略被证明是极其有效的。开源 Qwen 系列在 HuggingFace 上积累了上亿次下载，建立了巨大的开发者生态，而闭源的通义千问则服务阿里自身的产品和云客户。**"开源抢社区，闭源抢收入"**——这个策略后来被 DeepSeek 推到了极致。

### ChatGLM：智谱的学术开源路线

**2023-03** — 智谱 AI 与清华大学联合发布 **ChatGLM-6B**，一个仅有 6B 参数的中文对话模型。单卡消费级 GPU 可运行，开源，在 GitHub 上迅速获得数万 star。[^3] 随后在 2023-06 发布了 ChatGLM2-6B，上下文窗口扩展至 32K。

ChatGLM 的独特之处在于两个方面：

**第一，技术路线独立。** 与文心一言和通义千问不同，ChatGLM 不是"ChatGPT 的中文替代"，它有自己独立的模型架构——**GLM（General Language Model）**。GLM 在 2022 年就提出了，是一种自回归填空（autoregressive blank infilling）的预训练框架——同时具备 BERT 式的双向理解和 GPT 式的单向生成能力。在 Transformer 解码器主导一切的时代，GLM 是一个真正独立的架构选择。

**第二，学术出身。** 智谱 AI 脱胎于清华大学唐杰教授的团队。这使得 ChatGLM 从一开始就带有浓厚的学术开源色彩——模型权重公开、技术报告详细、鼓励社区微调和二次开发。这与百度的"全栈封闭"和阿里的"双轨商用"形成了第三极。

智谱的路线演进：
- **2023-03~06**：ChatGLM-6B 系列——学术开源，社区共建
- **2024-01**：GLM-4——128K 上下文、多模态、All-Tools，对标 GPT-4，进入商用阶段
- **2026-04**：GLM-5.1——318 事变后国产替代的核心力量，SWE-bench 表现优异

从学术开源到商业产品，智谱的轨迹是一条从清华实验室走向中国 AI 第一梯队的路程。在 318 事变（2026-03）中，GLM-5.1 因为在美国模型蒸馏指控中"全身而退"而获得了意外的信任红利。

### 三条路的分野

2023 年 3-4 月，文心一言、通义千问、ChatGLM 几乎同时出现。但仅仅一年后，它们走到了完全不同的位置：

- **百度**选择了最像 OpenAI 的路——闭源 + 强产品绑定 + 全栈自研。这条路依赖巨大的产品和流量矩阵，但开发者的离心力也很强。在 2025-2026 年，当 DeepSeek 以 MIT 开源炸开市场，百度的闭源策略开始承受压力。
- **阿里**选择了最灵活的路——双轨。开源 Qwen 抢占了 HuggingFace 和全球开发者生态，闭源通义千问服务于阿里云的企业客户。这条路在商业上稳，在生态上广，但"核心模型能力"始终被认为比前沿差半步。
- **智谱**选择了最纯粹的路——学术驱动 + 自主架构。GLM 架构的独特性让智谱避免了"追随 ChatGPT"的标签。但学术出身的成本和规模限制也使得智谱在 2023-2024 年的模型能力竞争中始终处于第二梯队，直到 GLM-5.1 才真正站上前排。

### 评曰

2023 年春天的中国大模型发布潮，与其说是一场技术竞赛，不如说是一场**路线选择实验**。

百度选了闭源全栈——这是最重的路，也是大公司最自然的直觉：既然我什么都有（芯片、框架、模型、产品、用户），为什么要给别人分一杯羹？阿里选了双轨——这是最务实的路，阿里云的基因决定了它必须同时做最封闭和最开放的事，因为它的客户要两者。智谱选了学术开源——这是最理想主义的路，也是资源最少的团队最理性的选择：当你的算力和数据都不如巨头时，开源是唯一能让你撬动外部力量的方式。

三条路在三年后各有胜负。阿里的双轨证明了可持续性——社区和收入两条腿走路。智谱的开源证明了独立架构的价值——与众不同本身就是一个防御壁垒。而百度的闭源，在 2026 年的 DeepSeek V4 和 GLM-5.1 面前，面临了最根本的拷问：当一个闭源模型的性能被开源模型追上时，它的品牌溢价在哪里？

这个拷问不只属于百度。OpenAI 也在回答同一个问题——只是它比百度多跑了两年。
