# 2026年8月

## 开放之后是部署：从 2.4T 权重到国产芯片与物理 Agent

> 7 月的模型竞赛证明前沿智能已经开始分层；8 月则把问题继续推向“最后一公里”：模型做出来以后，究竟由谁运行、在哪种硬件上运行、通过什么价格和云渠道交付，又能把行动权延伸到多远。阿里把 Max 级旗舰开放权重，又在月底推出更便宜的 Qwen3.8-Flash 与下一代架构预览；Meta 把 always-on Agent 压到单张消费级 GPU；智谱让 GLM-5.3-Flash 的匿名生产流量全部跑在国产 AI 芯片上；DeepSeek 从 V4-Flash 到高价 Pro、峰谷调度与视觉 Agent；Google 和 OpenAI继续压低高频工作模型的价格；Anthropic 则从 runtime safeguards、文本水印一路走到让 Agent 操作显微镜与机械臂的 Model Hardware Standard。到月底，“模型”已经越来越像权重、runtime、硬件、云、价格、权限和治理共同组成的执行系统。

### Qwen3.8-Max：Max 级模型第一次进入 Qwen 开放权重主线

**2026-08-03** — 阿里巴巴发布 **Qwen3.8-Max**，官方给出的规模为 **2.4T 总参数**，支持 **1M token** 上下文和原生视觉输入，并把编码、专业工作、研究与长程任务作为主要能力方向。阿里同时宣布，这一代将成为 Qwen 第一次开放 **Max 级旗舰模型**权重的版本。[^1][^2]

此前 Qwen 的开放生态虽然尺寸完整，但最顶层 Max 长期主要通过云 API 交付。Qwen3.8 改变了这个边界：旗舰层本身进入公开权重路线。

**2026-08-12** — **Qwen3.8-2.4T-A95B** 权重上线 Hugging Face 与 ModelScope。官方资料称其采用稀疏 MoE，2.4T 总参数、每步约 **95B 激活参数**，配合混合注意力与 1M token 上下文。[^3][^4]

这里出现了与 Kimi K3 相同的新矛盾：权重越开放，模型本身却越大。2.4T 或 2.8T 级模型不再是“下载下来就能自己跑”的传统开源体验。开放权重解决的是**可检查、可改造、可再部署**的问题，却没有自动解决**谁有机器把它跑起来**的问题。

因此 2026 年的“开放模型”至少已经分成两条路线：

| 路线 | 代表 | 开放主要解决什么 |
|------|------|------------------|
| 超大开放旗舰 | Qwen3.8-Max / Kimi K3 | 前沿权重可获得、可托管、可二次开发 |
| 本地开放 Agent | Muse Glimmer | 文件、记忆与工具留在个人设备，获得运行时控制权 |

### Muse Glimmer：把 Agent 从数据中心压回一张消费卡

**2026-08-10** — Meta 发布 **Muse Glimmer**，开放模型权重并采用 Apache 2.0 许可。模型规模 **30B**，目标不是与数万亿参数旗舰正面比榜，而是让 “always-on local agent” 在 Mac、PC 或单张消费级 GPU 上成立。Meta 将其使用场景定位为本地 Agent、函数调用、本地编码和 LLM-as-a-judge，并针对长程执行、工具调用、多模态理解和本地记忆进行训练与量化优化。[^5][^6]

Glimmer 让“开放”获得另一种含义：不是能不能下载一个世界级旗舰，而是**能不能真正掌握模型运行时**。一个能力弱一些但离线常驻的 Agent，在隐私、延迟、个人文件和持续记忆上可能比巨大开放权重模型拥有更直接的用户控制权。

### DeepSeek V4-Pro：低价品牌第一次明显形成高低档分层

**2026-08-13** — DeepSeek 正式发布 **DeepSeek-V4-Pro-0813**。官方称其 Agent 能力显著增强，并加入 Responses API 与 Codex 接入，网页、App 与 API 同时上线。Reuters 报道称，DeepSeek 同日调整 V4-Pro 与 V4-Flash API 价格，并引入峰谷定价。[^7][^8]

Reuters 援引 Artificial Analysis 的数据称，当时 V4-Pro 的输入 / 输出价格显著高于 V4-Flash。真正值得记录的并不是具体倍数，而是产品结构：

- Flash 负责压低单位调用成本；
- Pro 负责更复杂 Agent 与更高任务完成率；
- 峰谷价格把并发和资源调度直接写进价目表。

这修正了“DeepSeek 就是把一切卖得越来越便宜”的线性叙事。Agent 时代更贵的 token 只要减少重试、返工和人工接管，也可能拥有更低的**成功任务总成本**。

**2026-08-21** — DeepSeek 又上线 **V4-Flash-Vision-Exp**。官方称其纯文本能力大致保持 V4-Flash 水平，但视觉 Agent 任务明显增强。[^18]

视觉在这里不是“多一个看图功能”，而是 Agent 的感知通道：网页、截图、图表、GUI 和 computer-use 环境都需要模型看见状态才能继续行动。DeepSeek 从 V3.2 的 thinking-in-tool-use 到 V4 的长上下文，再到 V4 Vision，正在补齐长期执行系统的输入闭环。

### Gemini 3.7 Flash：旗舰迟到，工作马却三周一更

**2026-08-13** — Google 发布 **Gemini 3.7 Flash**，距离 3.6 Flash 仅三周。Google 将其称为 “most intelligent workhorse model yet”，重点提升软件工程、知识工作、网页开发和 Agent 工作流，并给出**仅为 3.6 Flash 原始价格一半**的首发价。[^9][^10]

此时市场等待已久的 Gemini 3.5 Pro 仍未正式发布。于是 Gemini 产品节奏出现看似反常的结构：旗舰 Pro 延期，Flash 却像软件版本一样连续迭代。

这符合 Agent 的经济学：一个任务可能触发几十轮搜索、代码执行、文件解析和工具调用，每次调用便宜一点、快一点、稳定一点，会在长任务中被成倍放大。最高 benchmark 分数属于旗舰，但**真正跑最多生产 token 的可能是工作马**。

### GPT-5.6：从发布更强模型转向扩大“可用智能总量”

**2026-08-06** — OpenAI 更新 ChatGPT 中的 **GPT-5.6 Sol**，强调回答聚焦度和事实可靠性，并加入可调节思考投入；同时扩大 **GPT-5.6 Luna** 对 Free 与 Go 用户的可用范围。[^11]

**2026-08-21** — OpenAI 将 GPT-5.6 Sol 的 API 与 credits 价格临时下调 **超过 20%**，持续三个月。此前 7 月 30 日，Luna 和 Terra 的价格已经分别大幅下调。[^12][^13]

这些动作没有创造新模型代际，却改变了**同一代智能被分配给谁、以多少成本被调用**。GPT-5.6 的后半段竞争从能力发布转向利用率：更大免费覆盖、更低单价，以及让用户自己选择 reasoning effort。

模型厂商开始优化的不只是“一个回答有多聪明”，而是整个社会能消耗多少高质量推理和工作 token。

### 安全与治理也被拆成独立基础设施

**2026-08-04** — Mistral 发布 **Shieldstral**，一个约 3.8B 的开放权重多模态安全分类模型，Apache 2.0 许可，可在单张 16GB GPU 上运行。它可以把审核规则写成自然语言 policy question，在推理时切换政策，而不必为每套规则重新训练分类器。[^14][^15]

这等于把 guardrail 从厂商 API 内部拆出来，变成开发者可以部署、查看和自定义的一层模型。

**2026-08-07** — Anthropic 更新 **Fable 5 biology safeguards**。官方称内部测试中 biology 相关 fallback 下降约 **85%**，让更多正常科研请求不再被过度切换到较低能力模型。[^19]

底层 Fable 权重没有改变，快速迭代的是围绕它的 classifier 与 fallback policy。安全层开始像模型服务本身一样版本化。

**2026-08-14** — Anthropic 宣布未来 Claude 模型文本采用统计式**文本水印**，以满足欧盟 AI Act 等透明度要求。Anthropic 强调该方法不添加隐藏字符、不额外消耗 token，也不携带可以追踪到具体用户、组织或对话的身份信息。[^16]

治理要求因此越来越直接进入推理栈：classifier、provenance、水印、权限、沙箱和审计日志开始像 tokenizer、KV Cache 一样成为模型系统的常规组成部分。

### 8 月 26 日：Flash 竞争同时向中国三条路线集中

8 月最后一周出现了一组很有代表性的同步发布。

#### Qwen3.8-Flash：Max 之后立刻争夺生产负载

**2026-08-26** — Alibaba Cloud 文档更新 **qwen3.8-flash**，作为 Qwen3.8 系列的 hybrid-thinking 多模态模型，与 qwen3.8-max 同时覆盖文本、视觉与深度思考场景。[^20]

这使 Qwen3.8 家族完整呈现出与 GPT / Gemini / DeepSeek 类似的分层逻辑：Max 不再独占产品叙事，Flash 负责高频、低延迟和成本敏感任务。

#### Qwen3.8-Flash-Next：开放权重开始提前预演下一代架构

同日，Qwen 团队开放 **Qwen3.8-Flash-Next** 权重。官方仓库将它描述为 Qwen3.8-Flash-Next foundation model，并明确标注 2026-08-26 release；相关发布材料把它作为下一代 Qwen 架构方向的早期预览。[^21]

这延续了 Qwen3-Next 的做法：开放权重不只交付“已经成熟的上一代”，还可以让社区提前参与下一代 runtime 和架构适配。

#### GLM-5.3-Flash：前沿模型第一次把“国产芯片 production serving”做成发布主角

**2026-08-26** — Z.ai / 智谱上线并开源 **GLM-5.3-Flash（320B-A18B）**，这是 GLM-5 系列首个原生多模态模型。官方披露其 **320B 总参数、18B 激活参数**，采用 sparse + linear attention hybrid、mHC，并在 30T-token 多模态语料上训练。[^22]

更值得记的是它的部署方式。正式发布前，模型以 **Ox-Alpha** 匿名测试，官方称这些真实流量**全部由国产 AI 芯片提供算力支持**。[^22]

这把“中国模型自主化”的衡量标准推进了一层：不再只是“国产模型能训练出来”，而是**前沿开放模型能否在国产加速器上承受真实、高并发、全球化的生产请求**。

如果说 DeepSeek 代表模型与算法效率，Qwen 代表开放模型与云平台循环，那么 GLM-5.3-Flash 把另一个问题推到前台：**serving stack 本身也是模型竞争力。**

### Kimi K3 云托管谈判：开放权重仍需要分发渠道

**2026-08-26** — Reuters 报道 Moonshot AI 正与 Microsoft、Amazon、Google 就 Kimi K3 云托管与收入分成进行早期谈判，讨论事项包括分成比例、数据访问和 token 使用审计；谈判当时尚未完成。[^17]

K3 是开放权重模型。理论上，任何合规获得权重的人都可以部署；现实中，2.8T 参数使企业级推理高度依赖成熟云基础设施。

开放权重和商业云并不矛盾。模型越大，二者甚至越绑定：**开放决定谁有权运行，云决定谁实际上跑得起。**

### 8 月 27 日：Agent 的“最后一公里”开始离开电脑

**2026-08-27** — Reuters 报道 Anthropic 发布 research preview **Model Hardware Standard（MHS）**，目标是让 AI Agent 通过标准化接口操作可编程物理设备，包括实验室和先进制造中的机械臂、显微镜等。Anthropic 先向部分合作伙伴开放用于安全评估，并计划未来将该框架开放。[^23]

截至本篇补录时，Anthropic 官方 MHS 页面尚未被本书抓取工具检索到，因此此条按**单一权威媒体来源**记录，并明确标记为待补官方一手来源。

MHS 的方向并非凭空出现：Anthropic 7 月已经公开与 UST 合作，把 Claude 用于半导体、汽车和制造工程流程，也发布 Project Pilot 评估模型控制无人机的能力。[^24][^25]

从 Agent 史看，MHS 很有象征意义：

**Function Calling → MCP → Computer Use → Hardware Interface**

模型行动空间从软件 API、浏览器和桌面继续延伸到真实设备。此后权限、回滚和安全问题也不再只是“误删文件”，而可能涉及实验设备、机器人和生产线。

### 评曰

2026 年 8 月把“开放”和“部署”都拆碎了。

以前讨论开放模型，最常问的是：**权重放不放？许可证是什么？** 到 Kimi K3、Qwen3.8 和 GLM-5.3-Flash 以后，这远远不够。

2T、3T 级权重可以公开，但多数开发者仍需要云；30B 的 Muse Glimmer 能在本地常驻，反而提供另一种运行权；GLM-5.3-Flash 则说明即使模型开放，真正决定国家和企业自主性的还有**能不能在自己的芯片和 runtime 上以生产规模服务**。

同样，闭源也不是单一形态。Google 用 Flash 把云模型做得越来越像廉价高吞吐基础设施；OpenAI 用 Luna 免费层和 Sol 降价扩大调用量；DeepSeek 从低价 Flash 到高价 Pro 做能力分层；Anthropic 则用 classifier、watermark、trusted access 和 MHS 把治理与设备控制继续塞进模型外围系统。

月底的 Qwen3.8-Flash、GLM-5.3-Flash 和 MHS 又把问题进一步推开：

- “Flash”说明最重要的模型未必是最高分旗舰，而可能是承担最大生产流量的工作马；
- 国产芯片 serving 说明模型自主权必须延伸到硬件与推理引擎；
- MHS 说明 Agent 的边界开始从电脑扩展到物理世界。

因此 8 月真正换掉的问题是：

> **不是“模型开放了吗”，而是“智能最终由谁控制、在哪里运行、借助什么硬件和接口行动，又由什么制度限制它”。**

权重、GPU、国产加速器、API、云托管、Agent runtime、guardrail、许可证、价格、监管和物理设备一起构成了模型的“最后一公里”。

2023 年人们争论开源和闭源；2026 年的现实已经迫使我们承认：真正的生态位存在于两者之间的一整条**执行链与控制链**上。
