# 2026年5月

## Claude Mythos：一个不能公开发布的模型，和它引发的全球恐慌

> Anthropic 造出了一个能在"每个主流操作系统和每个主流浏览器"中找到漏洞的模型。它没有选择发布——而是选择了封锁。但封锁没有成功：发布当天就有人通过数据泄露获得了未授权访问。一个月后，美国政府以出口管制为由撤销了全球访问权限。

### Mythos 泄露与公开

**2026-03-26** — Claude Mythos 的存在因泄露的博客草稿而首次公开。Anthropic 随后向 *Fortune* 证实了 Mythos 的开发，并表示该模型对网络安全构成重大风险。据 *Axios* 报道，Anthropic 已在当月向政府官员发出关于 Mythos 能力的警告。Wikipedia, "Claude Mythos"[^1]

**2026-04-07** — Anthropic 正式公开披露 Mythos。公司声明**没有向公众发布 Mythos 的计划**，而是启动了 **Project Glasswing**——一个由企业联盟使用 Mythos 来发现和修复软件漏洞的项目。超过 40 家公司获得访问权限，包括 Microsoft、Apple、Google、Amazon Web Services、Linux Foundation、Cisco、Nvidia 和 Broadcom。[^1]

同日，据 *Bloomberg News* 报道，数名未授权用户利用最近的 **Mercor 数据泄露**获取的信息，通过一个私人 Discord 频道获得了 Mythos 的访问权限。[^1]

### 能力与影响

Claude Mythos 是一个专门设计用于发现软件漏洞的大型语言模型。UK AI Security Institute 的网络靶场测试中，Mythos 排名第一，Claude Opus 4.6 排名第二，GPT-5.4 和 GPT-5.3 Codex 并列第三。[^1]

Anthropic 表示，Mythos 在测试中发现了"**每个主流操作系统和每个主流浏览器**"中的漏洞。[^1]

具体成果：

- **Mozilla** 在 Mythos 发布两周后宣布，已使用该模型发现并修补了 Firefox 中的 **271 个安全漏洞**。[^1]
- **2026-05-14**：Calif.io 的员工宣布使用 Mythos 创建了一个影响 **Apple M5 芯片**的内存损坏漏洞利用。[^1]

### 全球政府反应

Mythos 发布数小时后，美国财政部长 Scott Bessent 和美联储主席 Jerome Powell 召集金融高管发出警告。摩根大通、高盛、花旗、美国银行和摩根士丹利开始测试 Mythos。加拿大央行次日召集主要贷款人举行类似会议。[^1]

各国政府密集响应：

- **2026-04-14**：*Bloomberg* 报道美国财政部寻求获取 Mythos 访问权限。[^1]
- **2026-04-16**：白宫与 Anthropic 就 Mythos 举行会议。[^1]
- **2026-04-23**：印度财政部长 Nirmala Sitharaman 召集银行和政府官员讨论 Mythos 带来的网络安全威胁。[^1]
- **2026-04-24**：日本金融厅召开公私联合会议，同意成立工作组应对 Mythos。[^1]
- **2026-04 月**：中国政府请求获取 Mythos 访问权限，但被 Anthropic 拒绝。[^1]

欧洲央行行长 Christine Lagarde 赞扬 Anthropic 限制 Mythos 访问的决定。未能获得 Mythos 的欧洲银行促使 **Mistral AI** 开始研发自己的安全模型。[^1] *The Conversation* 的 Thomas Fraise 则警告 Mythos 可能"摧毁核威慑"。[^3]

### GPT-5.5 系列扩展

**2026-05-05** — OpenAI 将 **GPT-5.5 Instant** 作为 ChatGPT 默认模型向所有**免费用户**开放，替代此前的 GPT-5.3 Instant。Wikipedia, "GPT-5.5"[^4]

**2026-05-07** — OpenAI 发布 **GPT-5.5-Cyber**，面向受审核网络安全团队的限制预览变体。这是 OpenAI 首次推出网络安全专用模型——直接回应了 Anthropic 的 Mythos 在该领域的统治地位。[^4]

### Qwen3.7 与 Claude Dreaming

**2026-05-18** — 阿里巴巴发布 **Qwen3.7** 系列，包含 Qwen3.7 Max 和 Qwen3.7 Plus。Wikipedia, "Qwen"[^5]

**约2026年5月** — Anthropic 为 Managed Agents API 引入 **"Dreaming"** 研究预览功能，通过合并重复项和清除过期条目来整合代理在会话间的持久化记忆。此前 3 月 Claude Code 源码泄露已泄露该功能（代号 **autoDream**）。Wikipedia, "Claude (language model)"[^6]

### Opus 4.8 与 Mythos 路线图

**2026-05-28** — Anthropic 发布 **Claude Opus 4.8**，并表示预计在数周内向所有客户开放"Mythos 级"模型，但需先开发额外的网络安全保障措施。[^1]

**2026-06-02** — Anthropic 将 Claude Mythos 的访问权限扩展至 **15 个国家的 150 个组织**，包括印度的多个机构。[^1]

### Gemini 3 Flash 更新

**2026-05-19** — Google 发布 **Gemini 3.5 Flash**，作为 Gemini 3 系列的最新更新。同期，Gemini 3 系列已形成完整矩阵：3.1 Pro（2026-02-19）、3 Deep Think（2026-02-12）、3.1 Flash-Lite（2026-03-03）。Google 的 Flash 系列延续了其"高效低价"策略，在保持强大多模态能力的同时大幅降低推理成本。[^2]

### 评曰

Claude Mythos 史上第一次，一家 AI 公司主动造出了一个"危险级别"的模型——然后选择不发布它。

这个决定的重量需要被准确理解。Anthropic 花了大量计算资源训练出了一个在网络安全领域远超所有竞品的模型。它本可以凭此收取天价 API 费用、锁定整个安全行业、在与 OpenAI 和 Google 的竞争中取得决定性优势。但它选择了封锁——只通过 Project Glasswing 向受控的企业联盟开放。

这不是一个技术决定，是一个**治理决定**。它设定了一个先例：有些模型足够危险，不应该被公开发布。问题是——谁来定义"足够危险"？当中国政府请求访问被拒、当美国政府以出口管制撤销全球权限、当 Mistral AI 因欧洲银行被排除在外而开始自研——每个参与者都在用行动回答这个问题，但答案各不相同。

Mythos 的悖论在于：它的价值恰好来自它的危险性。能在"每个主流操作系统和每个主流浏览器"中找到漏洞——这意味着它也能被用来制造攻击。Mozilla 用它修了 271 个漏洞；但同样的能力如果落入攻击者手中，这 271 个漏洞就不是"已修补"而是"已武器化"。两周的时间差——发现到修补的窗口——可能就是安全与灾难之间的距离。

6 月 12 日的出口管制撤销把问题推到了更尖锐的位置：当美国政府同时在国防部层面拉黑 Anthropic、又在出口管制层面限制 Mythos 的全球传播时，Anthropic 到底应该听哪个政府指令？在 AI 安全的治理问题上，我们还处于没有规则的蛮荒时代。
