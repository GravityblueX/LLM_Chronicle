# 2026年4月

## DeepSeek V4：从追赶者到替代者

> R1 火爆 15 个月后，DeepSeek 交出了一份没有悬念但依然震撼的答卷。V4 把成本差拉到了 370 倍——但比价格更值得注意的是：这一次，不是中国人在追赶美国模型，而是中国开发者在主动弃用美国模型。

### 发布

**2026-04-24** — DeepSeek 发布 **V4 Preview**，距 R1（2025-01）时隔 15 个月的首个重大版本更新。V4 提供 Pro 和 Flash 两个变体，支持 1M token 上下文窗口，MIT 许可开源。DeepSeek API Docs, 2026-04-24[^1]

### 价格与成本叙事

V4 的 API 价格被多家中文媒体报告为 GPT-5.5 的约 1/370（2.5 元/百万 token vs 130 美元/百万 token）。[^2] 这一价格对比来自第三方换算而非官方对照表，具体换算方式与模型配置可能影响结果，应保留适当谨慎。[^3]

从 V2 时代约 100 倍的价格差扩大到 V4 时代约 370 倍，暗示 DeepSeek 的效率优势在 15 个月内持续拉大而非缩小。V4 的技术细节截至编纂时尚未完全公开，但从 API 定价推断，其成本控制能力延续了 V2 → V3 → R1 一以贯之的"效率优先"路线。

### Claude 访问收紧与国产迁移潮

**2026-04-09** — 中文社区和国内媒体报告 Claude 对中国地区访问进一步收紧。[^4] 同日，智谱 **GLM-5.1** 登陆 Modal 平台，限时免费试用。[^5]

318 事变（2026-03）之后，中文开发者社区的迁移从被动应对转向主动选择。多家社区观察指出，2026 年初中国模型在部分生产型调用场景中的占比明显上升。[^6] 这些数据来自开发者社区自报告，具体规模与统计口径尚需更权威的数据源确认。

此后数月，DeepSeek V4 和 GLM-5.1 在中文开发者社区中被广泛讨论为海外御三家的主要替代选项。

### 评曰

DeepSeek V4 的技术贡献需要等待正式技术报告才能完整评估。但它在大模型史上的位置已经清晰——不是因为 benchmark，而是因为时间点。

318 事变刚刚证明了一件事：中国开发者对海外模型的依赖是一个地缘政治风险。而 DeepSeek V4 在一个月后就证明了另一件事：这个风险是可以被化解的——不是靠情怀，不是靠政策，而是靠一个成本低两个数量级、性能在同一量级的替代品。

V2 时代，DeepSeek 的 1% 定价让行业震惊。V3 时代，$5.6M 的训练成本让行业困惑。R1 时代，MIT 开源让行业不安。V4 时代，行业不再震惊、困惑或不安——行业在迁移。从"不可能"到"正在发生"，DeepSeek 用四代模型完成了从技术冲击到生态替代的完整弧线。

但"替代"这个词需要精确使用。V4 替代的是 API 调用层面的可用性——中文开发者可以无缝切换到一个更便宜、中文能力更强、不受地缘政治封锁影响的模型。它替代的不是"最好的模型"这个认知——GPT-5.5、Claude 在英文推理和部分专业领域可能仍有优势。V4 的真正冲击是：**"足够好"加上"便宜 370 倍"加上"不会被封"，在多数商业场景中已经碾压了"可能更好一点但贵 370 倍且随时可能断供"。**

这不是技术胜利。这是经济学胜利。
