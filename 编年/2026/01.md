# 2026年1月

## Claude Cowork：从命令行到桌面——AI 代理的平民化

> Claude Code 在程序员中爆发了，但 Anthropic 想要的不只是程序员。2026 年 1 月发布的 Claude Cowork 是一个带图形界面的桌面应用，让非技术用户也能让 AI 读写文件、执行代码、完成多步骤任务。同月，美国国防部将 Anthropic 排除在军事 AI 平台之外——两件事同时发生，构成了 Anthropic 的 1 月叙事。

### Claude Cowork 发布

**约2026年1月** — Anthropic 发布 **Claude Cowork** 的研究预览版（research preview）。[^1][^2]

Claude Cowork 是 Claude Code 的 GUI 版本——面向非技术用户的桌面应用，提供 Mac、Windows 原生客户端和 Web 界面。[^3] 与 Claude Code 的命令行交互不同，Cowork 为 Claude 提供了对用户本地文件系统的沙箱化访问权限，用户可以选择授权特定文件夹，使模型能够**读取、写入和编辑文件、执行代码，并在单次对话中链式完成多步骤任务**——例如整理电脑文件、从本地文件夹中的材料生成文档。[^4][^5]

> **编者注**：Claude Cowork 的产品细节（GUI 界面、沙箱文件系统、企业版扩展、Dispatch 功能）来源于 Wikipedia "Claude (language model)" 词条所引用的 Mashable、Towards Data Science、*Wall Street Journal*、CNBC 等媒体报道，但截至本文编写时，这些原始报道的独立 URL 未能逐一验证。本节事实声称的可信度依赖于 Wikipedia 引用链的完整性，读者如需引用，建议回溯核查原始来源。**后续审查发现 [^2]–[^7] 均指向同一 Wikipedia URL，无独立可验证原始链接——以下标注 [存疑] 的条目请读者注意核实。**

*The Journal*（*Wall Street Journal*）的一位记者在测试后指出了用户的核心顾虑：**授予 AI 对个人电脑的广泛访问权限**——这是所有桌面端 AI 代理产品都必须面对的信任问题。[^5]

**2026年2月** — Anthropic 宣布 Cowork 的企业版扩展，新增 Google Drive、Gmail、Docusign 和 FactSet 等服务的连接器，并为金融分析、工程和人力资源等领域提供可定制插件。公司称此次更新标志着 Cowork 从研究预览过渡为"企业级产品"。[^6]

**2026年3月** [存疑] — Anthropic 为 Cowork 加入 **Dispatch** 功能，允许用户从手机发送指令，Claude 可远程访问用户电脑上的程序（如浏览器、电子表格应用）来执行任务。[^7]

据开发者透露，Cowork 本身大部分由 Claude Code 构建。[^2]

### Anthropic–美国国防部争端升级

**约2026年1月** — *Semafor* 报道，美国国防部长 Pete Hegseth 在宣布 **GenAI.mil**（国防部 AI 平台）时，先后签约 Google Gemini 和 OpenAI 的 ChatGPT，随后又加入 xAI 的 Grok——**独缺 Anthropic**。Hegseth 公开抨击"woke AI"，Anthropic 被排除在军事 AI 生态之外。[^8]

这一排除并非突然。争端的根源可追溯至更早：

- **2025 年 9 月**：Anthropic 的使用政策与联邦调查局（FBI）、特勤局（Secret Service）和移民与海关执法局（ICE）的监控系统产生冲突。[^8]
- **2025 年 10 月**：特朗普 AI 顾问 David Sacks 指控 Anthropic 正在实施"基于恐惧制造的复杂监管俘获策略"。[^8]
- **2025 年 12 月**：Anthropic CEO Dario Amodei 与特朗普官员和参议员会面，试图改善关系。[^8]

**2026 年 1 月后**：国防部将 Anthropic 指定为"供应链风险"（supply chain risk），禁止所有美国军事承包商、供应商和合作伙伴与该公司开展业务。[^9]

**2026-03-26**：联邦法官对国防部的指定发出**临时禁令**。[^9]

### 争端的核心：Claude 能不能被用于战争

Anthropic 拒绝删除合同中关于禁止将 Claude 用于**大规模国内监控**和**全自主武器**的条款。[^9] 这一立场将 Anthropic 置于一个独特的位置：它是唯一一家因伦理立场而被美国国防部拉黑的主流 AI 公司。

Google（Gemini）、OpenAI（ChatGPT）和 xAI（Grok）则接受了军事合同。Meta 的 Llama 模型通过开源方式流入军事领域，无需正式签约。

### 评曰

Claude Cowork 和国防部争端——这两个事件看似无关，实则指向同一个问题：**AI 代理的边界在哪里？**

Cowork 代表了 AI 代理能力向普通用户的扩散。Claude Code 改变了程序员的工作方式；Cowork 试图对非技术用户做同样的事。让 AI 直接操作你的文件系统、执行代码、跨应用完成任务——这是"AI 助手"到"AI 代理"的关键跃迁。*Wall Street Journal* 记者的顾虑是真实的：你愿意让一个 AI 读写你电脑上的所有文件吗？这个问题的答案将决定整个"agentic AI"品类的上限。

国防部争端则是同一枚硬币的另一面。当 AI 代理变得足够强大，强大到可以"读写文件、执行代码、完成多步骤任务"时，政府自然会问：它能不能也被用来操作导弹？Anthropic 说不能——不是因为技术做不到，而是因为合同不允许。这在美国 AI 行业是第一次：一家公司因拒绝军事化自己的产品而被政府报复。

Google 和 OpenAI 接受了合同。Anthropic 被列入黑名单。三个月后，联邦法官叫停了这一决定。无论最终裁决如何，2026 年 1 月已经在大模型史上划下了一条线：AI 公司可以对政府说"不"，但说"不"是有代价的。
