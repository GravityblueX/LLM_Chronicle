# 2024年6月

## Qwen 2/2.5：阿里开源的全规模覆盖

> 从 0.5B 到 72B，全部 Apache 2.0 开源。Qwen 2/2.5 不是最强的开源模型——但它是覆盖面最广的。当你需要一个能跑在手机上的 0.5B 模型，和一个能对打 GPT-4 的 72B 模型，它们共享同一个架构、同一套训练方法论——这是阿里的赌注：AI 的未来不在一个超级模型，而在一个系列。

### 发布

**2024-06** — 阿里云发布 **Qwen 2**，包含 0.5B、1.5B、7B、72B 四个规模，覆盖从移动端到服务器的全场景。**2024-09** — **Qwen 2.5** 发布，增加 3B、14B、32B 中间规模，形成 0.5B-72B 的全谱系。[^1]

Qwen 2.5 在 MMLU 上达到 85.0%——虽略低于 Llama 3.1 405B 的 88.6%，但 72B 的参数只有 405B 的六分之一。在中文基准上，Qwen 2.5 全面领先 Llama 和 Mistral 的同级模型。

阿里的开源策略很清晰：**不追求"最大最强"，追求"最全最灵活"**。开发者可以根据场景选择规模——手机跑 0.5B，边缘设备跑 7B，企业服务器跑 72B。这种"全家桶"策略在全球开源生态中是独一无二的。Meta 的 Llama 系列覆盖面更窄（8B/70B/405B），Mistral 更少（7B/Mixtral/Large）。

Qwen 系列在 HuggingFace 上累计下载量超过数亿次，是中国模型在海外开源社区中影响力最大的产品。

## Claude 3.5 Sonnet：程序员的集体选择

> Anthropic 做了一件聪明的事：不给 Opus 发升级，给 Sonnet 发。Claude 3.5 Sonnet 以比 Opus 更低的价格，达到了接近甚至更强的效果。Artifacts 功能则完全重新定义了"AI 对话"的界面——一段对话，一个完整的应用。

### 发布

**2024-06-20** — Anthropic 发布 **Claude 3.5 Sonnet**，跳过 Opus 直接升级中端线。[^2]

Claude 3.5 Sonnet 在多项基准上超越了 Claude 3 Opus——而价格只有其三分之一。这是 Anthropic 在成本效益上的一次重大胜利。更重要的是，它在编程基准（HumanEval 92.0%、SWE-bench 40.6%）上的表现大幅领先 GPT-4o——这使得它迅速成为全球程序员群体的首选 AI 编程助手。

### Artifacts

随 Claude 3.5 Sonnet 同步发布的 **Artifacts** 功能，改变了 AI 对话的交互方式。以往，用户和 AI 的交互限制在聊天框内——文本进，文本出。Artifacts 允许 Claude 在同一界面中直接生成一个独立的内容窗口——可以是一段代码（可执行）、一个 React 组件（可预览）、一个 SVG 图形（可直接渲染）、一份设计文档。

这个功能看似只是 UI 改进，但实际上它对 AI 产品的影响深远：**"聊天"不再是唯一的交互方式。AI 可以"建造"，而不仅仅是"回答"。** Artifacts 在此后一年中被各大 AI 产品广泛借鉴——ChatGPT Canvas、Gemini 的交互面板、共享的 Co-pilot workspace，都是 Artifacts 的后继者。

### 影响

Claude 3.5 Sonnet + Artifacts 的组合让 Anthropic 在开发者群体中建立了忠诚度——特别是在编程和原型设计场景中。到 2025 年，Claude 已经成为大模型在编程基准（SWE-bench）上的默认对标线——不是因为它最强，而是因为开发者**觉得它最好用**。

### 评曰

跳过 Opus 升级 Sonnet——这看似技术路线调整，实际上是一个聪明的品牌信号。

Anthropic 在 Claude 3 发布时把 Opus 定位为"最强、最贵"的旗舰。如果按惯性，自然升级路线是发布 Claude 3.5 Opus——更大、更贵、更强。但 Anthropic 没有这么做。它升级了中端线 Sonnet，用更低的成本打出了接近甚至超越 Opus 的效果。这个动作传达了两个信号：第一，"我们不靠堆参数来提升体验"；第二，"最贵的模型不一定是最好用的模型"。

Artifacts 恰恰强化了第二个信号。它不是"让 AI 更强"——是"让 AI 的产出能直接用"。一段对话生成一个 React 组件，这个组件可以直接预览、复制、部署——不需要"复制代码→粘贴到编辑器→运行"的多步切换。这种用户体验上的洞察是 Anthropic 的首创——ChatGPT Canvas、Gemini 的交互面板都是后来者。

但 Claude 3.5 Sonnet 最持久的遗产是它在编程能力上的口碑。它证明了基准分数（benchmark）和用户实际感知之间可以存在巨大差距——开发者集体选择了一个在某些基准上略低但"感觉更好用"的模型。当模型的能力接近时，信任感和体验感就变成了核心竞争力。
