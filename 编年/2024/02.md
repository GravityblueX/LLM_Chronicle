# 2024年2月

## Sora：当视频从像素变成 token

> 一个提示词，60 秒视频。Sora 没有公开可用，没有 API，没有产品——但它发布的那些视频片段，把"AI 视频生成"从实验室的模糊 demo 变成了一种令人不安的逼真。所有人都知道视频生成的 ChatGPT 时刻快到了，只是没想到它来得这么早。

### 发布

**2024-02-15** — OpenAI 发布 **Sora**，一个基于 **DiT**（Diffusion Transformer）架构的文生视频模型。能生成最长 60 秒的 1080p 视频，画面一致性和物体持久性远超此前的 Runway Gen-2 和 Pika。[^1]

Sora 的核心技术是将视频表示为"时空补丁"（spacetime patches）——类比于 ViT 将图像拆成 patch，Sora 将视频拆成三维的时空块，然后用 DiT（扩散模型 + Transformer 的结合）在潜在空间中生成。这使得 Sora 天生具有对物体的**3D 一致性**——同一物体在移动、遮挡、旋转后仍然保持形状和纹理不变。

OpenAI 展示的 demo 视频令人震撼：东京街头一位时髦女性在雨中走过霓虹灯下，水洼中的倒影随脚步波动，路人从镜头前穿过时自然地遮挡她——然后她从容地从遮挡后走出来，衣服、发型、步态完全一致。这不是"每帧独立生成再拼起来"能做到的。Sora 对物理世界有了一种粗略但令人不安的"理解"。

### 未公开的部署

Sora 发布后没有如期向公众开放。OpenAI 给出的理由包括：安全性评估、防止 deepfake 滥用、计算成本过高、需要与 2024 年美国大选保持距离。但外界普遍认为，推理成本是真正的原因——生成 60 秒高质量视频的计算量远超生成文本和图像，在没有大幅优化前，Sora 还不适合大规模 API 部署。

Sora 直到 2024 年底才向部分创作者开放测试。到 2025 年初，它仍然没有成为像 ChatGPT 那样的全民产品。但 Sora 的发布本身已经改变了行业的走向——**就像 GPT-3 的发布让所有人都知道了 scaling 的方向，Sora 的发布让所有人都知道了视频生成的 DiT 路线是对的。**

### 影响

Sora 是文生视频领域的"GPT-3 时刻"。发布后，全球视频生成模型的研发全面转向 DiT 路线。此前的主流方案（基于 UNet 的扩散模型 + 时序注意力）被迅速抛弃。中国的快手可灵（2024-06）、字节即梦、Runway Gen-3 等后来者都采用了 DiT 或类 DiT 架构。

Sora 也是 OpenAI 在"发布但不交付"策略上走得最远的一次。从 2024-02 发布到 2025 年中的实际可用，中间隔了超过一年。这种"技术预览式发布"在社区引发了越来越多的不满——"如果你不打算让我用，为什么要让我看到？"

## Gemini 1.5 Pro：把一本《战争与和平》塞进上下文

> 一百万 token——比 GPT-4 的 128K 多了八倍，比 Claude 的 100K 多了十倍。Gemini 1.5 Pro 没有在和 GPT-4 比 benchmark——它在和所有人比"你的上下文能装下多少东西"。在这场比赛中，它赢了。

### 发布

**同日 2024-02-15**（与 Sora 同一天——Google 试图用自己的核弹对抗 OpenAI 的核弹）— Google DeepMind 发布 **Gemini 1.5 Pro**，核心卖点是 **1M token 的上下文窗口**。[^2]

1M token 意味着什么？可以一次性输入：
- 整部《战争与和平》（约 560K token）
- 一部完整的电影剧本
- 一个中等规模代码库的全部源代码
- 数小时的音频转录文本

在"大海捞针"（Needle In A Haystack）测试中——在某处长文本中藏一条信息，测试模型能否找到——Gemini 1.5 Pro 在 1M token 的上下文中达到了 99% 的准确率。

技术基础是 **MoE（混合专家）架构**——Gemini 1.5 Pro 在保持与 1.0 Ultra 接近的能力的同时，大幅降低了推理成本。它还对长上下文的注意力机制做了特殊优化，使得"超长上下文"不只是参数上支持，而是真正可用。

### 影响

Gemini 1.5 Pro 的 1M token 上下文窗口重新定义了"超长上下文"的标准。此后，几乎每一家 AI 公司都被迫将长上下文作为核心能力来竞争。GPT-4 Turbo 的 128K 在 2023 年底还令人惊叹，到 2024 年上半年已经不够看了。Google 开辟了一个新战场——"谁记得更多"——而在这个战场上，它用自己的 TPU 和 Google 级基础设施建立了暂时无法追赶的壁垒。

### 评曰

超长上下文是一场"非对称战争"。Google 选择不和 OpenAI 在推理、编程、多模态交互这些 GPT-4 已经占据的地盘上正面厮杀——而是开辟了一个自己可以称王的新指标。

这个选择的聪明之处在于：长上下文的硬件壁垒比多模态或推理高得多。GPT-4 的多模态能力可以被 Claude 3 追上—— Anthropic 只是多做了几个月的 CV 训练。但 1M token 的真正可用上下文需要的不仅是算法——是 TPU v5p、是 Google 自研的推理基础设施、是"把整本《战争与和平》扔进模型"而不崩溃的工程能力。这三者都是 Google 独有的。

Gemini 1.5 Pro 最终没能让 Google 在整体能力上超越 GPT-4o 和 Claude 3.5 Sonnet——但它在长上下文这个特定指标上建立了一年以上的领先。这种"在对手不玩的赛道上赢"的策略，后来被其他追赶者广泛复制：Mistral 在开源效率上赢、DeepSeek 在 API 价格上赢、Anthropic 在安全定性上赢。大模型竞争从"谁最强"变成了"谁在自己的赛道最强"——这个格局的分化，2024 年 2 月的 Gemini 1.5 Pro 是第一个信号。
