# 2024年3月

## Claude 3：Anthropic 第一次站在能力之巅

> "我们不再需要和 GPT-4 比较了——Claude 3 Opus 在大多数基准上已经超越了它。"这段话背后是 Anthropic 等了三年的一刻：从 OpenAI 出走的安全团队，终于造出了一个比旧东家更强的模型。

### 发布

**2024-03-04** — Anthropic 发布 **Claude 3** 系列，三种规模：[^1]

| 版本 | 定位 | 能力对标 | API 价格（输入/输出 $/百万 token） |
|------|------|----------|:--:|
| **Opus** | 旗舰，最强 | 超越 GPT-4 | $15 / $75 |
| **Sonnet** | 均衡，适合大多数任务 | GPT-4 水平，更快更便宜 | $3 / $15 |
| **Haiku** | 轻量，极速低成本 | 接近 GPT-3.5，速度快 | $0.25 / $1.25 |

这是 Anthropic 首次在主流基准上**超越 GPT-4**。Opus 在 MMLU（86.8% vs GPT-4 86.4%）、HumanEval（84.9% vs 67.0%）、GPQA（科学推理）等基准上全面领先或持平。

与 Claude 2 相比，Claude 3 的飞跃不仅在于能力——200K token 上下文窗口、支持图像输入（多模态视觉理解）、大幅降低的幻觉率。Anthropic 称 Opus 在复杂推理任务上展现了"接近人类水平的表现"。

### 三层的差异化

Claude 3 的三层定价是 Anthropic 在商业化上向前迈出的一大步：

- **Opus** 是"钱不是问题"的选项——最贵，但最强。用于对准确性要求极高的场景：医疗诊断辅助、法律文书分析、复杂代码审查
- **Sonnet** 是"大多数人的默认选择"——价格适中，99% 的人不需要 Opus 的强大
- **Haiku** 是"嵌入式 AI"——极快、极便宜，适合实时客服、内容审核、简单的文本分类任务

这种"三种规模、三种定价、一个品牌"的策略，后来被证明是 Anthropic 对抗 OpenAI 的最有效武器。OpenAI 的回应是推出 o1-mini 和 GPT-4o-mini——但晚了半年。

### 视觉能力的加入

Claude 3 首次加入了对图像输入的支持——用户可以向 Claude 上传照片、图表、PDF 扫描件，模型能理解视觉内容并给出回应。这不是 GPT-4V 式的"可以看图"，而是将视觉理解作为模型的**默认能力**——不需要在"vision"和"text"模式之间切换。

这对 Anthropic 的客户来说很重要——很多企业用户的核心场景是"上传文件，让 AI 分析"，而非"对话聊天"。Claude 3 对这一场景的优化比 GPT-4 更彻底。

### 影响

Claude 3 的发布标志着大模型竞争进入了一个新阶段：**不再是 OpenAI 一家独大，而是一个三足鼎立的局面**——GPT-4 仍有最好的多模态和品牌，Claude 3 有安全和诚实的差异化，Gemini 1.5 有超长上下文和 Google 生态。用户第一次有了真正的选择——不是因为任何一个模型"赢了"，而是因为它们各有各的强项。

对 Anthropic 自身来说，Claude 3 是一个里程碑：它终于不再被视为"OpenAI 出走团队的安全情怀项目"，而是一个**真正有竞争能力的产品**。

### 评曰

Claude 3 的发布标志着一个微妙的历史节点：它比 OpenAI 本纪中所写的"2024 年 OpenAI 面临身份危机"来得更早。

Claude 3 Opus 在基准上超越 GPT-4 的意义不在于"Claude 更强"——而在于"闭源前沿不再只有一家"。这对整个生态产生了二阶效应：企业的多供应商策略成了可行选项，基准评测从"看 GPT-4 是不是又涨了"变成"看谁在这轮赢了"——去中心化的竞争格局开始形成。

但更值得关注的是 Anthropic 的三层定价策略。它本质上是把"安全"这个品牌资产转化成了价格歧视：最安全的模型卖最贵（Opus），最快的模型卖最便宜（Haiku），中间档位（Sonnet）是大多数人的实际选择。这个三层的精妙之处在于——它没有和 GPT-4 比谁更有创意、谁更能写诗、谁更会调情。它比的是"你选我吧，因为我诚实"。在一个被幻觉问题困扰的市场里，"诚实"本身就是一个产品属性。

不过，Claude 3 的成功也埋下了一个问题：当竞争对手的模型也开始变得"更安全"时，Anthropic 的护城河在哪？这个问题在 Claude 3.5 Sonnet 和 Artifacts 中得到了部分回答——但那是另一个故事了。
