# 2024年9月

## o1：推理模型的新品类

> OpenAI 不再追求"更大的语言模型"，而是造了一个"会思考的语言模型"。o1 在回答之前先进行链式思考——人类的"慢思考"第一次被嵌入了一个商业 AI 产品。推理模型这个品类，自此诞生。

### 发布

**2024-09-12** — OpenAI 发布 **o1**（最初代号为"Strawberry"），首个"推理模型"。[^1]

o1 的核心差异：它在回答之前会在内部生成一个**隐藏的思维链（chain of thought）**——用额外的推理时间来规划、验证、修正自己的思路。用户看到的只有最终回答，中间的推理过程被刻意隐藏。

这个设计的理念很清晰：GPT-4 的"下一个 token"预测是一种直觉式的快思考——流畅、快速，但在需要多步推理的任务上容易犯错。o1 的"先想再说"是一种推理式的慢思考——更慢、计算量更大，但在数学、编程和科学推理上准确得多。

### 性能

o1 在推理密集型基准上实现了飞跃：[^1]

| 基准 | o1 | GPT-4o | 提升 |
|------|:--:|:--:|:--:|
| AIME 2024 (数学竞赛) | 74.4% | 12.1% | **+62.3** |
| GPQA Diamond (科学推理) | 77.3% | 56.1% | +21.2 |
| Codeforces | 89%ile | 11%ile | +78 |
| International Math Olympiad | 83.3% | 13.4% | +69.9 |

在 2024 年国际信息学奥林匹克竞赛（IOI）中，o1 在人类同等条件下获得了 213 分，排名在所有参赛者中处于第 49 百分位。

最震撼的数字是 AIME 数学竞赛：从 12% 跳到 74%。这不是渐进式提升——是能力从一个领域突然迁移到了另一个领域。

### 隐藏的思维链

o1 最特别的设计决策是**隐藏思维链**。OpenAI 给出的理由是"安全"——如果用户能看到模型的内部推理，他们可能学会绕过安全限制。但批评者认为，这恰恰逆转了 OpenAI 早期"透明"的承诺——DeepSeek-R1（2025-01）在四个月后开源+公开思维链，直接给了 o1 一耳光。

OpenAI 对看到思维链的用户实施"零容忍"禁令——任何试图通过 prompt injection 或越狱看 o1 思考过程的行为都会导致账号被封。这让社区的不满进一步升级——"你说这是为了安全，但你不让任何人验证你的安全措施。"

### 推理模型的范式

o1 开创了一个全新的模型品类——"推理模型"（reasoning model）。此前的所有 LLM（GPT 系列、Claude 系列、Llama 系列）都是"直接生成"模式——预测下一个 token，没有内部分析步骤。o1 证明了一个新的 scaling 维度：**推理时间的计算量**。

"测试时计算"（test-time compute）——让模型在回答前花更多时间推理——成为 2024-2025 年最热的研究方向。之后的 DeepSeek-R1、Kimi K1.5、Claude extended thinking、Qwen3-Thinker 都是在 o1 开辟的赛道上奔跑。

### 从 o1-preview 到 o1 正式版

- **2024-09-12**：o1-preview 和 o1-mini 发布，仅限 ChatGPT Plus/Team 和 API Tier 5 用户
- **2024-12-05**：o1 正式版发布，加入多模态（图像输入）支持
- **2024-12-20**：o3 发布（跳过 o2），在编程和数学上再创新高

o1-preview 发布时引起了轰动，但用户很快发现了很多问题：它会过度思考简单问题（"一只猫有 4 条腿，10 只猫有多少条腿？"——思考 20 秒），在某些对话任务上不如 GPT-4o 灵活，API 价格极贵（o1-preview 输出 $60/百万 token，是 GPT-4o 的 4 倍）。

### 影响

o1 是大模型从"更大"到"更聪明"的范式转折。它回答了 GPT-4 时代搁置了一个问题：单纯的参数 scaling 可能正在接近收益递减，但**推理 scaling**（让模型花更多时间思考）仍然有巨大的提升空间。

此后的六个月里，全球几乎每一家 AI 公司都发布了自己的推理模型——这证明了 o1 定义的"品类"的可行性。但也证明了 o1 无法守住独占优势——推理模型的技术壁垒比预训练模型低，追赶速度更快。

### 评曰

o1 是大模型从"更大"到"更聪明"的范式转折。它回答了一个 GPT-4 搁置了的问题：单纯的参数 scaling 正在接近收益递减，但**推理 scaling**（让模型花更多时间思考）仍然有巨大的提升空间。这是一条新的 scaling law——不是训练时计算量，而是推理时计算量。

隐藏思维链的决定是 o1 最具争议的部分。OpenAI 说这是为了安全——但安全检查的前提是透明，而隐藏本身就是不透明。四个月后，DeepSeek-R1 用 MIT 开源 + 完全公开思维链给了 o1 一个最响亮的回答：推理模型可以既强大又透明。o1 开创了品类，但把定义这个品类规则的机会让给了 DeepSeek。

从产品角度，o1 也暴露了推理模型的一个核心张力：用户不一定想要"深思熟虑"的 AI。ChatGPT 的魅力在于即时对话——像聊天一样自然。o1 的"等 30 秒得到一个更好的答案"对于日常聊天是打断，对于数学题是恩赐。这个张力至今未被完全解决——后来的推理模型都在尝试"让快思考和慢思考共存"，但没有人找到一个优雅的 UI 来同时容纳两者。

## o1 补遗：Q* 前史、过度思考与价格锚点

> 上面的条目已经记下了 o1 的核心事实。以下补充三件事：o1 发布前那段充满传闻的前史、o1-mini 这个被人低估的产品决策、以及 o1 的定价在推理模型经济史上的位置。

### Q* 与 Strawberry：发布前的传闻时代

o1 不是突然出现的。在它正式发布前，OpenAI 内部代号和外部传闻已经酝酿了近一年。

**2023 年 11 月**，Sam Altman 被 OpenAI 董事会短暂解职前夕，路透社报道称，OpenAI 内部有一个名为 **Q\***（Q-Star）的项目取得了突破。报道称，几名 OpenAI 员工致信董事会，警告 Q\* 的进展可能威胁人类——这封信据称是董事会决定解雇 Altman 的导火索之一。Q\* 被描述为一个能解决小学数学题的模型——听起来不起眼，但在 AI 安全圈，"能解数学题"被视为通向通用推理的关键里程碑。[^2]

事后回看，Q\* 很可能就是 o1 的前身。OpenAI 从未正式确认两者的关系，但时间线吻合：Q\* 传闻出现在 2023 年 11 月，o1 在 10 个月后发布（2024-09-12）。

2024 年夏天，另一个代号"Strawberry"开始出现在 OpenAI 的招聘页面和社交媒体的隐晦提及中。The Information 在 2024 年 7 月报道，Strawberry 是 OpenAI 正在开发的一个推理增强项目——能够进行长时间、多步骤的推理。[^3] 两个月后，o1 以 Strawberry 为代号发布——o1-preview 的系统提示词中仍保留了 Strawberry 的痕迹。

这段前史之所以重要，不是因为它影响了 model 本身——而是它塑造了**公众对 o1 的期待**。当 OpenAI 在 2024 年 9 月发布 o1 时，市场上已经有一整年的"神秘突破"叙事在预热。这是 OpenAI 最擅长的节奏：先让传闻发酵，再用一个名字呼应传闻（o1 = Strawberry），最后用 demo 兑现部分期待。从 GPT-2 的"太危险不能一次放出"到 o1 的 Q\* → Strawberry → o1，这套叙事漏斗已经成了 OpenAI 的固定操作手册。

### o1-mini：更快、更便宜、更专一

o1 发布当天，OpenAI 同时推出了 **o1-mini**——一个更小、更快、更便宜的推理模型。o1-mini 专注于 STEM（科学、技术、工程、数学）推理，在非 STEM 任务上不如 o1-preview，但在数学和编程上的性价比远超旗舰。

定价差距显著：[^1]
- o1-preview：输入 $15/百万 token，输出 $60/百万 token
- o1-mini：输入 $3/百万 token，输出 $12/百万 token

o1-mini 便宜 80%，在某些推理基准上的表现却接近甚至超过 o1-preview。对于大多数开发者的实际场景（代码生成、数学解题、数据清洗），o1-mini 是更合理的选择。

这个决策在产品层面很精妙。o1-preview 树起了"最强推理"的品牌天花板，但高定价劝退了大多数人；o1-mini 则是一个低门槛入口，让开发者可以低成本试水"推理模型"。两者加在一起，组成了一个"品牌拉高 + 走量"的双层定价结构——和高端的奔驰 S 级与走量的 C 级是同一个逻辑。

### 过度思考：推理模型的第一个产品难题

o1 的用户很快发现了一个令人哭笑不得的现象：它会在不该思考的时候过度思考。

"一只猫有 4 条腿，10 只猫有多少条腿？"——o1-preview 会花 20 秒"思考"这个答案显然是 40 的问题，生成数百字的推理链条，然后再给出答案。更极端的情况下，用户问一个简单的"你好"，o1 也会启动推理模式，仔细分析这个问候语的含义和可能的回应策略。

这不是 bug——这是推理模型产品化的第一个系统性挑战。此前的语言模型都是"快思考"：输入即输出。它们也会犯错，但犯错的方式是直觉式的——快了所以粗心。o1 的慢思考在复杂任务上大幅降低了错误率，但在简单任务上浪费了用户的时间和 API 费用。

这个现象暴露的问题比它看起来深：**推理模型没有"任务难度感知"能力**。它不知道一个问题是 1+1=2 还是 AIME 竞赛题——它只是按照训练中学会的模式生成推理链。而训练教会它的是"所有问题都该想一想"。

后来的推理模型（Claude 3.7 Sonnet、Gemini 2.5 Pro、Qwen3）都在尝试解决这个问题——通过"思考开关"让用户决定什么时候需要慢想。但这个解决方式也有代价：它把判断负担转移给了用户。在 o1 的"一律多想"和 Claude 的"用户决定"之间，行业至今没有找到完美的中间点。

### 定价的经济学含义

o1-preview 的输出定价——$60/百万 token——在大模型定价史上是一个标志性数字。GPT-4o 的输出是 $15/百万 token。o1 贵了 4 倍。

这个差价的理由不是参数规模，而是**推理时计算**。o1 在回答问题时消耗的 token 远多于普通模型——那些隐藏的思维链也是按照 token 收费的。用户付的不仅是最终答案的钱，还有"思考过程"的钱。

因此 o1 的定价开创了一种新的大模型商品形态：**按思考量计价**。这在 GPT 系列中是第一次——GPT-3 和 GPT-4 的价格主要反映模型规模和训练成本，o1 的价格反映的是运行时的计算消耗。此前的 token 计费是对"生成内容"收费，o1 的 token 计费是对"生成思考"收费——而用户看不到思考内容。

这引发了信任问题：如果我付了思考的钱但看不到思考的过程，我怎么知道我付的钱是用于真正的推理还是浪费在无效循环上？OpenAI 的回应是"trust us"——但在隐藏思维链的前提下，这种信任很难建立。DeepSeek-R1 后来的做法——公开思维链 + 极低价格——正是对这种"隐藏+高价"模式的直接回应。
