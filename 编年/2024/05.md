# 2024年5月

## GPT-4o：当 AI 学会了实时交谈

> 平均延迟 320 毫秒——和人对话的反应时间差不多。GPT-4o 不只是多模态，它是原生多模态：文本、语音、视觉共享同一个神经网络，不再需要"先转文本再处理"。免费向所有用户开放——这个决定和模型本身一样重要。

### 发布

**2024-05-13** — OpenAI 发布 **GPT-4o**（"o"代表 omni，全能）。[^1]

GPT-4o 的核心不是更强的 benchmark——它的核心是**交互方式的质变**：
- **原生多模态**：一个神经网络同时处理文本、语音、图像，不需要像 GPT-4 那样先转文字再理解
- **实时语音对话**：平均响应延迟 320ms（GPT-4 语音模式要 2.8-5.4 秒）——接近人类对话的反应速度
- **情感表达**：能感知用户语音中的情绪，并以带情感的语调回应
- **视觉实时理解**：可以通过摄像头实时分析用户面前的环境

发布会的 Demo 展示了：GPT-4o 为一位盲人描述窗外的风景、实时翻译两个人的对话、根据一张手写数学题的图片一步步引导解题。这些能力单个来看并不新鲜，但整合到一个"实时对话"体验中产生了质变。

### 模型细节

GPT-4o 的具体参数规模、架构未公开。已知的信息：[^1]
- 在多项基准上与 GPT-4 Turbo 持平或略优
- 非英语语言能力大幅提升——特别是中文、日文、韩文和阿拉伯语
- 视觉理解能力接近 GPT-4V 但推理成本更低
- API 价格：输入 $5/百万 tokens，输出 $15/百万 tokens——比 GPT-4 Turbo 便宜 50%

### 免费开放的决定

GPT-4o 发布时最重要的宣布不是技术升级，而是商业模式的变化：**GPT-4o 向免费用户开放**。此前，GPT-4 一直是 $20/月 ChatGPT Plus 订阅的独占功能。GPT-4o 打破了这堵付费墙。

这个决定背后的逻辑是：OpenAI 需要在免费层保持竞争力。Google 的 Gemini 已经免费提供，Meta 的 Llama 3 开源免费，Claude 有免费版——如果坚持 GPT-4 只能在付费墙后面使用，OpenAI 将在用户规模上被蚕食。

从商业角度看，"免费开放 GPT-4o + Plus 用户获得 5 倍使用限额"的模式被证明是成功的——它维持了免费用户的增长，同时保住了付费用户的转化逻辑。

### 影响

GPT-4o 重新定义了"AI 助手"的交互标准。语音对话从"提一个问题等两秒"变成"像和人说话一样自然"。它没有像 GPT-3 或 GPT-4 那样提升能力上限，但它把已有能力**变得对所有人有用**。

### 评曰

320 毫秒。这个数字是 GPT-4o 最重要的技术指标。不是因为它很难——而是因为它恰好跨过了人类对话的"自然感门槛"。超过半秒的延迟让人感觉"在和机器对话"，低于半秒的延迟让人感觉"在和人说话"。GPT-4o 做到了后者。

但 GPT-4o 真正的历史意义在于免费开放。这不是技术决策——是商业决策。OpenAI 在 2024 年面临一个两难：GPT-4 只对付费用户开放，但 Google 的 Gemini 免费、Meta 的 Llama 3 开源免费。如果 OpenAI 不放下付费墙，它将在用户规模上被蚕食。GPT-4o 的免费开放是 AI 行业的"价格战第一枪"——这场战争后来在 DeepSeek V2（2024-05）和 2025 年的中国模型价格战中愈演愈烈，最终导致 API 价格暴跌 99% 以上。

从产品角度看，GPT-4o 是 OpenAI 对"AI 到底是什么"的一次重新定义。不是"更强的模型"——是"更自然的交互"。实时语音、情绪感知、视觉实时理解——这些不是 benchmark 上的数字，是用户体验上的质变。这一转向后来影响了整个行业：Claude 的 Artifacts、Gemini 的实时视觉、ChatGPT 的 Advanced Voice Mode——都在同一个坐标系里竞争：不是谁更聪明，是谁更自然。

## DeepSeek-V2：MLA 架构与价格战的导火索

> 236B 参数，激活仅 21B。API 价格是 GPT-4 的 1%。DeepSeek-V2 没有说要打败 GPT-4——它只是用一个新的注意力机制（MLA）和一个大降价的动作，告诉所有人：前沿能力不需要前沿的价格。

### 发布

**2024-05-06** — 深度求索发布 **DeepSeek-V2**。236B 总参数、21B 激活参数的 MoE 架构。性能接近 GPT-4（MMLU 80.3%），API 定价仅为 GPT-4 Turbo 的约 **1%**——输入 1 元/百万 token，输出 2 元/百万 token。[^2]

DeepSeek-V2 的技术贡献主要在架构上——它提出了 **MLA（Multi-head Latent Attention，多头潜在注意力）**，一种大幅压缩推理时 KV Cache 的方法。传统的多头注意力需要为每个 token 缓存 Key 和 Value 矩阵，KV Cache 随序列长度线性增长。MLA 将 KV 投影到低维潜在空间，再从中重建——在保持注意力质量的同时，将 KV Cache 压缩到原来的 5%-10%。

这个技术看着像是一个不起眼的工程优化。但它的后果是颠覆性的：KV Cache 是推理成本的最大瓶颈。把它压缩 90%，意味着推理成本压缩 90%。DeepSeek-V2 的极低定价不是靠烧钱——是靠 MLA。

### 价格战

DeepSeek-V2 的定价在中文 AI 圈引发了一场真正的价格战。此前的逻辑是：GPT-4 级的模型就应该有 GPT-4 级的价格。DeepSeek 打破了这个默契：

- 阿里云迅速将通义千问 API 大幅降价
- 百度的文心一言跟随
- 智谱下调 GLM 系列 API 价格
- 字节跳动豆包进一步压低价格

不到一个月，中国 AI API 的价格跌到了年初的十分之一以下。Community 管这叫"DeepSeek 价格屠夫"。讽刺的是：DeepSeek 不是一个商业公司在打价格战——它背后的幻方量化是一家量化对冲基金。它不需要从 API 赚钱。

### 影响

DeepSeek-V2 最重要的遗产不是 benchmark 分数，而是一句话：**"GPT-4 级的模型不需要 GPT-4 级的预算。"** 这句话在半年后的 DeepSeek-R1 中被放大到了极致——但 V2 是起点。MLA 也被后续的 DeepSeek-V3（2024-12）和 R1（2025-01）继承，成为 DeepSeek 的招牌架构。

### 评曰

V2 是大模型史上最被低估的模型之一。R1 吸引了全世界的注意力，英伟达一天蒸发 5890 亿——但 R1 没有 V2 就不可能存在。MLA 架构把推理成本砍到原来的十分之一，这个工程突破的重要性不亚于任何一个 SOTA benchmark。

更深层的问题是：V2 的定价到底是一个商业策略还是技术必然？答案是后者。MLA 不是烧钱补贴——它是结构性地降低了推理成本。这使得 DeepSeek 的定价优势不是暂时的促销，而是可持续的竞争优势。当阿里、百度、智谱、字节跟进降价时，它们是在跟随 DeepSeek 的价格——但它们的成本结构并没有改变。这种"价格领先 + 成本领先"的双重优势，后来在 V3（训练成本仅 ~$5.6M）中被验证了可重复性。

V2 还揭示了一个更残酷的事实：如果你不需要从 API 赚钱——比如你是一家量化基金——那么"低价格"本身就是一种武器。幻方量化不需要 DeepSeek API 的收入来生存，它可以用极低定价碾压所有以 API 为核心的商业模型公司。这不是市场竞争——这是"一只不需要吃饭的狼闯进了由一只只需要吃饭的羊组成的生态系统"。2025 年 R1 的 MIT 开源让这种逻辑变得更极端——但 V2 才是这个逻辑的起点。
