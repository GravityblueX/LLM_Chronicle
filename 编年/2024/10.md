# 2024年10月

## 10月8日：Hinton 与 Hopfield 获诺贝尔物理学奖

瑞典皇家科学院宣布，将 2024 年诺贝尔物理学奖授予 John J. Hopfield 与 Geoffrey E. Hinton，以表彰他们利用人工神经网络实现机器学习的基础性发现和发明。[^1][^2]

这次获奖把深度学习的前史正式写进了更广泛的科学史：Hopfield network 与 Boltzmann machine 并不是 LLM 技术栈里的直接组件，却构成了后来神经网络复兴的重要理论与方法背景。

## 10月22日：Claude Computer Use——桌面成为 Agent 的通用接口

**2024-10-22** — Anthropic 发布升级版 Claude 3.5 Sonnet，并同步开放 **Computer Use** beta。Claude 可以根据截图移动光标、点击、输入文本，并通过文本编辑 / shell 等工具与计算机环境交互。Anthropic 当时明确提醒该能力仍然笨拙、容易出错。[^3][^4][^5]

Computer Use 的历史意义不只是“AI 会点鼠标”。API / function calling 的前提是软件主动提供机器接口；Computer Use 反过来把**人类 GUI 当作兼容层**：即使旧系统没有 API，Agent 理论上仍可以通过屏幕、鼠标与键盘行动。

但覆盖面越广，权限问题越严重。一个能点击“下一页”的 Agent，也可能点击“确认付款”；一个能操作桌面的 Agent，也可能误删文件。因此 GUI Agent 从一开始就把能力问题与授权、确认、审计绑在一起。

## 10月25日：AutoGLM——Phone Use 成为中国 Agent 的独立路线

**2024-10-25** — 智谱 AI 发布 **AutoGLM**，把同一类 GUI Agent 思路推进到真实手机 App。智谱后续官方技术回顾将这一天列为 AutoGLM 首次发布节点，并把它描述为首批面向真实手机环境、依靠视觉理解与设备控制完成多步任务的 Phone Use 系统之一。[^8]

这件事在中国 Agent 史里尤其重要。

欧美 Agent 的通用环境往往是：

- Web；
- SaaS API；
- browser；
- terminal；
- desktop。

中国互联网却有大量真实生活服务长期封装在移动 App 中：微信、淘宝、京东、美团、携程、12306、滴滴、抖音、小红书等，并不都提供足以覆盖用户行为的开放 API。

于是 Phone Use 在中国不是 Computer Use 的简单“缩小版”，而可能是**通往本地生活与移动互联网服务的最后一公里**。

AutoGLM 的基本闭环是：

> 看屏幕 → 理解当前 App 状态 → 规划动作 → Tap / Type / Swipe / Back → 再看新状态 → 继续执行。

后来 AutoGLM-Phone 的官方文档会把支持范围扩展到 50+ 中文应用，并继续探索云手机 / 云电脑，让 Agent 拥有独立执行环境，而不是长期占用用户真实屏幕。

这条路线与 Claude Computer Use 同月出现，非常适合并读：

- Claude Computer Use 证明 **desktop GUI** 可以成为通用 Agent 接口；
- AutoGLM 证明 **mobile GUI** 同样可以成为 Agent 执行层，而且在中国移动互联网结构下具有更强的商业意义。

## 本月其他要事

**2024-10-17** — xAI 面向开发者开放 Grok API（此前 Grok 主要限于 X 平台内部），提供模型调用并配套函数调用与系统提示能力，标志着 xAI 开始从消费产品进入开发者 API 市场。[^6][^7]

## 评曰

2024 年 10 月常被记成“Computer Use 出现的月份”，但把 Claude 与 AutoGLM 放在一起看，会得到一个更完整的判断：

> **Agent 开始绕过“每个软件都必须先提供 API”这个限制。**

Function Calling 给模型一组结构化钥匙；GUI Agent 则尝试学会使用人类已经拥有的门把手。

这扩大了 Agent 的行动半径，也把风险从“工具参数写错”升级成现实界面里的误操作。尤其在手机里，账号、支付、通讯、位置、订单和隐私高度集中，Phone Agent 的成熟度最终不能只看 benchmark，还必须看：

- 哪些动作必须人工确认；
- 登录 / 验证码怎样处理；
- 支付权限怎样切分；
- 云端是否保存凭据；
- 操作日志能否审计；
- App UI 变化后是否仍可靠。

从此以后，Agent 的竞争不再只是“谁会用工具”，而是**谁能安全地进入真实软件世界。**
