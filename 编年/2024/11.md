# 2024年11月

## DeepSeek-R1-Lite：R1 的先遣队

**2024-11-20** — 深度求索发布 **DeepSeek-R1-Lite**，作为 DeepSeek-R1 的预览版在 DeepSeek 官网上线并开放试用。R1-Lite 是 DeepSeek 首个公开展示推理能力的模型，采用类似 o1 的"先思考再回答"模式，在数学、代码和逻辑推理任务上表现出色。[^1]

R1-Lite 的发布时机很微妙。OpenAI 的 o1-preview 在两个月前（2024-09-12）发布，定义了"推理模型"这个品类。DeepSeek 用 R1-Lite 快速跟进，向外界表明中国团队在这一品类上也在紧追。两个多月后（2025-01-20），基于 R1-Lite 打磨出的 DeepSeek-R1 正式发布，并以 MIT 许可证开源，彻底改变了推理模型竞争格局（详见《编年·2025年1月》）。

> 📖 详见《推理模型的分水岭》《GPT 世家》《GPT-4 列传》《Claude 世家》《Anthropic 本纪》《DeepSeek-R1 列传》《DeepSeek 世家》《DeepSeek 本纪》《Llama 世家》。
## Qwen2.5-Coder：开源代码模型新标杆

**2024-11-12** — 阿里通义千问团队发布 **Qwen2.5-Coder**，开源 1.5B 和 7B 两个尺寸（32B 版本随后发布），并在 5.5T tokens 的代码数据上训练。Qwen2.5-Coder 在 HumanEval、MBPP、LiveCodeBench 等代码基准上表现强劲，7B 版本在多项指标上超过 GPT-3.5-Turbo。[^2]

Qwen2.5-Coder 是 Qwen2.5 系列的代码专项子系列，它的策略是"做小但做精"——不大到 70B 参数，但在代码方向做到极致。这与 Code Llama 和 DeepSeek-Coder 的策略类似：单独训练一个代码模型，让它专注于生成、理解、调试和重构代码。

## Qwen2.5-Turbo：百万 token 上下文

**2024-11-25** — 阿里云发布 **Qwen2.5-Turbo**，将上下文长度从 128K 扩展到 1M token（约 100 万英文单词或 150 万中文字符，相当于 10 部完整小说）。在 1M 长度的 Passkey Retrieval 任务中达到 100% 准确率，长文本评测 RULER 得分 93.1，超过 GPT-4 的 91.6 和 GLM4-9B-1M 的 89.9。通过稀疏注意力机制，首次 token 延迟从 4.9 分钟降至 68 秒，加速 4.3 倍。[^3]

1M 上下文的实际意义是：模型可以一次性读完企业全部内部文档、完整代码库或超长法律合同，而不需要外挂的 RAG（检索增强生成）系统。定价保持在 ¥0.3/百万 token，成本仅为 GPT-4o-mini 同等上下文效率的约 28%。

## Mistral Large：欧洲阵营的升级

**2024-11-18** — Mistral AI 在 le Chat 平台上更新了 **Mistral Large**（后称 Mistral Large 2411），大幅增强了长上下文处理、函数调用和系统提示遵循能力。新版本在多项基准上缩小了与 GPT-4o 和 Claude 3.5 Sonnet 的差距，并在多语言（特别是法语、德语、西班牙语等欧洲语言）任务上保持优势。[^4]

与 OpenAI 和 Anthropic 不同，Mistral 的策略一直是"不追求成为最大，而是效率最高"。Mistral Large 继续走 MoE 路线，用稀疏激活保持相对较低的推理成本，同时维持逼近前沿的能力水平。

## Anthropic 的 Claude 3.5 Haiku

**2024-11-04** 前后 — Anthropic 正式发布 **Claude 3.5 Haiku**，此前在 2024-10-22 与升级版 Claude 3.5 Sonnet 一起宣布。Claude 3.5 Haiku 在多项评测上达到或超过前代 Claude 3 Opus 的性能水平，推理速度与上一代 Haiku 相当。这是 Anthropic 在"小模型高性能"方向上的重要一步——用更低的成本和更快的速度，提供接近旗舰模型的能力。[^5]

同一天，Anthropic 宣布 **computer use**（计算机使用）功能进入公测：开发者可以让 Claude 像人类一样操控计算机屏幕——移动光标、点击按钮、输入文字。这是第一个提供此类能力的前沿模型，标志着大模型从"理解和生成"迈向"直接操控环境"。[^5]

## 其他事件

**2024-11-05** — 腾讯发布 **Hunyuan-Large**（混元大模型），389B 参数 MoE 架构，激活参数 52B。腾讯宣称其在 MMLU、CMMLU、C-Eval 等综合基准上达到开源模型的前沿水平，并以宽松许可开放权重。[^6]

**2024-11-15** — OpenAI 向 ChatGPT Plus 用户推送 GPT-4o 的 **Advanced Voice Mode** 全球更新，并增加自定义指令支持和改进的口音识别。同日，ChatGPT 移动端月活用户数据被报道突破 3 亿。

**2024-11-19** — Microsoft 在 Ignite 大会上发布 **Azure AI Foundry**，统一 Azure AI Studio 和 Azure ML，提供模型目录、评估、安全过滤和部署的一体化平台。同时宣布推出 AI agent 开发框架和更多行业解决方案。

**2024-11-28** — 多家媒体报道 OpenAI 正在以 **1500 亿美元估值**进行新一轮融资谈判，这使其成为全球估值最高的非上市 AI 公司之一。同时，关于 OpenAI 向营利性实体转型的讨论升温。

## 评曰

2024 年 11 月是大模型"推理时代"被确认的月份。o1 在 9 月开创了推理模型品类，而 DeepSeek-R1-Lite 在 11 月就证明了这个品类不会是 OpenAI 的独占阵地。推理能力正在从"独家秘方"变成"准入条件"。

与此同时，上下文长度、多模态、代码专项、语音交互都在同步推进。一条共同的逻辑贯穿其间：大模型不是只要"变大"就够了，它需要在更多维度上同时进步——推理深度、上下文窗口、多模态融合、产品交互——每一个维度都可能成为下一轮竞争的突破口。
