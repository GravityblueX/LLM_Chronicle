# 2024年12月

## DeepSeek-V3：557.6 万美元真正说明了什么

> DeepSeek-V3 在 2024 年底最醒目的数字是 2.788M H800 GPU hours。技术报告按每 GPU-hour 2 美元折算为约 557.6 万美元。这个数字确实改变了行业对前沿训练效率的想象，但它不是 DeepSeek 全部研发成本，也不能证明“600 万美元现金就能从零复制一个 GPT-4o 级团队”。把神话拿掉以后，V3 的工程意义反而更清楚：大规模 MoE、MLA、FP8 与 Multi-Token Prediction 可以系统性改变前沿模型的计算成本曲线。

### 发布

**2024-12-26** — DeepSeek 发布 **DeepSeek-V3**。技术报告给出的架构规模为 **671B 总参数、37B 每 token 激活参数**，在 **14.8T tokens** 上完成预训练，并报告整个训练过程消耗 **2.788M H800 GPU hours**。[^1]

V3 是稀疏 MoE 模型，延续 V2 的 MLA 与 DeepSeekMoE，并进一步引入 auxiliary-loss-free load balancing、Multi-Token Prediction（MTP）和大规模 FP8 混合精度训练。[^1]

### 许可：代码与模型权重不是同一份许可证

V3 发布时高度开放，但旧稿把它写成“MIT 许可开源模型权重”并不准确。

官方仓库分别提供：

- `LICENSE-CODE`：MIT License；
- `LICENSE-MODEL`：**DeepSeek License Agreement**，对模型及其衍生物附加特定用途限制。[^2][^3]

因此 V3 更准确的称呼是**开放权重模型**，不能仅因为代码仓库使用 MIT 就把模型权重也记成 MIT。

这个区别后来尤其重要：一个月后的 DeepSeek-R1 才明确写明**代码仓库和主模型权重均采用 MIT License**。[^4]

### 核心技术

**MLA（Multi-head Latent Attention）**：将 KV 信息压缩进低维潜在表示，降低长序列推理时 KV Cache 的内存成本。MLA 不是把所有推理成本“直接压缩 90%”，而是显著压缩注意力缓存这一关键瓶颈；真实端到端收益仍取决于硬件、batch、上下文长度和推理实现。[^1]

**DeepSeekMoE + auxiliary-loss-free load balancing**：V3 使用细粒度专家并通过动态偏置方式改善负载均衡，避免传统辅助损失在负载均衡与模型质量之间制造额外冲突。[^1]

**Multi-Token Prediction（MTP）**：主模型之外训练额外预测模块，让训练目标同时利用更多后续 token 信号；MTP 也可以在推理时服务于 speculative decoding。[^1]

**FP8 混合精度训练**：V3 把 FP8 训练扩展到超大 MoE 规模，并报告整个训练过程没有出现需要回滚的不可恢复 loss spike。[^1]

### 557.6 万美元：应该怎样记

技术报告写道，V3 完整训练消耗 **2.788M H800 GPU hours**；按作者采用的 **2 美元 / GPU-hour** 价格估算，对应约 **557.6 万美元**训练计算成本。[^1]

这个数字可以支持的历史判断是：

> **V3 的最终训练计算预算显著低于此前公众对前沿模型的常见想象。**

但它不能自动包含：

- 数据采购、清洗与存储；
- 人员工资；
- 前置研究与失败实验；
- 训练集群资本开支；
- 电力、网络、冷却与机房；
- V2、DeepSeekMoE、MLA 等前代研发成本。

因此“V3 只花 557 万美元研发”是对论文指标的过度外推。

这项纠正不会削弱 V3，反而让真正的技术成就从新闻数字中显现出来：DeepSeek 证明的不是“钱不重要”，而是**训练系统的设计可以改变钱被消耗的速度**。

### 与 Llama 3.1 的算力对照也要谨慎

Meta 对 Llama 3 系列披露了约 **30.84M H100-80GB GPU hours**的总体训练计算统计。[^5] DeepSeek V3 的 2.788M H800 GPU hours 与其数量级差异很大，但两者模型、数据、训练目标、硬件、统计范围均不同，不能简单把 GPU-hour 比值等价为“谁训练便宜多少倍”。

这类对照更适合说明：**前沿模型不存在唯一训练配方**。

### 评曰

DeepSeek-V3 的历史位置，不需要“600 万美元打败一亿美元”这种标题才能成立。

V3 更重要的是把多条效率路线在同一超大 MoE 模型上合起来：MLA 管 KV Cache，MoE 管激活计算，FP8 管数值与吞吐，MTP 管训练信号利用率，分布式系统管通信与稳定性。

这使“前沿模型训练成本”第一次被广泛讨论成一个**可以通过算法与系统设计改变的变量**，而不只是 GPU 数量乘以时间。

V3 也留下两个后来必须修正的认识。

第一，**开放不是一个许可证标签。** 代码 MIT、模型 DeepSeek License 的并存证明，模型时代必须分别检查代码、权重、数据和衍生限制。

第二，**训练计算便宜不等于整个 AI 项目便宜。** 前沿模型的总成本仍然包括大量看不见的前置投入。

一个月后，R1 会把 V3 基座上的强化学习推理和更宽松的 MIT 权重许可推到全球舆论中心。但如果没有 V3 这块地基，所谓“DeepSeek 时刻”不会突然出现。
