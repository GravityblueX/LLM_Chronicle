# 2019年9月

## Megatron-LM：8.3B，以及并行训练的黎明

> NVIDIA 用 512 块 GPU 训练了当时最大的 Transformer 语言模型——8.3B 参数。比模型本身更重要的是它开源的方法：模型并行 + 数据并行，让"大模型训练"从少数巨头的秘密变成了工程师都可以上手的工程问题。

### 发布

**2019-09** — NVIDIA 发布 **Megatron-LM**，8.3B 参数。此时 GPT-2（1.5B，2019 年 2 月）已发布 7 个月——Megatron-LM 不是第一个大参数模型，但带来了更重要的东西：一种高效的模型并行训练方法。论文的核心贡献在于把 Transformer 的注意力头和全连接层拆到多块 GPU 上，配合数据并行，实现了近乎线性的扩展效率，让"训练十亿级模型"从少数巨头的秘密变成了工程上可复制的方法。[^1]

8.3B 的 Megatron-LM 在 512 块 NVIDIA V100 GPU 上训练。今天看来参数不大，但在 2019 年这是一个工程示范——证明了"只要并行策略对了，往上堆 GPU 就能往上堆参数"。Megatron 后来成为训练 GPT-3 规模模型的核心工具。

### 影响

Megatron-LM 开启了"大规模训练基础设施"这个子领域。后来的 Megatron-Turing NLG（530B）、DeepSpeed、FSDP 等都是这条路的延续。它的开源代码让中小团队也能尝试训练大模型，降低了 scaling 的工程门槛。

### 评曰

Megatron-LM 不是那种"改变了 AI 方向"的模型——但它属于另一种同样重要的贡献：让"改变方向"这件事变得工程上可行。在它之前，训练十亿级模型需要每个团队自己摸索并行策略、自己解决显存分配、自己写通信原语。Megatron 把这些问题抽象成了可以复用的模块：切分注意力头、切分全连接层、重叠计算和通信。这套方法后来被 GPT-3、DeepSpeed、FSDP 吸收和扩展，成为大模型训练的工程基础。

NVIDIA 作为 GPU 硬件厂商，发布这样一个开源训练框架有明确的商业动机——降低训练门槛 = 更多人买 GPU。但客观上，Megatron 的代码和技术报告比它训练的 8.3B 模型本身影响更深远。这是一份少见的"方法比结果更值钱"的论文。
