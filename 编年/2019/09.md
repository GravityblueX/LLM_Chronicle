# 2019年9月

## Megatron-LM：8.3B，以及并行训练的黎明

> NVIDIA 用 512 块 GPU 训练了当时最大的 Transformer 语言模型——8.3B 参数。比模型本身更重要的是它开源的方法：模型并行 + 数据并行，让"大模型训练"从少数巨头的秘密变成了工程师都可以上手的工程问题。

### 发布

**2019-09** — NVIDIA 发布 **Megatron-LM**，8.3B 参数——第一个突破 10 亿参数的 Transformer 语言模型。论文的核心贡献是一种高效的模型并行训练方法：把 Transformer 的注意力头和全连接层拆到多块 GPU 上，配合数据并行，实现了近乎线性的扩展效率。[^1]

8.3B 的 Megatron-LM 在 512 块 NVIDIA V100 GPU 上训练。今天看来参数不大，但在 2019 年这是一个工程示范——证明了"只要并行策略对了，往上堆 GPU 就能往上堆参数"。Megatron 后来成为训练 GPT-3 规模模型的核心工具。

### 影响

Megatron-LM 开启了"大规模训练基础设施"这个子领域。后来的 Megatron-Turing NLG（530B）、DeepSpeed、FSDP 等都是这条路的延续。它的开源代码让中小团队也能尝试训练大模型，降低了 scaling 的工程门槛。
