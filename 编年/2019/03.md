# 2019年3月

## ERNIE 1.0：中文 NLP 的「预训练宣言」

> 百度发布 ERNIE 1.0——中国第一个大规模预训练语言模型，在中文 NLP 基准上超越了 BERT。这是中文 NLP 社区第一次拥有与世界同步的预训练基础设施。

### 发布

**2019-03** — 百度发布 **ERNIE 1.0**（Enhanced Representation through kNowledge IntEgration），110M 参数，与 BERT-base 规模相当。论文提出"知识增强"的持续学习范式——先在大规模中文语料上训练，再逐步引入百科知识、对话数据等结构化知识进行多阶段预训练。[^1]

不同于 BERT 随机遮盖单个中文字，ERNIE 的掩码策略考虑了中文的语义单元——实体（如"北京"）和短语被整体遮盖，迫使模型学习更完整的语义知识。

### 影响

ERNIE 是中文大模型的开端。此后中文 NLP 从"翻译英文模型 + 中文微调"进入自主预训练时代。百度将 ERNIE 系列迭代至 3.0（2021 年，10B）、4.0（2023 年），成为中文 LLM 领域的重要力量。

### 评曰

英文 NLP 的预训练时代以 BERT 为标志，中文则以 ERNIE 为标志——两者相差不到五个月。ERNIE 1.0 的技术本质上是对 BERT 的中文化改良，但它的意义不在于技术原创性，而在于证明了一件事：中文 NLP 不需要永远跟在英文后面做翻译和适配，可以有自己的预训练模型和评估标准。
