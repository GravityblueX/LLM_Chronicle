# 2019年7月

## RoBERTa：BERT 被低估了

> Meta AI 用更长的训练、更多的数据、更简单的目标，证明 BERT 的性能远未被充分释放。RoBERTa 不是新模型——它是一份宣言：你们之前对 BERT 太吝啬了。

### 发布

**2019-07-26** — Meta AI（当时 Facebook AI Research）发布 **RoBERTa**（Robustly optimized BERT approach）。355M 参数，架构与 BERT-large 几乎相同，改动全在训练策略上：[^1]

- 更大数据：160GB（BOOKCORPUS + CC-NEWS + OpenWebText + STORIES），而非 BERT 的 16GB
- 更长训练：500K 步，batch size 8K——远超 BERT 的 256 步
- 去掉 NSP（下一句预测）任务——只用 MLM
- 动态掩码：每轮训练重新随机遮罩，而非 BERT 的静态掩码
- 更大的字节级 BPE 词表（50K vs 30K）

结果：在 GLUE 上超越 BERT-large 和 XLNet，刷新 SOTA。

### 意义

RoBERTa 证明了 BERT 的核心局限不是架构，而是**训练不足**。"BERT 被低估了"——这句话是整个论文的真正 message。后来的 ALBERT（压缩版 BERT）、DeBERTa（解耦注意力）都是在 RoBERTa 揭示的"BERT 还有空间"这条路上继续挖。

### 评曰

一篇论文，零架构创新，四个训练策略改动，就超越了当时所有 SOTA。RoBERTa 的贡献不在于"发明了什么"，而在于"证明了什么"——BERT 的潜能远未被充分释放。这在整个 AI 领域是一个反复出现的模式：人们太快地跳到新架构，而忽略了把现有架构做扎实。

RoBERTa 之后，"BERT 还有多少空间"成了一个子领域。ALBERT 用参数共享把模型压到原来的十分之一、DeBERTa 用解耦注意力进一步挖掘、ELECTRA 换了训练目标——每一篇都是一铲子，往下挖 BERT 这座矿。而 RoBERTa 是第一个告诉大家"这里还有矿"的。

放在 2019 年的语境里，RoBERTa 是在两大路线之间的一座桥梁：一边是 GPT 路线（追求生成能力、追求规模），一边是 BERT 路线（追求理解能力、追求效率）。RoBERTa 没有选边——它把 BERT 这条路做到了极致，然后平静地告诉后来者：这条路还有很长。
