# 2020年6月

## GPT-3：涌现，以及 LLM 应用时代的到来

> 175B 参数、31 位作者、72 页论文。GPT-3 用一顿暴力 scaling 证明了一个让所有人沉默的事实：不需要微调，不需要架构创新——只要给得足够大，模型自己就能学会一切。

### 发布

**2020-05-28** — OpenAI 在 arXiv 发布论文《Language Models are Few-Shot Learners》，正式公布 GPT-3。[^1] **2020-06-11** — OpenAI 发布 GPT-3 API 的私有测试版，不公开模型权重，仅通过 API 提供访问。[^2]

GPT-3 的参数规模是 GPT-2 的 100 倍——从 1.5B 到 175B。在 2018-2020 年间，这是参数增长最大的一次跳跃：

| 模型 | 时间 | 参数 | 倍数增长 |
|------|------|------|----------|
| GPT-1 | 2018-06 | 117M | — |
| BERT-large | 2018-10 | 340M | 3× |
| GPT-2 | 2019-02 | 1.5B | 4× |
| T5 | 2019-10 | 11B | 7× |
| GPT-3 | 2020-06 | 175B | **16×** |

训练 GPT-3 的成本估计在 460 万到 1200 万美元之间（具体数字 OpenAI 未公开）。使用了微软提供的 Azure 超级计算机——这也是 2019 年微软投资 OpenAI 10 亿美元的第一次大规模技术落地。[^3]

架构仍然是 Transformer 解码器——和 GPT-1、GPT-2 一样。96 层，12288 维隐藏层，96 个注意力头。创新不在架构，而在规模。论文的标题已经说出了全部主张：语言模型，只要给几个例子（few-shot），就能学会做任务。

### 涌现：不需要微调的能力

GPT-3 的核心发现在于 **涌现能力**（emergent abilities）——某些能力在参数规模达到某个阈值之前不存在，跨过阈值后突然出现。这不是一个设计出来的特性，而是 scaling 过程中的意外发现。

具体来说，GPT-3 在三种设定下展示了不同的能力梯度：

- **Few-shot**：给 10-100 个示例（在 prompt 中），模型直接完成任务。翻译、问答、代码生成、简单的数学推理——均不需要微调。
- **One-shot**：只给 1 个示例。在大多数任务上也表现良好。
- **Zero-shot**：只给任务描述，不给示例。GPT-3 的表现超越了之前所有 zero-shot 方法，在某些任务上甚至接近微调过的 BERT。

论文在 40+ 个基准上做了系统评测。几个关键结果：

| 任务 | GPT-3 Few-shot | 此前 SOTA（微调） |
|------|:--:|:--:|
| SuperGLUE | 71.8 | 89.0（T5-11B 微调） |
| TriviaQA | 71.2 | 68.0（RAG） |
| LAMBADA | 86.4 | 68.0（微调） |
| HellaSwag | 79.3 | 85.6（ALUM） |
| 算术 (3-digit) | 80.1% | — |

但最令人印象深刻的不是 benchmark 数字，而是 GPT-3 展示的**定性行为**：它能在没有专门训练的情况下生成新闻文章（人类评估者难以区分），编写基本的 Python 代码，将法律条款翻译成平实的语言，甚至模拟一个 AI 与人类对话。论文中展示了 GPT-3 生成的新闻文章——在约 200 字的篇幅内，人类评估者只有 52% 的概率能正确判断"这是人类写的还是 AI 写的"（随机猜测是 50%）。

这项实验后来被广泛引用，但也被批评为设计上的取巧——人类在做这种判断时非常依赖"有没有事实错误"，而 GPT-3 通过生成模糊的、没有明确事实主张的文本来规避被识别。不过这恰好说明了关键：GPT-3 学会了生成**看起来合理**的文本，而不只是统计上常见的文本。

### 规模法则的实证

GPT-3 论文对 scaling 做了跨任务、跨规模的系统分析，给出了一个强有力的实证结论：**模型性能与参数规模、训练数据量之间呈幂律关系**——随着模型增大，在验证集上的 loss 会持续下降，且没有出现平台期的迹象。

论文训练了 8 个不同规模的 GPT-3 模型（从 125M 到 175B），展示了在 TriviaQA、LAMBADA、PhysicalQA 等任务上，准确率随参数规模平滑增长。更重要的是，一些特定能力（如三位数算术）在小模型上不存在，在 13B 时开始出现，在 175B 时显著提升。这就是"涌现"的曲线——不是线性的，是到了某个点后突然跳升。

这种涌现性质后来在 2022 年由 Wei 等人的论文《Emergent Abilities of Large Language Models》做了系统调查——发现涌现不是 GPT-3 特有的，而是大语言模型的普遍属性。[^4]

### 从模型到 API：商业模式的转型

GPT-3 发布时有一个关键的变化：OpenAI 不再开源模型权重。取而代之的是一个按 token 计费的 API。这在当时是一个有争议的决定。

OpenAI 给出的理由：安全可控——通过 API 可以监控和限制滥用。批评者的理由：这背离了 OpenAI 的"开放"初衷（公司名称里的"Open"），同时也让独立研究者无法深入检查模型的偏见、安全性和鲁棒性。

从商业结果上看，这个决定是对的。API 模式让 OpenAI 在 GPT-3 发布后的两年内积累了超过 300 个应用的开发者生态——包括 Copy.ai、Jasper 等早期 AI 写作工具。到 2022 年 11 月 ChatGPT 发布时，OpenAI 已经有了成熟的 API 基础设施和付费用户群。从"非营利研究实验室"到"以 API 为核心的商业公司"，GPT-3 是转折点。

### 局限性——写在成功之前

GPT-3 论文在结尾处花了整整一页来讨论局限性，这在当时的 AI 论文中并不常见：

- **文本生成中的重复和退化**：长文本生成时，模型会陷入循环、重复或降级
- **常识与物理推理的缺失**：模型没有真正的世界模型，"如果我把袜子放进抽屉里，袜子还在抽屉里"这种推理对它来说不是显然的
- **虚假信息与偏见**：GPT-3 生成的文本可以流畅而完全错误，且会反映训练数据中的社会偏见
- **不可解释性**：175B 参数的前馈过程几乎不可验证，"为什么这么回答"没有答案
- **高推理成本**：哪怕只是生成几百个 token，也需要一次完整的模型前向传播——这对实时应用来说是高昂的

这些局限性不是在说 GPT-3 不好，而是在说"这还远远不够"。有趣的是，这些局限中的大部分在三年后的 GPT-4 中仍然存在——改善是渐进式的，不是突破式的。BERT 用预训练解决了理解的问题，GPT-3 用 scaling 解决了生成的问题，但真正的推理、真正的世界知识、真正的可靠性，是另一个量级的问题。

### 影响

GPT-3 的影响不是"又一个 SOTA 模型"级别的。它改变了整个行业对 LLM 的认知和期待：

- **「Few-shot 即一切」**：GPT-3 证明了一个模型可以不做任何微调就在 40+ 个任务上有竞争力。这直接启发了后来的 prompt engineering、in-context learning、chain-of-thought 等方向
- **LLM 作为平台**：GPT-3 API 开创了"模型即服务"（MaaS）模式。后来的 Anthropic API、Cohere API、Google Vertex AI 都是这个模式的追随者
- **涌现研究的起点**：GPT-3 中展示的非线性能力增长，为 2022 年 Wei 等人的涌现系统研究提供了原始数据。"什么能力在什么规模出现"成为一个独立的研究问题
- **ChatGPT 的直接前身**：2022 年初的 InstructGPT（GPT-3 + RLHF）把 GPT-3 朝"有用、诚实、无害"的方向对齐。InstructGPT 的 sibling model 就是 ChatGPT。从 GPT-3 到 ChatGPT，差异不是模型能力的飞跃，而是对齐方式和产品化的飞跃
- **闭源商业模式的先例**：GPT-3 的 API-only 模式重新定义了 AI 公司的商业模式路径。之前在 AI 领域没有人靠卖 API token 赚钱——GPT-3 把这个变成了一个数十亿美元的生意

### 评曰

GPT-3 的意义可以从两个角度来理解。

**从工程角度**，GPT-3 做了一件很简单的事：把一个已经用了三年的架构（2017 年 Transformer 解码器），配合更大的数据和更多的 GPU，硬生生堆到了 175B。没有任何一个组件是新发明的。没有任何一个训练技巧是此前未知的。论文的 31 位作者中，大多数人的工作不是设计新算法，而是做工程——数据处理、分布式训练、超参数调优、API 基础设施。GPT-3 是**工程战胜了算法**的宣言：当你的规模足够大，你不需要更聪明的架构。

**从认知角度**，GPT-3 打破了一个长期存在的直觉——"模型越大，需要的标注数据越多"。GPT-3 证明了相反的事实：模型越大，需要的标注数据越少。few-shot、one-shot、zero-shot——这些都是模型在没有任何任务特定训练的情况下表现出的能力。这意味着 scaling 不仅仅是在提升性能，而是在**创造新的能力**。在某个规模以下不存在的推理模式，在跨过阈值后突然出现——这更像是相变，而不是渐变。

但"涌现"这个词也有被过度使用的风险。GPT-3 的涌现能力令人兴奋，但它不是通用智能的萌芽。它是统计模式在极端参数规模下的行为质变——值得研究，但不必神秘化。就像水的三相变化：从冰到水再到蒸汽，不是水"学会"了沸腾，而是分子动力学在不同温度尺度上的必然行为。GPT-3 的涌现，可能也是如此——不是魔法，是数学在一个我们尚未完全理解的维度上按预期运作。

最后值得一提的是 GPT-3 的商业化路径。从开源到 API，从非营利到 capped-profit，GPT-3 发布时的 OpenAI 已经和 2015 年创办时完全不同。这是一种微妙的张力：一篇展示"语言模型可以用作思维工具"的论文，催生了一个以 API token 计价的商业引擎。学术的理想主义和市场的现实主义在 175B 的参数上交汇。之后的 ChatGPT、GPT-4、Sora 不过是这条路的自然延伸。
