# 2018年10月

## BERT：预训练时代的「哥伦布时刻」

> 双向 Transformer 编码器，11 项 NLP 基准任务全面刷新 SOTA。BERT 不是第一个预训练语言模型，但它是第一个让整个 NLP 领域意识到「预训练 + 微调」不是选修课，而是必修课的那个。

### 论文发布

**2018-10-11** — Google AI 的 Jacob Devlin 等人发布论文《BERT: Pre-training of Deep Bidirectional Transformers for Language Understanding》，在 arXiv 上公开。[^1] 同时开源了预训练模型权重和代码。

BERT 的全称是 **B**idirectional **E**ncoder **R**epresentations from **T**ransformers——从 Transformer 来的双向编码器表示。名字取得很直白，但做的事在当时是颠覆性的。

四个月前，OpenAI 发布了 GPT-1（2018 年 6 月），提出「生成式预训练 + 任务微调」范式。GPT-1 用的是 Transformer 解码器——单向的，从左到右预测下一个词。这个方向很自然：语言本来就是从左到右的，预测下一个词就是语言模型的标准任务。

BERT 换了一个方向：用 Transformer **编码器**——双向的，同时看左边和右边。训练目标也不是预测下一个词，而是两个更巧妙的任务：

- **掩码语言模型（Masked Language Model, MLM）**：随机遮住 15% 的输入词，让模型根据上下文猜出被遮住的是什么。这逼迫模型必须理解双向上下文。
- **下一句预测（Next Sentence Prediction, NSP）**：给模型两句话，判断第二句是不是紧跟在第一句之后的。这个任务后来被证明不是关键（RoBERTa 去掉 NSP 后效果反而更好），但在当时帮助 BERT 学会了句子间的关系。

BERT 发布了两个版本：BERT_base（110M 参数，12 层）和 BERT_large（340M 参数，24 层）。在今天看来参数很少——GPT-3 的 175B 是 BERT_large 的 500 多倍——但在 2018 年，340M 已经算是「大模型」了。

### 11 项 SOTA 的震撼

BERT 发布后在 11 项 NLP 基准任务上刷新了当时的最好成绩，包括：

- **GLUE 基准**（通用语言理解评估）：BERT_large 得了 80.5%，比之前最好的模型高了 7.7 个百分点——不是小幅度提升，是碾压式的
- **SQuAD 1.1 / 2.0**（阅读理解）：全面超越人类基准
- **SWAG**（常识推理）：大幅超越此前结果
- 命名实体识别、情感分析、自然语言推理等一大串任务

这种「一个模型打穿所有榜单」的现象，后来在大模型时代反复出现。但 BERT 是第一个。在它之前，NLP 的研究范式是为每个任务单独设计模型架构和训练策略。BERT 出现之后，范式变成了「下载预训练模型 → 在自己的任务上微调几轮 → 提交结果」。

### BERT 与 GPT-1：两条路的分叉

2018 年是 NLP 预训练范式的「双源元年」：

| | GPT-1 (2018-06) | BERT (2018-10) |
|---|---|---|
| 架构 | Transformer 解码器 | Transformer 编码器 |
| 方向 | 单向（左→右） | 双向 |
| 预训练目标 | 预测下一个词 | 掩码预测 + 下一句判断 |
| 擅长的任务 | 文本生成 | 文本理解 |
| 后续路线 | GPT-2 → GPT-3 → ChatGPT | RoBERTa → ALBERT → DeBERTa |

这两条路在 2018 年分岔，最终 GPT 路线统治了生成式 AI——因为生成能力强、可 scaling、可 chat。但 BERT 路线的「理解优先」思路没有消失：它演变成了检索增强生成（RAG）、语义搜索、文本分类等需要深度理解而非生成的后端能力。

### 为什么 BERT 是一个「时刻」

BERT 不是技术上最复杂的模型——架构几乎就是 Transformer 编码器堆叠，训练目标也是论文里就能讲清楚的东西。它的历史地位来自一个认知上的冲击：**一个预训练好的通用语言理解模型，配合少量任务特定数据微调，就可以在所有 NLP 任务上达到当时最好的水平。**

在 BERT 之前，大多数 NLP 研究者不相信这一点。他们相信每个任务需要专门设计的架构、专门设计的特征、专门设计的损失函数。BERT 用一个简单的实验设计粉碎了这种信念：同一个模型，同样的预训练权重，只是在最后一层换了不同的任务头，就在 11 个完全不同性质的任务上拿到了 SOTA。

这对 NLP 社区的冲击相当于：「你们专门为每个任务做的手工设计，打不过一个通用的预训练模型。」

### 影响

- **「BERTology」研究潮**：BERT 发布后，大量论文研究 BERT 内部的注意力头到底学到了什么——句法结构、指代关系、语义角色、知识存储……一个完整的子领域由此诞生
- **模型命名风潮**：BERT 之后，NLP 界出现了一波 Sesame Street（芝麻街）角色命名潮——Big BIRD、ERNIE（百度）、ALBERT、RoBERTa、ELECTRA……这个传统一直延续到后来的 Grover、Zap 等
- **中文 NLP 的转折点**：Google 发布的 BERT-base 包含中文版（基于简体+繁体的 Wikipedia 训练），极大降低了中文 NLP 的门槛。百度随后发布 ERNIE 1.0（2019 年 3 月），专门针对中文做了知识增强
- **预训练范式的固化**：「下载模型 → 微调 → 提交」成为 NLP 研究的标准流程，直到 2022 年 ChatGPT 的出现将其替换为「prompt → 生成 → 迭代」

### 评曰

BERT 最大的贡献，是让 NLP 社区集体接受了「预训练」这个前提。

在它之前，「为每个任务从头训练一个模型」是默认做法。BERT 证明了一个反直觉的事实：一个在大规模无标注文本上预训练好的通用模型，微调几轮就能在几乎所有 NLP 任务上碾压专门设计的模型。这动摇了 NLP 研究的方法论根基——手工设计的任务特定架构的价值被大幅贬低，通用预训练模型的地位被急剧抬高。

公平地说，GPT-1 比 BERT 早四个月提出了同样的范式。但 GPT-1 的 117M 参数和相对克制的实验结果没有引发像 BERT 那样的地震。BERT 的 340M 参数 + 11 项 SOTA 的结果组合，是在社区心里引爆的第一颗炸弹。之后的 GPT-2、GPT-3 不过是把爆炸半径继续扩大。

BERT 也是「大模型命名学」的起点。用一个经典儿童节目角色命名一个 AI 模型，这个行为本身就是一种宣言：我们将严肃的技术幽默化，将复杂的东西亲民化。后来 OpenAI 用 GPT、Meta 用 Llama、Google 用 Gemini、百度用 ERNIE——每个名字都是一个品牌叙事。而 BERT 是第一个让品牌叙事成为 AI 行业常态的模型。
