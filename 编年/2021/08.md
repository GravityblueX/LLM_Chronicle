# 2021年8月

## Codex：当语言模型开始写代码

> "写一个 Python 脚本，把 CSV 里的日期格式从 MM/DD/YYYY 改成 YYYY-MM-DD。"——Codex 用 12B 参数，在一个叫 HumanEval 的基准上解决了 28.8% 的编程问题（GPT-3 是 0%）。然后它变成了 GitHub Copilot。程序员的工作方式从此不同。

### 发布

**2021-08-10** — OpenAI 发布 **Codex**，一个基于 GPT-3 架构、在 GitHub 公开代码上微调的代码生成模型。12B 参数，通过 API 提供访问。同期发布 **HumanEval** 基准——一个包含 164 个手写编程问题的测试集，用来衡量模型的实际编程能力。[^1]

Codex 在 HumanEval 上的 pass@1（一次生成就通过测试）达到了 28.8%，而 GPT-3 是 0%。这是巨大的跳跃——GPT-3 虽然展示了初步的代码生成能力，但 Codex 把它变成了一个可靠的工具。

### GitHub Copilot

Codex 最深远的影响不在于论文，而在于它驱动的产品——**GitHub Copilot**。2021-06-29（论文发布前两个月），GitHub 与 OpenAI 联合发布了 Copilot 的技术预览版，基于 Codex 模型。2022-06-21，Copilot 正式商用，每月 $10/人。[^2]

Copilot 是第一个大规模落地的"AI 编程助手"。它在编辑器中以补全建议的形式出现——你写一个函数名和注释，它补全整个函数体。到 2023 年，Copilot 已有超过 100 万付费用户，生成代码量占 GitHub 新代码的 40% 以上。

### 影响

- **编程范式转变**：从"写代码"到"审查代码+提示代码"，Copilot 开启了一个至今仍在加速的转变
- **AI 辅助编程品类诞生**：Codex/Copilot 之后，Gemini Code Assist、Cursor、Windsurf、Claude Code（Claude 3.5 Sonnet）等雨后春笋般出现
- **HumanEval 成为标准**：这个 164 题的基准至今仍是衡量代码模型能力的核心指标之一

### 评曰

Codex 是 GPT 路线从"语言"到"生产力"的关键一跳。GPT-2 证明了 zero-shot，GPT-3 证明了 few-shot，但公众看到的是文字——有趣的 demo，离钱还远。Codex 直接把 LLM 嵌入了一个有真实付费场景的产品——写代码。这是大语言模型第一次以"生产力工具"而非"让人惊叹的技术"的身份落地。从那以后，"我们这个模型能不能帮人写代码"变成了衡量 LLM 实用性的不成文标准。Copilot 成功后，AI 编程工具市场在三年内膨胀到数十亿美元。而这一切的起点，是一个 12B 参数的模型和 164 道手写的编程题。
