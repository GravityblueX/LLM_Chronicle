# 2025年12月

## GPT-5.2：Code Red 之后的 OpenAI 反击

> Gemini 3 Pro 抢跑三周，OpenAI 一份内部"Code Red"备忘录把 GPT-5.2 的发布从月底提前到了 12 月 11 日。三种推理模式、一个编程变体——这不是一次常规迭代，而是一次定向反击。

### 发布

**2025-12-11** — OpenAI 发布 **GPT-5.2**，这是继 GPT-5（2025-08-07）和 GPT-5.1（2025-11-12）之后，GPT 系列在四个月内的第三次重大更新。GPT-5.2 包含三种模式：**GPT-5.2 Instant**（即时回答）、**GPT-5.2 Thinking**（标准推理 + 扩展推理），以及 **GPT-5.2 Pro**（深度推理，消耗更多计算资源）。The Verge, 2025-12-11[^1]; Wikipedia[^2]

**2025-12-18** — OpenAI 发布 **GPT-5.2-Codex**，面向编程与 agentic 任务的专用变体，将安全性融入大规模软件重构流程。VentureBeat, 2025-12-18[^3]

### Code Red：Gemini 3 Pro 催化的紧急发布

GPT-5.2 的发布时间比原计划提前了约两周。多家媒体报道，Google 的 **Gemini 3 Pro**（约 2025 年 11 月中旬发布）在多项基准测试中超越 GPT-5.1，被业界广泛视为当时最强的多模态模型——这触发了 OpenAI 内部代号为 **"Code Red"** 的紧急响应备忘录。[^4][^5]

OpenAI 高管对此叙述进行了部分修正。OpenAI 应用业务 CEO Fidji Simo 对 *Wired* 表示，公司"已经为这个模型的发布工作了好几个月"，但承认 Code Red 以及为 ChatGPT 额外调配的资源"在最终部署中是有帮助的"。[^6]

Anthropic CEO Dario Amodei 则公开嘲讽了 OpenAI 和 Google 之间的"Code Red"竞争。[^7]

### 三种模式：从即时回答到深度推理

GPT-5.2 延续了 GPT-5 引入的"路由器"架构——系统根据对话类型、复杂度、工具需求和用户意图自动选择模型。但 GPT-5.2 将推理梯度进一步细化：

- **Instant**：速度优先，面向日常对话和简单任务
- **Thinking**：标准推理模式，可选扩展推理（extended thinking），面向需要逻辑链条的复杂任务
- **Pro**：深度推理，消耗最多计算资源，面向专业分析和高难度问题

这一设计回应了一个行业趋势：自 DeepSeek-R1（2025-01）证明推理模型可以通过开源 + 低价颠覆市场以来，推理能力已不再是"奢侈品"，而是标配。GPT-5.2 的三层推理架构试图在同一个模型系统内覆盖从"轻量即时"到"重量深度"的全部场景。

### 定位：从聊天到工作

GPT-5.2 的能力侧重于**电子表格创建、财务建模、演示文稿制作和多步骤项目执行**——明显面向知识工作者而非休闲用户。Reuters, 2025-12-11[^8]

Box 公司 CEO Aaron Levie 报告称，在其公司的实际知识工作测试中，GPT-5.2 比 GPT-5.1"高出 7 分"。*VentureBeat* 的早期评测总结道，GPT-5.2"面向的是重度用户、开发者和企业代理，而非休闲聊天"。[^9]

### 后续

- **2026-02-05**：OpenAI 发布 **GPT-5.3-Codex**，速度比前代提升 25%，定位从编程助手扩展为通用工作代理。OpenAI 称其为"第一个参与构建自身的模型"。[^10]
- **2026-03-05**：OpenAI 发布 **GPT-5.4**，继续迭代。[^11]
- **2026-01-24**：*The Guardian* 报道，GPT-5.2 被发现在回答中引用 Elon Musk 的百科全书 Grokipedia 作为来源，后者因来源质量低下而受到批评。[^12]

### 评曰

GPT-5.2 的发布标志着 OpenAI 在 2025 年下半年进入了一种全新的节奏——从"按计划发布"变成"被竞争对手逼着发布"。

这在 OpenAI 的历史上是罕见的。自 ChatGPT 以来，OpenAI 一直是赛道的定义者：GPT-3 定义了大模型，GPT-4 定义了多模态，ChatGPT 定义了对话式 AI，o1 定义了推理模型。但 2025 年的格局已经不同——DeepSeek-R1 在 1 月用 MIT 开源炸开了推理模型的围墙，Gemini 3 Pro 在 11 月用多模态能力抢走了技术话语权。当 Google 的 Gemini 3 Pro 被"广泛引用为领先的多模态模型"时，OpenAI 第一次从"定义者"变成了"回应者"。

Code Red 不只是一个内部代号。它是 OpenAI 成立以来第一次被另一个巨头的模型发布逼到需要紧急调动资源。Fidji Simo 说"已经为此工作了好几个月"——这可能是事实，但两个月前没有人觉得 GPT-5.1 需要被紧急替换。

GPT-5.2 本身是一个扎实的产品：三层推理梯度、面向企业场景的能力提升、一周后跟进的 Codex 变体。但它在大模型史上的位置不取决于它的 benchmark——而取决于它回答了一个问题：**当竞争对手追上来时，OpenAI 能以多快的速度转身？** 答案是三周。
