# 2025年8月

## GPT-5：OpenAI 的第五代基座模型

> GPT-5 不是一次技术革命——它是 OpenAI 在 GPT-4、GPT-4o、GPT-4.5、o1、o3 之后，把所有技术线终于合并到一个模型里的尝试。"统一"本身就是这个产品最大的叙事。

### 发布

**2025-08-07** — OpenAI 通过线上直播发布 **GPT-5**，同步上线 ChatGPT 与 Microsoft Copilot，以及 OpenAI API。[^1]

GPT-5 是 GPT 系列的第五代基座模型，前代为 GPT-4（2023-03）、GPT-4o（2024-05）、GPT-4.5（2025-02，内部代号 Orion，原定为 GPT-5 但效果未达预期而降级发布）。[^2]

### 技术亮点

据 OpenAI 官方，GPT-5 的核心改进包括：

- **统一推理模式**：内置一个"路由器"（router），自动判断任务是否需要深度推理。简单问题直接作答（快速模式），复杂问题进入"thinking longer"的推理链——无需用户手动选择 o1/o3 模式。[^1]
- **Safe Completions**：新安全策略——不再对潜在有害查询直接拒绝，而是尝试给出安全的高层次回答。OpenAI 称此策略使 GPT-5 "拒绝更多真正不安全的问题，同时对无害信息更少拒绝"。[^1]
- **减少讨好式回答**：GPT-5 被训练为比前代更少"拍马屁"——回答更直接、更具批判性。[^1]
- **降低幻觉率**：在多项准确性测试中，GPT-5 的幻觉率显著低于 GPT-4o 和 GPT-4.5。[^1]

### 性能

GPT-5 在发布时于数学、编程、金融和多模态理解的基准测试上达到最先进水平（SOTA）。Sam Altman 在发布前夕称其为"通往 AGI 之路上的显著一步"，具有"PhD 级别的能力"。[^1]

### 行业背景

GPT-5 的发布时机紧随 2025 年初的"推理模型大战"——OpenAI o3-mini（2025-01）、DeepSeek-R1（2025-01）、Claude 4（2025-05）先后发布。GPT-5 的核心策略不是"更强"，而是"统一"——把此前分裂的 GPT 对话线和 o 系列推理线合为一个模型，用路由器自动调度。这回应了一个用户痛点：o1/o3 需要手动切换，GPT-4o 不擅长推理，GPT-5 试图让两个世界合一。

值得注意的是，GPT-5 发布前两天（2025-08-05），OpenAI 还开源了 **GPT-OSS**——两个具备推理能力的开放权重模型。[^1] 这是 OpenAI 罕见的开源举动，被视为对 DeepSeek 开源策略的一种回应。
