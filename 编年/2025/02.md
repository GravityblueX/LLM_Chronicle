# 2025年2月

## 从“会思考”到“会完成任务”：Deep Research、Copilot Agent Mode、Claude Code 与 GPT-4.5

> 2025 年 2 月不是只有 GPT-4.5 与 Claude 3.7 Sonnet 的模型竞争。更深的变化发生在产品边界：**Deep Research 把多步网络研究变成长程任务，Copilot Agent Mode 把 IDE 变成行动环境，Claude Code 把终端和代码库直接交给模型。** 同一个月里，“推理模型”与“执行 Agent”开始真正合流。

### Deep Research：研究本身成为一种 Agent 工作流

**2025-02-02** — OpenAI 发布 **Deep Research**。[^1]

它不是简单搜索后写摘要，而是在较长时间内自主执行多步网络研究：搜索、打开来源、读取材料、改变检索方向、整合证据，再生成带引用的报告。

它说明 Agent 的“行动”并不一定意味着点击购买按钮或修改文件。

只要系统能够：

1. 接受高层目标；
2. 自主选择下一步信息动作；
3. 根据观察结果调整计划；
4. 持续执行直到形成可验收产物；

就已经具备典型的 Agent 工作流。

Deep Research 因而成为“research agent”产品化的重要节点，也为 7 月 ChatGPT Agent 把 research 与 browser action 合并埋下伏笔。

### Copilot Agent Mode：IDE 里的循环从人驱动变成 Agent 驱动

**2025-02-06** — GitHub 发布 **Copilot Agent Mode**。[^2]

传统 Copilot 的主交互是补全：人写，AI 猜下一段。

Agent Mode 则允许 Copilot 根据目标：

- 判断要修改哪些文件；
- 自动提出和执行修改；
- 发现编译 / lint / terminal 错误；
- 根据错误继续迭代。

这意味着 IDE 中的控制循环发生变化。

过去：

> 人 → 编辑 → 编译 → 看错 → 再编辑

现在开始变成：

> 人给目标 → Agent 编辑 → 运行 → 观察错误 → 再编辑 → 人验收

软件工程之所以成为 Agent 最早跑通的领域，核心正是 compiler、test、lint、Git、diff 这些机器反馈能够不断校正行动。

### Claude 3.7 Sonnet 与 Claude Code：推理能力第一次直接配上终端

**2025-02-24** — Anthropic 发布 **Claude 3.7 Sonnet**，并同步公开 **Claude Code** research preview。[^3]

Claude 3.7 Sonnet 的重要变化是 hybrid reasoning：同一个模型既可快速回答，也可以在复杂任务中投入更多推理计算。

但从 Agent 历史看，同日的 Claude Code 更关键。

Claude Code 把模型直接放进开发者终端，使其能够：

- 浏览代码库；
- 搜索符号和文件；
- 修改多个文件；
- 运行命令；
- 读取测试 / 编译结果；
- 继续修复；
- 与 Git 工作流结合。

终端比 GUI 更适合 Agent：文本紧凑、可组合、状态容易记录，也能覆盖文件、网络、构建、测试和系统管理等大量能力。

这也是为什么后来的 Codex CLI、Terminal-Bench 等工作都把 shell 视为 Agent 的重要“机器接口”。

> 关于 Claude 的 extended thinking，应避免把产品中可见的思考界面简单等同于“原始内部思维链全部公开”。对外展示、内部计算和安全处理并不是同一个概念。

### GPT-4.5：预训练主线的最后一次高价扩张

**2025-02-27** — OpenAI 发布 **GPT-4.5**。[^4]

GPT-4.5 强调更广泛的知识、更自然的互动与较低幻觉，而不是 o 系列那样的推理时计算。其 API 初始价格显著高于 GPT-4o。

它后来常被描述成“非推理式 GPT scaling 的尾声”。这一判断可以保留，但不宜写成“预训练 scaling 从此停止”：后续所有推理与 Agent 模型仍然依赖更好的预训练基座。

更准确的变化是：

> **预训练不再是唯一可购买的能力扩展方式。**

到 2025 年初，用户还可以购买：

- 更多 test-time reasoning；
- 更长上下文；
- 工具调用；
- 长程 Agent 执行。

模型产品的 scaling 维度开始分叉。

| 日期 | 事件 | 主要变化 |

| 02-02 | Deep Research | 把多步研究变成长程 Agent 任务 |

### 评曰

2024 年的 Agent 还很容易被理解成“模型会点电脑”。

2025 年 2 月之后，这个理解已经不够。

Deep Research 没有必须点击 GUI，却能独立完成长程研究；Claude Code 不需要“像人一样用鼠标”，terminal 反而让它更有效；Copilot Agent Mode 则把 compiler 和 lint 变成自动反馈。

所以 Agent 的本质不是拟人操作，而是：

> **系统把一个目标交出去，并允许模型通过环境反馈持续推进，直到产生可验收结果。**

这一点比“有没有鼠标”更重要。

同月 GPT-4.5 的高价发布又形成了鲜明对照：行业正在从“给你一个更强的模型”转向“给你一个能把工作做完的系统”。
