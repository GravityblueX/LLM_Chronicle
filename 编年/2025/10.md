# 2025年10月

## Claude Haiku 4.5 与 Claude Code 网页版

**2025-10-15** — Anthropic 发布 **Claude Haiku 4.5**，这是 Claude 4 系列（2025-05-22 发布）之后的首个子版本更新，定位为轻量、快速、低成本的推理模型。[^1]

Haiku 4.5 的发布延续了 Anthropic 自 Claude 3 系列以来的"三件套"策略：Haiku（轻量快速）、Sonnet（均衡主力）、Opus（旗舰推理）。Claude 4 发布时仅包含 Sonnet 级别（对应 2025-05-22 发布的 Claude 4），Haiku 4.5 补齐了轻量端的空缺。

**2025-10-20** — Anthropic 推出 **Claude Code 网页版**，同时上线沙箱（sandboxing）功能，允许用户在浏览器中直接使用 Claude Code 进行代码生成与调试，不再局限于命令行环境。[^1]

Claude Code 网页版的发布是一个信号——Anthropic 正将 Claude Code 从开发者工具推向更广泛的用户群体。此前，Claude Code 仅以 CLI 形式存在（2025-02 预览，2025-05 随 Claude 4 正式发布），网页版和沙箱功能的加入大幅降低了使用门槛。

> ⚠ **说明**：任务清单中提及的"Claude 3.5 Opus"在编纂时未找到可靠来源——Anthropic 的版本命名体系中不存在此型号。Claude 3.5 系列仅有 Sonnet 和 Haiku（2024 年发布），Opus 级别跳过了 3.5 版本号，直接在 Claude 4 系列中推出（Claude Opus 4，2025-05）。2025 年 10 月 Anthropic 的实际发布为 Claude Haiku 4.5。
