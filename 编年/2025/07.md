# 2025年7月

## Mistral Large 2：欧洲旗舰的 123B 更新

**2025-07-24** — Mistral AI 发布 **Mistral Large 2**，总参数 123B，支持 128K 上下文窗口，号称在多项基准上对标 Llama 3.1 405B 级别性能。模型同时开放权重与 API 调用。[^1]

Mistral Large 2 延续了 Mistral 一贯的"效率优先"路线——不做最大的模型，但做每参数性能最高的模型。123B 参数规模在当时的开源/开放权重阵营中属于上游水平，但其真正卖点是多语言能力（尤其法语、德语、西班牙语等欧洲语言）和代码生成质量。Mistral 声称 Large 2 在代码和多语言任务上与 Llama 3.1 405B 持平或超越，而推理成本仅为后者的一小部分。

这一策略在当时并不令人意外。2025 年上半年，开源阵营已形成 Llama（Meta）与 Mistral（法国）两极并立之势。Llama 3.1 405B 以绝对参数规模称霸，Mistral 则以 MoE 架构和更紧凑的参数量打出差异化。Mistral Large 2 的发布进一步确认了欧洲在开源大模型赛道中的存在感。
