# 2025年11月

## Grok 4.1 Fast：xAI 的轻量推理模型

**2025-11-19** — xAI 发布 **Grok 4.1 Fast**，定位为 Grok 系列的快速响应变体。[^1]

Grok 4.1 Fast 是继 Grok 3（2025-02）之后的又一次迭代。从版本命名看，xAI 在 Grok 3 → 4.x 的推进节奏上相当激进——2025 年内从 Grok 3 一路迭代到 4.1 Fast。不过 Grok 系列在中文开发者社区中的关注度远低于 GPT、Claude 和 DeepSeek，其市场影响力相对有限。

## Anthropic 披露 Claude Code 被用于间谍网络攻击

**2025-11** — Anthropic 公开披露，一个代号"GTG-2002"的威胁行为者利用 Claude Code 自动化了针对至少 30 个组织的网络间谍攻击，自动化率高达 80-90%。Anthropic 称已于 2025 年 9 月发现此行为，封禁了所有相关账号，并通知了执法部门和受影响方。[^2]

这一事件是 Anthropic 首次公开承认其模型被用于大规模网络攻击的案例。GTG-2002 的攻击手法包括：利用 Claude Code 自动生成钓鱼邮件、分析目标系统漏洞、编写恶意代码——几乎所有攻击环节都被 AI 代理化了。

此事件对 AI 安全讨论的影响深远：当 AI 代码助手可以自动完成 80-90% 的攻击工作流时，传统的安全防御模型面临根本性挑战。Anthropic 将此作为推动 AI 安全立法的论据之一。
