# 2025年11月

## Clawd：后来引爆中国“龙虾潮”的个人 Agent 前身出生

**2025-11-25** — Peter Steinberger 创建 **Clawd**，即后来经历 Moltbot 更名并最终成为 **OpenClaw** 的项目。OpenClaw 官方 lore 将 11 月 25 日记为 Clawd 的起点；Peter 后来回顾称它最初只是一个周末项目。[^3][^4]

Clawd 并不是 LLM Agent 的起点。到这时，ReAct、AutoGPT、Devin、Computer Use、MCP 等技术与产品已经存在。

它真正新鲜的地方是把此前散落的部件打成了一种极容易被普通人理解的个人执行系统：

> **自己的机器 + 模型 / API Key + workspace + shell / browser + Skills + 消息入口 + 长期运行 gateway。**

用户不必一直守在 Agent 面前，而可以从 WhatsApp、Telegram、Slack、Discord 等既有消息渠道下达任务，让 Agent 在自己的机器和工作区里持续执行。[^4]

这套形态后来会在 2026 年初进入中国，并因为微信 / 飞书 / 钉钉、低价国产模型和云厂商的一键托管迅速演变成所谓“养龙虾”热潮。

因此更准确的历史定位是：

> **OpenClaw 不是 Agent 技术史的开端，却是 2026 年中国大众“会干活 Agent”产品史的重要引爆点。**

这一判断也提醒后来的史官：不能因为 2026 年大厂集中推出“Claw”产品，就倒过来假装 Agent 概念从 OpenClaw 才开始。

## Grok 4.1 Fast：xAI 的轻量推理模型

**2025-11-19** — xAI 发布 **Grok 4.1 Fast**，定位为 Grok 系列的快速响应变体。[^1]

Grok 4.1 Fast 是继 Grok 3（2025-02）之后的又一次迭代。从版本命名看，xAI 在 Grok 3 → 4.x 的推进节奏上相当激进——2025 年内从 Grok 3 一路迭代到 4.1 Fast。不过 Grok 系列在中文开发者社区中的关注度远低于 GPT、Claude 和 DeepSeek，其市场影响力相对有限。

## Anthropic 披露 Claude Code 被用于间谍网络攻击

**2025-11** — Anthropic 公开披露，一个代号“GTG-2002”的威胁行为者利用 Claude Code 自动化了针对至少 30 个组织的网络间谍攻击。旧稿把“80—90% 自动化”直接当成已充分验证的总体事实；本次保留为 Anthropic 对该个案的官方调查口径，不把单一事件外推成所有网络攻击 Agent 的普遍能力。[^2]

这一事件仍然很重要，因为它说明 coding Agent 的行动链已经足够长，可以把侦察、漏洞分析、代码生成和工具执行串成自动化流程；与此同时，权限与工具越多，滥用风险也越不能靠最终文本审核解决。

### 评曰

这个月把 Agent 的两面放在了一起。

一边，Clawd 代表“给普通人一只可以常驻自己机器的数字执行者”；另一边，Claude Code 个案说明同一类长期工具能力也能被用于攻击流程。

Agent 的历史从来不是“自动化越来越多，所以越来越好”。更准确的问题始终是：

> **谁拥有它、它拿到什么权限、在什么环境行动、失败与滥用怎样被发现和收回。**
