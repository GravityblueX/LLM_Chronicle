# 2025年1月

## DeepSeek-R1：开放推理模型的「DeepSeek 时刻」

> 2025 年 1 月最重要的不是一句“600 万美元做出 o1”。DeepSeek 从未披露 R1 的完整训练总成本。真正足够改变历史的事实已经很多：R1 把强化学习推理公开写进技术报告，把主模型权重置于 MIT License 下，把蒸馏小模型送进本地生态，并在发布一周后引发全球资本市场对 AI 算力经济学的重新估值。

### 发布

**2025-01-20** — DeepSeek 正式发布 **DeepSeek-R1** 与 **DeepSeek-R1-Zero**。R1 基于 DeepSeek-V3-Base，后者为 **671B 总参数、37B 激活参数**的 MoE。[^1][^2]

DeepSeek 官方仓库明确写明：**代码仓库与 R1 主模型权重采用 MIT License**，允许商业使用、修改和衍生。[^1]

但六个蒸馏模型需要进一步区分：它们分别基于 Qwen2.5 与 Llama 3.x 模型，仍需遵守上游基座许可证。DeepSeek 官方 README 也专门提示了这一点。[^1]

因此，“R1 全家桶全部无条件 MIT”是不准确的；更准确的说法是：**R1 主模型本身的开放程度显著高于此前许多主流开放权重旗舰，而 distill checkpoint 仍携带模型谱系。**

### 技术路线：R1-Zero 与 R1 不是同一训练故事

#### R1-Zero：强化学习直接激发推理行为

R1-Zero 从 DeepSeek-V3-Base 出发，**不先进行传统的 cold-start SFT**，而直接使用大规模强化学习。DeepSeek 采用 **GRPO（Group Relative Policy Optimization）**，并主要使用可验证的准确率奖励与格式奖励。[^2]

训练过程中，模型出现更长的思考、反思和重新检查等行为。论文用 “aha moment” 展示模型会在推理中重新评估原先路径。

这个实验的重要意义不是证明“人类完全不需要教模型推理”。R1-Zero 的基座本身已经经过大规模预训练，而强化学习奖励又由人类设计。

它真正证明的是：

> **相当一部分显式推理行为可以通过 outcome-oriented reinforcement learning 被强化出来，而不需要先提供大量人工书写的思维链示范。**

#### R1：加入 cold-start data 和多阶段训练

最终发布的 DeepSeek-R1 并不是纯 RL 模型。

为改善 R1-Zero 的语言混杂、可读性和通用任务表现，DeepSeek 为 R1 引入少量 cold-start long-CoT 数据，然后进行 reasoning-oriented RL；随后又加入 rejection sampling、非推理数据 SFT 与第二阶段 RL。[^2]

因此最准确的路线是：

**R1-Zero：base → RL**  
**R1：cold start → RL → SFT / rejection sampling → RL**

旧稿把 R1 本身概括成“纯强化学习训练”会混淆这两个实验。

### GRPO：减少 critic，但不是“完全不要奖励模型”这么简单

GRPO 相比 PPO 类方法省去了单独训练 value function / critic 的需要，通过同一问题多个采样答案的组内相对表现计算优势。

在 R1 的可验证推理任务中，答案正确性可以直接成为奖励来源，因此不需要传统 RLHF 那种对每个输出进行偏好打分的独立 reward model。

但这不意味着所有 RL 场景都不再需要 learned reward。R1 后期面向 helpfulness / harmlessness 等通用目标仍使用模型化评价。[^2]

### 公开评测：对标 o1 的意义在“同一量级”

以下为 DeepSeek 技术报告公开数字：

| 基准 | DeepSeek-R1 | R1-Zero | OpenAI o1-1217 |
|------|:--:|:--:|:--:|
| AIME 2024 | 79.8% | 71.0% | 79.2% |
| MATH-500 | 97.3% | — | 96.4% |
| Codeforces | 96.3 percentile | — | 96.6 percentile |
| SWE-bench Verified | 49.2% | — | 48.9% |

这些数字来自模型发布方的评测设置，最稳妥的历史判断不是“R1 全面击败 o1”，而是：**开放权重推理模型第一次公开进入与当时闭源前沿推理模型直接比较的能力区间。**[^2]

### API 定价：推理能力不再只能按奢侈品卖

R1 发布时，DeepSeek API 采用缓存命中 / 未命中分价，输出 token 价格显著低于 OpenAI o1。[^1]

R1 由此给行业造成了双重压力：

- 权重可以自己部署；
- 不想自己部署的人，也可以用很低的 API 价格调用。

开放权重与低价云 API 并不是互斥的商业路线，它们可以互相加强。

### 训练成本：R1 的“约 600 万美元总成本”没有官方依据

2025 年 1 月大量报道把两个不同数字拼在了一起：

1. V3 技术报告披露 **2.788M H800 GPU hours**，并按 2 美元/GPU-hour 换算为 **557.6 万美元训练计算成本**；[^3]
2. 外部媒体随后推测 R1 的强化学习开销不高，于是出现“R1 总成本约 600 万美元”说法。

DeepSeek **没有公开 R1 完整训练总成本**，也没有给出足以证明“V3 + R1 全项目 600 万美元”的官方账目。

因此本书不再采用这一估算作为事实。

R1 真正能够确定的成本史料是：它建立在已经训练好的 V3-Base 上，而 R1 论文主要披露训练方法和能力结果，没有披露完整 RL GPU-hour / 美元成本。[^2]

### 蒸馏：推理能力进入更小模型

R1 同步发布六个 distilled models，覆盖 1.5B 至 70B，基座来自 Qwen2.5 与 Llama。[^1]

这件事的意义甚至不低于主模型本身。

开放旗舰解决的是“前沿权重能不能获得”；蒸馏解决的是“普通硬件能不能获得一部分推理能力”。

因此 R1 的影响存在两条方向相反的扩散：

- 向上：671B 开放推理旗舰挑战闭源前沿；
- 向下：1.5B—70B 蒸馏模型把推理行为压进可本地运行的尺寸。

### 冲击波

**2025-01-27** — DeepSeek App 登上美国 Apple App Store 免费应用榜首。同日，NVIDIA 股价大跌约 17%，市值单日减少约 5890 亿美元，成为当时美国上市公司最大单日市值损失之一。[^4][^5]

市场反应并不能证明“未来不再需要 GPU”。事实恰恰相反：之后全球 AI 基础设施投资仍继续扩大。

市场真正重新定价的是另一个假设：

> **同等级模型能力与 GPU 资本投入之间的关系，可能没有投资者此前想象得那么固定。**

这比“算力不是护城河”更准确。算力依然重要，但算法、架构、数据和系统效率可以显著改变一单位算力产生多少能力。

### 蒸馏争议

2025 年初，OpenAI 表示其掌握迹象，怀疑 DeepSeek 可能通过 distillation 使用 OpenAI 模型输出。此后 Anthropic 等公司也在 2026 年公开提出针对中国模型公司的大规模蒸馏指控。

这些是重要产业事件，但应区分**指控**与**已证明事实**。公开信息不足以精确重建 R1 的全部训练数据来源，因此本书不把“R1 使用了 OpenAI 输出”写成已经坐实的技术事实。

### 后续

**2025-05-28** — DeepSeek 发布 **R1-0528**，继续提升数学与推理能力，并成为新的蒸馏来源。[^6]

**2025-09** — DeepSeek-R1 论文正式发表于 *Nature*，把一场年初的产业冲击变成经过同行评议的研究记录。[^7]

之后 DeepSeek 的主线逐渐从“单独 reasoning model”回到统一 Agent 模型：V3.1、V3.2 将 thinking / non-thinking、工具调用与 thinking-in-tool-use 结合；2026 年的 V4 又进一步扩展到百万上下文和 Agent 工作负载。

### 评曰

DeepSeek-R1 的历史意义，如果只剩“便宜”和“英伟达跌了”，反而会被低估。

它至少改变了四件事。

第一，**公开展示 outcome-based RL 可以在强基座上大规模强化推理行为。** R1-Zero 不是完整产品，却是非常干净的实验。

第二，**开放权重推理模型进入真正的前沿比较。** 在此之前，o1 把推理模型变成闭源产品；R1 证明这个品类没有天然理由只能存在于 API 后面。

第三，**推理能力可以被蒸馏和重新分发。** 一个旗舰模型的价值不再只存在于它自己身上，还可以成为小模型训练数据与行为模式的来源。

第四，**AI 能力的经济学开始与 AI 能力本身同等重要。** 同一量级的 benchmark 能力，因为权重是否可得、API 多贵、能否本地部署，会产生完全不同的产业后果。

所以 R1 真正炸开的不是某家公司的一堵墙，而是三个长期被绑定在一起的概念：

**前沿能力 ≠ 必须闭源；推理能力 ≠ 必须高价；大模型能力 ≠ 只能由最大尺寸模型消费。**

这三条裂缝后来会一直延伸到 2026 年的 Kimi K3、Qwen3.8 和本地 Agent。
