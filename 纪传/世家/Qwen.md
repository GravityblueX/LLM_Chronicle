# 《Qwen 世家》

> Qwen（通义千问）系列是阿里云自 2023 年起开发的大模型家族。从闭源的通义千问产品到 Apache 2.0 全谱系开源，从纯文本到视觉、音频、代码的多模态覆盖——Qwen 的迭代史记述了一个中国科技巨头如何用"双轨策略"（闭源抢收入，开源抢社区）在全球开源 LLM 生态中建立起最完整的模型家族。

---

## 一、概述

Qwen 系列由阿里云通义实验室开发，全称取自"通义千问"（Tongyi Qianwen）中"千问"的拼音缩写。它经历了三个阶段：**产品落地**（通义千问，2023-04）、**开源扩张**（Qwen→Qwen2→Qwen2.5，2023-08 至 2024-09）、**推理整合**（Qwen 3，2025-04）。

Qwen 的演化主线不是架构的剧烈变革——全程 Transformer 解码器——而是**覆盖面的持续扩张**：参数规模从 1.8B 覆盖到 235B MoE，模态从纯文本扩展到视觉、音频、代码，许可从闭源产品线扩展到 Apache 2.0 全系开源。到 2025 年，Qwen 系列在 HuggingFace 上累计下载量超过数亿次，是中国模型在海外开源社区中影响力最大的产品体系。[^1]

| Qwen 1.5 | 2024-02 | 0.5B–72B | 全谱系覆盖，训练数据与架构升级 | Apache 2.0 |
| Qwen 2 | 2024-06 | 0.5B / 1.5B / 7B / 72B | 全面改进的预训练与对齐 | Apache 2.0 |

### 2.1 通义千问：阿里的"AI 底座"

2023 年 3–4 月，中国大模型行业进入密集发布期。百度文心一言（3 月 16 日）、阿里通义千问（4 月 11 日）、智谱 ChatGLM（3 月）几乎同时登场。

**2023-04-11** — 阿里云在北京阿里云峰会上发布 **通义千问**。CEO 张勇宣布"阿里巴巴所有产品未来都将接入大模型"。[^2] 通义千问的定位一开始就与文心一言不同：它不是一个人的对话助手，而是**所有阿里产品的 AI 底座**——钉钉、天猫精灵、淘宝搜索、高德地图、阿里云，全线接入。

这一次发布没有开源模型权重，通义千问是闭源产品。但它给后续的开源路线奠定了品牌和工程基础。

### 2.2 Qwen 1：开源起手式

**2023-08** — 阿里发布 Qwen 开源系列，包含 7B、14B、72B 三个规模。这是中国互联网巨头中第一个大规模开源 LLM 的举动。[^2]

首批开源模型的许可选择了 **Tongyi Qianwen LICENSE**——一个允许商用和研究使用、但非标准开源协议的许可。这一选择在当时引发社区争议：许可的商用友好性不及 Apache 2.0 或 MIT，但比百度的全闭源已经是一大步。

Qwen-7B 和 Qwen-14B 迅速在 HuggingFace 上获得关注，尤其在中文 NLP 社区中填补了 Llama 系列中文能力不足的空白。Qwen-72B 则是当时开源社区中参数规模最大的中文模型之一。

### 2.3 Qwen-VL 与多模态扩展

**2023-09** — 阿里发布 **Qwen-VL**，将 Qwen 的文本理解能力扩展到视觉领域。Qwen-VL 支持图像描述、视觉问答、图文定位等任务。这是 Qwen 系列从纯文本走向多模态的第一步。[^3]

此后，视觉分支持续迭代：**Qwen2-VL**（2024 年下半年）提升了高分辨率图像理解和视频理解能力；**Qwen2.5-VL**（2025 年初）进一步强化了动态分辨率支持和多图推理。

同时期，**Qwen-Audio**（2023-12）将模态扩展到音频理解，支持语音识别、音频描述、音乐分析等任务。[^4]

### 2.4 Qwen 1.5：全谱系 + Apache 2.0 转向

**2024-02** — 阿里发布 **Qwen 1.5**。这不是一个"更大更强"的迭代，而是一次**生态策略的升级**。[^5]

关键变化有三：第一，许可从 Qwen LICENSE 切换到 **Apache 2.0**——此后所有 Qwen 开源模型均不再使用自有许可，彻底消除了商用顾虑。第二，首次推出全谱系覆盖——从 0.5B 到 72B，每个规模都有对应的模型，从手机到服务器，所有算力节点都能找到合适的 Qwen。第三，训练数据和架构做了系统性升级，统一了上下文窗口和对话模板。

Qwen 1.5 的 Apache 2.0 许可是一个分水岭——它让 Qwen 从"一个不错的中国模型"变成了"全球开源社区的一等公民"。此后 HuggingFace 上的下载量开始指数级增长。

### 2.5 Qwen 2/2.5：全规模覆盖的完成

**2024-06** — 阿里云发布 **Qwen 2**，包含 0.5B、1.5B、7B、72B 四个规模，覆盖从移动端到服务器的全场景。[^1] Qwen 2 在预训练数据规模、多语言能力（新增约 30 种语言）、长上下文支持（32K–128K）上相比 Qwen 1.5 做了全面提升。

**2024-09** — **Qwen 2.5** 发布，增加 3B、14B、32B 中间规模，形成 0.5B–72B 的全谱系。Qwen 2.5 在 MMLU 上达到 85.0%——虽略低于 Llama 3.1 405B 的 88.6%，但 72B 参数仅为 405B 的六分之一。在中文基准上，Qwen 2.5 全面领先 Llama 和 Mistral 的同级模型。[^1]

Qwen 2.5 还推出了 **MoE**（混合专家）版本——如 Qwen2.5-14B-A3B（总 14B，激活约 3B）——用更少的推理成本获取接近密集模型的能力。这是 Qwen 系列在效率方向上的重要实验。

同期的 **CodeQwen / Qwen2.5-Coder** 子系列（2024-04 至 2024-11）专攻代码生成，在 HumanEval、MBPP 等编程基准上对标专有代码模型。[^6]

阿里的"全家桶"策略在这个阶段已经完全显形：不是追求"最大最强"，而是追求"最全最灵活"。开发者可以根据场景选择规模——手机跑 0.5B，边缘设备跑 7B，企业服务器跑 72B。Meta 的 Llama 覆盖面更窄（8B/70B/405B），Mistral 更少（7B/Mixtral/Large）。这种"全覆盖"策略在全球开源生态中是独一无二的。

### 2.6 Qwen 3：混合推理与开源霸权

**2025-04-29** — 阿里云发布 **Qwen 3**，Apache 2.0 开源。全谱系覆盖 0.6B、1.7B、4B、8B、14B、32B、72B、235B（MoE，激活 22B）。[^7]

Qwen 3 的旗舰版 **235B MoE** 在多项基准上与 GPT-4o 对标，AIME 2025 数学基准上达到约 80%。关键创新是**"思考/非思考"双模式**——受 Claude 3.7 Sonnet 启发，用户可以让模型在简单问题上即时回答，在复杂问题上进入推理模式。这是继 Claude 3.7 Sonnet 之后第二个采用混合推理的主流模型，也是第一个开源的。[^7]

Qwen 3 的发布时机极具戏剧性——仅在 Llama 4 发布 24 天之后。Llama 4 当时正陷入 LMArena 评测争议，社区普遍不满 Meta"提交实验版刷榜"的做法。Qwen 3 以"全面开源、没有花招、覆盖全谱系"的姿态进入市场，社区反应形成鲜明对比——Llama 4 被骂，Qwen 3 被赞。这标志着"开源 LLM 的旗舰"从 Meta 手中交接到了中国团队手中。

Qwen 3 发布后，阿里进一步推出了 **Qwen3-Coder**（代码优化版）和 **Qwen3-Thinker**（推理增强版），延续全谱系策略覆盖更多垂直场景。

## 三、技术路线变迁

### 3.1 架构

Qwen 全系列的核心架构始终是 **Transformer 解码器**。Qwen 1 到 Qwen 2.5 使用标准 dense Transformer；Qwen 2.5 和 Qwen 3 的旗舰版引入 MoE（混合专家），以"激活参数效率"取代"总参数规模"作为新的效率度量。Qwen 3 的 235B MoE 每次推理仅激活约 22B 参数——不到 Llama 3.1 405B 的 6%——但在多项基准上对标。

位置编码经历了从 RoPE（旋转位置编码）到 YaRN 扩展的演进，以支持从 8K 到 128K 的上下文窗口扩展。

### 3.2 训练方法

- Qwen 1/1.5：标准语言模型预训练 + SFT（监督微调）+ RLHF
- Qwen 2/2.5：预训练数据规模大幅扩展，多语言比例优化，长上下文持续预训练
- Qwen 3：预训练 → SFT → RL → 混合推理训练（思考模式与非思考模式联合训练）

与 GPT 系列不同，Qwen 的对齐从未成为叙事焦点——阿里的策略是"做好基础能力，让社区自己去调"。这与阿里云的平台基因一致：不做最惊艳的产品，做最可靠的基础设施。

### 3.3 许可策略

Qwen 的许可演变是整个大模型开源运动的一个重要案例：

| 代际 | 许可 | 说明 |
|------|------|------|
| Qwen 1 | Qwen LICENSE | 阿里自有许可，允许商用但非标准开源 |
| Qwen 1.5 起 | Apache 2.0 | 永久转向标准开源许可 |

从自有许可转向 Apache 2.0 的决定发生在 2024 年 2 月——恰逢 Llama 2 以"伪开源"许可引发争议、Mistral 以 Apache 2.0 赢得社区青睐的时期。阿里选择了最开放的路，这让 Qwen 在之后一年内成为 HuggingFace 上下载量最高的非 Meta 模型家族。

### 3.4 开源策略：双轨

阿里的"双轨"是 Qwen 系列区别于所有竞品的根本特征：

- **闭源轨**：通义千问（Tongyi Qianwen），服务阿里云企业客户和阿里自身产品矩阵（钉钉、淘宝、高德等），通过 API 按量计费。
- **开源轨**：Qwen 系列，Apache 2.0 全系开源，覆盖 HuggingFace、ModelScope、GitHub，面向全球开发者。

闭源产品负责收入，开源系列负责生态。"闭源抢收入，开源抢社区"——这个策略后来被 DeepSeek 推到了极致（完全开源、API 极低价），但阿里是第一个把双轨玩明白的中国大厂。

## 四、生态与影响

### 4.1 直接衍生

Qwen 系列是中文开源 LLM 生态的基础设施。大量模型基于 Qwen 进行微调、蒸馏和二次开发：

- **蒸馏基座**：DeepSeek-R1 发布时，其蒸馏小模型（1.5B 至 70B）直接使用 Qwen 和 Llama 作为基座模型初始化。
- **中文垂直领域微调**：法律、医疗、金融、教育等垂直领域的大量微调模型首选 Qwen 作为基座——因为它的中文能力全面、许可友好、全谱系覆盖。
- **多模态下游**：Qwen-VL 和 Qwen-Audio 成为中文多模态研究和应用的基础模型。

HuggingFace 上累计下载量超过数亿次，OpenCSG、ModelScope（阿里自建的模型社区）上亦有大量基于 Qwen 的衍生模型。

### 4.2 竞品关系

| 竞品 | 与 Qwen 的关键互动 |
|------|-------------------|
| **Llama** | 2023-2024 年 Llama 在英文社区占主导；2024 年中开始 Qwen 在中文 + 全谱系覆盖上超越；2025-04 Qwen 3 在 Llama 4 评测争议中接棒"开源旗手" |
| **Mistral** | 同为 Apache 2.0 开源玩家，但 Mistral 覆盖面窄。Qwen 以全谱系覆盖做差异化 |
| **DeepSeek** | 互补关系而非直接竞争。DeepSeek 专注前沿推理，Qwen 提供基础基座。DeepSeek 的蒸馏模型大量使用 Qwen 作为初始化 |
| **文心一言（百度）** | 闭源 vs 开源双轨的对立面。百度全栈闭源，Qwen 用开源建立社区壁垒 |
| **ChatGLM（智谱）** | GLM 自主架构 vs Qwen 标准 Transformer。智谱走学术开源 + 自主架构路线，Qwen 走工业开源 + 全谱系覆盖路线 |

### 4.3 行业影响

Qwen 系列对 AI 行业的影响是多维度的：

- **开源许可的标杆**：Qwen 1.5 的 Apache 2.0 转向，为后续中国模型的开源许可设立了标准。DeepSeek-R1 的 MIT 开放在某种程度上是在 Apache 2.0 的基础上更进一步。
- **"全家桶"策略的示范**：Qwen 证明了"全覆盖比单点突破更可持续"——不是靠一个最强模型赢得市场，而是靠一个完整系列让每个开发者都找到适合自己的模型。
- **中国开源模型的国际化**：Qwen 是第一个在 HuggingFace 全球生态中获得主流关注的中国模型家族。它的英文能力虽然不如中文，但多语言覆盖和全谱系策略让它在非中文市场上也有使用场景。
- **318 事变的受益者**：2026 年 3 月 Anthropic/OpenAI/Google 集体收紧对中国的 API 限制后，Qwen 系列成为开发者迁移的首选之一——不是因为"国产替代"的情怀，而是因为它的能力确实够用了。

## 评曰

Qwen 系列的迭代史，可以看作中国大模型从"追赶"到"建立标准"的一个缩影。

第一阶段（通义千问 + Qwen 1）是卡位——在 ChatGPT 引爆市场后的四个月内发布产品，在六个月内开源模型。速度本身就是战略。第二阶段（Qwen 1.5→2→2.5）是铺面——用 Apache 2.0 许可、全谱系覆盖、多模态分支，把每一个可能的开发者需求都占住。第三阶段（Qwen 3）是登顶——在 Llama 4 陷入评测争议的同一周，用没有花招的开源和混合推理创新，从 Meta 手中接过了"开源旗手"的位置。

Qwen 最被低估的遗产不是某个 benchmark 分数，而是它证明了**开源可以是一门好生意**。阿里云通过开源 Qwen 吸引了海量开发者，这些开发者最终变成了阿里云的付费客户。这比卖 API token 更高明——不是卖模型，是卖算力。模型是入口，云是终点。"闭源抢收入，开源抢社区"这十个字，比任何一篇论文都更精准地概括了大模型时代的商业逻辑。
