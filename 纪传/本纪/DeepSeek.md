# 《DeepSeek 本纪》

> 一家中国的量化对冲基金，怎么会训练出改变 AI 全球格局的大模型？DeepSeek 的故事不是一家 AI 公司的故事——是一个"根本不需要从 AI 赚钱的公司，用极低成本碾压了一整个行业"的故事。从 V2 到 V3 到 R1 到 V4——每一步都在回答同一个问题：如果钱不是问题，那么什么才是？

---

## 一、概述

深度求索（DeepSeek）成立于 2023 年，是幻方量化旗下的 AI 研究机构。幻方量化是中国最大的量化对冲基金之一，管理的资产规模庞大到足以让 DeepSeek 完全不需要从 API 收入中盈利。

这个出身让 DeepSeek 拥有了任何竞争对手都无法复制的结构优势。OpenAI、Anthropic、Google——它们训练模型的成本必须通过订阅或 API 费用回收。DeepSeek 不需要。这使得它可以做出让整个行业无法理解的事情：以 GPT-4 级别模型 1% 的价格出售 API、以 ~$5.6M 的成本训练出 GPT-4o 级别的模型、以 MIT 许可完全开源一个推理模型——包括思维链。

这些决策在商业逻辑的框架下是疯狂的。但在"不需要从 AI 赚钱"的前提下——它们只是理性的。

---

## 二、起源：幻方、量化、以及"不在乎钱"的入场

### 2.1 背后的量化基因

幻方量化由梁文锋创立，是中国最具技术实力的量化对冲基金之一。在进入大语言模型之前，幻方已经积累了以下关键优势：

- **GPU 集群**：量化对 GPU 的需求极高——高频交易中的深度学习模型需要大规模并行计算。当其他初创公司还在为 A100 排队时，幻方已经有了成熟的 GPU 基础设施。
- **没有融资压力**：作为一个盈利的量化基金，幻方不需要对外融资来训练模型。这意味着 DeepSeek 不需要向任何风险投资人解释为什么它在亏钱卖 API。
- **工程文化**：量化交易和 LLM 训练有一个共通的工程问题——"如何用最少的计算资源获得最大的效果"。这个思维方式贯穿了 DeepSeek 的所有技术决策。

### 2.2 DeepSeek-LLM（2023-11）——低调开场

2023 年 11 月，DeepSeek 发布了第一个语言模型 DeepSeek-LLM（67B）。几乎没有人注意到。

在 2023 年 11 月的 AI 行业，所有人都在盯着 OpenAI 的 Sam Altman 罢免与复职。一个 67B 的参数模型——即使性能不差——没有任何引起关注的资本。但 DeepSeek 选择了最聪明的时间窗口：在别人吵架的时候，安静地做技术积累。

67B 的 DeepSeek-LLM 在多项基准上接近 Llama 2 70B——这不足以改变行业，但足以让 DeepSeek 的团队证明自己可以训练一个靠谱的基座模型。真正的锋芒将在下一次发布中显现。

---

## 三、关键事件

### 3.1 DeepSeek-V2（2024-05）：MLA 与价格屠夫

2024 年 5 月，DeepSeek 发布了 V2。这是 DeepSeek 第一个真正改变行业的产品——不是因为它的 benchmark 分数（虽然接近 GPT-4），而是因为它做到了两件竞争令人无法理解的事：

1. API 价格是 GPT-4 Turbo 的约 **1%**
2. 它提出了 **MLA（Multi-head Latent Attention）**——一种将推理成本压缩到十分之一的注意力机制

1% 定价在行业引起了一场价格战。阿里、百度、智谱、字节在几周内纷纷大幅降价——中国的 AI API 价格在一个月内跌至年初的十分之一以下。

但 DeepSeek 不是在做慈善或烧钱抢市场。MLA 让它的推理成本降到了 GPT-4 的十分之一，所以它可以把售价压到 GPT-4 的 1%——同时还能盈利。"成本优势"和"价格优势"在这里是同一件事。这不是价格战——这是一个结构性优势的自然结果。

更让人不安的是：DeepSeek 背后的幻方量化不需要从 API 赚钱。即使 API 完全免费，DeepSeek 也可以作为一个研究机构继续运转——因为它的资金来自量化交易利润。这意味着 DeepSeek 可以永远维持 1% 的定价，直到所有以 API 为核心的竞争对手被挤出市场。

（详见《编年·2024年5月》）

### 3.2 DeepSeek-V3（2024-12）：$5.6M 的 GPT-4o

2024 年 12 月，DeepSeek 发布了 V3：671B MoE 参数（激活 37B），性能对标 GPT-4o 和 Claude 3.5 Sonnet。最重要的数字不是参数规模——是训练成本：仅约 **557 万美元**（H800 GPU）。

作为对比，GPT-4 的训练成本估计在 6,300 万到 1 亿美元之间。V3 的训练成本约是 GPT-4 的 **6%**。

V3 能够在如此低的成本下达到前沿性能，依赖三个技术支柱：

- **MoE 架构**：671B 总参数，但每次只激活 37B——训练和推理成本大幅降低
- **MLA（从 V2 继承）**：KV Cache 压缩 90%，推理成本大幅降低
- **MTP（Multi-Token Prediction）**：多 token 预测训练目标，提升样本效率

V3 在 2024 年 12 月发布时没有像 R1 那样引起全球轰动。但 V3 才是真正的"不可解释"的成就——它证明了前沿模型不需要前沿预算是可重复的。V2 的极低推理成本可能是侥幸，V3 的训练极低成本证明这不是偶然。DeepSeek 有了一套从训练到推理的全链路成本控制方法论。

V3 采用 MIT 许可开源。至此，DeepSeek 已经完全建立了一套连贯的技术 + 商业策略：极低成本训练 → 极低成本推理 → 开源 → 维持价格优势 → 扩大市场份额。这每一步都不需要"靠 AI 赚钱"这个前提。

### 3.3 DeepSeek-R1（2025-01）：MIT 开源 + 英伟达蒸发 5890 亿

2025 年 1 月 20 日，DeepSeek 发布 R1——一个基于 V3 微调的推理模型，完全采用强化学习训练。核心创新是"冷启动 RL"——先让模型通过纯强化学习学会推理，而不是像 OpenAI 那样先让人类标注员示范推理步骤。

R1 最大的冲击力来自三个行动的结合：

- **MIT 开源**：权重、代码、方法——全部开源。商业友好许可。
- **性能对标 o1**：在数学（AIME 79.8% vs o1 79.2%）、编程（Codeforces 96.3%ile vs o1 96.6%ile）基准上达到 o1 水平。
- **公开思维链**：让用户完全看到 R1 的推理过程——而 o1 刻意隐藏。

结果：英伟达股价一天暴跌 17%，市值蒸发 5890 亿美元。这不是因为 R1 真的有 5890 亿美元的价值——而是因为 R1 粉碎了一个核心假设：训练前沿模型需要最昂贵的 GPU。如果 DeepSeek 可以用 H800（被美国出口管制的 GPU）训练出对标 o1 的模型——那么市场对 H100/GB200 的需求预期就被严重高估了。

R1 的 MIT 开源是另一个冲击。当 o1 还在每月收 $200 订阅费时，DeepSeek 把一个同级别的推理模型完全开源。这个选择的逻辑延续了 V2 和 V3 的一致性——"如果不需要从模型赚钱，那为什么不开源？"

（详见《编年·2025年1月》）

### 3.4 DeepSeek V4（2026-04）：价格差拉到 370 倍

2026 年 4 月 24 日，DeepSeek 发布 V4——距 R1 时隔 15 个月的重磅更新。V4 的 API 价格仅为 GPT-5.5 的 1/370。这一价格差——从 V2 时代的 100 倍扩大到 V4 时代的 370 倍——暗示 DeepSeek 的成本优势不仅没有被追赶者们缩小，反而在拉大。

V4 的发布标志着 DeepSeek 从"追赶者"到"替代者"的转变。在 318 事变（2026-03）之后，DeepSeek 和 GLM-5.1 一起，成为中国 AI 应用"去美国化"的核心替代方案。

（详见《编年·2026年3月》）

## 四、兴衰分析

### DeepSeek 的核心悖论

DeepSeek 的成功建立在一个悖论之上：它的最大优势——"不需要从 AI 赚钱"——也是它最不可复制的特质。没有任何竞争对手可以模仿这一策略，因为没有任何竞争对手拥有一家盈利的量化对冲基金作为资金源。

这个悖论让 DeepSeek 在竞争中处于一个独特位置：它是一个**不需要市场验证的顶级 AI 研究机构**。它的存在本身粉碎了 AI 行业的一个默认假设——"训练前沿模型必须需要一个商业模式来支撑"——从而提出了一个令人不安的问题：如果 AI 行业最有竞争力的玩家不参与同一个商业游戏，那么"市场竞争"这个概念在 AI 领域还有多大意义？

### DeepSeek 的技术哲学

从 V2 到 V4，DeepSeek 的技术路线有一条清晰的主线：**效率优先于规模**。

这与 OpenAI 从 GPT-1 到 GPT-4 的路线形成了鲜明对比。OpenAI 的哲学是"用更多来换更强"——更多参数、更多 GPU、更多钱。DeepSeek 的哲学是"更聪明的工程省出更多的能力"——MLA 省出推理成本、MoE 省出训练成本、Pure RL 省出对齐成本。

这条效率路线的哲学根源可以追溯到它的量化基因。在量化交易中，GPU 是成本——不是资产。一个交易策略的效率提升直接转化为利润。DeepSeek 把同样的思维带进了大模型：KV Cache 压缩 90% 不是一篇论文的优雅——是可以变现的利润。当 OpenAI 和 Google 在比谁花钱更多时，DeepSeek 在比谁省得更多。而在一个经济学基本法则——"成本优势是终极优势"——的支配下，后者才是更可持续的竞争策略。

### 地缘政治维度

DeepSeek 的崛起还有一个必须提及的背景：美国对中国的 GPU 出口管制。DeepSeek 训练 V3 和 R1 使用的 H800 GPU 是出口管制的产品——它们的性能被特意限制以阻止前沿 AI 训练。

但 DeepSeek 的效率路线意外地证明了一件事：管制的效果可能适得其反。当美国的 AI 公司依赖最强的 GPU 来实现竞争力时，中国的公司被迫在更弱的 GPU 上做更好的工程。结果不是管制让中国落后——是管制让中国学会了在资源约束下做到极致效率。而效率一旦被"开化"——成本优势就变成了一个永久的护城河。

R1 发布的当天，英伟达蒸发 5890 亿美元。这个数字不仅是对市场预期的修正——更是对美国 AI 管制逻辑的一次市场投票。市场在说：限制硬件不能阻止模型进步——它只会催生更有效的软件。

## 评曰

DeepSeek 是 AI 史上最不可复制的玩家。

训练 V2 并把它定价在 GPT-4 的 1%——这需要不靠 AI 赚钱。训练 V3 只用 557 万美元——这需要量化交易级别的 GPU 优化经验。发布 R1 并完全 MIT 开源——这需要一个不在乎商业回报的决策者。这三样东西集中在同一家公司身上，是偶然的、不可重复的。

但 DeepSeek 的遗产不是"DeepSeek 很厉害"——是"AI 的成本可以低到之前无法想象的程度"。V2 的 1% 定价撕开了第一道裂口，V3 的 $5.6M 训练成本撕开了第二道裂口，R1 的 MIT 开源撕开了第三道裂口。这三道裂口连起来，形成了一个震撼的信息：**前沿 AI 能力的边际生产成本可以趋近于零。**

如果这是真的——如果成本可以持续下降，同时能力持续提升——那么 AI 行业的整个经济模型都需要重写。OpenAI 每月收 $200 订阅的商业模式，在 DeepSeek 免费开源的逻辑面前，变得脆弱不堪。

但 DeepSeek 也面临自己的挑战。"不靠 AI 赚钱"是它最大的竞争优势——但这也是它的天然瓶颈。当 AI 技术从模型能力扩展到产品生态（Agent、工具链、企业集成、硬件设备）时，DeepSeek 的"只做模型"策略会越来越受限。它可能永远是最好的模型工厂——但永远不是最好的产品公司。

这恰恰是 DeepSeek 的宿命：它的成功束缚了它的自我定义。它无法成为 OpenAI——因为成为 OpenAI 意味着"开始靠 AI 赚钱"，而这会摧毁它的一切成本优势。它只能继续做它已经做到最好的一件事：用最少的资源，训练最好的模型，然后开源。
