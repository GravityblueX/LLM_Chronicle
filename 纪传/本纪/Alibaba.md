# 《Alibaba 本纪》

> 阿里在大模型时代最值得记录的，不是“有没有做出中国最强模型”，而是它把模型、云和开放生态绑成了一套循环。从 Qwen 的多尺寸开放，到 Qwen3.8-Max 首次把 Max 级旗舰权重交给社区，再到 QwenWork 与阿里云 Agent 平台，阿里的路线逐渐清楚：**开放模型扩大可用生态，云基础设施承接真正的大规模运行。**

---

## 一、概述

阿里巴巴进入大模型竞争时，天然拥有与纯模型创业公司不同的条件：

- 阿里云提供训练、推理与企业交付基础设施；
- 淘宝、钉钉、高德等业务提供真实产品入口；
- Qwen 可以开放权重扩大开发者采用；
- Model Studio / 百炼等云平台则把模型转化为持续调用和企业服务。

因此阿里的大模型战略不能只用“开源”概括。更准确的是：

> **开放权重、商业 API、企业平台和 Agent 产品共同组成一个循环。**

到 2026 年，Qwen3.8-Max 与 QwenWork 把这套路线推进到了新的阶段：连过去长期保留在云端的 Max 级旗舰也开始开放，而阿里云则承担越来越重的运行和分发角色。

---

## 二、前史：为什么阿里天然会把模型做成云基础设施

阿里云成立于 2009 年。长期建设云计算基础设施，使阿里在大模型时代拥有一个直接商业问题：

> **怎样让企业愿意把更多 AI 工作负载放进云？**

这和“怎样做一个最受欢迎的聊天机器人”并不是同一个问题。

达摩院、通义实验室等研究组织为阿里积累了 NLP、多模态和大规模训练经验，但真正决定 Qwen 产业形态的是云平台：模型不仅要强，还需要覆盖不同参数规模、不同延迟要求和不同部署成本。

---

## 三、通义千问与 Qwen：从产品入口到开放模型族

### 3.1 通义千问：先作为集团能力进入产品

**2023-04-11**，阿里正式发布通义千问，并宣布未来将把大模型能力接入多项业务。[^1]

与 ChatGPT 那种单一明星产品不同，通义千问很早就以“集团基础能力”的形式存在：钉钉、云服务、办公、电商等都可以成为入口。

### 3.2 Qwen 开放：把模型变成开发者基座

2023 年起，Qwen 系列逐渐开放不同规模权重。Qwen2 / Qwen2.5 / Qwen3 形成一个越来越完整的模型谱系：通用、代码、数学、多模态以及 dense / MoE 多尺寸并行。

这里最值得注意的不是“阿里一直最开放”。事实上不同代际、不同尺寸的许可证与开放程度并不完全相同。更准确的历史是：

> **Qwen 的开放边界持续扩大。**

中小模型先成为社区基座，旗舰能力长期更多保留在云端；直到 2026 年，这条边界才明显再次移动。

---

## 四、Qwen3：开放谱系开始进入 Agent 时代

**2025-04**，Qwen3 发布，dense 与 MoE 模型并行，并提供 Thinking / Non-Thinking 模式。[^2]

这一代的历史意义之一，是“推理”不再必须绑定一个完全独立的模型型号。同一模型可以在不同任务上使用不同思考预算。

随后 Qwen 系列继续向代码、工具调用、视觉和长程任务扩展。

阿里在这个阶段也越来越明确地把模型放进云 Agent 平台，而不是只把 API 当作文字生成接口。

---

## 五、2026：从 Qwen3.x 到 Qwen3.8-Max

### 5.1 开放边界继续向上移动

2026 年 Qwen 3.x 系列继续快速迭代。到 **2026-08-03**，阿里发布 **Qwen3.8-Max**：

- 2.4T 总参数；
- 1M token 上下文；
- 原生视觉能力；
- 面向 coding、real-life work、research 与 long-horizon tasks。[^3]

更重要的是，阿里宣布这一代的权重将公开。

这意味着 Qwen 过去长期存在的一条边界发生变化：

> **Max 不再只等于云端旗舰。**

### 5.2 2.4T 开放权重：开放不等于个人可运行

随后 Qwen3.8-2.4T-A95B 权重发布。它采用稀疏 MoE，总参数约 2.4T、每 token 激活约 95B，并支持百万上下文。[^4]

这件事产生了一个新的开放悖论：

- 权重可以下载；
- 可以检查、微调和重新托管；
- 但绝大多数个人和小团队无法直接高效运行这种规模。

于是“模型有没有开放”与“用户有没有运行权”开始分离。

这恰好反过来增强云平台的重要性。开放旗舰并不会消灭云，反而可能让更多云服务商围绕同一权重竞争托管、量化和推理效率。

---

## 六、QwenWork：阿里把模型进一步推入工作流

**2026-08-03**，与 Qwen3.8-Max 同期，阿里推出 **QwenWork**，定位为 all-in-one workplace AI agent platform。[^5]

这个节点很重要，因为它让阿里的产品层次更完整：

| 层 | 阿里的形态 |
|---|---|
| 权重 | Qwen 开放模型谱系 |
| API | Alibaba Cloud Model Studio / 百炼 |
| 企业基础设施 | 云推理、私有数据、部署与治理 |
| Agent 产品 | QwenWork 等工作平台 |

因此“开源引流、云服务变现”虽然仍然成立，却已经太简单。

新的循环更像：

**开放权重 → 社区和企业采用 → 云端高效运行 → Agent 产品产生真实工作流 → 反馈继续推动模型与基础设施。**

---

## 七、2026 年的阿里 AI：全栈不只是口号

2026 年 8 月，阿里在财务与公司更新中继续强调 full-stack AI 与云增长。[^6]

“全栈”在这里至少包含：

- 模型训练；
- 开放权重；
- API；
- 云算力；
- 企业数据连接；
- Agent runtime；
- 消费和工作产品。

这与 Meta 的开放路线不同，也与 DeepSeek 的效率路线不同。阿里的核心资源是：**既能发布模型，也拥有大规模承载模型工作负载的商业云。**

---

## 八、阿里路线的三个阶段

### 阶段一：集团能力（2023）

通义千问首先服务阿里现有业务，大模型是集团产品的共同引擎。

### 阶段二：开放模型族（2023—2025）

Qwen 通过多尺寸、多任务、逐渐放宽的开放策略建立开发者生态。

### 阶段三：开放旗舰 + Agent 云（2026）

Max 级旗舰开始开放权重，同时 QwenWork 和云 Agent 平台承接更长程、更复杂的真实任务。

这里最重要的变化是：

> **开放与商业化不再是两条平行路线，而开始互相制造需求。**

---

## 评曰

阿里的大模型史最容易被写成“务实”。这个词没错，却解释得太少。

真正值得记住的是它逐渐形成了一种平台式 AI 经济：模型权重可以越来越开放，但运行模型、连接企业数据、管理权限、提供 SLA、调度算力、组织 Agent 工作流，仍然需要大量基础设施。

Qwen3.8-Max 因此不是“阿里终于彻底开源”的终点，而是一个更复杂阶段的开始。

2.4T 权重公开之后，真正稀缺的东西已经不只是权重：

- 谁能高效运行；
- 谁能把它接入企业系统；
- 谁能提供长期稳定服务；
- 谁能让 Agent 真正完成工作。

所以阿里的路线最终不是简单的“模型免费，云赚钱”。它更像在证明：

**当权重逐渐商品化以后，云和 Agent runtime 会成为新的控制面。**

这也是阿里在 2026 年最有历史解释力的位置。
