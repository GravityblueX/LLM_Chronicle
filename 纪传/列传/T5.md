# 《T5 列传》

> T5（Text-to-Text Transfer Transformer）在 2019 年以一篇 67 页论文登场，做了一件当时看来略显枯燥、现在看来影响深远的事：把所有 NLP 任务都化成"输入一段文本，输出一段文本"。它不是某个任务的最优解，而是把 NLP 的多样性统一成了一组可比较的实验，回答了一个关键问题——预训练目标的差异到底有多重要？

---

## 一、技术背景

到 2019 年下半年，NLP 领域已经被预训练+微调改写过了。ELMo、BERT、GPT-2、XLNet、RoBERTa 各占一块山头，每个模型有自己的预训练目标、自己的最佳适配任务、自己的训练配方。

BERT 用 masked language modeling（MLM）和 next sentence prediction（NSP），擅长理解类任务。GPT-2 用自回归语言建模，专注生成。XLNet 用排列语言建模，在多个基准上超过 BERT。RoBERTa 证明了 BERT 的 NSP 目标并非必要，更多数据和更大 batch 有时比改模型更重要。

这背后的错位是：大家都在做预训练+微调，但没有人系统回答——**不同的预训练目标、架构选择、数据量和模型大小，到底各自贡献了多少？**

Raffel 等人在 Google 提出 T5，就是要用一只统一的框架来系统回答这个问题。论文全称是《Exploring the Limits of Transfer Learning with a Unified Text-to-Text Transformer》，"Exploring the Limits"——不是"提出一个新 SOTA 模型"，而是"把这个范式的边界摸清楚"。[^1]

---

## 二、核心创新

### 2.1 Text-to-Text：一切 NLP 任务都是"给你一段文字，还你一段文字"

T5 的最大设计决策也是它的命名来源：把**所有** NLP 任务统一成 text-to-text 格式。

- 机器翻译："translate English to German: That is good." → "Das ist gut."
- 文本摘要："summarize: [文档]" → [摘要]
- 情感分类："sst2 sentence: This film is terrible." → "negative"
- 问答："question: What is the capital of France? context: France is a country in Europe. Its capital is Paris." → "Paris"
- 自然语言推理："mnli premise: I like apples. hypothesis: I like fruit." → "entailment"

这个统一的技巧是给输入加一个**任务前缀（task prefix）**——一个短的文本描述，告诉模型现在在做什么任务。任务前缀就像给模型发指令："现在你要做翻译""现在你要做情感分析"。2020—2022 年 prompt engineering 的流行，可以说是这种任务前缀思路的自然延续。

text-to-text 的好处不是"模型更好"，而是**实验框架统一**。所有任务的输入和输出都是同一格式，所有任务的损失函数都是同一个（teacher forcing 交叉熵），所有任务的超参数都用同一套调优脚本。这让大规模消融实验成为可能。

### 2.2 C4：一个干净到能公开发表的数据集

T5 的另一个重要贡献是 C4（Colossal Clean Crawled Corpus）。Common Crawl 是互联网上最大的公开文本集合之一，但也非常脏——HTML 残留、重复、代码、菜单、占位文本混在一起。T5 团队写了一套启发式过滤流水线，从 Common Crawl 中提取出约 750GB 干净英文文本。

过滤规则包括：只保留以标点结尾的行、删除含"lorem ipsum"的页面、删除含污言秽语的页面、用最小哈希做近似去重等。这些规则后来被很多工作复用或参考。

发布 C4 这件事本身很重要。在此之前，BERT 用 BooksCorpus + 英文维基百科，GPT-2 用 WebText（从 Reddit 链接爬取，未公开），RoBERTa 用的数据也没有完全公开。C4 是第一个大规模、干净、可复现的英文预训练数据集——后来的 mC4 又把范围扩展到 101 种语言。

### 2.3 系统性消融实验：论文最值钱的部分

T5 论文的核心正文是一系列消融实验。团队用 text-to-text 框架和 C4 数据，跑了几百次实验来比较：

**模型架构**：标准的 encoder-decoder Transformer；纯 decoder（语言模型）；纯 encoder + 前缀（prefix LM）。结论：encoder-decoder 在大多数任务上略优于其他两种架构，但差距不大。

**预训练目标**：MLM（类似 BERT）、去噪自编码（denoising）、LM（自回归）、span corruption（随机遮盖连续片段，用哨兵 token 标记缺失位置）等。结论：span corruption（论文称之为"denoising"）优于单纯的 MLM 和 LM，尤其适合生成任务。论文推荐的"最佳配置"是随机遮盖 15% 的 token，每个 span 长度服从均值 3 的几何分布。

**无监督数据量**：预训练数据是不是越多越好？在固定算力下是，但增长渐缓。

**模型大小**：比较了 Small（60M）、Base（220M）、Large（770M）、3B、11B 等版本。结论是在同一预训练步数和数据集下，更大的模型持续更好——比预训练目标的差异更明显。

**训练策略**：多任务预训练 vs 先预训练再微调 vs 多任务微调。结论：对于未在训练中见过的任务，先无监督预训练、再针对性微调是最优方案。

这些消融实验的结论在今天看来似乎"本来就这样"，但 2019 年它们是第一次被系统回答。T5 的历史价值不在于训练出了最聪明的模型，而在于回答了一组"到底什么在起作用"的问题。

### 2.4 关键数据

| T5 版本 | 参数量 | 架构 | 与同期对比 |
|------|------|------|------|
| T5-Small | 60M | Encoder-Decoder | 比 BERT-base (110M) 小 |
| T5-Base | 220M | Encoder-Decoder | 与 BERT-large (340M) 同级 |
| T5-Large | 770M | Encoder-Decoder | 超过大多数同期模型 |
| T5-3B | 3B | Encoder-Decoder | 2019 年公开模型前列 |
| T5-11B | 11B | Encoder-Decoder | 2019 年最大公开 Transformer |

T5-11B 在 SuperGLUE 上达到了当时的最高成绩（89.3），超过 BERT、RoBERTa 和所有同期非 T5 模型。但论文的结论很清楚：**做到这一步的主要因素是"足够大的模型 + 足够多的高质量数据 + 统一的 loss"，而不是某一个精巧的架构设计。**

## 三、影响与后继

### 3.1 "一切都是 text-to-text"的思维渗透

T5 的思想影响可以分两层。

第一层是**工程习惯**。把模型输入统一成 `[task prefix]: [input]` 这种模式，后来被 T0、FLAN、InstructGPT 和所有 instruction-tuned 模型继承。prefix tuning 和 prompt tuning 的语言来自 T5 的任务前缀；"把什么都写成文本再让模型处理"的思路，从 NLP 扩展到多模态（图文 token 拼接）、到代码（代码理解与生成共用同一格式）、到 agent（工具调用的输入输出都是文本）。

第二层是**消融实验文化**。T5 证明了一件事：与其在模型小修小改中纠结，不如花算力跑系统性的对比实验，把不确定变成确定。后来的 scaling laws、Chinchilla 最优配置研究、Llama 系列的数据消融，都可以看作 T5 实验精神的延续。

### 3.2 T5 变体与后续

T5 本身并没有像 GPT 或 Llama 那样形成持续的版本迭代，但它的变体和后人非常多：

- **mT5**（2020）：把 T5 的 text-to-text 框架和 C4 扩展到 101 种语言，用 mC4 数据集训练。[^2]
- **T0**（2021）：在 T5 的基础上做多任务 instruction tuning，用 prompt 模板让模型在未见过的任务上做 zero-shot 推理。[^3]
- **FLAN-T5**（2022）：Google 把 FLAN（instruction tuning）用在 T5 上，大幅提升了 zero-shot 和 few-shot 能力。[^4]
- **UL2**（2022）：Mixture-of-Denoisers，把 T5 的 span corruption 和 GPT 的自回归生成以及其他去噪目标混合在一起训练。[^5]
- **PaLM、Gemini 等**虽然规模远超 T5，但 encoder-decoder + text-to-text 的思路在 Google 内部的产品化（如翻译 API）中一直沿用。

T5 的 encoder-decoder 架构没有像 decoder-only 那样统治一切，但在需要强编码能力的场景——机器翻译、文本摘要、文档理解——encoder-decoder 仍然是自然选择。T5 作为这个家族中最系统的开源代表，它的设计决策至今还在被参考。

### 3.3 被降格与吸收

到 2023 年以后，decoder-only 的自回归语言模型（GPT 路线）成为公众和产业的主线，encoder-decoder 退居更专业的场景。T5 不再出现在前沿模型的竞争名单上。

但这不意味着 T5 失败了。它的研究方法——"把困难的问题拆成一组可控实验，用大规模计算去回答"——被整个行业消化吸收。它的数据集 C4 成为 NLP 的公共基础设施。它的 60M 到 11B 的多个尺寸，长期作为研究者测试新方法时使用的标准基座。

一种方法被"降格"为研究工具和基础设施，对一篇论文来说是极高的认可。不是每种技术都要活在聚光灯下才叫有用~

## 评曰

T5 的历史位置，不在它训出了多么惊艳的模型，而在它给 NLP 的预训练时代做了一次严谨的"体检"。

在 BERT 和 GPT-2 各说各话的 2019 年，T5 用统一的 text-to-text 格式，把模型架构、预训练目标、数据量和规模这四个变量拆开，逐一回答了"什么真正在起作用"。结论是：架构和预训练目标有影响，但**规模和数据质量**的影响更大——这个判断在 GPT-3 和后来的 scaling 路径中被反复证实。

T5 的 text-to-text 框架也提前布了一个局：当 instruction tuning 和 prompt 成为 2022 年后的主流，大家回头看才发现，T5 的任务前缀其实就是最早的 instruction prompt。它没有发明 prompt engineering，但它的设计让"告诉模型你希望它做什么"这件事变得自然而然。

历史给 T5 的位置，不是王座，而是那个拿着尺子把所有变量量了一遍的实验者——他的结论让别人去争霸，但他画的地图，后来的人都在用~
