# 《DeepSeek-R1 列传》

> DeepSeek-R1（2025-01）是大模型史上一个范式事件。它不仅仅是一个推理模型——它是纯强化学习催生涌现行为的首次公开演示，是 MIT 开源对闭源推理模型的正面回答，也是 6000 亿美元市值蒸发背后的那颗子弹。R1 证明了两件事：推理能力不需要闭源围墙，最先进的 AI 不需要最多的 GPU。在 o1 开辟的赛道上，R1 不是追赶者——它重新定义了这条赛道的规则。

---

## 一、技术背景

### 1.1 推理模型的诞生：o1 的遗产

2024 年 9 月 12 日，OpenAI 发布 o1，开创了"推理模型"这个品类。[^1] o1 的核心思路是：让模型在回答之前先在内部进行链式思考（hidden chain-of-thought），用额外的推理时间来规划、验证、修正自己的思路。AIME 数学竞赛从 GPT-4o 的 12% 跳到 74%——这不是渐进式提升，是能力从一个领域突然迁移到了另一个领域（详见《o1 列传》）。

但 o1 有一个根本性的矛盾：**它用隐藏思维链和高定价把自己做成了奢侈品**。o1-preview 的输出定价 $60/百万 token，是 GPT-4o 的 4 倍。[^1] 思维链被刻意隐藏，任何试图通过越狱查看推理过程的行为都会导致账号被封。OpenAI 的逻辑是：思维链是核心 IP，推理能力是稀缺资源，稀缺资源就该高价出售。

四个月后，DeepSeek-R1 用一个 MIT 协议把这个逻辑炸开了。

### 1.2 Test-Time Compute：新的 Scaling 维度

o1 的成功验证了一个新的 scaling 维度：**推理时间的计算量**（test-time compute）。2024 年 8 月，Charlie Snell 等人发表论文，系统性地论证了在推理阶段投入更多计算，可以在不增大模型的前提下显著提升有效表现。[^2]

o1 用产品验证了这个理论。但 o1 的训练方法——SFT + RLHF，先用人工标注的推理范例做监督微调，再用强化学习优化——仍然依赖昂贵的人类标注数据。行业默认的假设是：推理能力需要先被人类"教会"，然后才能被 RL "强化"。

DeepSeek-R1 打破了这个假设。

## 二、核心事件

### 2.1 发布（2025-01-20）

**2025 年 1 月 20 日**，DeepSeek 正式发布推理模型 R1，同步开源模型权重，采用 MIT 许可证。[^3]

R1 基于 DeepSeek-V3-Base（MoE 架构，总参数 671B / 37B 激活），专攻数学、代码与逻辑推理任务。此前，DeepSeek 已于 2024 年 11 月 20 日发布预览版 R1-Lite，初步展示了强化学习在推理任务上的潜力。[^3]

R1 的发布时间选在特朗普就职典礼当天——这个细节被多家媒体注意到，但在技术讨论中被迅速淹没。真正被记住的是 R1 的三个标签：**MIT 开源、性能对标 o1、API 价格仅为 o1 的 3%**。

### 2.2 R1-Zero：纯 RL 炼出推理

R1 的核心技术路径分两步。第一步是 R1-Zero——一个没有走完但最具历史意义的实验。

**DeepSeek-R1-Zero** 完全跳过监督微调（SFT），仅使用 GRPO（Group Relative Policy Optimization）强化学习进行训练。所有奖励基于规则——准确率奖励（数学答案是否正确、代码是否通过测试）和格式奖励（是否将思维链置于 `<think>...</think>` 标签内）。不使用基于模型的奖励函数。[^3]

这个实验的前提假设很激进：**推理能力不需要先被人类教，可以直接被 RL "逼"出来**。传统的训练范式是 SFT → RLHF——先喂人工标注的高质量推理范例，让模型"学会"什么是好的推理，再用 RL 微调。R1-Zero 把第一步完全砍掉了。

结果出乎意料。纯 RL 训练催生了模型的**涌现行为**：在训练过程中，模型自发学会了"顿悟时刻"（Aha Moment）——在某道题上，它突然停下来，用人类可读的语言重新评估自己的推理过程，并主动分配更多思考时间。[^3] DeepSeek 团队在论文中写道："这不是被编程进去的，而是模型与强化学习环境交互中自行发展的。"

此前我们见过的涌现多是 benchmark 数字的跳变——参数量越过某个阈值，模型突然"会"做某类题。R1-Zero 的涌现不同：涌现出来的是一种**行为**——停下来、反思、重新思考。这件事的哲学分量在于：它暗示推理不一定是被教会的，也可以是被"逼"出来的。

但 R1-Zero 也有明显缺陷：输出可读性差（推理过程晦涩、语言混杂）、初始 RL 训练不稳定。它证明了纯 RL 路线的可行性，但还不足以直接作为产品发布。

### 2.3 R1：冷启动 + RL 的折中

第二步是 R1 本身——在 R1-Zero 的基础上引入冷启动 SFT 数据（数千条高质量思维链范例），再进行 RL 训练。[^3]

这个折中解决了 R1-Zero 的两个问题：输出可读性差和初始 RL 训练不稳定。最终模型在保持推理能力的同时，输出更加清晰、对用户友好。

值得注意的是，R1 的 SFT 数据量很小——数千条，而非数万或数十万。这意味着 RL 仍然是推理能力的主要来源，SFT 只是"润滑剂"——让 RL 炼出的能力更容易被人类理解和使用。这与 o1 的路线形成了微妙对比：o1 的推理能力主要来自 SFT + RLHF 的组合，R1 的推理能力主要来自 RL，SFT 只是锦上添花。

### 2.4 GRPO：更高效的 RL 算法

R1 使用的 GRPO（Group Relative Policy Optimization）是 DeepSeek 自研的 RL 算法。[^3] 传统 RLHF 使用 PPO（Proximal Policy Optimization），需要一个单独的奖励模型来评估输出质量。GRPO 的创新在于：**不需要独立的奖励模型**，而是通过组内相对比较来评估输出——对同一问题生成多个候选答案，根据规则奖励（答案对不对、格式对不对）进行组内排名，用排名信号直接优化策略。

这个设计的效率优势显著。PPO 需要维护三个模型（策略模型、参考模型、奖励模型），显存和算力开销大。GRPO 只需要两个（策略模型、参考模型），省掉了奖励模型的开销。在 671B 参数的规模上，这个节省意味着 RL 训练可以在更少的 GPU 上完成。

### 2.5 性能对标 o1

R1 在多项基准上全面对标 OpenAI o1：[^3]

| 基准 | DeepSeek-R1 | R1-Zero | OpenAI o1-1217 |
|------|:--:|:--:|:--:|
| AIME 2024 | 79.8% | 71.0% | 79.2% |
| MATH-500 | 97.3% | — | 96.4% |
| Codeforces | 96.3%ile | — | 96.6%ile |
| SWE-bench Verified | 49.2% | — | 48.9% |

这些数字的含义不是"R1 比 o1 好"——两者在同一量级，互有胜负。真正的含义是：**R1 用 MIT 开源 + 3% 的价格，达到了 o1 用闭源 + $60/百万 token 达到的水平**。

### 2.6 MIT 开源：炸开围墙

R1 以 MIT 许可完全开源——权重、代码、方法，包括思维链输出。[^3] 对比 o1：[^1]

| 特征 | DeepSeek-R1 | OpenAI o1 |
|------|-------------|-----------|
| 许可证 | MIT（完全开放） | 专有 |
| 思维链 | 完全公开 | 刻意隐藏 |
| 模型权重 | 可下载 | 不可下载 |
| API 价格（输出） | 16 元/百万 token | $60/百万 token |
| 本地部署 | 可（需多卡） | 不可 |

o1 刻意隐藏思维链，且收取高额订阅费。R1 把同等能力的模型完全免费、完全透明地交给了全世界。这个对比不是技术对比——是哲学对比。推理模型应该透明还是不透明？答案在 R1 发布的那一刻变得不再是修辞问题。

### 2.7 蒸馏生态

R1 发布时同步推出了 6 个蒸馏小模型（1.5B 至 70B 参数，基于 Qwen 和 Llama 初始化）。[^3] 其中 32B 和 70B 模型在多项基准上超越了 OpenAI o1-mini。

这催生了一个强大的推理模型蒸馏生态：开发者可以下载 R1 蒸馏模型，在自己的硬件上跑推理——不再需要 API 费用，不再受 rate limit 限制。推理能力从"只有大公司和付费用户才能用"变成了"任何有 GPU 的人都可以用"。

蒸馏生态的影响比表面看起来深远。它证明了推理能力可以被"压缩"——一个 70B 的蒸馏模型可以继承 671B 模型的大部分推理能力。这为推理模型的边缘部署（手机、笔记本、嵌入式设备）打开了大门。

### 2.8 冲击波

**2025 年 1 月 27 日**，DeepSeek 超越 ChatGPT 登顶苹果 App Store 美国区免费应用榜首。[^4]

同日，英伟达股价暴跌近 17%，单日市值蒸发约 5890 亿美元——美国股市历史最大单日跌幅。[^5] 市场恐惧的不是 R1 本身，而是它揭示的事实：最先进的 AI 不一定需要最多的 GPU。算力不是护城河。

Meta 在内部组建了四个专门研究 DeepSeek 的小组——分别研究成本降低、训练数据、模型架构重构。[^6] Mark Zuckerberg 宣布 2025 年 AI 投入超 600 亿美元——这个回应本身就说明了 R1 的冲击有多大。OpenAI 声称有证据表明 DeepSeek 使用其专有模型输出训练 R1（模型蒸馏指控），DeepSeek 否认了这一指控。[^7]

### 2.9 后续

- **2025-05-28**：发布 R1-0528 升级版，AIME 2025 准确率从 70% 跃升至 87.5%，平均思考长度从 ~12k token 增至 ~23k token。[^8]
- **2025-09-17**：R1 论文在 *Nature* 正式发表，成为首批登上 Nature 的大模型论文之一。[^7]
- **2025-02 起**：深圳、北京、佛山等多地政府部门接入 DeepSeek；宝马、比亚迪、东风、本田等车企宣布合作。[^9]

## 三、影响与后继

### 3.1 推理模型品类的爆发

R1 证明了 o1 不是推理模型的唯一形态——推理模型可以开源、可以便宜、可以让用户看到思维链。

此后的半年里，全球几乎每一家 AI 公司都发布了自己的推理模型——这证明了 o1 定义的品类的可行性，也证明了 R1 重新定义了这个品类的规则。主要的推理模型包括（详见《o1 列传》）：

- **Kimi K1.5**（2025-01）：月之暗面的推理模型，在中文推理任务上表现出色
- **Claude 3.7 Sonnet**（2025-02）：Anthropic 的混合推理模型，支持普通模式与 extended thinking 模式切换
- **Gemini 2.5 Pro**（2025-03）：Google 的推理模型，集成到 Google 全线产品
- **Qwen3-Thinker**（2025-04）：阿里的推理模型，在中文推理任务上领先

这些模型中，没有任何一个采用 o1 的"隐藏思维链"路线——R1 的开源透明范式，成了行业默认。

### 3.2 "DeepSeek 时刻"的文化意义

R1 的影响超越了技术圈。"DeepSeek 时刻"（DeepSeek moment）这个说法在 2025 年初被全球主流媒体广泛使用，用来形容一个中国 AI 公司在技术上追平美国前沿、在商业模式上颠覆行业预期的事件。

这个文化冲击有两层。第一层是技术层面的：一个成立不到两年、融资规模远小于 OpenAI 的公司，用不到 600 万美元的训练成本，做出了对标 o1 的推理模型。第二层是地缘政治层面的：在中美 AI 竞争的叙事框架下，R1 成为了"中国 AI 能力不逊于美国"的象征——无论这个简化是否准确。

### 3.3 对 DeepSeek 世家的意义

R1 是 DeepSeek 世家从"价格屠夫"到"范式挑战者"的转折点（详见《DeepSeek 世家》）。[^10]

V2 的 MLA 让推理成本降到 GPT-4 的 1/100，V3 用 $5.6M 的训练成本做了 GPT-4o 级别的模型——这些是技术成就，但影响主要限于 AI 行业内。R1 的 MIT 开源和 6000 亿美元市值蒸发，让 DeepSeek 从行业内部的成功案例变成了全球公众事件。

从技术路线看，R1 的 GRPO 纯 RL 训练，是 DeepSeek 世家"效率优先"哲学的极致体现——不仅训练成本低，而且对齐成本也低。传统 RLHF 需要昂贵的人类标注数据来训练奖励模型；GRPO 用规则奖励替代了人类标注，对齐成本趋近于零。这与 V2 的 MLA（推理成本低）、V3 的 MTP + FP8（训练成本低）一脉相承——每一代都在回答同一个问题：还有什么成本可以砍掉？

### 3.4 蒸馏模型的长期影响

R1 的蒸馏模型生态催生了一个重要的副产品：**推理能力的民主化**。

在 R1 之前，推理模型是 API 服务——用户付钱，平台提供推理结果。在 R1 之后，推理模型是可下载的权重——开发者可以在自己的硬件上运行 1.5B、7B、14B、32B、70B 的蒸馏模型，完全离线、完全免费。这意味着推理能力可以被嵌入到任何应用中——手机上的数学辅导、笔记本上的代码助手、嵌入式设备上的决策引擎。

这个影响的长期意义可能比 R1 本身更大：**它把推理能力从"云服务"变成了"本地能力"**。就像 SD 把文生图从 API 变成了本地工具，R1 把推理从 API 变成了本地工具。两次"从云到端"的迁移，遵循着同一个逻辑：开源 + 蒸馏 = 能力下沉。

## 评曰

DeepSeek-R1 有两个贡献，一个大头，一个小头。小头是技术上的，大头是生态上的。但两个都值得被记住。

**小头：纯 RL 炼出推理能力。** R1-Zero 完全跳过 SFT，直接从基座模型出发，用 GRPO 强化学习和纯规则奖励，硬生生炼出了推理能力。过程中自发涌现的"顿悟时刻"——模型在训练中自己学会了停下来、重新评估、重新思考——是大模型时代最令人震动的涌现现象之一。此前的涌现是数字的跳变，这一次涌现的是行为。它暗示了推理不一定是被教会的，也可以是被"逼"出来的。

**大头：MIT 开源炸开了推理模型的围墙。** 如果 R1 只是又一个闭源的高价 API，它不过是 o1 的一个竞争者，不会引发地震。OpenAI o1 把推理模型做成了奢侈品：思维链不可见，价格高不可攀，模型权重是黑箱——一个"能力稀缺 → 高溢价 → 算力投入 → 壁垒加固"的精巧闭环。R1 用一个 MIT 协议把这个闭环炸开了。推理模型从奢侈品变成了公共品。

英伟达一天蒸发 6000 亿美元，市场恐惧的不是 R1 本身，而是它揭示的事实：最先进的 AI 不一定需要最多的 GPU。算力不是护城河。此后全球推理模型浪潮——Kimi K1.5、Qwen3-Thinker、Claude extended thinking——无一不受 R1 催化。它定义的不只是一个模型，而是一个品类。而"开源推理模型"这五个字，在 2025 年 1 月 20 日之前并不存在。
