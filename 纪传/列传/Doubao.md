# 《豆包 / Doubao 列传》

> 豆包不是第一个中国大模型，也不是技术最强的大模型。它做了一件别人不愿做的事——把价格打到地板。2024 年 5 月，字节跳动发布豆包大模型；三个月后，把推理价格降到 0.8 元/百万 token，直接把中国大模型市场拖入了价格战。豆包的逻辑很字节：不靠模型本身赚钱，靠应用层的规模效应赚钱。这个逻辑对不对，至今仍有争议。

---

## 一、技术背景

2023 年是中国大模型的"元年"。百度文心一言（3 月）、阿里通义千问（4 月）、科大讯飞星火（5 月）、智谱 ChatGLM（6 月）先后发布。[^1] 但 2023 年的中国大模型市场有一个明显的特征：**大家都在做模型，但很少有人想清楚模型怎么赚钱**。

大多数厂商的策略是"先发布模型、证明技术实力、再慢慢想商业模式"。API 定价普遍参考 OpenAI——GPT-4 的 API 价格约为 30 美元/百万 token（输入），折合人民币约 200 多元。[^2] 中国的厂商定价略低，但差距不大。大模型 API 对大多数开发者来说，仍然是一件"用得起但舍不得随便用"的东西。

字节跳动在这个阶段是**迟到的**。2023 年上半年，当百度、阿里、智谱都在争抢"中国第一个大模型"的标签时，字节跳动没有公开表态。字节的 AI 布局更早、更深，但集中在推荐算法、内容理解和广告投放——它的大模型团队起步较晚，没有像百度 ERNIE 那样十年积累的 NLP 底子。

字节的优势不在起步，而在另一件事上：**它拥有中国最大的移动互联网内容生态**。抖音 6 亿日活、今日头条、飞书、剪映——字节不需要证明大模型"有用"，它只需要把大模型塞进已经存在的 6 亿用户产品里。[^3]

---

## 二、核心创新

### 2.1 豆包大模型：2024 年 5 月发布

2024 年 5 月 15 日，字节跳动在火山引擎原力大会上正式发布豆包大模型（Doubao）。[^4] 豆包系列包含多个规格——从轻量级的端侧模型到千亿参数的旗舰模型，覆盖对话、角色扮演、内容创作、代码生成等场景。

豆包的技术亮点并不以"刷榜"著称。字节的策略是**做够用的模型，不做最强的模型**。豆包在主流基准测试上的表现处于中国大模型的第一梯队，但并不总是第一。字节赌的是：当模型能力的差距缩小时，价格和应用生态才是决定胜负的关键。

### 2.2 价格战：0.8 元/百万 token

2024 年 8 月，火山引擎大幅下调豆包大模型 API 价格——**主力模型的推理价格降至 0.8 元/百万 token（输入），约 1.2 元/百万 token（输出）**。[^5] 这个价格比行业平均水平低了一个数量级。同期 GPT-4 的价格约 200 元/百万 token，即使是中国厂商中最便宜的，也普遍在 10-50 元/百万 token 区间。

0.8 元/百万 token 意味着什么？一个普通开发者每天调用 100 万次 token，一个月的费用不到 25 元。大模型 API 从"企业级开支"降到了"个人开发者的零花钱"。

这个定价不是慈善——字节的逻辑是**以规模换成本**。字节拥有自建的 AI 基础设施（火山引擎），推理成本可以通过大规模部署摊薄。更关键的是，字节不指望 API 本身赚钱——它指望的是：当开发者大量涌入豆包生态后，应用层的增值服务（智能体平台、企业解决方案、广告变现）才是真正的收入来源。

### 2.3 引发价格战

豆包的定价直接引爆了中国大模型市场的价格战。[^6]

2024 年 5 月到 8 月之间，百度、阿里、腾讯、科大讯飞先后下调了自家大模型的 API 价格。阿里通义千问的 Qwen-Long 价格降至 0.5 元/百万 token；百度文心一言的 ERNIE Speed 模型宣布限时免费；智谱 AI 的 GLM-4-Flash 也进入了"免费"区间。[^6]

价格战的本质是**争夺开发者**。大模型的商业模式正在从"卖模型"转向"卖平台"——谁的 API 调用量最大，谁的生态就最繁荣，谁在应用层的变现空间就最大。字节用价格作为杠杆，试图把整个市场的游戏规则从"技术竞赛"切换到"规模竞赛"。

### 2.4 C 端增长：豆包 App

价格战是 to B 的事，但豆包在 C 端的增长同样惊人。

豆包 App 上线后，依托字节系的流量分发能力（抖音推荐、今日头条导流），用户规模迅速攀升。截至 2024 年 11 月，豆包 App 的月活跃用户（MAU）突破 6000 万，成为中国用户量最大的 AI 原生应用之一。[^7] 到 2025 年初，豆包的 MAU 进一步增长，持续领跑中国 AI 应用榜单。

豆包在 C 端的产品策略非常"字节"——**不追求学术深度，追求上瘾和留存**。豆包内置了大量角色扮演、创意写作、AI 伴侣等娱乐化功能，瞄准的是年轻用户的消遣需求，而不是专业用户的生产力需求。这与 ChatGPT 的"工具人"定位形成了鲜明对比——ChatGPT 帮你写代码和分析数据，豆包陪你聊天和编故事。

## 三、影响与后继

### 3.1 价格战的连锁反应

豆包引爆的价格战，深刻改变了中国大模型市场的竞争逻辑。

在价格战之前，中国大模型市场的竞争主要围绕**技术能力**——谁的模型在 C-Eval、MMLU 等基准上排名更高。价格战之后，竞争的重心转向了**性价比**——同样的能力，谁能以更低的价格、更稳定的服务提供给开发者。[^6]

这个转变的受益者是开发者和中小企业。2024 年之前，大模型 API 的调用成本让很多创业公司望而却步；2024 年之后，"大模型调用"变成了和调用云服务器一样的基础开支。中国的大模型应用生态因此加速了——智能客服、AI 写作助手、代码补全工具、教育产品，一批基于大模型 API 的应用在 2024 年下半年集中涌现。

但价格战的另一面是**利润的消失**。当 API 价格降到 0.8 元/百万 token 时，大多数厂商在这个价格上是不赚钱的，甚至在亏钱。价格战加速了行业的洗牌——没有自研基础设施、没有应用场景变现能力的小模型公司，在价格战中几乎没有生存空间。

### 3.2 字节的 AI 战略：应用大于模型

豆包代表了字节跳动在 AI 领域的核心策略——**不追求模型的绝对领先，追求应用层的绝对规模**。

这个策略与字节在短视频领域的打法一脉相承。抖音不是第一个短视频产品（快手比它早），但抖音在内容分发算法和用户体验上做到了极致，最终实现了反超。[^3] 豆包也不是第一个中国大模型（文心一言比它早一年），但字节在流量获取和产品打磨上的能力，让豆包在 C 端用户规模上迅速追上了先行者。

字节的 AI 战略可以用一句话概括：**模型是基础设施，应用才是生意**。字节不需要豆包成为最强的模型——它需要豆包成为最多人用的 AI 助手，然后围绕这个用户基数做变现。

### 3.3 与抖音/TikTok 生态的结合

豆包最大的结构性优势，是它背后的内容生态。

抖音 6 亿日活、今日头条 3 亿日活、飞书数千万企业用户——字节的 AI 产品不需要从零获客，只需要把这些存量用户转化为 AI 用户。[^3] 在抖音中嵌入 AI 搜索、在飞书中嵌入 AI 助手、在剪映中嵌入 AI 视频编辑——每一个嵌入点都是一条低成本的获客通道。

这种"生态嫁接"策略是百度和阿里难以复制的。百度的搜索生态正在萎缩，阿里的电商生态与 AI 助手的结合不如内容平台自然。字节把"内容消费"和"AI 对话"结合在一起的路径，是所有中国大模型公司中最顺畅的。

### 3.4 局限与争议

豆包的策略不是没有风险。

首先，**价格战不可持续**。0.8 元/百万 token 的价格低于大多数厂商的推理成本，这意味着字节在补贴市场。当补贴停止后，价格是否会上升？开发者是否会流失？这些问题尚无答案。

其次，**C 端应用的护城河不深**。豆包 App 的角色扮演和创意写作功能，其他竞品（如 Kimi、文心一言、通义千问）也都能做。用户从一个 AI 助手迁移到另一个的成本极低——切换 App 比切换搜索引擎还容易。豆包的用户规模虽然大，但留存和粘性是否足够，仍需时间验证。

第三，**模型能力的天花板**。字节的策略是"够用就好"，但在某些高端场景（复杂推理、长文档分析、专业领域问答），豆包与 DeepSeek、通义千问等技术导向的模型仍有差距。当应用层的竞争从"谁更便宜"升级到"谁更强"时，字节能否跟上？

## 评曰

豆包是字节跳动在 AI 时代押下的最大赌注——赌的不是技术领先，而是规模为王。

这个赌注的逻辑是清晰的：大模型的能力正在趋于同质化，当模型之间的差距从"代际"缩小到"百分比"时，竞争的决定因素就从"谁的模型更好"变成了"谁的用户更多"。字节用 0.8 元/百万 token 的定价和 6 亿日活的流量入口，试图在中国大模型市场上重演抖音的剧本——不是第一个做，但做到最大。

价格战是这个策略的利刃，也是它的软肋。利刃在于：它让整个行业的定价逻辑崩溃重建，逼迫所有玩家从"卖模型"转向"卖应用"。软肋在于：价格战消耗的是利润，而利润是持续创新的燃料。当字节自己也不得不在 0.8 元的价格上亏钱运营时，它实际上是在用资本市场的耐心换取市场份额的时间窗口。

豆包的最终命运，取决于一个尚未有答案的问题：**AI 助手是像搜索引擎一样的基础设施（赢者通吃），还是像社交软件一样的应用层产品（多元共存）？** 如果是前者，字节的规模策略可能最终胜出；如果是后者，豆包的先发优势可能不会比文心一言更持久。在答案揭晓之前，豆包是中国大模型市场上最具攻击性的变量——它不一定是最后的赢家，但它正在塑造这个市场的竞争规则。
