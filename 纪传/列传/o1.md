# 《o1 列传》

> o1 是 OpenAI 在 2024 年 9 月发布的首个"推理模型"。它没有追求更大的参数或更多的训练数据——它在回答之前先在内部进行链式思考，用额外的推理时间来规划、验证、修正自己的思路。AIME 数学竞赛从 GPT-4o 的 12% 跳到 74%，这不是渐进式提升——是能力从一个领域突然迁移到了另一个领域。o1 开创了"推理模型"这个品类，也重新定义了 Scaling Law 的边界。

---

## 一、技术背景

GPT-4（2023-03）定义了"前沿"标准，但它的推理是"直觉式"的——预测下一个 token，没有内部分析步骤。GPT-4 可以流畅地写代码、解数学题、做翻译，但在需要多步推理的任务上仍有明显短板。它像一个聪明的学生——知道很多知识，但面对复杂问题时容易犯"粗心"的错误。

2024 年初，行业面临一个未解问题：**单纯的参数 scaling 正在接近收益递减。** GPT-4 的参数规模据传是 1.76 万亿，但它的推理能力并没有比 GPT-3.5 有质的飞跃——只是在更多基准上"及格"了。Kaplan 法则（2020）和 Chinchilla 修正（2022）都聚焦于训练阶段的 scaling：更多参数、更多数据、更多算力。但训练侧的 scaling 正在逼近天花板——数据墙、成本墙、能源墙，让"继续堆训练算力"变得越来越困难。

2024 年 8 月，Charlie Snell 等人发表了"Scaling LLM Test-Time Compute Optimally can be More Effective than Scaling Model Parameters"，系统性地论证了一个此前被低估的维度：**在推理阶段投入更多计算，可以在不增大模型的前提下，显著提升模型的有效表现。**[^1]

一个月后，OpenAI 用 o1 把这个理论变成了产品。

---

## 二、核心创新

### 2.1 "思考"范式的开创：内部 chain-of-thought

o1 的核心差异是：它在回答之前会在内部生成一个**隐藏的思维链（hidden chain-of-thought）**——用额外的推理时间来规划、验证、修正自己的思路。用户看到的只有最终回答，中间的推理过程被刻意隐藏。[^2]

这个设计的理念很清晰：GPT-4 的"下一个 token"预测是一种直觉式的快思考——流畅、快速，但在需要多步推理的任务上容易犯错。o1 的"先想再说"是一种推理式的慢思考——更慢、计算量更大，但在数学、编程和科学推理上准确得多。

o1 的"思考"不是传统的 chain-of-thought prompting（用户要求模型"一步一步想"，模型就把推理过程写在输出里）。o1 的推理是**隐式的**——推理过程被系统拦截，用户只看到最终结论，看不见模型如何从问题到达结论。OpenAI 称之为 hidden chain-of-thought。[^2]

### 2.2 o1-preview / o1-mini：两个产品的组合

**2024-09-12** — OpenAI 发布 **o1-preview** 和 **o1-mini**，仅限 ChatGPT Plus/Team 和 API Tier 5 用户。[^2]

o1-preview 是旗舰推理模型，专注于复杂推理任务。o1-mini 是一个更小、更快、更便宜的推理模型，专注于 STEM（科学、技术、工程、数学）推理。o1-mini 在非 STEM 任务上不如 o1-preview，但在数学和编程上的性价比远超旗舰。

定价差距显著：[^2]
- o1-preview：输入 $15/百万 token，输出 $60/百万 token
- o1-mini：输入 $3/百万 token，输出 $12/百万 token

o1-mini 便宜 80%，在某些推理基准上的表现却接近甚至超过 o1-preview。对于大多数开发者的实际场景（代码生成、数学解题、数据清洗），o1-mini 是更合理的选择。

这个决策在产品层面很精妙。o1-preview 树起了"最强推理"的品牌天花板，但高定价劝退了大多数人；o1-mini 则是一个低门槛入口，让开发者可以低成本试水"推理模型"。两者加在一起，组成了一个"品牌拉高 + 走量"的双层定价结构——和高端的奔驰 S 级与走量的 C 级是同一个逻辑。

### 2.3 数学/编程/科学推理能力跃升

o1 在推理密集型基准上实现了飞跃：[^2]

| 基准 | o1-preview | GPT-4o | 提升 |
|------|:--:|:--:|:--:|
| AIME 2024 (数学竞赛) | 74.4% | 12.1% | **+62.3** |
| GPQA Diamond (科学推理) | 77.3% | 56.1% | +21.2 |
| Codeforces | 89%ile | 11%ile | +78 |
| International Math Olympiad | 83.3% | 13.4% | +69.9 |

最震撼的数字是 AIME 数学竞赛：从 12% 跳到 74%。这不是渐进式提升——是能力从一个领域突然迁移到了另一个领域。GPT-4o 在 AIME 上的 12% 正确率意味着它"基本不会"做竞赛数学题；o1 的 74% 意味着它"大部分都会"。这个差距不是靠更大的模型或更多的训练数据实现的——而是靠模型在回答每个问题时投入了远多于前代的推理计算。

在 2024 年国际信息学奥林匹克竞赛（IOI）中，o1 在人类同等条件下获得了 213 分，排名在所有参赛者中处于第 49 百分位。这意味着 o1 的编程能力已经超过了近一半的人类参赛者——而这些参赛者是全球最优秀的年轻程序员。

### 2.4 ARC-AGI 表现

o1 在 ARC-AGI（Abstraction and Reasoning Corpus for Artificial General Intelligence）上的表现引起了广泛关注。ARC-AGI 是 François Chollet 在 2019 年提出的推理基准，专门测试模型的抽象推理能力——它不测试知识记忆，只测试"从少量例子中归纳规则"的能力。

o1 在 ARC-AGI 上的表现远超此前所有模型——虽然仍未达到人类水平，但已经跨过了"有意义的进展"的门槛。这被视为推理模型在"通用推理"方向上的一个重要里程碑。[^3]

### 2.5 Test-Time Compute 的胜利

o1 的成功证明了一个新的 scaling 维度：**推理时间的计算量**。传统的大模型 scaling 聚焦于训练阶段——更多参数、更多数据、更多算力。o1 开辟了一个新的方向：让模型在回答问题时花更多时间"思考"。

"测试时计算"（test-time compute）——让模型在回答前花更多时间推理——成为 2024-2025 年最热的研究方向。之后的 DeepSeek-R1、Kimi K1.5、Claude extended thinking、Qwen3-Thinker 都是在 o1 开辟的赛道上奔跑。

o1 的成功回答了一个关键问题：**推理计算可以替代一部分训练计算。** 与其花费数十亿美元训练一个更大的模型，不如在推理阶段花更多 token 让现有模型"多想一想"。这为行业提供了一条新的 scaling 路径——在训练侧 scaling 逼近天花板的背景下，推理侧的 scaling 成为了新的增长曲线。

### 2.6 隐藏思维链的争议

o1 最具争议的设计决策是**隐藏思维链**。OpenAI 给出的理由是"安全"——如果用户能看到模型的内部推理，他们可能学会绕过安全限制。但批评者认为，这恰恰逆转了 OpenAI 早期"透明"的承诺。[^2]

OpenAI 对看到思维链的用户实施"零容忍"禁令——任何试图通过 prompt injection 或越狱看 o1 思考过程的行为都会导致账号被封。这让社区的不满进一步升级——"你说这是为了安全，但你不让任何人验证你的安全措施。"

四个月后，DeepSeek-R1 用 MIT 开源 + 完全公开思维链给了 o1 一个最响亮的回答：推理模型可以既强大又透明（详见《DeepSeek-R1 列传》）。这个对比成为了 2025 年初 AI 行业最重要的争论之一——推理模型应该透明还是不透明？答案至今没有定论。

### 2.7 过度思考：推理模型的第一个产品难题

o1 的用户很快发现了一个令人哭笑不得的现象：它会在不该思考的时候过度思考。

"一只猫有 4 条腿，10 只猫有多少条腿？"——o1-preview 会花 20 秒"思考"这个答案显然是 40 的问题，生成数百字的推理链条，然后再给出答案。更极端的情况下，用户问一个简单的"你好"，o1 也会启动推理模式，仔细分析这个问候语的含义和可能的回应策略。

这不是 bug——这是推理模型产品化的第一个系统性挑战。此前的语言模型都是"快思考"：输入即输出。它们也会犯错，但犯错的方式是直觉式的——快了所以粗心。o1 的慢思考在复杂任务上大幅降低了错误率，但在简单任务上浪费了用户的时间和 API 费用。

这个现象暴露的问题比它看起来深：**推理模型没有"任务难度感知"能力**。它不知道一个问题是 1+1=2 还是 AIME 竞赛题——它只是按照训练中学会的模式生成推理链。而训练教会它的是"所有问题都该想一想"。

后来的推理模型（Claude 3.7 Sonnet、Gemini 2.5 Pro、Qwen3）都在尝试解决这个问题——通过"思考开关"让用户决定什么时候需要慢想。但这个解决方式也有代价：它把判断负担转移给了用户。在 o1 的"一律多想"和 Claude 的"用户决定"之间，行业至今没有找到完美的中间点。

## 三、影响与后继

### 3.1 从 o1-preview 到 o1 正式版

- **2024-09-12**：o1-preview 和 o1-mini 发布，仅限 ChatGPT Plus/Team 和 API Tier 5 用户
- **2024-12-05**：o1 正式版发布，加入多模态（图像输入）支持
- **2024-12-20**：o3 发布（跳过 o2），在编程和数学上再创新高

o1-preview 发布时引起了轰动，但用户很快发现了很多问题：它会过度思考简单问题，在某些对话任务上不如 GPT-4o 灵活，API 价格极贵（o1-preview 输出 $60/百万 token，是 GPT-4o 的 4 倍）。

### 3.2 o3：推理模型的进一步突破

**2024-12-20** — OpenAI 发布 **o3**（跳过 o2），在编程和数学上再创新高。[^4]

o3 的发布证明了推理模型的 scaling 不是一次性的——它可以持续迭代。o3 在多项基准上超越了 o1，特别是在编程和数学推理上。这验证了一个关键假设：**推理计算的 scaling 可以持续产生收益**——只要模型的训练质量足够高，推理计算的投入就能持续提升有效表现。

o3 的发布也引发了关于"推理模型的天花板在哪里"的讨论。如果 o1 可以从 12% 跳到 74%，o3 可以从 74% 跳到多少？推理计算的 scaling 是否有极限？这些问题在 2025 年成为了 AI 研究的前沿课题。

### 3.3 推理模型品类的爆发

o1 开创了一个全新的模型品类——"推理模型"（reasoning model）。此前的所有 LLM（GPT 系列、Claude 系列、Llama 系列）都是"直接生成"模式——预测下一个 token，没有内部分析步骤。o1 证明了一个新的 scaling 维度：**推理时间的计算量**。

此后的六个月里，全球几乎每一家 AI 公司都发布了自己的推理模型——这证明了 o1 定义的"品类"的可行性。但也证明了 o1 无法守住独占优势——推理模型的技术壁垒比预训练模型低，追赶速度更快。

主要的推理模型包括：
- **DeepSeek-R1**（2025-01）：MIT 开源，完全公开思维链，用 RL 涌现推理能力
- **Kimi K1.5**（2025-01）：月之暗面的推理模型，在中文推理任务上表现出色
- **Claude 3.7 Sonnet**（2025-02）：Anthropic 的混合推理模型，支持普通模式与 extended thinking 模式切换
- **Gemini 2.5 Pro**（2025-03）：Google 的推理模型，集成到 Google 全线产品
- **Qwen3-Thinker**（2025-04）：阿里的推理模型，在中文推理任务上领先

### 3.4 对 Scaling Law 的重新定义

o1 的成功重新定义了 Scaling Law 的边界。Kaplan 法则（2020）和 Chinchilla 修正（2022）都聚焦于训练阶段的 scaling：更多参数、更多数据、更多算力。o1 开辟了一个新的维度：**推理时的计算量**。

这不是否定训练侧的 scaling——而是补充。训练侧的 scaling 决定模型的"能力上限"——模型"知道"多少，能"做"什么。推理侧的 scaling 决定模型在每次任务中"接近这个上限的程度"——面对具体问题时，模型实际能发挥出多大比例的潜力。

这意味着"智能"不再是一个静态属性（"这个模型有多聪明"），而是一个动态过程（"这个问题上，模型用了多少计算来接近它的能力上限"）。同一个模型，在简单问题上快速回答（低推理计算），在复杂问题上深度推理（高推理计算），表现出的"智能"截然不同。

### 3.5 定价的经济学含义

o1-preview 的输出定价——$60/百万 token——在大模型定价史上是一个标志性数字。GPT-4o 的输出是 $15/百万 token。o1 贵了 4 倍。[^2]

这个差价的理由不是参数规模，而是**推理时计算**。o1 在回答问题时消耗的 token 远多于普通模型——那些隐藏的思维链也是按照 token 收费的。用户付的不仅是最终答案的钱，还有"思考过程"的钱。

因此 o1 的定价开创了一种新的大模型商品形态：**按思考量计价**。此前的 token 计费是对"生成内容"收费，o1 的 token 计费是对"生成思考"收费——而用户看不到思考内容。这引发了信任问题：如果我付了思考的钱但看不到思考的过程，我怎么知道我付的钱是用于真正的推理还是浪费在无效循环上？

## 评曰

o1 是大模型从"更大"到"更聪明"的范式转折。它回答了一个 GPT-4 搁置了的问题：单纯的参数 scaling 正在接近收益递减，但**推理 scaling**（让模型花更多时间思考）仍然有巨大的提升空间。这是一条新的 scaling law——不是训练时计算量，而是推理时计算量。

隐藏思维链的决定是 o1 最具争议的部分。OpenAI 说这是为了安全——但安全检查的前提是透明，而隐藏本身就是不透明。四个月后，DeepSeek-R1 用 MIT 开源 + 完全公开思维链给了 o1 一个最响亮的回答：推理模型可以既强大又透明。o1 开创了品类，但把定义这个品类规则的机会让给了 DeepSeek。

从产品角度，o1 也暴露了推理模型的一个核心张力：用户不一定想要"深思熟虑"的 AI。ChatGPT 的魅力在于即时对话——像聊天一样自然。o1 的"等 30 秒得到一个更好的答案"对于日常聊天是打断，对于数学题是恩赐。这个张力至今未被完全解决——后来的推理模型都在尝试"让快思考和慢思考共存"，但没有人找到一个优雅的 UI 来同时容纳两者。

o1 最深远的影响，可能是它对"智能"这个概念的重新定义。过去，"这个模型有多聪明"是一个可以给出确定答案的问题——参数多少、数据多少、benchmark 多高，模型的能力就是多少。现在，"这个模型有多聪明"取决于它在具体任务上愿意花多少推理计算。模型的能力不再是一个固定的点，而是一条曲线——横轴是推理计算投入，纵轴是有效表现，曲线的形状由训练质量决定。

o1 是第一个让"思考"成为商品的模型——用户为模型的"思考时间"付费，但看不到思考的内容。这到底是效率还是浪费，取决于你站在哪一边。但无论站在哪一边，你都无法否认：o1 改变了"AI 能力"的定义——而新的定义，至今仍在生效。
