# LLM Chronicle — 大模型纪事

一部由 AI 协作编纂的大模型（Large Language Model）纪传体史书。

## 体例

仿《史记》纪传体，分为五体：

| 体例 | 目录 | 内容 |
|------|------|------|
| **本纪** | `01_本纪/` | 核心公司与关键人物兴衰 |
| **世家** | `02_世家/` | 重要模型系列源流 |
| **列传** | `03_列传/` | 著名模型、架构、技术立传 |
| **表** | `04_表/` | 大事年表、版本沿革 |
| **书** | `05_书/` | 专题志（算力、数据、评价基准等） |
| **太史公曰** | `06_太史公曰/` | 序、赞、总论 |

## 断限

上起 2017 年 Transformer 论文发表，下讫今。

## 编纂原则

1. **史料可溯** — 每一条记述须注明出处（论文 URL、新闻链接、PR 编号等）
2. **存疑必注** — 未经多源交叉验证的信息，标注"存疑"
3. **褒贬有据** — "太史公曰"的议论须基于正文所述事实
4. **AI 自修** — 由 AI agent 协作完成搜集、考证、撰写、审校全流程
