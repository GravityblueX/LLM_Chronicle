# LLM Chronicle Translation Style Guide

## 1. General Principles

### 1.1 Translation Philosophy
- **Accuracy First**: Faithful translation of technical content
- **Natural Flow**: Readable English while preserving original meaning
- **Consistency**: Uniform terminology across all files
- **Professional Tone**: Academic yet accessible style

### 1.2 Quality Standards
- **Completeness**: No content omission
- **Technical Precision**: Accurate translation of AI/ML concepts
- **Cultural Sensitivity**: Preserve nuanced meaning
- **Readability**: Natural English flow

## 2. Terminology Guidelines

### 2.1 Technical Terms
| Chinese Term | English Translation | Notes |
|--------------|---------------------|-------|
| 大模型 | Large Language Model (LLM) | Use abbreviation after first mention |
| 预训练 | Pre-training | Hyphenated |
| 微调 | Fine-tuning | Hyphenated |
| 推理 | Inference | Context-dependent |
| 对齐 | Alignment | AI safety context |
| 开源 | Open-source | Hyphenated as adjective |
| 闭源 | Closed-source | Hyphenated as adjective |
| 涌现能力 | Emergent abilities | Plural |
| 参数规模 | Parameter count | Technical context |
| 基准测试 | Benchmark | Standard term |
| 伦理 | Ethics | Academic context |
| 治理 | Governance | Policy context |

### 2.2 Model Names
- Keep original names: GPT-4, Llama, DeepSeek, Claude
- Add version numbers: GPT-4.5, Claude 3.5 Sonnet
- Preserve special formatting: DALL·E, FLUX.1

### 2.3 Company Names
- Use official English names: OpenAI, Google, Meta
- Keep Chinese names when no official English: 字节跳动 (ByteDance)
- Add Chinese names in parentheses for clarity: 腾讯 (Tencent)

## 3. Formatting Rules

### 3.1 Headers
- Preserve original header hierarchy
- Use sentence case for English headers
- Maintain markdown formatting

### 3.2 Dates
- Use ISO format: YYYY-MM-DD
- Preserve original date precision
- Example: **2017-06-12** — Transformer paper published

### 3.3 Citations
- Keep original URLs
- Preserve footnote format
- Maintain source references

### 3.4 Cross-references
- Update internal links to English versions
- Preserve reference format: See [Article Name]
- Maintain bidirectional links

## 4. Style Guidelines

### 4.1 Sentence Structure
- Use active voice when possible
- Maintain parallel structure
- Avoid overly complex sentences
- Preserve technical precision

### 4.2 Paragraph Flow
- Logical progression
- Clear topic sentences
- Smooth transitions
- Consistent terminology

### 4.3 Technical Writing
- Precise terminology
- Clear explanations
- Appropriate detail level
- Professional tone

## 5. Special Cases

### 5.1 Chinese Cultural References
- Add brief explanations when needed
- Preserve cultural context
- Maintain original meaning

### 5.2 Technical Jargon
- Use established translations
- Keep original when no standard translation
- Add explanations for complex concepts

### 5.3 Quotations
- Translate accurately
- Preserve original meaning
- Maintain attribution

## 6. Quality Assurance

### 6.1 Review Checklist
- [ ] Technical accuracy
- [ ] Terminology consistency
- [ ] Natural English flow
- [ ] Complete translation
- [ ] Proper formatting
- [ ] Functional links

### 6.2 Common Errors to Avoid
- Literal translation
- Inconsistent terminology
- Overly formal language
- Cultural misunderstandings
- Technical inaccuracies

## 7. Examples

### 7.1 Good Translation
**Original**: "Transformer架构的提出，标志着大模型时代的开始"
**Translation**: "The introduction of the Transformer architecture marked the beginning of the large language model era"

### 7.2 Technical Precision
**Original**: "GPT-3展示了涌现能力"
**Translation**: "GPT-3 demonstrated emergent abilities"

### 7.3 Cultural Context
**Original**: "AI孙燕姿现象"
**Translation**: "The 'AI Stefanie Sun' phenomenon"
