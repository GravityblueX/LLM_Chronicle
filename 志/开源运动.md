# 《开源运动》

> 大模型的开源运动，不是一条从封闭走向开放的直线。它先由一次权重泄漏点燃，再被公司战略、社区复刻、国家竞争和许可证争议反复改写。这里记录事实脉络：谁在什么时候放出了什么，放出的到底是代码、权重、数据，还是一种“开放”的名义。

---

## 一、概述

2023 年以前，开源语言模型并非没有存在过。EleutherAI 的 GPT-Neo、GPT-J、GPT-NeoX，BigScience 的 BLOOM，都证明了社区可以训练大模型。但 ChatGPT 之后，行业的注意力集中到“能不能得到一个强大的、可本地部署的、可微调的对话基座模型”上。这个问题真正被推到台前，是 2023 年 2 月 LLaMA 权重泄漏之后。

从那以后，“开源 AI”至少分成了几层含义：

- **开放权重**：可以下载模型参数，部署、微调、量化；
- **开放代码**：训练、推理、评测代码可查；
- **开放数据信息**：知道模型用什么数据、怎样筛选、怎样处理；
- **开放许可证**：允许任何用途，包括商业用途，不附加歧视性限制。

大模型行业日常说的“开源”，很多时候其实只是“开放权重”。OSI 后来围绕 Open Source AI Definition（OSAID）展开的争议，正是为了解决这个词被混用的问题。[^1]

---

## 二、2023：LLaMA 泄漏与社区爆发

**2023-02-24**，Meta 发布 LLaMA，规模为 7B、13B、33B、65B。Meta 当时不是面向公众开放下载，而是以研究许可向经过审批的研究人员提供权重。论文强调“小而高效”：13B 模型在多个基准上超过 GPT-3，65B 接近 Chinchilla、PaLM 等更大模型。[^2]

发布后不久，LLaMA 权重经 4chan 与 BitTorrent 泄漏。到 **2023-03-08**，主流科技媒体已经报道这次泄漏，并指出它迅速引发了关于 AI 安全、研究开放和权重扩散的争论。[^3]

泄漏之后，社区不是只“围观”模型，而是立刻把它变成了生产材料：

| 时间 | 事件 | 意义 |
|------|------|------|
| 2023-02 | LLaMA 发布并泄漏 | 强基座模型第一次以不可回收的方式进入公众网络 |
| 2023-03 | Stanford Alpaca 发布 | 用较低成本指令微调 LLaMA，展示“便宜做出可用聊天模型”的路径 |
| 2023-03 | Vicuna 发布 | 用 ShareGPT 对话数据微调，推动社区评测与聊天模型复刻 |
| 2023-04 前后 | GPT4All、Koala、RedPajama 等跟进 | 数据集、微调、量化、本地运行工具链开始成形 |

这阶段的开源运动有一个明显特征：**它不是由许可证授权启动的，而是由事实可得性启动的**。权重一旦进入公共网络，开发者会围绕它建立工具链；工具链一旦建立，新的模型发布就会默认要考虑 Hugging Face、llama.cpp、vLLM、本地量化、LoRA 微调这些下游环节。

这也是 LLaMA 泄漏的历史位置：它没有给出完整的开源许可证，却给出了一个足够强、足够小、足够可复制的基座。开放生态先于正式授权出现。

---

## 三、Meta 的策略转身：Llama 2 到 Llama 3.1

**2023-07-18**，Meta 与 Microsoft 发布 Llama 2，提供 7B、13B、70B 版本，包含预训练模型和 Llama 2-Chat。与 LLaMA 1 不同，Llama 2 明确允许研究和商业使用，但许可中保留了限制：例如月活超过 7 亿的服务需要向 Meta 申请额外许可。[^4]

这一步把“事故”改写成了“战略”。Meta 的选择有三层含义：

1. **承认社区路径有效**：LLaMA 1 泄漏后的生态扩张证明，开放权重能快速制造影响力；
2. **把开放变成分发策略**：通过 Azure、Hugging Face 等渠道，Llama 2 进入企业与开发者工作流；
3. **保留平台级控制权**：许可证允许大多数人商用，但对超大平台设置门槛。

**2024-04**，Meta 发布 Llama 3 的 8B 与 70B 版本；**2024-07-23**，Meta 发布 Llama 3.1，其中旗舰模型达到 405B 参数，支持 128K 上下文，并把开放模型能力推到接近闭源前沿的位置。[^5]

同日，Mark Zuckerberg 发表《Open Source AI Is the Path Forward》。文章把 Llama 的开放路线解释为类似 Linux 的基础设施路线：开放能让开发者定制模型、降低供应商锁定、提高安全审查能力；对 Meta 而言，开放生态也能削弱竞争对手的闭源护城河。[^6]

但 Llama 3.1 也把争议推到了正面：它是开放权重模型，却不等于 OSI 意义上的开源 AI。原因包括：许可证对超大用户有限制，训练数据没有完整公开，训练流程也不能由外部完整复现。

## 四、欧洲路线：Mistral 把“小而强”产品化

LLaMA 之后，欧洲最重要的开放权重玩家是 Mistral AI。它的路线不是一开始就追求最大参数，而是把“效率”和“宽松许可”放在前面。

**2023-09-27**，Mistral 发布 Mistral 7B。它是 7.3B 参数模型，使用 GQA 与 Sliding Window Attention，官方称其在多项基准上超过 Llama 2 13B，并以 Apache 2.0 许可发布，允许不受限制地使用。[^7]

**2023-12-11**，Mistral 发布 Mixtral 8x7B。它采用稀疏 MoE 架构，总参数 46.7B，但每个 token 只激活约 12.9B 参数。官方称它在多数基准上超过 Llama 2 70B，推理速度约快 6 倍，并匹配或超过 GPT-3.5 的多项标准基准。Mixtral 同样以 Apache 2.0 许可开放权重。[^8]

Mistral 的事实贡献在于：

- 把开放权重模型从“追随 Llama”推进到独立架构路线；
- 证明小模型和 MoE 可以在成本/性能曲线上取得优势；
- 用 Apache 2.0 这类宽松许可证，给企业采用降低法律成本。

不过，Mistral 后来也发布了更多闭源或 API 优先的商业模型。这说明开放权重并不必然意味着公司整体选择“全开源”。更准确地说，Mistral 把开放模型当作进入市场、建立声誉和扩展生态的一部分。

## 五、中国路线：Qwen 与 DeepSeek 扩大开放权重版图

2024 年以后，中国团队成为开放权重模型的重要来源。这里最突出的两条线，是阿里 Qwen 和 DeepSeek。

### Qwen：多尺寸、多语种、多任务的模型族

Qwen 的策略是模型族式发布：同一代模型覆盖多个参数规模，并配套代码、数学、视觉等专项模型。

**2024-09**，Qwen2.5 发布。官方称这是一次大规模开源发布，包含 Qwen2.5、Qwen2.5-Coder、Qwen2.5-Math 等系列；Qwen2.5 主模型覆盖 0.5B、1.5B、3B、7B、14B、32B、72B 等尺寸，训练数据最高达到 18T tokens，支持 128K 上下文与 29 种以上语言。官方说明中也写明：除 3B 与 72B 外，多数开放模型使用 Apache 2.0 许可。[^9]

**2025-04**，Qwen3 发布。Qwen3 开放了两个 MoE 模型 Qwen3-235B-A22B、Qwen3-30B-A3B，以及 0.6B 到 32B 的多个 dense 模型，官方称这些模型以 Apache 2.0 许可开放，并支持“Thinking / Non-Thinking”两种模式。[^10]

Qwen 的影响不只在模型本身，还在于它给下游提供了稳定的中文、多语种、代码、数学基座。DeepSeek-R1 的蒸馏模型中，也包含基于 Qwen2.5 的多个版本，这进一步扩大了 Qwen 在开放生态中的基础设施地位。[^11]

### DeepSeek：从开放权重到开放推理模型

DeepSeek 的开放路线更强调“前沿能力也可以开放”。

**2024-12**，DeepSeek-V3 发布。V3 是 671B 总参数、每 token 激活 37B 的 MoE 模型，使用 MLA、DeepSeekMoE、辅助损失自由的负载均衡策略与 Multi-Token Prediction。官方仓库称，V3 在 14.8T tokens 上预训练，训练成本为 2.788M H800 GPU hours，并达到接近闭源前沿模型的表现。[^12]

**2025-01**，DeepSeek-R1 发布。R1 基于 DeepSeek-V3-Base，主打推理能力；官方同步开放 DeepSeek-R1-Zero、DeepSeek-R1，以及 6 个由 R1 蒸馏出的 dense 小模型，基座包括 Qwen2.5 与 Llama 系列。DeepSeek 明确称 R1 在数学、代码、推理任务上达到 OpenAI o1 可比水平。[^11]

DeepSeek-R1 的关键不只是“权重开放”，而是把推理模型这个此前高度闭源的方向推入开放生态：研究者可以下载模型、观察推理输出、蒸馏小模型、复现实验方向。这使开放权重运动从“追赶聊天模型”进入“追赶推理模型”的阶段。

## 六、OSI 定义争议：什么才算 Open Source AI

随着 Llama、Mistral、Qwen、DeepSeek 等模型流行，“开源 AI”这个词变得越来越混乱。有人把开放权重叫开源，有人要求训练代码和数据也开放；有人关注商业使用自由，有人关注能否复现训练过程。

**2024-10-28**，Open Source Initiative 发布 Open Source AI Definition 1.0。定义强调，Open Source AI 应当赋予使用、研究、修改、分享四项自由；而机器学习系统的“首选修改形式”应包括三类要素：训练数据的充分信息、训练和运行代码、模型参数。[^13]

这里的关键不在于必须公开每一条训练样本原文。OSI 的表述更细：如果数据不能完整分享，也需要提供足够详细的数据来源、范围、选择、标注、处理和过滤信息，让有能力的人可以构建“实质等价”的系统。[^1]

争议也集中在这里：

- **模型公司担心数据公开带来版权、隐私和商业风险**；
- **开源组织担心只开放权重会把“开源”降格为营销词**；
- **研究者关心可复现性**：不知道数据和训练流程，就很难判断模型能力来自哪里；
- **企业用户关心使用自由**：许可证若限制特定规模、特定用途或特定竞争者，就不是传统开源定义下的自由使用。

因此，OSI 定义把 Llama 这类模型推到了一个尴尬位置：它们对产业非常重要，也确实开放了权重，但未必满足 Open Source AI 的完整定义。更准确的称呼是 **open-weight models（开放权重模型）**。

## 八、趋势分析

- **第一阶段是泄漏驱动**：LLaMA 1 的影响来自事实扩散，不来自许可证设计。
- **第二阶段是公司战略驱动**：Llama 2、Llama 3.1 把开放权重变成平台竞争手段。
- **第三阶段是多中心竞争**：Mistral、Qwen、DeepSeek 证明开放权重不再由 Meta 单独定义。
- **第四阶段是定义收紧**：OSI 试图把“开放权重”“开放模型”“开源 AI”区分开，防止术语被营销化。
- **最稳定的现实是分层开放**：权重最容易开放，训练代码次之，训练数据最难；许可证越宽松，商业采用越容易，但公司越难保留战略控制。

---

## 评曰

开源运动在大模型时代换了形状。传统软件开源，核心是源代码；大模型的核心却是权重、数据、训练流程和算力经验的组合。只放出权重，已经足以改变产业分工，却不足以让外部完整理解模型如何生成。LLaMA 泄漏点燃了生态，Mistral 证明了宽松许可的效率路线，Qwen 和 DeepSeek 把开放权重推向多语种、推理和前沿能力，OSI 则提醒行业：开放不是一个口号，而是一组可以检查的自由。史官记此事，应把“开源”二字拆开看：哪些是真的自由，哪些只是可下载，哪些是战略赠品，哪些才是公共基础设施。
