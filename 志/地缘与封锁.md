# 《地缘与封锁》

> 大模型的地缘政治不只发生在芯片海关。2022 年以后，封锁逐渐沿着整条 AI 栈向上爬：先限制先进 GPU 和半导体设备，再限制云算力与转运，随后模型 API 的地区支持、公司所有权、模型权重、危险能力访问和云托管都进入国家安全讨论。到 2026 年，“一个模型能不能用”已经至少有四个答案：芯片能不能买、API 能不能调、权重能不能拿、拿到后能不能在自己的硬件和云上跑。

---

## 一、为什么 AI 地缘政治从芯片开始

训练和运行前沿模型需要大量高带宽加速器、先进封装、HBM、网络互联和电力。模型参数可以通过网络复制，但训练它的物理基础设施不能瞬间复制。

因此，美国在 2022 年以后最先控制的是**先进计算能力的物理供应链**。

这与传统软件出口管制不同：软件复制成本接近零，而先进 GPU 需要晶圆、先进封装、HBM 和复杂供应链。

大模型时代第一次让“一个国家能买多少计算”直接影响其前沿模型能力。

---

## 二、2022：先进计算出口管制正式进入 AI 时代

**2022-10-07**，美国商务部工业与安全局（BIS）发布针对中国先进计算与半导体制造的出口管制规则。规则限制特定高性能计算芯片、先进半导体制造设备及相关技术向中国出口。[^1]

NVIDIA A100 / H100 等产品受到影响。

随后 NVIDIA 推出面向中国市场的 A800 / H800 等合规产品，通过降低部分互连等能力满足当时规则要求。

这里已经出现后来几年不断重复的模式：

> **监管规定一个能力边界，供应商围绕边界设计产品，监管再根据新的规避路径调整规则。**

因此芯片管制从来不是一条静止红线，而是监管与产品设计之间的动态追逐。

---

## 三、2023：A800 / H800 路径被进一步收紧

**2023-10-17**，BIS 更新先进计算与半导体制造出口规则，扩大受控先进计算芯片范围，并减少通过降规格型号绕过既有阈值的空间。[^2]

A800 / H800 等中国特供产品随后受到新规则约束。

这一轮变化的重要性在于：美国政策目标从“限制某几张卡”进一步转向**限制先进 AI 训练所需的有效计算能力**。

厂商之后继续推出 H20 等针对中国市场的产品，说明商业需求并没有消失，而是在监管边界内重新寻找可销售区间。

---

## 四、DeepSeek 让“受限硬件能做到什么”成为全球问题

DeepSeek-V3 技术报告披露其训练使用 H800，并报告 2.788M H800 GPU hours。[^3]

2025 年 1 月 R1 爆发后，全球市场把这一事实迅速政治化：如果一个中国团队可以在受限型号 GPU 上训练出具有强竞争力的模型，先进芯片管制是否还能有效维持能力差距？

这个问题不能用“管制失败”或“管制反而帮助中国”一句话回答。

至少有三种同时存在的效应：

1. **绝对资源约束仍然存在**：受限芯片、互连和供应量会增加训练与部署难度；
2. **效率创新的收益变大**：MLA、MoE、低精度训练、通信优化等在资源受限环境下更有价值；
3. **替代供应链的投资回报上升**：国产加速器、推理框架和模型适配得到更强政策与市场动力。

因此出口管制不仅减少可获得资源，也会改变研究机构**最值得优化什么**。

## 五、2025 年 AI Diffusion Rule：必须记录“提出，也必须记录被撤销”

旧稿把 **AI Diffusion Rule** 写成已经确立并持续实施的全球三级算力体系，这是错误的。

**2025-01-13/15**，拜登政府公布 **Framework for Artificial Intelligence Diffusion**。该规则拟对先进计算芯片和部分闭源 AI 模型权重的全球扩散建立新的分层管制框架。[^4]

它确实提出了一个历史上非常重要的政策方向：

> **模型权重本身可以像先进芯片一样成为出口管制对象。**

但这套规则并没有按原计划长期实施。

**2025-05-13**，特朗普政府商务部宣布撤销 Biden-era AI Diffusion Rule，并指示 BIS 执法人员不执行原本将在 5 月 15 日开始生效的相关要求；商务部同时表示将制定新的替代框架，并继续加强芯片相关出口控制。[^5]

因此正确的史实是：

**AI Diffusion Rule 提出了全球模型/算力分层治理方案，但在主要合规要求生效前即被新政府撤销。**

这件事非常值得记，因为它证明 AI 出口治理并不是一条只会越来越严的直线；它会随政府、外交与产业政策改变。

## 六、2025：服务地区和公司所有权也进入“出口边界”

芯片出口控制解决的是“谁能获得计算”，但闭源模型主要通过云 API 分发。

于是另一个问题出现：

> 如果一家受限制地区的公司不购买芯片，只在海外调用最强模型 API，限制还有效吗？

### 6.1 OpenAI：supported countries / territories

OpenAI 长期通过 supported countries and territories 列表定义 ChatGPT / API 的正式服务范围。官方帮助中心明确写明：在未支持地区访问或提供 API 访问可能导致账户暂停。[^6]

因此“模型服务的地理边界”本身就是一种控制层。

### 6.2 Anthropic：从所在地扩展到所有权

**2025-09-04**，Anthropic 更新 unsupported regions 销售限制，并明确表示来自受限制地区、包括中国的公司可能通过海外子公司继续访问 Claude；Anthropic 因此把限制扩展到受这些地区控制的实体。[^7]

这一步把规则从：

**“你的服务器在哪里？”**

推进到：

**“谁控制这家公司？”**

模型访问权因此开始类似金融制裁与出口管制中的 ultimate beneficial ownership 问题。

---

## 七、2026：蒸馏争议让“API 输出”成为战略资源

**2026-02**，Anthropic 公开指控 DeepSeek、Moonshot、MiniMax 等中国模型公司通过大量账号对 Claude 进行工业规模 distillation。[^8]

无论对具体训练来源的争议如何，这件事揭示一个结构性问题：

闭源模型即使不交出权重，**输出本身仍可能成为下一代模型的训练数据**。

于是 AI 能力扩散出现四层：

1. 芯片；
2. 模型权重；
3. API 使用权；
4. API 输出与蒸馏数据。

第四层比芯片更难管，因为模型输出本来就是服务的正常产物。

这也是为什么账号验证、rate limits、异常调用检测和模型 extraction 防护开始成为国家安全讨论的一部分。

---

## 八、2026 的 Fable / Mythos 事件：危险能力访问开始按模型等级管制

Anthropic 的 **Claude Fable 5 / Mythos 5** 提供了另一个非常重要的案例。

**2026-06-09**，Anthropic 发布 Fable 5 与 Mythos 5：二者基于同一底层前沿模型，但 Mythos 允许更广的高风险能力访问，采用更严格 trusted access；Fable 则部署额外 runtime safeguards。[^9]

**2026-06-12**，美国政府指令导致两款模型暂停访问；**6 月 30 日 / 7 月 1 日**限制解除后，Fable 恢复全球部署，Mythos 仍保持更严格的访问条件。[^10][^11]

这件事的意义远超 Anthropic 一家公司。

此前出口管制主要问：

- 哪个国家；
- 哪家公司；
- 哪块芯片；
- 哪份权重。

Fable / Mythos 开始问：

> **同一个模型里的哪一级危险能力，可以给哪一类经过验证的用户？**

这意味着未来 AI 管制的基本单位可能不再是完整模型，而是**capability tier + access policy**。

## 九、开放权重又把地缘政治推向相反方向

闭源服务可以按地区断开。

开放权重一旦公开，就很难撤回。

这使开放权重在地缘政治上拥有一种非常特殊的属性：**不可撤回性**。

### 9.1 R1 / Kimi K3 / Qwen3.8

DeepSeek-R1、Kimi K3、Qwen3.8 等模型表明，越来越强的中国模型可以通过公开权重全球分发。

到 2026 年，Kimi K3 为 2.8T 总参数、Qwen3.8 为 2.4T 级模型。它们即使开放权重，也远非普通个人可以轻松运行，因此又出现新的中间层：

- 权重公开；
- 但推理仍需要大型云 / 集群。

于是权重地缘自由与算力地缘集中可以同时发生。

### 9.2 美国国内的 open-weight 争论

**2026-07**，美国政策讨论中出现限制中国 open-weight models 的声音。Anthropic CEO Dario Amodei 随后公开表示，Anthropic **从未主张禁止 open-weight models**；他认为不具危险能力的开放权重模型可以是公共品，真正难题是达到高危险能力的权重一旦扩散后无法重新加装 safeguards。[^12]

这说明“美国闭源公司 vs 中国开源模型”也不能写成简单阵营对立。

真正争议是：

> **不可撤回的权重扩散应在哪一个能力阈值之后受到特殊治理？**

截至 2026 年，这个阈值没有全球共识。

## 十、中国应对：从“有没有 GPU”转向“整条栈能不能迁移”

中国 AI 自主化早期常被概括成“国产 GPU 替代 NVIDIA”。

到 2026 年，这个说法已经太窄。

真正需要迁移的是一整条栈：

- 加速器；
- 集群互联；
- 编译器和 kernel；
- 推理框架；
- 模型权重；
- API 协议；
- 企业 Agent runtime；
- 云托管。

DeepSeek、Qwen、GLM 等国产模型的价值之一，就是让“模型层”不再是迁移中的唯一外部依赖。

而 DeepSeek V4 等模型对多种国产硬件和推理平台的适配，则说明竞争逐渐从“训练出一个国产模型”进入**让整个运行栈真正可替换**。

因此“国产替代”最值得衡量的指标不是某个 benchmark，而是：

> **发生供应链或服务中断时，一个真实工作负载需要多久、需要改多少代码，才能迁移到另一套模型与硬件。**

这是一种 resilience 指标。

## 十一、云托管重新成为地缘中间层

开放权重模型并不意味着绕开美国云平台。

**2026-08-26**，Reuters 报道 Moonshot 正与 Microsoft、Amazon、Google 就 Kimi K3 云托管与收入分成进行早期谈判。[^13]

这形成一个非常有意思的结构：

- 中国公司训练并开放权重；
- 美国云公司可能负责全球企业分发；
- 权重开放降低模型供应商锁定；
- 但 2T / 3T 级推理又提高云基础设施依赖。

因此“模型国籍”与“模型实际在哪里运行”越来越可能分离。

AI 地缘政治不再只是美中各自建一套封闭系统，而会出现大量**跨国模型—云—芯片组合**。

---

## 十二、欧盟：另一条主权路线是法律而不是芯片

**2024-08-01**，EU AI Act 正式生效，并按阶段推进适用。[^14]

欧盟与美国的治理重点长期不同：

- 美国更强调先进计算、国家安全与出口；
- 欧盟更强调部署风险、透明度、责任和市场规则。

2026 年 Claude 文本 watermark 等产品更新，已经直接引用 EU AI Act 等透明度要求作为背景。

因此模型的全球部署必须同时面对三种不同边界：

1. **供应边界**：芯片与算力；
2. **访问边界**：API、权重与能力等级；
3. **合规边界**：模型在当地市场必须满足什么规则。

## 评曰

大模型地缘政治最初看起来像一场芯片战争。

现在回头看，芯片只是第一层。

当芯片被限制，企业寻找降规版 GPU；当降规版也被限制，研究者优化架构；当模型 API 受地区限制，开发者迁移到国产模型；当闭源 API 输出可能被蒸馏，供应商开始监控账号和调用模式；当危险能力继续上升，Anthropic 又把同一底层模型拆成 Fable / Mythos 两种访问制度；当中国开放权重模型越来越大，微软、亚马逊和 Google 又可能成为它们真正进入企业的托管渠道。

于是“封锁”与“开放”不是两支军队，而是一组不断互相绕行的技术和制度。

最重要的变化，是地缘政治已经从**硬件层**进入**运行时层**。

今天控制 AI 能力，不只可以控制 GPU，还可以控制：

- 账号；
- API；
- 模型权重；
- reasoning / capability tier；
- cloud deployment；
- safety classifier；
- ownership eligibility；
- regulatory compliance。

同样，一个国家或企业追求 AI 主权，也不能只囤 GPU。

真正的主权是：

> **在任何一个供应商、国家或技术层失效时，仍然能够迁移并继续运行关键工作负载。**

这比“有没有国产大模型”难得多，也比“有没有最强 GPU”更接近 2026 年 AI 基础设施的真实问题。
